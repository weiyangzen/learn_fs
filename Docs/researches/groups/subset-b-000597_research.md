# sources/distributed-fs/ceph-client/Documentation/devicetree/bindings/pci/brcm,iproc-pcie.yaml

**Purpose:** Defines the Devicetree YAML/JSON-schema contract for `Broadcom iProc PCIe controller with the platform bus interface`. **Dependencies:** Direct schema dependencies are `/schemas/interrupt-controller/msi-controller.yaml#`, `/schemas/pci/pci-host-bridge.yaml#`, `/schemas/types.yaml#/definitions/uint32`. **Purpose:** Defines the Devicetree YAML/JSON-schema contract for `Qualcomm PCIe Endpoint Controller`. It is a endpoint controller or endpoint-bus binding in the Qualcomm DesignWare-derived PCIe host/endpoint family; it constrains how DTS/DTB nodes identify the PCI hardware, describe register windows, interrupts, clocks, resets, PHYs, address translation, DMA/IOMMU reachability, and optional child/root-port layout for Linux PCI probing.

Its public ABI surface is `$id` `http://devicetree.org/schemas/pci/qcom,pcie-ep.yaml#`, `$schema` `http://devicetree.org/meta-schemas/core.yaml#`, the `properties` block, `required` list, schema-composition keywords, inline examples, and the compatible strings consumed by kernel OF match tables. Directly declared properties are `compatible`, `reg`, `reg-names`, `clocks`, `clock-names`, `qcom,perst-regs`, `interrupts`, `interrupt-names`, `iommus`, `reset-gpios`, `wake-gpios`, `interconnects`, `interconnect-names`, `dma-coherent`, `resets`, `reset-names`, `power-domains`, `phys`, `phy-names`, `num-lanes`.

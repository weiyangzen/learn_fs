# sources/distributed-fs/ceph-client/include/uapi/linux/cec.h

Purpose: defines the public HDMI Consumer Electronics Control ABI used by media CEC adapters and userspace tools. Important APIs and types include `struct cec_msg`, `struct cec_caps`, `struct cec_log_addrs`, connector/event structs, `CEC_ADAP_*`, `CEC_TRANSMIT`, `CEC_RECEIVE`, `CEC_DQEVENT`, mode/capability flags, helper predicates, and the large opcode/operand table consumed by CEC tooling. Control flow is ioctl-driven: userspace discovers adapter caps, sets physical and logical addresses when permitted, configures filehandle initiator/follower mode, transmits commands with optional reply matching, receives messages/events, and interprets tx/rx status bits. Test signals include CEC ioctl selftests, cec-compliance, transmit retry/status coverage, logical address fallback, monitor modes, hotplug connector updates, and parser regeneration.

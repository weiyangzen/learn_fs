## sources/distributed-fs/ceph-client/drivers/scsi/aic7xxx/aic7xxx_core.c

Purpose: implements the portable core of the Adaptec AIC7xxx SCSI host adapter driver. It owns controller initialization, sequencer firmware download and patching, SCB allocation and queueing, interrupt handling, SCSI message/negotiation state machines, error recovery, reset handling, residual calculation, diagnostics, and optional target-mode support. The OS-specific layer supplies platform allocation, DMA, locking, and CAM/Linux SCSI glue, while this file drives the hardware registers and sequencer-visible memory layout.

Important APIs/types/functions: lookup tables include `ahc_chip_names`, `ahc_hard_errors`, `ahc_phase_table`, and `ahc_syncrates`. Public/core entry points include `ahc_alloc()`, `ahc_softc_init()`, `ahc_init()`, `ahc_chip_init()`, `ahc_free()`, `ahc_reset()`, `ahc_suspend()`, `ahc_resume()`, `ahc_intr()`, `ahc_intr_enable()`, `ahc_pause_and_flushwork()`, `ahc_queue_scb()`, `ahc_get_scb()`, `ahc_free_scb()`, `ahc_lookup_scb()`, `ahc_find_syncrate()`, `ahc_find_period()`, `ahc_set_syncrate()`, `ahc_set_width()`, `ahc_update_neg_request()`, `ahc_reset_channel()`, `ahc_abort_scbs()`, `ahc_search_qinfifo()`, `ahc_search_disc_list()`, `ahc_search_untagged_queues()`, `ahc_print_register()`, and `ahc_dump_card_state()`. Optional target-mode APIs include `ahc_find_tmode_devs()`, `ahc_handle_en_lun()`, `ahc_send_lstate_events()`, and the target command FIFO handlers.

Control flow: attach starts with `ahc_alloc()` and `ahc_softc_init()`, then `ahc_init()` allocates shared DMA memory, SCB resources, target-state tables, reads BIOS/scratch settings, initializes transfer goals, and calls the bus-specific chip initializer. `ahc_chip_init()` programs SCSI IDs, bus control, command-complete FIFOs, sequencer shared-memory addresses, CDB size tables, target-mode queue offsets, hardware SCB free lists, and downloads the sequencer with `ahc_loadseq()`, then `ahc_restart()` clears message state and starts execution. Commands enter through `ahc_get_scb()`/OSM setup and `ahc_queue_scb()`, which swaps the SCB into the reserved next-HSCB slot, syncs DMA, records the tag in `qinfifo`, and updates either queue registers or scratch `KERNEL_QINPOS`.

Interrupt flow is split by interrupt type. `ahc_intr()` first uses in-memory completion queues to avoid register reads in the common case, clears command-complete interrupts and drains `qoutfifo` through `ahc_run_qoutfifo()`, optionally drains target incoming commands, and then handles hard sequencer breaks, sequencer interrupts, or SCSI bus interrupts. `ahc_handle_seqint()` processes sequencer status such as check condition/autosense setup, no-match reselection, protocol violation, message-loop handoff, parity recovery, data overrun, SCB mismatch, and out-of-range conditions. `ahc_handle_scsiint()` handles bus-level events such as transceiver state changes, external resets, parity errors, selection timeouts, and unexpected busfree, then delegates to reset, renegotiation, abort, or restart paths as needed.

Message and negotiation flow is host assisted when the sequencer raises `HOST_MSG_LOOP`. `ahc_setup_initiator_msgout()` builds identify/tag, abort, target reset, or transfer negotiation messages. `ahc_build_transfer_msg()` chooses PPR, SDTR, or WDTR based on current/goal settings, bus capabilities, role, and whether DT is possible. `ahc_handle_message_phase()` manually drives message-in/message-out bus bytes and calls `ahc_parse_msg()` for incoming messages. The parser accepts or rejects SDTR/WDTR/PPR, validates period/offset/width/options against adapter and user limits, updates current/goal transfer state, falls back from rejected PPR to WDTR/SDTR, disables unsupported tag forms on message reject, and queues responses by asserting ATN.

State and persistence: the durable device state is `struct ahc_softc`, including chip/features/bugs/flags, pause/unpause masks, sequencer critical-section metadata, target/initiator IDs, target negotiation tables in `enabled_targets`, pending SCBs, untagged queues, SCB data, shared DMA FIFOs, target-mode command storage, and message buffers. `struct scb_data` owns the kernel SCB array, hardware SCB DMA memory, sense buffers, S/G DMA pages, tag-to-SCB index, and free list. `struct ahc_tmode_tstate` and `struct ahc_initiator_tinfo` persist user/goal/current transfer settings; `auto_negotiate` tracks targets needing negotiation. Runtime queue state is mirrored between host memory (`qinfifo`, `qoutfifo`, pending lists, untagged queues) and sequencer registers/lists (`WAITING_SCBH`, `DISCONNECTED_SCBH`, `FREE_SCBH`, busy target table). Reset/device-reset paths intentionally revert current transfer state to async/narrow while preserving user/goal settings for later renegotiation.

Dependencies and integration: depends on `aic7xxx_osm.h` for OS abstraction, `aic7xxx_inline.h` for shared prototypes, generated `aic7xxx_seq.h` for sequencer firmware, `aicasm_insformat.h` for instruction patch/download formats, SCSI SPI message helpers, CAM/Linux SCSI status conventions, bus-DMA APIs, register access macros, and platform hooks such as `ahc_platform_alloc()`, `ahc_platform_free()`, `ahc_platform_scb_free()`, `ahc_platform_flushwork()`, `ahc_platform_abort_scbs()`, `ahc_platform_freeze_devq()`, `ahc_send_async()`, and `ahc_done()`. It integrates with PCI/EISA/VL bus attachment through `ahc->bus_chip_init` and `ahc->bus_intr`, and with optional target-mode CAM queues through `xpt_*` helpers.

Risks and invariants: this is high-risk hardware code with tight ordering requirements. Sequencer pause/unpause must respect critical sections or the host can inspect/update partial sequencer state. Posted register writes require flushes before queue scans and interrupt clear sequences. SCB tag/HSCB swapping must preserve `scbindex`, `NEXT_QUEUED_SCB`, qinfifo links, and DMA synchronization or completions can refer to the wrong command. Abort/reset searches must consistently cover qinfifo, waiting list, disconnected list, untagged queues, pending list, and platform-owned commands. Message negotiation has many fallback paths where current/goal/user settings, active hardware registers, and pending SCBs must remain consistent. Residual and ignore-wide-residue math depends on SG pointer conventions where the hardware residual pointer references the next SG entry. Target-mode paths risk resource starvation if accept-TIO or immediate-notify queues are empty. Several detected invariants still `panic()` for safety, so malformed hardware state can take down the host.

Test signals: build with and without `AHC_TARGET_MODE`, `AHC_DEBUG`, `AHC_DUMP_SEQ`, PCI and non-PCI configurations. Exercise attach/init/failure unwind, SCB allocation growth, command queueing/completion, qinfifo removal/requeue, untagged queue serialization, autosense, check-condition recovery, transfer negotiation including SDTR/WDTR/PPR acceptance and rejection, parity/data-overrun handling, selection timeout, unexpected busfree, bus reset, device reset, suspend/resume with pending work, removable-device hot eject status `0xff`, and sequencer load patching for feature combinations. For hardware or emulation testing, verify no leaked SCBs after resets, correct async/narrow fallback after reset, correct residuals for no-transfer/full/partial residual cases, correct DMA sync around shared FIFOs, and diagnostic dumps that show coherent queue state after error injection.

## sources/distributed-fs/ceph-client/drivers/scsi/aic7xxx/aic7xxx_inline.h

Purpose: declares the small shared inline/prototype interface for portable AIC7xxx core operations. Despite the name, the only inline body here is `ahc_name()`, while the remaining declarations expose sequencer control, DMA synchronization, register-width accessors, SCB allocation/queue helpers, sense-buffer lookup, transfer-info lookup, and interrupt dispatch to other driver compilation units.

Important APIs/types/functions: sequencer execution control is `ahc_is_paused()`, `ahc_pause()`, and `ahc_unpause()`. DMA helper exposure is `ahc_sync_sglist()`. Debug naming is `static inline ahc_name()`, returning `ahc->name`. Miscellaneous support includes `ahc_fetch_transinfo()`, `ahc_inw()/ahc_outw()`, `ahc_inl()/ahc_outl()`, `ahc_inq()/ahc_outq()`, `ahc_get_scb()`, `ahc_free_scb()`, `ahc_lookup_scb()`, `ahc_queue_scb()`, and `ahc_get_sense_buf()`. Interrupt entry is `ahc_intr()`.

Control flow: consumers include this header after `aic7xxx_osm.h` so `struct ahc_softc`, `struct scb`, `struct ahc_tmode_tstate`, `struct ahc_initiator_tinfo`, and SCSI sense types are visible. Callers pause the sequencer around sensitive register or SCB-memory operations, queue SCBs through the core, use register accessors for little-endian multi-byte port reads/writes assembled from byte accesses, and dispatch hardware interrupts through `ahc_intr()`.

State and persistence: the header owns no persistent state. Its exposed functions operate on state owned by `struct ahc_softc` and `struct scb`: names, pause masks, transfer tables, SCB free/index lists, shared DMA buffers, hardware SCB memory, and sense buffers. The inline `ahc_name()` assumes `ahc->name` remains valid for the controller lifetime and is frequently used in diagnostics.

Dependencies and integration: depends on the surrounding aic7xxx core/OSM type universe and is implemented primarily by `aic7xxx_core.c`. It is the narrow include surface for files that need core helpers without directly declaring them. The APIs integrate register access, bus-DMA sync, SCSI command block lifecycle, and interrupt handling across OS-specific and bus-specific driver code.

Risks and invariants: prototypes must stay synchronized with implementations or platform builds can fail in ways hidden by conditional compilation. `ahc_name()` is only safe after `ahc_alloc()` has initialized the name pointer and before `ahc_free()` releases it. Multi-byte register helpers imply byte-addressable register ordering and should not be used for registers with side effects on intermediate byte reads unless the core already does so intentionally. SCB helpers require caller-side locking/interrupt context discipline from the OSM.

Test signals: compile all aic7xxx variants that include this header, especially target-mode and non-target-mode builds. Test that interrupt dispatch, pause/unpause, SCB queue/free, register-width accessors, and sense-buffer access link correctly from OS-specific files. Static analysis should verify no stale declarations remain after core signature changes and no caller uses `ahc_name()` after free or before allocation completes.

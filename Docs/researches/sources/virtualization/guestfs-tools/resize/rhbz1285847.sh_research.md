# File Research: sources/virtualization/guestfs-tools/resize/rhbz1285847.sh

Regression test for Red Hat Bugzilla 1285847, covering `virt-resize` handling of logical partitions/volumes.

Key behavior:
- Sources shared test functions, enables `set -e` and `set -x`.
- Skips via standard skip predicate and unless `virt-resize --help` works.
- Creates a 4G raw disk with MBR layout: primary partition, extended partition, and logical partition.
- Formats `/dev/sda1` as ext4 and `/dev/sda5` as swap.
- Creates a 10G target and runs `virt-resize rhbz1285847.img rhbz1285847-2.img --expand /dev/sda2`.
- Verifies copied filesystems are exactly `/dev/sda1: ext4` and `/dev/sda5: swap`.
- Cleans generated images and output.

Research notes:
- The test expands the extended partition container while expecting the logical partition’s swap content to survive.

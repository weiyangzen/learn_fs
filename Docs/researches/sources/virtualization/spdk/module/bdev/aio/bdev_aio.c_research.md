# File Research: sources/virtualization/spdk/module/bdev/aio/bdev_aio.c

This file implements the SPDK `aio` bdev module, mapping a regular file or block device file descriptor into an SPDK block device using OS asynchronous IO. Linux uses libaio and an optimized userspace AIO ring read path; FreeBSD uses `aio_readv`/`aio_writev` with kqueue notifications.

The main disk object is `struct file_disk`, which embeds `spdk_bdev`, stores filename, fd, readonly/fallocate/nowait flags, block-size override state, reset retry state, and hot-remove state. Per-bdev IO context is `struct bdev_aio_task`, containing an OS AIO control block plus requested length and channel pointer. Each IO channel owns either a Linux `io_context_t` or FreeBSD kqueue fd and links into a group channel. The group channel owns an eventfd interrupt resource when interrupt mode is active and a poller that polls every channel in the group.

Creation validates and opens the backing file. `bdev_aio_open()` first tries `O_DIRECT`, falls back to non-direct open for non-disk files, and optionally enables `RWF_NOWAIT` only for block devices and only when compiled with support. `create_aio_bdev()` detects disk size and block length, validates block size is at least 512 and power-of-two, rejects disk sizes not divisible by block length, sets required alignment from detected or requested block size, registers an SPDK IO device, registers the bdev, and tracks it in `g_aio_disk_head`.

Read/write submission uses `spdk_bdev_io_get_buf()` to ensure aligned buffers, then prepares a platform AIO request. Linux uses `io_prep_preadv()`/`io_prep_pwritev()`, optional `io_set_eventfd()`, optional `RWF_NOWAIT`, and `io_submit()`. FreeBSD fills an `aiocb` with iov and kqueue notification settings and calls `aio_readv()` or `aio_writev()`. Submission errors map `-EAGAIN` to `SPDK_BDEV_IO_STATUS_NOMEM`; other errors complete with AIO status.

Completion polling differs by platform. Linux `bdev_user_io_getevents()` reads directly from the kernel AIO ring when the ring version is compatible, with memory barriers around ring head/tail access, otherwise falls back to `io_getevents()`. Completion code handles success by exact length match, maps `-EAGAIN` to NOMEM, detects device detachment by `spdk_fd_get_size(fd) == 0`, triggers hot-remove through the app thread, and completes with appropriate AIO status. FreeBSD polls kqueue events, uses `aio_return()` and `aio_error()`, and completes original SPDK IOs.

The module supports READ, WRITE, FLUSH, RESET, and on non-FreeBSD optional UNMAP and WRITE_ZEROES when `fallocate` was enabled. FLUSH calls `fsync()`. UNMAP uses `fallocate(FALLOC_FL_KEEP_SIZE | FALLOC_FL_PUNCH_HOLE)`. WRITE_ZEROES uses `fallocate(FALLOC_FL_ZERO_RANGE)`. RESET waits until all channel `io_inflight` counters are zero by repeatedly walking channels with a short poller.

Lifecycle and management include JSON config emission, info JSON with filename/block-size/readonly/fallocate/nowait fields, `bdev_aio_rescan()` for size changes and hot-remove detection, and `bdev_aio_delete()` using `spdk_bdev_unregister_by_name()`. Destruction unregisters the IO device, removes the disk from the global list, closes the fd, and frees strings/structs. Module initialization registers a shared group IO device for polling/interrupt management.

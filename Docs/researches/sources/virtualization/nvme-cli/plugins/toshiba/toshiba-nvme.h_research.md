# File Research: sources/virtualization/nvme-cli/plugins/toshiba/toshiba-nvme.h

Registers the `toshiba` plugin.

Commands:
- `vs-smart-add-log`: extended SMART/vendor log.
- `vs-internal-log`: internal log.
- `clear-pcie-correctable-errors`: clear PCIe correctable error count.

Uses `NVME_VERSION`.

# File Research: sources/os/plan9/9front/sys/src/9/ppc/m8260.h

MPC8260 register, parameter RAM, buffer descriptor, CPM, and helper definitions.

Key responsibilities:
- Defines buffer descriptors and generic receive/transmit `Ring` layout.
- Defines MCC, SCC, FCC, SMC, SPI, bank map, port, IDMA, UART SMC, SI, IMM, FCC extra, and internal memory map structures with hardware offsets.
- Defines CPM command-register bitfields, sub-block/page codes, command opcodes, and channel IDs for SCC/FCC/SMC/MCC/IDMA-style blocks.
- Defines clock-route constants and external `iomem` plus helper prototypes for BD allocation, CPM commands, I/O locking, and reboot.

Dependencies:
- Consumed by MPC8260 board code and FCC/MCC/IRQ drivers.

Notable behavior:
- The structure definitions encode hardware register layout directly with offset comments, so padding and field sizes are part of the interface.

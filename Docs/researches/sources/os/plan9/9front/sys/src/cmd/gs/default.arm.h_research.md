Ghostscript architecture constants for 32-bit ARM. It sets 4-byte pointer/long/int/float alignment, 8-byte double size, little-endian order, 1 MiB cache constants, IEEE floats, arithmetic right shift behavior, full-long shift support, and negative division truncation.

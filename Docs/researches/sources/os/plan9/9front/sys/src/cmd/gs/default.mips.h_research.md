# File Research: sources/os/plan9/9front/sys/src/cmd/gs/default.mips.h

Ghostscript architecture constants for MIPS. It defines 32-bit pointers, big-endian byte order, 4 KiB L1 and 512 KiB L2 cache constants, IEEE floats, arithmetic right shift behavior, no full-long shift support, and negative division truncation.

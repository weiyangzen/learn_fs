# File Research: sources/os/plan9/9front/sys/src/cmd/grap/misc.c

Miscellaneous state and helpers for `grap`: saved numeric input lists, current text justification/size modifiers, symbol table lookup/insertion, variables, point construction, attribute allocation/linking/freeing, string-list printing, justification string conversion, and limited `sprintf` support for string attributes.

It also updates coordinate ranges from plotted points and tick values, preserving explicit coordinate bounds.

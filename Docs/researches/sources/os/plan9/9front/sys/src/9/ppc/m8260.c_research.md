# File Research: sources/os/plan9/9front/sys/src/9/ppc/m8260.c

MPC8260/Blast board initialization, interrupt controller, timer, shared segments, CPM helpers, and descriptor-ring allocation.

Key responsibilities:
- Maps interrupt vector numbers to high/low interrupt-mask bits and provides vector enable/disable/acknowledge for the MPC8260 interrupt controller.
- Initializes machine state, clock frequencies, chip selects, FPGA bus width, caches, FP state, `plan9.ini` source/defaults, and active CPU state.
- Initializes hardware interrupts, FPGA reset pin, machine-check timeout behavior, and CPM interrupt masks.
- Implements `fastticks()`, `timerset()`, `timerinit()`, and the MPC8260 cascaded timer interrupt path.
- Adds configured `fpgaN` and `dspN` physical segments.
- Wraps CPM command register operations under a shared I/O lock.
- Provides SCC NMSI clock routing, shared I/O memory lock/unlock, dual-port RAM BD allocation, and cached descriptor-ring initialization.
- Installs trap vectors and simple reboot behavior.

Dependencies:
- Uses `m8260.h`/`blast.h` register definitions, PPC cache/special-register assembly helpers, generic timers, and Plan 9 physical-segment infrastructure.

Notable behavior:
- Ethernet FCCs are disabled during machine init to avoid stale boot-code DMA buffers.
- `ioringinit()` intentionally allocates FCC buffer descriptors in normal memory rather than dual-port RAM for cache/DMA reliability.

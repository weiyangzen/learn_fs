# File Research: sources/os/plan9/9front/sys/src/cmd/gs/lib/fixmswrd.pl

Perl filter that patches PostScript generated by old MS Word printer drivers so page independence works better in Ghostview.

Main behavior:
- Accepts `-v`, optional input file, and optional output file.
- Reads and preserves header comments, adding `%LOCALGhostviewPatched` before `%%EndComments` unless already present.
- If already patched, passes the remaining file through unchanged with an optional warning.
- Otherwise detects a procset/dictionary name from `%%BeginResource: procset ...` or `%%BeginProcSet: ...`.
- Removes the original global `<dict> begin` line and trailer `end`, inserts `<dict> begin` after every `%%Page:`, and inserts `end` after every `showpage`.

Implementation notes:
- Uses legacy `getopts.pl`.
- `read_comments` stores header lines and detects the marker.
- `put_comments` re-emits the headers and marker.
- Verbose mode warns when document structure is unrecognized by `%%EndProlog:`.

Filesystem relevance:
- Stream/text rewrite utility for PostScript files; no filesystem implementation content.

# File Research: sources/os/plan9/9front/sys/src/cmd/auth/x5092pub.c

Converts an X.509 certificate or certificate request into a Plan 9 RSA public key line.

Important behavior:
- Reads stdin or one file fully into a dynamically grown buffer.
- `-r` selects certificate request parsing via `X509reqtoRSApub`; default uses `X509toRSApub`.
- Captures subject into a 1024-byte buffer.
- Prints `key proto=rsa size=<bits> ek=<exponent> n=<modulus> subject=<quoted subject>`.

Interfaces/dependencies:
- Uses libsec X.509 and RSA helpers.
- Installs `%B` mpint and `%H` encode formats.

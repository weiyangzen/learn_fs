# File Research: sources/os/plan9/9front/sys/src/cmd/gs/default.power.h

Ghostscript architecture constants for 32-bit PowerPC. The file notes it was copied from the MIPS defaults and not tested. It sets 32-bit pointers, big-endian order, 4 KiB/512 KiB cache constants, IEEE floats, arithmetic right shift, no full-long shift support, and negative division truncation.

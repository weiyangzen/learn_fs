# File Research: sources/os/plan9/9front/sys/src/9/pc/ether82557.c

Intel 82557/82558/82559 Fast Ethernet driver for Plan 9's PC Ethernet layer, registered as `i82557`.

Primary role:
- Drives Intel EtherExpress PRO/100-class PCI NICs and related 82562/82801 integrated 10/100 variants.
- Uses I/O-port CSR access, chip command/RU/CU units, EEPROM reads, MII/PHY management, receive frame descriptors, and command blocks for transmit/configuration.

Key structures:
- `Rfd`: receive frame descriptor with embedded packet data buffer.
- `Cb`: command block for transmit, configuration, individual address setup, multicast setup, and NOP.
- `Ctlr`: per-controller state, including PCI device, EEPROM, MII lock, receive RFD ring, transmit command-block ring, configuration bytes, dump counters, and watchdog state.

Important behavior:
- `i82557pci()` scans Intel PCI vendor `0x8086`, filters supported device IDs, allocates I/O ports, and builds a controller list.
- `reset()` claims an inactive controller, enables PCI bus mastering, resets the chip, loads CU/RU bases, allocates rings, reads EEPROM, configures PHY/media, starts CU, loads station address, and wires generic `Ether` callbacks.
- `attach()` unmasks interrupts, starts the receive unit, and optionally launches `watchdog()` for the receiver lockup erratum.
- `txstart()` fills command blocks with queued packets or pending configuration/address/multicast actions, then resumes the command unit.
- `receive()` walks completed RFDs, copies small packets or swaps large RFD buffers, passes good packets to `etheriq()`, and maintains a sentinel RFD to avoid hardware prefetch races.
- `interrupt()` acknowledges chip status, handles receive, receiver-not-ready resume, transmit completions, underrun threshold tuning, and command queue refill.
- `ifstat()` dumps and resets hardware statistics through `DumpSC`, updates generic error counters, prints EEPROM and optional PHY registers.

Hardware and media details:
- EEPROM access is bit-banged through `hy93c46r()`, with dynamic EEPROM address-size discovery and checksum validation against `0xBABA`.
- MII access uses `miir()`/`miiw()` through the controller MDI register.
- Includes PHY-specific handling for DP83840[A] and Intel 82555, link-partner resolution, media override parsing, full-duplex configuration-byte updates, and a 10Mb half-duplex NOP workaround.

External dependencies:
- Plan 9 kernel Ethernet interfaces: `Ether`, `Block`, `etheriq`, `qget`, `qopen`, `intrenable`.
- PCI helpers: `pcimatch`, `pcienable`, `pcisetbme`.
- I/O helpers: `inb`, `ins`, `inl`, `outb`, `outs`, `outl`.

Research notes:
- The driver is self-contained and does not share code with the later Intel gigabit driver.
- Multicast is implemented by toggling configuration into multicast-all when multicast addresses exist, not by programming an exact multicast list.
- Shutdown performs a port reset and masks interrupts.

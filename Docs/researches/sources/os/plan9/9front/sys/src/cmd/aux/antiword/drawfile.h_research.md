# File Research: sources/os/plan9/9front/sys/src/cmd/aux/antiword/drawfile.h

Drawfile type and API header derived from RISC OS OSLib definitions.

Important contents:
- Defines conversion macros between Draw units and screen units.
- Defines SWI numbers for DrawFile render, bbox, and font declaration.
- Declares Drawfile scalar types, object type enum, path command enum, font/text/path/sprite/group/tagged/text-area/options/transform/JPEG structures, and top-level `drawfile_diagram`.
- Defines Drawfile error constants and flags for paths, text, rendering, font declaration, paper options, and entry modes.
- Declares Drawfile SWI wrappers plus Antiword helpers: create, append, render, verify, and query bounding box.

Role:
- Provides the binary layout contract for RISC OS Drawfile objects generated by Antiword.

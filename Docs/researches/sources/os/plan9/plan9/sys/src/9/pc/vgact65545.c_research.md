# File Research: sources/os/plan9/plan9/sys/src/9/pc/vgact65545.c

Chips & Technologies 65545 hardware cursor and page hook. The `VGAdev` is named `"ct65540"` with a comment noting it is really 65545. `ct65545page()` writes index/data ports `0x3D6/0x3D7`.

Cursor behavior:
- `ct65545enable()` chooses cursor storage after the visible framebuffer rounded to 1024 bytes, writes storage to port `0xB3D0`, sets colors through `0xA7D0`, and enables through `0xA3D0`.
- `ct65545disable()` clears `0xA3D0`.
- `ct65545initcursor()` builds AND/XOR cursor planes in framebuffer storage, with shifted alternate image support for negative coordinates.
- `ct65545move()` selects image 0 or 1 and writes position through `0xAFD0`.

Exports `VGAdev vgact65545dev` and `VGAcur vgact65545cur`.

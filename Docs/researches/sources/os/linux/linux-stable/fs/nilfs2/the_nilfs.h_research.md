# File Research: sources/os/linux/linux-stable/fs/nilfs2/the_nilfs.h

## Purpose
Defines `struct the_nilfs`, `struct nilfs_root`, state flags, inline helpers, and function prototypes for NILFS2 shared filesystem/device state.

## Main Types
`struct the_nilfs` supervises a NILFS block device and multiple mount/checkpoint roots. It contains:
- State flags and flushed-device flag.
- Superblock/device back-pointers.
- Locks and semaphores: `ns_sem`, `ns_snapshot_mount_mutex`, `ns_last_segment_lock`, `ns_segctor_sem`, `ns_cptree_lock`, `ns_inode_lock`.
- Primary/secondary superblock buffers and raw pointers.
- Superblock write time/count/size/mount state/update frequency.
- Live segment constructor cursor fields: `ns_seg_seq`, `ns_segnum`, `ns_nextnum`, `ns_pseg_offset`, `ns_cno`, `ns_ctime`, `ns_nongc_ctime`.
- Last stable segment fields protected by `ns_last_segment_lock`.
- Metadata file inodes: DAT, checkpoint file, segment usage file.
- Checkpoint rb-tree, dirty file list, GC inode list.
- Mount options, reserved IDs, checkpoint interval, dirty-buffer watermark.
- Static disk layout fields.
- Sysfs device kobject, completion, and subgroup pointer.

`struct nilfs_root` represents a checkpoint root:
- Checkpoint number `cno`.
- rb-tree node and refcount.
- Back-pointer to `the_nilfs`.
- `ifile` inode.
- Atomic inode/block counters.
- Snapshot sysfs kobject and unregister completion.

## Flags and Constants
- `THE_NILFS_INIT`
- `THE_NILFS_DISCONTINUED`
- `THE_NILFS_GC_RUNNING`
- `THE_NILFS_SB_DIRTY`
- `THE_NILFS_PURGING`
- `NILFS_CPTREE_CURRENT_CNO` is `0`.
- `NILFS_SB_FREQ` is `10` seconds.

## Inline Helpers
- Flag accessors are generated by `THE_NILFS_FNS`.
- Mount option helpers set, clear, and test `NILFS_MOUNT_*` bits.
- `nilfs_sb_need_update()` checks whether periodic superblock update is due.
- `nilfs_sb_will_flip()` predicts superblock alternation from write count low bits.
- `nilfs_valid_fs()` reads clean-state under `ns_sem`.
- Segment geometry helpers map segment numbers and blocks:
  - `nilfs_get_segment_range()`
  - `nilfs_get_segment_start_blocknr()`
  - `nilfs_get_segnum_of_block()`
- Segment cursor helpers:
  - `nilfs_terminate_segment()`
  - `nilfs_shift_to_next_segment()`
  - `nilfs_last_cno()`
  - `nilfs_segment_is_active()`
- `nilfs_flush_device()` conditionally issues `blkdev_issue_flush()` for barrier-enabled mounts and uses `smp_wmb()` after setting `ns_flushed_device`.

## Exported Prototypes
Declares allocation/destruction, initialization/loading, segment discard/free-space operations, checkpoint root lookup/lifetime, disk-full checks, and superblock fallback/swap helpers.

## Research Notes
This header is the shared contract for NILFS2 state ownership and synchronization. The comments explicitly identify which fields are lock-protected, which are static after initialization, and which sysfs objects are embedded in the shared state.

# File Research: sources/os/linux/linux-stable/fs/smb/client/gen_smb1_mapping

## Summary
Perl generator for SMB1 error mapping C tables. It reads annotated definitions from `nterr.h` or `smberr.h`, validates mapping comments, sorts entries numerically, merges synonyms with identical numeric values, and writes one of the supported generated C table fragments.

## Main Responsibilities
- Validate command-line usage as `<in-file> <out-file>`.
- Detect input and output basenames for mode selection and generated-file comments.
- Parse NT status definitions from `nterr.h` with class/code annotations.
- Parse SMB1 DOS/server error definitions from `smberr.h` with POSIX error annotations.
- Reject annotated macros whose comments do not match the expected mapping format.
- Reject input files that yield no mapping entries.
- Sort entries by numeric code before output.
- Generate NT-status-to-DOS mapping rows for `smb1_mapping_table.c`.
- Generate SMB1 error-to-POSIX rows for `smb1_err_dos_map.c` or `smb1_err_srv_map.c`.
- Reject unsupported output filenames.

## Input Parsing
For `nterr.h`, the script matches `#define NT_STATUS_* <value> // CLASS, CODE` or equivalent block-comment annotations. It handles backslash continuations, skips duplicate macro names, strips whitespace and parentheses from value expressions, ORs pipe-separated hex pieces into a single numeric value, and stores the status name, value, class, and code.

For `smberr.h`, the script watches comments that identify the current error class, such as `ERRDOS` or `ERRSRV`, then matches `#define ERR*` or `#define Err*` entries followed by a `-POSIX_ERR` style annotation. It stores the numeric value, macro name, POSIX error, and current SMB1 error class.

## Output Behavior
All entries are sorted by numeric value. For NT status mappings, adjacent entries with the same value are emitted as one row with names joined by ` or `, preserving a readable synonym list. For SMB1 error maps, the output filename selects either `ERRDOS` or `ERRSRV` entries and emits `{name, error}` pairs.

The generated output starts with an autogenerated comment naming the input file and generator script, then table rows intended to be included or compiled by surrounding CIFS SMB1 mapping code.

## Dependencies And Invariants
The script depends on strict annotation formats in `nterr.h` and `smberr.h`. Its output mode is selected by exact output basename, not by an explicit option. The `smberr.h` path depends on class marker comments appearing before the associated error definitions.

## Risks
Build correctness depends on comments being machine-readable. A harmless-looking comment edit can break generation or stop a mapping from being emitted. The script opens the output directly rather than writing atomically, so interruption during generation could leave a partial generated file. NT value parsing is limited to hex pieces joined by `|` after removing whitespace and parentheses.

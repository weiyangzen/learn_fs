# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/1394/ieee1212.h

This small public header defines IEEE 1212 configuration ROM entry constants and parsing helpers.

Key definitions:
- Fixed quadlet offsets for node capabilities and root directory.
- Directory length and CRC extraction macros.
- `CONFIG_ROM_GEN`, `CFGROM_ROOT_DIR`, and `CFGROM_DIR_LEN` helpers.
- `CFGROM_TYPE_KEY_VALUE` extracts key type, key value, and entry value from a config ROM quadlet.
- Key types: immediate, CSR offset, leaf, and directory.
- Key values for textual descriptors, vendor/spec/software IDs, node/unit descriptors, capabilities, unique ID, extents, unit directories, and poll masks.
- Bit masks/shifts for key type/value and 24-bit entry value.
- Node capabilities mask.

This header has no functions or structures; it is a shared constants/macro layer for config ROM scanning and construction.

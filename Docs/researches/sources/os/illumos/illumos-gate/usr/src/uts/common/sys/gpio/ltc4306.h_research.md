# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/gpio/ltc4306.h

## Role

`ltc4306.h` defines KGPIO attributes for the LTC4306 GPIO-capable I2C multiplexer/switch driver.

## Key Interfaces and Data

- `LTC4306_GPIO_ATTR_INPUT` is read-only and uses `ltc4306_gpio_input_t`: low or high.
- `LTC4306_GPIO_ATTR_OUTPUT` is read/write and uses `ltc4306_gpio_output_t`: disabled, low, or high. Disabled places the pin in input-only mode.
- `LTC4306_GPIO_ATTR_OUTPUT_MODE` is read/write and uses `ltc4306_gpio_output_mode_t`: push-pull or open-drain.
- The standard `KGPIO_ATTR_NAME` is referenced as an additional supported attribute.

## Dependencies and Use

This is a provider-specific attribute vocabulary consumed through the generic KGPIO nvlist interface.

## Research Notes

The file is intentionally small and declarative, matching the LTC4306 hardware's limited GPIO controls.

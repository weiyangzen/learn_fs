# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/1394/ixl1394.h

This public header defines the Isochronous Transfer Language (IXL) used by target drivers to describe isochronous transmit/receive DMA programs.

Main content:
- Compilation/update error codes from `IXL1394_EMEM_ALLOC_FAIL` through `IXL1394_ERISK_PROHIBITS_UPD`, bounded by `IXL1394_COMP_ERR_FIRST/LAST`.
- `IXL1394_ENO_DMA_RESRCS` for DMA resource exhaustion.
- Opcode flag bits for updateable commands, receive/transmit validity, transfer-ending, and transfer commands.
- IXL command opcodes for label, jump, callback, receive packet/buffer, send packet/buffer, header-only, no-packet skip, store timestamp, set tag/sync, set skip mode, and set sync-wait.
- Updateable opcode variants with `IXL1394_OPF_UPDATE`.

Main types:
- `ixl1394_priv_t`: compiler-private opaque handle stored in commands.
- `ixl1394_skip_t`: skip to self, next, stop, or label.
- `ixl1394_command_t`: generic command header with next pointer, compiler-private fields, opcode, and operands.
- `ixl1394_buf_t`: DMA-bound buffer address union with endian-aware 32-bit address access aliases.
- Command-specific structs for packet transfer, buffer transfer, transmit special command, callback, label, jump, set tag/sync, set skipmode, set syncwait, and store timestamp.

Macros:
- `IXL1394_GET_IR_TIMESTAMP`, `GET_IR_DATALEN`, `GET_IR_TAG`, `GET_IR_CHAN`, and `GET_IR_SYNC` extract received isochronous header fields from DMA memory quadlets.

Research notes:
- Public commands embed private compiler fields, allowing the HAL compiler to avoid side allocations for common state.
- Updateable commands permit live DMA program modifications, but the private compiler/update layer enforces opcode and risk constraints.

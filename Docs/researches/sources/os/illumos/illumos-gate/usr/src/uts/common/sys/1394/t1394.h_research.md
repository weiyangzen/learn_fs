# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/1394/t1394.h

This public target-driver API header defines the Solaris 1394 framework interface used by 1394 target drivers.

Foundational definitions:
- `T1394_DATA32` and `T1394_DATA64` convert bus byte streams to/from big-endian values on little-endian systems.
- Opaque handles for target, address allocation, isoch single, isoch CEC, and config ROM entries.
- `t1394_localinfo_t` and `t1394_attachinfo_t` provide bus generation, local node ID, interrupt cookie, access attributes, and DMA attributes at attach time.

Address/FCP/CMP structures:
- Address enable/type enums and `t1394_addr_evts_t` callbacks for incoming read/write/lock requests.
- `t1394_alloc_addr_t` describes address-space allocation, backing store, fixed address, callbacks, and returned handle.
- FCP callbacks for controller/target sharing of IEC 61883 FCP address space.
- CMP register enum and callbacks, plus read/CAS routines for shared iMPR/oMPR registers.

Isochronous resource structures:
- Single-channel allocation info/output with resource-failure callback.
- CEC properties, callbacks, join options, join info, and setup callback args.
- Target info and config ROM entry descriptors.

Public APIs:
- Attach/detach.
- Allocate/free async commands and submit read/write/lock.
- Allocate/free address ranges and complete incoming requests.
- FCP controller/target register/unregister.
- CMP register/unregister/read/CAS.
- Allocate/free/setup/start/stop/teardown isoch single and CEC resources.
- Allocate/free/start/stop/update local isoch DMA.
- Get target info, initiate bus reset, get topology map, compute CRC16, add/remove config ROM entries, and translate error codes.

Error/result bounds:
- Address allocation errors around `-400`.
- CEC setup errors around `-500`.
- Isoch DMA allocation errors around `-600`.
- Config ROM errors around `-700`.

Research notes:
- `T1394_NOERROR` is defined as `-703`, inside the config-ROM error range, which is counterintuitive and should be interpreted through existing framework conventions.
- Bus resets are exposed but documented as expensive and disruptive.

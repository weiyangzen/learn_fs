# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/i8042.h

## Role

`i8042.h` defines virtual register numbers and locking semantics for child drivers communicating with the i8042 keyboard/mouse controller driver.

## Key Interfaces and Data

- Interrupt-driven virtual registers:
  - `I8042_INT_INPUT_AVAIL`
  - `I8042_INT_INPUT_DATA`
  - `I8042_INT_OUTPUT_DATA`
- Polled-mode virtual registers for kmdb or unavailable system services:
  - `I8042_POLL_INPUT_AVAIL`
  - `I8042_POLL_INPUT_DATA`
  - `I8042_POLL_OUTPUT_DATA`
- `I8042_LOCK` and `I8042_UNLOCK` allow child drivers to hold exclusive access across multi-byte command transactions such as keyboard enable or mouse reset.
- `I8042_SOFTINT_PRI` defines soft interrupt priority 4.

## Dependencies and Use

The header is a compact child-driver contract. It does not include implementation state.

## Research Notes

The lock/unlock virtual registers are essential because i8042 command sequences are not always single-byte atomic operations.

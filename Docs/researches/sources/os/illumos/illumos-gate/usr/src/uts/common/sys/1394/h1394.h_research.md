# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/1394/h1394.h

This public/internal HAL-facing header defines the interface between a 1394 HAL driver and the Solaris 1394 services layer.

Main types:
- Cleanup levels `H1394_CLEANUP_LEVEL0..7`.
- `h1394_phy_t`: 1394-1995 vs 1394A PHY.
- `h1394_error_t`: HAL error categories reported to services.
- `h1394_posted_wr_err_t`: posted write error address/source container.
- `h1394_node_pwr_flags_t`: node power-state transition flags.
- `h1394_addr_type_t` and `h1394_addr_map_t`: HAL address-space map descriptors.
- `h1394_mblk_t` and `h1394_cmd_priv_t`: HAL-private command metadata, including speed, timestamps, generation, mblk state, and HAL overhead pointer.
- `h1394_evts_t`: the HAL callback vector used by services to drive PHY packets, async read/write/lock request/response, isoch DMA, config ROM update, bus resets, CSR operations, physical request filters, and node power changes.
- `h1394_halinfo_t`: attach-time HAL descriptor with private pointer, dip, event vector, interrupt cookie, access/DMA attributes, PHY type, overhead, bus capabilities, GUID, node capabilities, generation rollover, address maps, and reserved maps.

Services-layer entry points:
- HAL module init/fini and attach/detach.
- Command completion, bus reset, self-ID, incoming request delivery, command allocation/free, ioctl, PHY packet, and error notification.

Research notes:
- `HAL_CALL(hal)` accesses `hal->halinfo.hal_events`.
- HAL event version is `H1394_EVTS_V1`.
- Command statuses passed back to services encode ACK/event/response outcomes.

# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/1394/adapters/hci1394_q.h

This private header abstracts async OpenHCI descriptor/data queue handling for asynchronous transmit and receive paths.

Main types:
- `hci1394_q_mode_t`: queue mode, `HCI1394_ARQ` or `HCI1394_ATQ`.
- `hci1394_q_start_t` and `hci1394_q_wake_t`: DMA engine callbacks used when descriptors are first queued or appended.
- `hci1394_q_info_t`: queue sizes, mode, callbacks, and callback arg passed to init.
- `hci1394_q_cmd_t`: per-AT-command tracking, with public command arg/generation/timestamp/status and private descriptor/data buffer cleanup pointers plus a timed-list node.
- `hci1394_q_bufptr_t`: circular segmented DMA buffer pointer state, including top/bottom/current/free addresses, current cookie boundaries, offsets, cookie indices, and reservation size.
- `hci1394_q_buf_t`: descriptor or data buffer, its backup pointers, DMA cookies, buffer handle, and buffer info.
- `hci1394_q_t`: queue object, queued AT list, driver/OHCI handles, previous descriptor pointer, block count, AR head/space tracking, DMA-running state, descriptor/data buffers, queue info, and mutex.

Key APIs:
- Lifecycle/control: `hci1394_q_init`, `fini`, `resume`, `stop`.
- AT submit paths for header-only, contiguous data, or mblk data; completion retrieval through `hci1394_q_at_next`.
- AR receive path helpers for next packet, freeing consumed space, reading 32-bit values, copying bytes, and copying to mblk.

Research notes:
- AT command completion order is assumed to match submission order; the queued list head identifies the completed command.
- AR processing relies on hardware residual count updates after whole packets, avoiding partial-packet processing.

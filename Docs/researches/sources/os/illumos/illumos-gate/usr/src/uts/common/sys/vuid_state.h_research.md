# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/vuid_state.h

`vuid_state.h` declares the client-facing interface for the virtual user input device state package. The package tracks the state of events generated by one or more physical devices that produce `Firm_event` input events, with the conceptual VUID event namespace described by `vuid_event.h`.

The public state handle is intentionally opaque: `Vuid_state` is a `caddr_t`, with `VUID_STATE_NULL` as the null sentinel. The API consists of `vuid_set_value()` to update state from a `Firm_event`, `vuid_get_value()` to query a value by VUID event ID, `vuid_destroy_state()` to free a state object, and `vuid_copy_state()` to duplicate state. Comments on mutating/copying/destruction functions warn callers not to invoke them in critical sections or at interrupt level, implying allocation or blocking behavior in the implementation.

This header is the stable consumer contract, while `vuid_store.h` defines the private storage structures used behind the opaque handle.

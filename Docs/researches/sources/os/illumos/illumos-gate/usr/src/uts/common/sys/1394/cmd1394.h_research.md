# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/1394/cmd1394.h

This public 1394 framework header defines asynchronous command types, command payloads, options, and result codes used by `t1394_read`, `t1394_write`, and `t1394_lock`.

Main enums:
- `cmd1394_cmd_type_t`: async read/write quadlet/block and 32/64-bit lock commands.
- `cmd1394_flags_t`: bus-reset cancellation, address/max-payload/speed override, address-increment disable, and blocking behavior.
- `cmd1394_lock_type_t`: IEEE lock operations plus software-local extended bit/arithmetic operations.

Payload structures:
- `cmd1394_quadlet_t`: single quadlet.
- `cmd1394_block_t`: mblk data block, length, transferred byte count, max payload.
- `cmd1394_lock32_t` and `cmd1394_lock64_t`: old/data/arg values, retry count, and lock type.
- `cmd1394_cmd_t`: common command with version, volatile result, options, type, completion callback, callback arg, 1394 address, speed, generation, node ID, broadcast flag, and union payload.

Error model:
- Immediate failures are negative codes from `-10` through `-20`.
- Completion results include success `0` and negative device/bus/timeout/resource errors from `-30` through `-37`.
- `CMD1394_ERR_FIRST/LAST` bound the error table used by `t1394_errmsg.c`.

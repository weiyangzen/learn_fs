# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/1394/id1394.h

This public header defines local isochronous DMA allocation/control structures for target drivers.

Main types:
- `t1394_isoch_dma_handle_t`: opaque local isoch DMA handle returned by the framework.
- `id1394_isoch_dma_options_t`: transmit (`ID1394_TALK`), receive packet mode, receive buffer mode, and receive-headers flag.
- `id1394_isoch_dma_stopped_t`: callback reason, `ID1394_DONE` or `ID1394_FAIL`.
- `id1394_isoch_dmainfo_t`: allocation request containing first IXL command, channel, default tag/sync, transmit speed, global callback arg, default transmit skip behavior/label, options, stopped callback, and callback arg.
- `id1394_isoch_dma_ctrlinfo_t`: start-cycle control.
- `id1394_isoch_dma_updateinfo_t`: dynamic update request with temporary IXL command, original IXL command, and command count.

Constants:
- `ID1394_START_ON_CYCLE` asks the framework to start DMA at a specified bus cycle.

Dependencies:
- Includes `ixl1394.h`, because all DMA programs are described with IXL commands.

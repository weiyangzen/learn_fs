# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/1394/s1394.h

This large private header defines the internal Solaris 1394 services-layer state, topology/config-ROM machinery, target/HAL records, address-space allocator, fixed-address support, isochronous CEC state, command private storage, and internal function prototypes.

Core constants and states:
- Self-ID buffer size, max allocated commands, lock retry limit, invalid node/speed markers, node online/offline states, bus-reset failure threshold, topology/gap-count constants, config ROM update delay, Sun OUI, config ROM read retry/delay, command transaction types, isoch resource retry counts, red-black tree colors/sides, and isoch bandwidth conversion factors.
- `s1394_hal_state_t`: HAL init/reset/normal/DREQ/shutdown.
- `s1394_isoch_cec_type_t` and `s1394_isoch_cec_state_t`: single/peer-to-peer CEC and legal state transitions.
- `s1394_status_t`: internal async/config/topology status flags.
- `s1394_free_cfgrom_t`: config ROM free policy.

Major structures:
- `s1394_node_t`: topology node, self-ID packet, port links, old/current node links, target list, config ROM buffer/state, bus enumeration flags, directory stack, read progress, and retry counters.
- `s1394_target_t`: target driver registration on a node/HAL, payload limits, allocated command count, physical AR enable count, target state, and fixed-address data.
- `s1394_hal_t`: central per-HAL services state covering target list, HAL info, bus reset thread, kstats, CSR bits, bus manager state, local config ROM, cycle-master timer, address-space free/used structures, async outstanding/pending queues, self-ID buffers, topology trees, speed map, traversal scratch structures, isoch CEC list, kmem cache, NDI events, CPR info, FCP/CMP fixed-address state.
- `s1394_addr_space_blk_t`: red-black tree/free-list node describing allocated 1394 address ranges, permissions, type, callbacks, backing store, and callback arg.
- `s1394_config_rom_t`: local config ROM entry allocation record.
- `s1394_kstat_t`: service-layer statistics for AR/AT requests, failures, allocations, bus reset, self-ID, pending queue, and GUID.
- `s1394_isoch_cec_t` and `s1394_isoch_cec_member_t`: isochronous channel event coordinator state and member callbacks/properties.
- `s1394_cmd_priv_t`: private storage appended after `cmd1394_cmd_t`, with queue links, transfer type, target/HAL pointers, lock retry state, blocking synchronization, in-use flags, fixed-address extension, and HAL command-private data.
- `s1394_state_t`: global HAL list root; `s1394_statep` is externally declared.

Important macros:
- Node/config-ROM state setters/getters.
- Fixed-address FCP/CMP address constants and initial CMP register values.
- `S1394_GET_CMD_PRIV` computes the private command trailer following a public command allocation.
- `S1394_IS_CMD_FCP` detects FCP fixed-address commands.

Function prototype groups:
- Address-space allocation/free/search and address classification.
- Async command allocation/free/setup/transfer/completion/response/pending queue.
- Bus reset, self-ID parsing, topology tree build/match/optimization, speed map, IRM, and physical AR setup.
- CSR/config-ROM setup, update, parsing, validation, and tree locking.
- Hotplug/devinfo processing and target-node list management.
- Fixed-address, FCP, and CMP support.
- Isochronous resource allocation/free/reallocation and CEC member/list management.
- Cleanup, HAL shutdown/reset, bus-reset thread control, blocking commands, error checks, CRC, ioctl, power management, kstats, node info printing, dip/target lookup, timer destruction.

Research notes:
- This header is the private integration point between the public `t1394` API, HAL `h1394` API, and driver-internal services implementation.
- There is a likely macro typo in `CFGROM_BLK_READ_OK(n)`: the conditional expression uses `!= 0 : B_TRUE : B_FALSE` rather than the expected `!= 0 ? B_TRUE : B_FALSE`.
- `SET_NODE_IDENTIFIED` macros reference `S1394_NODE_IDENTIFIED`, but this constant is not defined in the read file; call sites or other headers should be checked.

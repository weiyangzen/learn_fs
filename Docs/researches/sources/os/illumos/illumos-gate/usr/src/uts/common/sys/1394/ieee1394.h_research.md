# File Research: sources/os/illumos/illumos-gate/usr/src/uts/common/sys/1394/ieee1394.h

This public header defines core IEEE 1394 constants, address masks, transaction codes, self-ID parsing, PHY config fields, CSR addresses, speeds, and map metadata.

Major definitions:
- Node and bus limits: 64 node IDs, broadcast node 63, 16 ports per node, local bus `0x3FF`.
- Address extraction macros for node ID, bus ID, PHY ID, and offset.
- Data sizes for quadlet and octlet.
- Transaction codes for write/read/lock/isochronous/cycle/PHY packets.
- Response codes for complete, conflict, data, type, and address errors.
- Self-ID packet validation and field extraction macros for PHY ID, link-on, gap count, speed, delay, contender, power, port state, initiated reset, more packets, and packet number.
- PHY configuration masks/shifts for T/R bits, gap count, and root holdoff.
- CSR and serial bus CSR address constants, config ROM address/size, topology and speed map addresses.
- Bus speeds S100 through S3200.
- Bandwidth bounds and map/config-ROM CRC/length fields.
- CSR state bits and bus-info-block masks.
- Bus manager timeout constants.

Research notes:
- `IEEE1394_SELFID_ISVALID` compares data and inverse quadlets using bitwise complement semantics; call sites should be checked for expected truth value.
- These constants underpin both the services layer (`s1394.h`) and HAL descriptor/OHCI code.

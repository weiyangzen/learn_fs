# File Research: sources/os/bsd/freebsd-src/sbin/dhclient/dhclient-script

## Purpose
Shell-side network configuration backend for `dhclient`. It receives environment variables from the C client and mutates interface addresses, routes, hostname, aliases, ARP cache, and resolver configuration for DHCP state transitions.

## Main Elements
- Helper commands: `ARP`, `HOSTNAME`, and `IFCONFIG` command paths.
- `check_hostname()`: updates system hostname when unset or matching the previous DHCP hostname.
- Address helpers: `delete_old_address()`, `add_new_address()`, `delete_old_alias()`, `add_new_alias()`.
- Route helpers:
  - `fill_classless_routes()` decodes RFC 3442 classless-route octet lists into route/router pairs.
  - `delete_old_routes()` removes classless, default, or static routes and flushes ARP entries.
  - `add_new_routes()` prefers classless routes over router/static-routes per RFC 3442.
- Resolver helper: `add_new_resolv_conf()` writes `/var/run/resolv.conf.$interface`, optionally updates `/etc/resolv.conf`, or uses `resolvconf`.
- Hook support: sources `/etc/dhclient-enter-hooks` and `/etc/dhclient-exit-hooks`.
- State dispatcher handles `MEDIUM`, `PREINIT`, `ARPCHECK`, `ARPSEND`, `BOUND`, `RENEW`, `REBIND`, `REBOOT`, `EXPIRE`, `FAIL`, and `TIMEOUT`.

## Dependencies And Integration
Executed by the privileged dhclient child through `execve`. It depends on environment variables such as `reason`, `interface`, `new_ip_address`, `old_ip_address`, `new_routers`, `new_domain_name_servers`, `new_classless_routes`, and alias variables generated by `dhclient.c`.

## Risk Notes
Most commands are built from DHCP-provided environment values. The C side validates and escapes options before exporting, but route and resolver correctness still depends on that sanitization. Resolver handling intentionally preserves symlink targets by writing through `/etc/resolv.conf`.

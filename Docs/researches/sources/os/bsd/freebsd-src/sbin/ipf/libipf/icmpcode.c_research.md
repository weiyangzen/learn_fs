# File Research: sources/os/bsd/freebsd-src/sbin/ipf/libipf/icmpcode.c

This file defines the legacy `icmpcodes` string table for IPv4 ICMP unreachable/code names up to `MAX_ICMPCODE`.

Entries include network/host/protocol/port unreachable, need fragmentation, source fail, unknown/prohibited/TOS/preference variants, and a terminating `NULL`.

# File Research: sources/os/bsd/openbsd-src/sbin/route/Makefile

This Makefile builds the OpenBSD `route` utility.

Key settings:
- `PROG=route`
- `SRCS=route.c show.c`
- `MAN=route.8`
- Adds `-Wall -DBFD` to `CFLAGS`.
- Declares `route.o tags: keywords.h`.

Behavior and integration:
- `keywords.h` is generated by `keywords.sh`, but the generated header is kept in-tree for special distribution builds.
- Links through the standard `<bsd.prog.mk>` program build rules.

Risk notes:
- Keyword additions require rerunning `keywords.sh` and committing the regenerated `keywords.h` copy.

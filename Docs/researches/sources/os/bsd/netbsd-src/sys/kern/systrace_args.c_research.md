Generated NetBSD DTrace syscall-provider support code. The file is explicitly marked "DO NOT EDIT" and is generated by `makesyscalls.sh`; `sys/kern/syscalls.conf` names this generated output as `systrace_args.c`, and the kernel Makefile regenerates it from the syscall source alongside `init_sysent.c`, `syscalls.c`, `syscall.h`, and `syscallargs.h`.

Core functions:
- `systrace_args(register_t sysnum, const void *params, uintptr_t *uarg, size_t *n_args)` converts a syscall number and syscall argument structure into the generic DTrace register argument array.
- `systrace_entry_setargdesc(int sysnum, int ndx, char *desc, size_t descsz)` maps each syscall argument index to a C type description string for syscall-entry probes.
- `systrace_return_setargdesc(int sysnum, int ndx, char *desc, size_t descsz)` maps return-value slots to C type description strings for syscall-return probes.

Argument conversion model:
- `systrace_args()` switches on syscall numbers from legacy low-numbered calls through modern calls up to `sys_semtimedop` at case 506.
- Each handled case casts `params` to the exact generated `struct ..._args` type, reads fields with `SCARG(p, field)`, writes signed scalar arguments through an `intptr_t *` alias, writes pointer/unsigned/size-like arguments through `uintptr_t *`, sets `*n_args`, and breaks.
- Zero-argument syscalls simply set `*n_args = 0`; unknown/default cases also set `*n_args = 0`.
- The table covers standard process/file calls, VFS and path calls, VM calls, sockets, signals, timers, scheduler calls, LWP calls, kqueue/kevent, ACLs, extended attributes, POSIX message queues/semaphores, SysV IPC, epoll compatibility calls, and many NetBSD compatibility syscall variants.

Description tables:
- `systrace_entry_setargdesc()` mirrors the argument conversion table but emits type strings such as `int`, `const char *`, `size_t`, `struct timespec *`, `gid_t *`, `register_t`, and syscall-specific structure pointer types.
- `systrace_return_setargdesc()` maps both return register slots (`ndx == 0 || ndx == 1`) to the syscall return type, including `int`, `ssize_t`, `pid_t`, `off_t`, `long`, `void *`, `mqd_t`, and `void`.
- Both descriptor helpers leave `desc` unchanged when no type string is available; when a type exists they copy with `strlcpy(desc, p, descsz)`.

Conditional coverage:
- Several compatibility cases are guarded by `#if !defined(_LP64)`, reflecting 32-bit-only syscall ABI entries.
- NTP-related syscalls are guarded by `#if defined(NTP) || !defined(_KERNEL_OPT)`.
- These conditionals mean the generated table must remain synchronized with kernel configuration and syscall numbering.

Integration and dependencies:
- Depends on generated syscall argument structures from `syscallargs.h`, syscall numbering from `syscall.h`, `register_t`, `uintptr_t`, `size_t`, `intptr_t`, `SCARG`, and `strlcpy`.
- The functions are `static`, so this file is intended to be compiled or included as part of the DTrace syscall provider implementation rather than exporting standalone symbols.
- It performs no user-memory access, permission checks, or syscall execution; it only formats already-captured syscall arguments and type metadata for tracing.

Risks and notes:
- Correctness is entirely tied to syscall table generation. Manual edits or stale generation would produce misleading trace arguments or incorrect type descriptions.
- The code trusts that `params` points to the correct syscall argument structure for `sysnum`; a caller/table mismatch would reinterpret memory incorrectly.
- Pointer arguments are exposed as raw numeric addresses for tracing, not dereferenced or copied.
- `desc` remains untouched for unknown syscall/index pairs, so callers must initialize or handle empty descriptions.

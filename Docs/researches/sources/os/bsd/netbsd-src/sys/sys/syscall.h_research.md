# File Research: sources/os/bsd/netbsd-src/sys/sys/syscall.h

This generated header defines NetBSD native system call numbers. It is generated by `makesyscalls.sh` from `syscalls.master` and explicitly says not to edit it directly.

Key interface details:
- Defines `SYS_MAXSYSARGS` as `8`.
- Maps syscall names to numeric syscall codes, starting with `SYS_syscall` 0 and ending with `SYS_semtimedop` 506.
- Defines `SYS_MAXSYSCALL` as `507` and `SYS_NSYSENT` as `512`.
- Contains syscall comments with return types and argument lists.
- Preserves obsolete and compatibility slots as comments or `compat_*` syscall numbers.
- Contains conditional syscall definitions for configuration/ABI cases such as NTP and non-LP64 legacy SysV IPC entries.

Notable syscall families covered:
- Process and credentials: fork/exit/wait, uid/gid, sessions, tracing, signals.
- File and VFS: open/close/read/write, stat variants, mount/unmount, pathconf, fsync, `*at` syscalls.
- Filesystem-specific and storage-adjacent: LFS calls, `swapctl`, `fdiscard`, `statvfs`, file handles, extended attributes, ACLs.
- IPC/network/event: sockets, SysV IPC, kqueue, epoll compatibility, eventfd, message queues.
- VM/time/threading: mmap, mlock, futex, LWP calls, timers, clocks.

Research notes:
- This is a stable syscall-number ABI surface. Numeric values are contractual and must remain synchronized with `syscallargs.h`, syscall tables, libc wrappers, compat layers, and emulation definitions.
- Gaps and obsolete entries are intentional ABI preservation, not dead code.
- For filesystem research, the most relevant entries include `open`, `mount`, `unmount`, `__sysctl`, LFS calls, `swapctl`, extattr/xattr calls, stat/statvfs families, ACL calls, `fdiscard`, and `memfd_create`.

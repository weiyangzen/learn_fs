# File Research: sources/os/bsd/netbsd-src/sys/sys/syscallargs.h

This generated header defines syscall argument structures and kernel syscall function prototypes. It is generated by `makesyscalls.sh` from `syscalls.master` and must remain synchronized with `syscall.h`.

Key interface details:
- Includes syscall-related type headers, with many includes suppressed for `RUMP_CLIENT`.
- Defines `SYS_MAXSYSARGS` as `8`.
- Defines `syscallarg(x)` as an endian-aware union padded to `register_t`.
- Defines `check_syscall_args(call)` to assert each syscall argument struct fits in `SYS_MAXSYSARGS * sizeof(register_t)`.
- Contains 431 syscall argument structures and 429 argument-size checks.
- Contains 459 syscall implementation prototypes using `struct lwp *`, syscall args or `void *`, and `register_t *`.
- Uses extensive `#ifndef RUMP_CLIENT` guards to omit kernel-only syscall surfaces for rump clients.
- Includes compatibility argument structs for historical NetBSD ABIs.

Important syscall argument families:
- Core file/VFS: `sys_open_args`, `sys_read_args`, `sys_write_args`, `sys___sysctl_args`, `sys_mmap_args`, `sys_openat_args`, `sys_fdiscard_args`.
- Filesystem metadata: stat/statvfs variants, file handles, ACLs, extattr/xattr operations.
- Storage/swap: `sys_swapctl_args`.
- LFS: `sys_lfs_bmapv_args`, `sys_lfs_markv_args`, `sys_lfs_segclean_args`.
- Event/IPC/time/threading: kqueue, epoll, aio, futex, LWP, timers, message queues.

Research notes:
- This is syscall ABI marshalling infrastructure. The `syscallarg` union handles register-sized argument extraction on different endian/word-size platforms.
- Adding or changing a syscall requires regeneration from `syscalls.master`; hand edits are fragile.
- The `check_syscall_args` pattern enforces the machine-independent syscall argument limit.
- Filesystem relevance is broad because all path, mount, stat, xattr, ACL, swap, LFS, and discard syscall entry points are represented here.

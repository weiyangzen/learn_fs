# File Research: sources/os/bsd/netbsd-src/lib/libkvm/kvm_x86_64.c

x86-64 libkvm crash-dump address translator. `_kvm_kvatop()` rejects live kernels, walks PML4, L3, L2, and PTE levels from `ptdpaddr`, and supports 1GB and 2MB large pages.

`_kvm_pa2off()` builds a static physical-to-packed-offset map from RAM segments and uses `bsearch`. `_kvm_mdopen()` sets normal user VA bounds.

# File Research: sources/os/bsd/netbsd-src/lib/libc/stdlib/l64a.c

Read completely: 63 lines.

Implements `l64a()` and `l64a_r()`, encoding a `long` into the historical base-64-like alphabet used by `a64l()`. `l64a()` uses a static 8-byte buffer; `l64a_r()` writes into caller storage and returns `0` if the whole value was encoded or `-1` if the buffer was too small.

The encoder emits least-significant six-bit digits first and terminates with NUL.

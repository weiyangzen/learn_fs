Implements `a64l()`, decoding up to six base-64-like characters into a `long`. Character ranges map `.`/`/`, digits, uppercase, and lowercase letters to six-bit values, which are packed little-endian into the result.

The function asserts non-null input but does no validation beyond range-based mapping, matching the historical API.

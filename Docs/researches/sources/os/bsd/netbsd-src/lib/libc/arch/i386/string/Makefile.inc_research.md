# File Research: sources/os/bsd/netbsd-src/lib/libc/arch/i386/string/Makefile.inc

This i386 string make fragment builds assembler implementations for classic byte/string primitives including `bcopy`, `bzero`, `ffs`, `memchr`, `memcpy`, `memmove`, `memset`, `strcat`, `strchr`, `strcmp`, `strcpy`, `strlen`, `strncmp`, `strrchr`, and `swab`.

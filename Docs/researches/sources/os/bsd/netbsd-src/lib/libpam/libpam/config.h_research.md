# File Research: sources/os/bsd/netbsd-src/lib/libpam/libpam/config.h

Generated OpenPAM configuration header for NetBSD. It declares available libc/system features such as `asprintf`, `fpurge`, `strlcpy`, `strlcat`, `vasprintf`, headers, and crypto/crypt libraries.

It records OpenPAM package metadata version `20130907`, enables common feature-test macros, defines `restrict` as `__restrict`, and avoids overriding `LIB_MAJ` on NetBSD because the build passes that value separately.

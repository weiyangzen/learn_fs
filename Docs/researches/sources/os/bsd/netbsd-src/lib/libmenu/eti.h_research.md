# File Research: sources/os/bsd/netbsd-src/lib/libmenu/eti.h

Public error-code header shared by libmenu and libpanel. It defines `E_OK` and negative error constants such as `E_SYSTEM_ERROR`, `E_BAD_ARGUMENT`, `E_POSTED`, `E_CONNECTED`, `E_BAD_STATE`, `E_NO_ROOM`, `E_NOT_POSTED`, `E_UNKNOWN_COMMAND`, `E_NO_MATCH`, `E_NOT_SELECTABLE`, `E_NOT_CONNECTED`, `E_REQUEST_DENIED`, `E_INVALID_FIELD`, and `E_CURRENT`.

This file has no runtime logic; it establishes the ABI-level status vocabulary for menu APIs.

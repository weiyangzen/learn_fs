# File Research: sources/os/bsd/netbsd-src/lib/libwrap/rfc931.c

## Summary
Implements RFC 931/AUTH/IDENT/RFC 1413 remote username lookup for a connection. It opens a TCP connection to the peer’s port 113, sends the remote/local port pair, parses a `USERID` response, and copies the username or `unknown`.

## Main Responsibilities
- Validate matching address families for local and remote socket addresses.
- Support IPv4 and conditionally IPv6.
- Bind the query socket to the same local address as the protected connection.
- Connect to the remote ident server on port 113.
- Use `alarm()` and `setjmp`/`longjmp` timeout handling.
- Parse and verify returned port numbers before accepting the username.

## Key Interfaces
- Global `rfc931_timeout`.
- `rfc931(struct sockaddr *rmt_sin, struct sockaddr *our_sin, char *dest)`.

## Risks
The file intercepts `SIGALRM` globally and uses a static jump buffer, so it is not thread-safe and can interfere with callers using alarms. The result is explicitly unsuitable for authentication. It relies on stdio over sockets and expects `dest` to have `STRING_LENGTH` capacity.

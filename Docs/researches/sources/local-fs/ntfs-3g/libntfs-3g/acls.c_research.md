# File Research: sources/local-fs/ntfs-3g/libntfs-3g/acls.c

Implements NTFS security descriptor, SID, ACL, POSIX ACL, and uid/gid mapping support for libntfs-3g. The file is designed for the library and for tools running on Linux or Windows. It translates between NTFS ACL semantics and Unix mode/POSIX ACL semantics, validates security descriptors read from disk, constructs descriptors for new files, handles inheritance, and parses user/group SID mapping files.

The file defines built-in SIDs for null, world, authenticated users, administrators, system, creator-owner, and creator-group. Core helpers compute SID sizes, compare SIDs, classify world-like SIDs, identify Windows user SIDs, identify known special groups, validate SIDs, and validate implicit mapping SID patterns. Explicit and implicit mapping functions translate uid/gid to SID and SID back to uid/gid; implicit mappings encode uid/gid into the tail authorities of a pattern SID using parity to separate users and groups.

Security descriptor validation is split between `ntfs_attr_size()`, `valid_acl()`, and `ntfs_valid_descr()`. The code checks descriptor revision, aligned offsets, DACL/SACL presence flags, owner/group SID validity, ACL revision, ACE bounds, ACE sizes, and SID validity inside ACEs. It tolerates some real Windows oddities, including descriptors with `SE_DACL_PRESENT` but no DACL.

`ntfs_inherit_acl()` copies inheritable NTFS ACEs from a parent ACL into a child ACL. It filters unsupported ACE types, rewrites generic access masks into file or directory-specific rights, handles object/container inheritance flags, replaces creator-owner and creator-group SIDs with the child owner/group, marks inherited ACEs when requested, and coalesces some authenticated-user and owner ACEs.

When `POSIXACLS` is enabled, the file defines a compact `POSIX_SECURITY` representation and functions to validate, sort, merge, replace, and build POSIX ACLs. `ntfs_valid_posix()` enforces header fields, tag ordering, duplicate rules, owner/group/other presence for access ACLs, mask/mode consistency, and tag-set consistency. `ntfs_build_basic_posix()` creates a simple owner/group/other ACL from mode and umask. `ntfs_build_inherited_posix()` derives access and default ACLs from a parent default ACL, constraining permissions by creation mode and adding missing base entries.

POSIX ACL to NTFS descriptor conversion is implemented by `buildacls_posix()` and `ntfs_build_descr_posix()`. It maps POSIX users, groups, masks, defaults, and special mode bits into ordered NTFS allow/deny ACEs. The conversion uses deny ACEs to preserve POSIX mask semantics, emits inheritance-only ACEs for default ACLs, adds administrator and system full-access ACEs, inserts a world execute denial for inherited regular files from directories, and stores setuid/setgid/sticky bits in a null-SID ACE using Cygwin-compatible conventions.

Plain Unix mode to NTFS descriptor conversion is implemented by `buildacls()` and `ntfs_build_descr()`. It builds a self-relative security descriptor with DACL first, then owner and group SIDs, matching Windows’ preferred ordering for descriptor reuse/hash stability. The ACL emits owner, group, world, administrator, system, optional owner/group denial ACEs, optional directory inheritance denial, and optional null-SID special-mode ACEs. It has special handling when owner or group is administrator, or when owner and group map to the same SID.

NTFS ACL to Unix mode conversion is implemented by `merge_permissions()`, `build_std_permissions()`, `build_owngrp_permissions()`, `build_ownadmin_permissions()`, and the public `ntfs_build_permissions()`. The selected path depends on whether owner/group are administrator or identical. These routines scan effective ACEs, ignore inheritance-only entries, collect owner/group/world grants and denials, decode null-SID special bits, and merge Windows access masks into `mode_t` read/write/execute and special permission bits.

When `POSIXACLS` is enabled, `ntfs_build_permissions_posix()` performs a fuller NTFS ACL to POSIX ACL reconstruction. It allocates a worst-case POSIX descriptor, walks NTFS ACEs into raw POSIX ACEs, maps SIDs through user/group mappings, distinguishes access versus default ACLs by inheritance flags, recognizes root-as-designated-user/group marker bits, handles group masks, synthesizes missing owner/group/other entries, sorts entries, normalizes grants and denials through `norm_std_permissions_posix()` or `norm_ownadmin_permissions_posix()`, then validates the final descriptor.

Optional `OWNERFROMACL` support can derive owner SID from the first user ACE allowed to change owner. Without it, `find_tenant()` provides a special approximation for administrator-owned Windows-created trees where a mapped user has write rights and should be treated as the tenant.

The mapping parser reads colon-separated mapping records of `uid:gid:sid`. `ntfs_read_mapping()` reads complete lines through an abstract `FILEREADER`, supports buffered reads for mappings stored either outside the mounted filesystem or inside NTFS before FUSE is running, skips comments, truncates overlong lines, and stores raw text in `MAPLIST` nodes. `ntfs_do_user_mapping()` resolves numeric or named users, validates user SIDs or implicit mapping patterns, and builds the user mapping chain. `ntfs_do_group_mapping()` resolves numeric or named groups in two passes so standalone groups are preferred before uid-associated groups, supports known special group SIDs, and builds the group mapping chain. `ntfs_free_mapping()` releases shared SID ownership carefully so user mappings do not free SIDs also referenced by group mappings.

Important edge cases handled throughout include root/admin equivalence, owner/group SID equality, Windows inheritance of generic permissions, POSIX mask preservation, unknown SIDs, special Windows groups treated as world-like access, default ACL inheritance for directories, and avoiding recursion hazards when resolving passwd/group names while mounting an NTFS filesystem through FUSE.

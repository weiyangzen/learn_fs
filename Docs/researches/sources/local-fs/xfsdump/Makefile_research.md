# File Research: sources/local-fs/xfsdump/Makefile

Purpose: top-level GNU make orchestration for xfsdump. It handles bootstrap from an unconfigured tree, includes generated `include/builddefs` when available, drives recursive subdirectory builds, and packages source distributions.

Key behavior:
- Implements quiet/verbose build mode via `V=1`, `Q`, and `MAKEOPTS`.
- Detects whether `include/builddefs` exists. If missing, `default`, `dist`, and `deb` first generate `configure`, run `./configure`, then re-enter make.
- Defines source distribution metadata: `SRCDIR`, `SRCTAR`, autotools files, `LSRCFILES`, and `SRCTARINC`.
- Recurses into `include`, `librmt`, and tool/doc/package subdirs: `common inventory invutil dump restore m4 man doc po debian`.
- Establishes subdir dependencies: all lib/tool dirs depend on `include`; `invutil`, `dump`, and `restore` depend on `librmt`.
- Provides `configure`, `include/builddefs`, `include/config.h`, `install`, `install-dev`, `distclean`, `realclean`, `dist`, `deb`, source-tarball, and `.gitcensus` targets.

Important details:
- `configure` regenerates libtool/autoconf files and handles old/new `libtoolize` behavior with `LIBTOOLIZE_INSTALL`.
- `include/config.h` has recovery logic for missing config header by deleting `include/builddefs` and rebuilding configuration.
- `install` installs the README under `$(PKG_DOC_DIR)` after recursive install targets.
- `dist` uses `.gitcensus` generated by `git ls-files` and `tar --transform` to place files under the versioned source directory.

Risks/notes:
- Recursive self-invocation depends on configure successfully creating `include/builddefs`; failures there affect most targets.
- `clean` is a no-op before configuration, so unconfigured generated files outside `LDIRT` may persist.
- `.gitcensus` is only refreshed when `.git` exists; source trees without `.git` rely on an existing file.

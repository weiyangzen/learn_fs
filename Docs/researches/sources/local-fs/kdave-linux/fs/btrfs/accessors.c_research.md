# File Research: sources/local-fs/kdave-linux/fs/btrfs/accessors.c

Purpose: Implements generic low-level read/write helpers for Btrfs on-disk metadata fields stored in `extent_buffer` folios.

Main behavior:
- `btrfs_get_8/16/32/64()` and `btrfs_set_8/16/32/64()` are generated by `DEFINE_BTRFS_SETGET_BITS`.
- Helpers treat metadata item pointers as logical offsets into an `extent_buffer`.
- They handle fields crossing folio boundaries, which matters when metadata block size exceeds page size.
- Bounds violations are reported through `report_setget_bounds()` and return zero or skip the write.
- Little-endian unaligned loads/stores are used for field conversion.
- `btrfs_node_key()` reads a node key from a key pointer slot using `read_eb_member`.

Dependencies: Uses `extent_io.h` for extent-buffer/folio layout helpers, `messages.h` for warnings, `fs.h`, and declarations/macros from `accessors.h`.

Invariants and edge cases:
- Access is bounded by `eb->len`; overflow logs a warning with pointer, start, member offset, and size.
- Cross-folio fields are copied through a small byte array, with special handling for two-byte fields.
- The code assumes the extent-buffer folio array represents a linear metadata address space even when physical pages are not contiguous.

Risk notes: This is foundational metadata access code. Incorrect offsets, item sizes, or folio indexing can silently corrupt on-disk metadata, so the bounds checks and typed accessor macros in the header are central safety mechanisms.

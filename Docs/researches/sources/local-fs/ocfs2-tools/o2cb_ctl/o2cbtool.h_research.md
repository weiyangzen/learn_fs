# File Research: sources/local-fs/ocfs2-tools/o2cb_ctl/o2cbtool.h

Shared command framework header for `o2cb`.

It defines default config path `/etc/ocfs2/cluster.conf`, default IP port `7777`, the `struct o2cb_command` dispatch contract, long-option enum values, all command action prototypes, cluster-stack initialization, signal blocking, and utility predicates for registered clusters and active heartbeat.

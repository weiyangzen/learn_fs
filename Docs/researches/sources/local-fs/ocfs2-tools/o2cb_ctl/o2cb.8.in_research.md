# File Research: sources/local-fs/ocfs2-tools/o2cb_ctl/o2cb.8.in

Manual page for the command-oriented `o2cb` cluster configuration utility.

It documents global options, alternate config-file path support, cluster/node/heartbeat editing commands, listing commands, configfs registration/unregistration, global heartbeat start/stop, and cluster status. It also gives a minimal workflow for creating a cluster, adding nodes, adding a heartbeat device, and enabling global heartbeat.

# File Research: sources/local-fs/ocfs2-tools/o2cb_ctl/ocfs2.cluster.conf.5.in

Manual page for `/etc/ocfs2/cluster.conf`.

It describes cluster, node, and heartbeat stanzas, their required fields, cluster-name constraints, node hostname/IP/port/number semantics, optional global heartbeat regions, and the requirement that the file be consistent across all nodes. It warns that manual editing must follow strict formatting: stanza at column one, colon terminator, parameter lines after a tab, and blank-line separation.

# File Research: sources/local-fs/ocfs2-tools/o2cb_ctl/o2cb_ctl.8.in

Manual page for the older flag-oriented `o2cb_ctl`.

It documents create, delete, info, and change modes; object naming and type selection; attribute syntax; optional live-cluster modification flags; compact vs verbose info output; and examples for adding/querying/changing nodes. The page explicitly discourages direct user use in favor of init service or higher-level tools.

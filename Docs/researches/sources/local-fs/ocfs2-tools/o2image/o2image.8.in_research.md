# File Research: sources/local-fs/ocfs2-tools/o2image/o2image.8.in

Manual page for `o2image`.

It describes copying OCFS2 metadata, not file data, into an image for debugging or layout analysis. It documents packed default images, raw/sparse mode with `-r`, metadata restore with dangerous `-I`, and interactive space-confirmation mode with `-i`. The examples cover creating an image and restoring it back to a device with a corruption warning.

# File Research: sources/local-fs/ocfs2-tools/mounted.ocfs2/mounted.ocfs2.8.in

Manual page for `mounted.ocfs2`.

It documents quick detect `-d`, full detect `-f`, optional device scanning, output columns, global-heartbeat flag `G`, and examples for both UUID/label listing and node mount-state listing. The notes warn that full detect can show stale mounted nodes after unclean unmount until slot recovery occurs.

# File Research: sources/local-fs/ocfs2-tools/mount.ocfs2/sundries.h

Declarations and shared status constants for mount-helper support routines.

It declares global option state, string helpers, path canonicalization, option/type matching, fatal/nonfatal reporting, and signal blocking. It also defines util-linux-style exit status bits such as `EX_USAGE`, `EX_SYSERR`, `EX_FILEIO`, and `EX_FAIL`.

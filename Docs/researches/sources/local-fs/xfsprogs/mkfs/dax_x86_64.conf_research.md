# File Research: sources/local-fs/xfsprogs/mkfs/dax_x86_64.conf

This mkfs profile targets persistent memory on x86_64.

It fixes block size at 4096 bytes so filesystem block size matches the common x86_64 page size and enables v5 metadata CRCs. In the data section it sets a 2 MiB stripe unit with width 1, inherits extent-size hints of 512 filesystem blocks, and enables inherited DAX. The realtime section sets realtime extent size to 2 MiB.

The profile is designed to encourage PMD-sized allocation behavior for DAX/persistent-memory deployments.

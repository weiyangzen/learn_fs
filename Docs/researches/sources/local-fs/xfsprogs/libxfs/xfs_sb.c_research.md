# File Research: sources/local-fs/xfsprogs/libxfs/xfs_sb.c

This file implements XFS superblock feature validation, in-core/on-disk conversion, buffer verification, mount-time geometry derivation, superblock logging/syncing, geometry export, secondary superblock handling, stripe validation, and realtime summary log computation.

Version and feature validation starts with v5 feature sanity. `xfs_sb_validate_v5_features` ensures v5 superblocks contain only known v4-compatible feature bits and all v4 flags required by the v5 implementation. `xfs_sb_good_version` accepts valid v5 superblocks and v4 superblocks with v2 directories and unwritten extents. `xfs_sb_version_to_features` converts legacy v4/v5 feature fields into in-memory `XFS_FEAT_*` flags, including newer features such as exchange range, parent pointers, metadir, and zoned.

Read/write validation is split by purpose. `xfs_validate_sb_read` handles unknown v5 feature masks and read-only compatible restrictions. `xfs_validate_sb_write` checks primary superblock summary counters, unknown feature corruption, unknown log incompat features, and LSN validity before writes. `xfs_validate_sb_common` performs most structural validation: magic, version, v5 block size, quota flag layout, sparse inode alignment, metadir padding and rtgroup validation, zoned validation, internal/external log consistency, AG geometry, block/sector/inode sizes, log size, realtime geometry, stripe geometry, and supported inode sizes.

Realtime geometry validation is significant for this group. `xfs_expected_rbmblocks` returns zero bitmap blocks for zoned realtime filesystems. `xfs_validate_rt_geometry` requires zoned realtime extent size of one filesystem block; non-zoned realtime extent size must be within min/max byte bounds. It checks `rblocks`, `rextents`, `rextslog`, bitmap block count, and for zoned rt requires `rextents` to be aligned to `rgextents`. `xfs_validate_sb_rtgroups` validates metadir rtgroups: nonzero `rextsize`, group size under `XFS_MAX_RGBLOCKS`, group size at least `XFS_MIN_RGEXTENTS`, group count under `XFS_MAX_RGNUMBER`, group coverage of all realtime extents, exchange-range support, and exact `sb_rgblklog`. `xfs_validate_sb_zoned` enforces zero `sb_frextents`, non-overlap between `sb_rtstart` and data blocks, and valid `sb_rtreserved`.

On-disk conversion uses `__xfs_sb_from_disk`, `xfs_sb_from_disk`, `xfs_sb_quota_from_disk`, `xfs_sb_quota_to_disk`, and `xfs_sb_to_disk`. The conversion layer normalizes legacy quota inode values, maps v4 quota flags into in-core v5-style flags, handles meta-uuid fallback to fs uuid, reads/writes metadir fields only when the metadir feature is set, zeroes legacy rbm/rsum inode fields for metadir filesystems, and reads/writes zoned fields only when zoned is enabled.

Superblock buffer verifiers are exported through `xfs_sb_buf_ops` and `xfs_sb_quiet_buf_ops`. `xfs_sb_read_verify` conditionally checks CRC for v5 or nonzero CRC fields, tolerates some old secondary-superblock CRC issues, converts from disk without quota conversion, runs common and read validation, and maps errors to verifier or I/O errors. The quiet verifier suppresses noise when probing non-XFS media. `xfs_sb_write_verify` validates, stamps the log item LSN for v5 buffers, and updates the checksum.

Mount geometry setup is in `xfs_sb_mount_rextsize`, `xfs_mount_sb_set_rextsize`, and `xfs_sb_mount_common`. These functions precompute realtime extent log/mask, rtgroup block count/log/mask/start, zone gap handling, AG group geometry, bitmap block word geometry, max/min records for allocation, bmap, rmap, realtime rmap, refcount, and realtime refcount btrees, block conversion sizes, allocation set-aside, and maximum usable AG blocks.

Superblock logging and syncing are handled by `xfs_log_sb`, `xfs_sync_sb`, and `xfs_sync_sb_buf`. `xfs_log_sb` updates lazy counters before writing the incore superblock to the transaction buffer; for rtgroups on non-zoned filesystems it also refreshes `sb_frextents` from the realtime free counter. `xfs_sync_sb_buf` can also call `xfs_log_rtsb` to update and synchronously write the realtime superblock buffer.

`xfs_update_secondary_sbs` rewrites all secondary superblocks from the primary state, batching delayed writes and continuing after per-AG failures so repair has more updated copies than stale copies. `xfs_sb_read_secondary` and `xfs_sb_get_secondary` read or allocate transaction buffers for secondary superblocks and mark AG superblock sickness on metadata read corruption.

`xfs_fs_geometry` exports user-visible geometry in versioned structures. Version 5 adds rtgroup count/extents and zoned `rtstart`/`rtreserved`. Feature flags include metadir and zoned. `xfs_validate_stripe_geometry` centralizes stripe unit/width validation and can allow later repair from mount options. `xfs_compute_rextslog` correctly uses `xfs_highbit64` for realtime volumes with more than 2^32 extents.

## sources/distributed-fs/beegfs/client_module/source/common/toolkit/ListTk.c

**Purpose:** Implements common list utilities for NIC lists, NIC stats lists, UInt16 list/vector copying, and string-list lookup. **APIs/functions:** `ListTk_cloneNicAddressList`, `cloneSortNicAddressList`, `kfreeNicAddressListElems`, `kfreeNicAddressStatsListElems`, `copyUInt16ListToVec`, and `listContains`. **Control flow:** NIC sorting honors explicit `NicAddressFilter` positions, then prefers RDMA, then IPv4-mapped addresses, then original order; cloning allocates element copies with kernel allocation; free helpers only free elements and leave list container uninit to caller. **State/persistence:** utilities create/free volatile list entries and do not own source lists. **Dependencies/integration:** used by `NodeConnPool`, stripe patterns, network interface selection, and config-derived filters. **Risks/tests:** clone-sort uses `__GFP_NOFAIL` and assumes tiny lists; tests should cover filter ordering, RDMA/TCP include flag, IPv4 preference, element ownership, and `outPos` on missing strings.

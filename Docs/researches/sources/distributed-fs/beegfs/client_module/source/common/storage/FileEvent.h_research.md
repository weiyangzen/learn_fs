## sources/distributed-fs/beegfs/client_module/source/common/storage/FileEvent.h

**Purpose:** Declares file event types and the event value object used for kernel-client event serialization. **APIs/types:** `FileEventType` enumerates flush/truncate/setattr/create/unlink/rename/open/read/write, last-writer, blocked-open, stripe-pattern, and inode-lock events; `FileEvent` stores event type, path, target, and optional page-backed storage PFNs; helpers initialize, uninitialize, set string/dentry targets, serialize, and define `FILEEVENT_EMPTY`. **Control flow/state:** path and target may be NULL when unavailable; target ownership depends on whether `targetPagePFN` is set. **Dependencies/integration:** feeds watch/event messages and uses the common serialization toolkit. **Risks/tests:** enum values are part of the event protocol and must stay aligned with consumers; tests should verify target-present booleans and memory cleanup across all initialization paths.

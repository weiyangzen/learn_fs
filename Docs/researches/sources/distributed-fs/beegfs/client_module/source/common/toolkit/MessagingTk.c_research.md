## sources/distributed-fs/beegfs/client_module/source/common/toolkit/MessagingTk.c

**Purpose:** Implements client request/response RPC helpers over pooled node sockets, including retries, target/mirror routing, target-state checks, generic response handling, and response-buffer ownership. **Important APIs/functions:** `MessagingTk_requestResponseWithRRArgsSock`, `requestResponseKMalloc`, `requestResponseSock`, `requestResponseRetry`, `requestResponseNode`, `requestResponseNodeRetryAutoIntr`, `__requestResponseNodeRetry`, `__requestResponseWithRRArgsComm`, and `__handleGenericResponse`. **Control flow:** the basic retry loop increments RPC stats, performs one communication attempt, handles fatal signals/inactive nodes/non-retry errors, sleeps on retry schedules, and suppresses repeated logs through `rrArgs->logFlags`. Node/target routing resolves target IDs or mirror groups through mapper/store data, checks `TargetStateStore` for good/offline/intermediate states, may sleep on non-good states when allowed, acquires mirror buddy sequence numbers, and releases sequence handles on exit. The comm path acquires a pooled socket unless supplied, allocates a response buffer from `NoAllocBufferStore` or kmalloc, serializes/sends the request, receives a full message, builds a `NetMessage`, handles `AckNotifyResp` as failover retry, handles `GenericResponse` codes (`TRYAGAIN`, `INDIRECTCOMMERR`, `NEWSEQNOBASE`), validates expected response type, and releases or invalidates the socket. **State/persistence:** no durable state, but mutates `RequestResponseArgs` outputs, node socket pools, app RPC counters, and mirror sequence state. **Dependencies/integration:** uses `App`, `Config`, `Logger`, `Node`, `NodeStoreEx`, `TargetMapper`, `TargetStateStore`, `MirrorBuddyGroupMapper`, `NetMessageFactory`, `NoAllocBufferStore`, and `StorageErrors`. **Risks/tests:** high-risk areas are response-buffer cleanup on every goto path, socket release vs invalidation, retry loops under signals, mirror sequence base updates, target-state sleep behavior, and handling caller-supplied sockets; tests should cover wrong response type, generic retry/no-retry, timeout, inactive node, offline/bad target, mirror failover `AckNotifyResp`, and kmalloc vs buffer-store buffers.

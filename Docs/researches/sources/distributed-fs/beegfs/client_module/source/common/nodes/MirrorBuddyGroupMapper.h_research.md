## sources/distributed-fs/beegfs/client_module/source/common/nodes/MirrorBuddyGroupMapper.h

**Purpose:** Declares the mirror buddy group mapper object and public/unlocked APIs for querying, synchronizing, and validating mirror group membership. **APIs/types:** `MirrorBuddyGroupMapper` contains an `RWLock` and rb-root of `MirrorBuddyGroup`; exported functions construct/destruct, return primary/secondary target IDs, acquire a mirrored sequence number, sync a list of `BuddyGroupMapping`, and add/update one group with optional storage target validation. **Control flow/state:** public functions own locking, while `__MirrorBuddyGroupMapper_getBuddyGroupIDUnlocked` and `__MirrorBuddyGroupMapper_syncGroupsUnlocked` require an external write lock so `TargetStateStore` can update target states and groups atomically. **Dependencies/integration:** includes config, `TargetMapper`, `MirrorBuddyGroup`, `RWLock`, list iterators, string toolkit, and storage errors. **Risks/tests:** callers must respect the unlocked helper contract and maintain target IDs as nonzero; tests should verify public lock coverage, add error returns, and simultaneous state/group refresh behavior.

## sources/distributed-fs/beegfs/client_module/source/common/storage/striping/BuddyMirrorPattern.c

**Purpose:** Implements virtual behavior for buddy-mirrored stripe patterns, where stripe target IDs are mirror buddy group IDs. **APIs/functions:** deserialization, stripe target index/ID lookup, target ID copy/reference, min/default target counts. **Control flow:** deserialization reads default target count and a serialized `UInt16Vec`, requiring at least one group; stripe index is `(pos / chunkSize) % group_count`, and target ID is the group ID at that index. **State/persistence:** stores group IDs in `mirrorBuddyGroupIDs` and default target count in-memory after wire decode. **Dependencies/integration:** created by `StripePattern_createFromBuf` for pattern type `STRIPEPATTERN_BuddyMirror`; request routing later resolves group IDs through mirror mappers. **Risks/tests:** zero targets, zero/non-power-of-two chunk sizes, and group-vs-target confusion are key risks; tests should cover multiple groups and boundary positions.

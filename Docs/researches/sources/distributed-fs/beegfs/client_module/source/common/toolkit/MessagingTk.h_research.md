## sources/distributed-fs/beegfs/client_module/source/common/toolkit/MessagingTk.h

**Purpose:** Declares high-level BeeGFS client request/response messaging helpers and inline buffer/receive/retry utilities. **APIs/types:** public request/response variants for node, socket, retry, and kmalloc response buffers; internal comm/generic-response/node-retry helpers; inline `MessagingTk_createMsgBuf`, `recvMsgBuf`, retry wait helpers, and convenience wrappers. **Control flow:** `recvMsgBuf` first receives the minimum NetMessage header, extracts message length, rejects oversized messages with `-EMSGSIZE`, then receives the payload with long timeout; retry wait intervals are 0 for first try, 5s through retry 12, 20s through retry 24, and 60s after. **Dependencies/integration:** includes app/config/logger, sockets, nodes, mirror groups, threading, message factory, and storage errors. **Risks/tests:** `MessagingTk_createMsgBuf` serializes even if allocation returns NULL by passing length 0, so message serializers must tolerate that path; tests should cover header-only messages, oversize rejection, recv timeout, and retry schedule compatibility with config.

## sources/distributed-fs/beegfs/client_module/source/common/storage/PathInfo.h

**Purpose:** Defines the client-side path metadata object for chunk file discovery and stub/original-parent flags. **APIs/types:** feature flags `PATHINFO_FEATURE_ORIG`, `ORIG_UNKNOWN`, `IS_STUB`; `PathInfo` stores const-visible flags, original UID, and original parent entry ID with private mutable union fields; inline init/uninit/dup/update/setters plus serialize/deserialize externs. **Control flow/state:** init stores the supplied entry ID pointer and flags, uninit frees it, dup deep-copies the entry ID, and update replaces the whole object only when flags, UID, or entry ID differ. **Dependencies/integration:** carried in successful open/lookup responses and duplicated by `LookupIntentInfoOut`. **Risks/tests:** pointer ownership is transferred to the object, while setters can assign non-owned pointers if misused; tests should cover update no-op vs replacement and open-result cleanup.

## sources/distributed-fs/beegfs/client_module/source/common/storage/EntryInfo.h

**Purpose:** Defines `EntryInfo`, owner identity, feature flags, and ownership helpers for metadata operations. **APIs/types:** `ENTRYINFO_FEATURE_INLINED`, `ENTRYINFO_FEATURE_BUDDYMIRRORED`, `NodeOrGroup`, `EntryInfo`, `EntryInfo_init/uninit/dup/update`, parent/file name update helpers, accessors, buddy-mirror test, and logging helpers. **Control flow/state:** initialization stores caller-supplied string pointers and marks buddy-mirrored entries when the owner is a group; uninit frees all three strings; `dup` deep-copies strings; `update` transfers parent/file-name pointers from a new info object, preserves entry ID/type, and updates owner only for non-directories. **Dependencies/integration:** central to lookup intent output, metadata cache revalidation, file event/open paths, and serialization. **Risks/tests:** ownership transfer in `EntryInfo_update` is subtle and can double-free if callers reuse `newEntryInfo`; tests should cover directory owner preservation, group owner flagging, duplicate/uninit lifetimes, and logging owner flag.

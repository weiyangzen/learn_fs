## sources/distributed-fs/beegfs/client_module/source/common/nodes/TargetMapper.c

**Purpose:** Implements an RW-lock protected rb-tree mapping storage target IDs to owning numeric node IDs. **APIs/functions:** construct/destruct, `TargetMapper_mapTarget`, `syncTargets`, `getTargetIDs`, and `getNodeID`. **Control flow:** mapping allocates a new `TargetMapping`, inserts or replaces under the write lock, frees any old mapping, and returns whether it was new; sync frees the old tree, consumes the supplied list of mapping objects, and inserts them; list export iterates rb order under read lock. **State/persistence:** volatile target-to-node mapping populated from management state; missing targets return node ID 0. **Dependencies/integration:** validates mirror group target existence, routes target requests in `MessagingTk`, and uses Linux rb helpers generated by `BEEGFS_RBTREE_FUNCTIONS`. **Risks/tests:** sync consumes caller-owned mapping list nodes, so callers must not reuse them; tests should cover replacement, missing target, list export order, and concurrent readers during sync.

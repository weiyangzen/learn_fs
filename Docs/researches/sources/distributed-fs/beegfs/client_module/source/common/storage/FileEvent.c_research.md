## sources/distributed-fs/beegfs/client_module/source/common/storage/FileEvent.c

**Purpose:** Implements kernel-side file event path capture and serialization for BeeGFS watch/event reporting. **APIs/functions:** `FileEvent_init`, `FileEvent_uninit`, `FileEvent_setTargetDentry`, and `FileEvent_serialize`. **Control flow:** initialization zeroes the object, records the event type, optionally allocates one page and calls `dentry_path_raw` for the event path; target setters free previous target storage and either duplicate a string or allocate a page for a target dentry path. Serialization writes event type, path string or empty path, a boolean target-present flag, and target string when set. **State/persistence:** event owns optional path/target backing pages or duplicated target strings until uninit; serialized form is transient message payload. **Dependencies/integration:** used by filesystem operations that emit file events and by `Serialization`. **Risks/tests:** `FileEvent_uninit` calls `FileEvent_setTargetStr(NULL)`, so target string duplication must tolerate NULL in the kernel helper; tests should cover missing dentry, `IS_ERR` path results, rename/link target serialization, and repeated target replacement.

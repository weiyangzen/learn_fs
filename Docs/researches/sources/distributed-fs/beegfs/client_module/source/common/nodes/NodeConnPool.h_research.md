## sources/distributed-fs/beegfs/client_module/source/common/nodes/NodeConnPool.h

**Purpose:** Declares the per-node stream connection pool contract for kernel client messaging. **APIs/types:** `NodeConnPoolStats`, `NodeConnPoolErrorState`, and `NodeConnPool` hold app/node backlinks, remote/local NIC lists, RDMA stats, connection list, ports, capabilities, counters, limits, error state, mutex/condition, and connection-attempt semaphore. Public APIs acquire/release/invalidate streams, disconnect idle/available streams, update interfaces, read stats, and report peer names; internal APIs manipulate sockets, stats, and log state. **Control flow/state:** inline lock helpers expose the mutex for callers that need stable NIC-list access, while clone/update wrappers keep list ownership internal. **Dependencies/integration:** includes socket, NIC, list, condition, mutex, logger, app config, and connection-list headers. **Risks/tests:** callers must return or invalidate every acquired socket; direct use of internal helpers assumes pool lock/counter invariants; tests should validate list cloning ownership, mutex coverage, and statistics after each socket lifecycle path.

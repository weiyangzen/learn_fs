## sources/distributed-fs/beegfs/client_module/source/common/toolkit/HashTk.c

**Purpose:** Implements BeeGFS hashing helpers for directory/hash distribution and authentication secret hashing. **Important APIs/functions:** Hsieh 32-bit hash, half-MD4 hash using kernel `half_md4_transform` or local fallback, `HashTk_hash32`, `HashTk_hash64`, `HashTk_sha256`, and `HashTk_authHash`. **Control flow:** unknown hash types log and fall through to the default half-MD4 path; 64-bit Hsieh hashes hash the first and second halves separately, while 64-bit half-MD4 combines major/minor buffer words. SHA-256 allocates a kernel shash transform and descriptor for one digest. Auth hash takes the first eight SHA-256 bytes in little-endian order to match other implementations. **State/persistence:** no persistent state; outputs must remain stable across clients/servers. **Dependencies/integration:** uses Linux crypto API and common hash constants; half-MD4 mirrors ext4 behavior. **Risks/tests:** `HashTk_halfMD4` passes the original `len` to each block conversion, which is intentional/ext4-derived but worth regression coverage; tests should compare known vectors across C++/kernel implementations and cover crypto allocation failure.

## sources/distributed-fs/beegfs/client_module/source/common/nodes/Node.h

**Purpose:** Defines the `Node` abstraction representing a BeeGFS meta/storage/client/mgmt node in the kernel client. **APIs/types:** `NodeType`, `NodeString`, `Node` fields, kref helpers `Node_get/put`, and inline getters/setters for numeric ID, NIC cloning, local interface updates, connection pool, active flag, UDP/TCP ports, and node type. **Control flow/state:** state is split between `aliasAndTypeMu` for alias/type/display string, `mutex` for active/port/heartbeat data, and `NodeConnPool` for stream connectivity. `NodeString` deliberately copies aliases into a 64-byte fixed buffer for log safety while dynamic alias storage remains protected by the RW lock. **Dependencies/integration:** includes `NumNodeID`, `Condition`, `Mutex`, `RWLock`, `Time`, `NodeConnPool`, and Linux `kref`; embedded rb-tree linkage is consumed by `NodeTree`. **Risks/tests:** direct access to `alias` and `nodeAliasWithTypeStr` bypasses the dynamic alias safety contract; tests should prefer public copy helpers and cover kref teardown through store/tree erase.

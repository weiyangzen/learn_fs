## sources/distributed-fs/beegfs/client_module/source/common/storage/striping/Raid10Pattern.c

**Purpose:** Implements RAID10 stripe-pattern behavior with primary stripe targets and separate mirror target IDs. **APIs/functions:** deserialization, target index/ID lookup, stripe target copy/reference, mirror target reference, min/default target counts. **Control flow:** deserialization reads a stripe target vector then a mirror target vector and rejects empty or unequal-length vectors. Target indexing handles mirrored layout by computing a stripe set and mapping positions to alternating primary/mirror targets; mirror target lookup exposes the mirror vector. **State/persistence:** stores two target vectors after wire decode. **Dependencies/integration:** created from `STRIPEPATTERN_Raid10`; consumers can access mirror IDs through the base virtual `getMirrorTargetIDs`. **Risks/tests:** mismatched vector lengths and off-by-one stripe math are the main risks; tests should cover chunk boundaries, multiple target pairs, and mirror vector access.

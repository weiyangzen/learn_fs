## sources/distributed-fs/beegfs/client_module/source/common/toolkit/LookupIntentInfoOut.h

**Purpose:** Defines the output aggregator for compound lookup/create/stat/revalidate/open intent responses. **APIs/types:** `LookupIntentInfoOut` stores response flags, per-operation results, stat output pointer, entry info pointer, revalidate flags, file handle ID, path info, and stripe pattern; helpers prepare, initialize from `LookupIntentRespMsg`, set pointers/patterns, and uninitialize. **Control flow:** prepare sets caller-owned output pointers and initializes results to internal error. Init copies result fields based on response flags, converts stat data on stat success, updates revalidate flags without duplicating entry info, duplicates entry info on lookup/create success, and on open success duplicates handle ID/path info and constructs a stripe pattern from the response buffer. Uninit frees duplicated entry info when lookup/create succeeded and releases path info/stripe pattern when open succeeded. **State/persistence:** owns only duplicated response artifacts, not the external stat/entry pointer storage itself. **Dependencies/integration:** central to metadata lookup/open paths and stripe-pattern creation. **Risks/tests:** cleanup predicates must match allocation predicates; tests should cover lookup-only, create, revalidate, stat failure, open success/failure, invalid stripe pattern fallback, and repeated uninit avoidance.

## sources/distributed-fs/beegfs/client_module/source/common/storage/striping/StripePattern.c

**Purpose:** Implements base stripe-pattern deserialization and factory creation for RAID0, RAID10, buddy mirror, or invalid simple patterns. **APIs/functions:** `StripePattern_virtualDestruct`, `StripePattern_deserializePatternPreprocess`, `StripePattern_createFromBuf`, `__StripePattern_deserializeHeader`, and default `StripePattern_getMirrorTargetIDs`. **Control flow:** preprocess peeks pattern length, returns the start pointer, and advances the outer context by the whole serialized pattern. Creation deserializes a header, instantiates the subclass by type, calls its virtual deserializer, and falls back to invalid `SimplePattern` on unknown type or decode failure. Header decode reads length, type, chunk size, optional storage pool ID unless `HAS_NO_POOL_FLAG` is set, strips that flag, and rejects too-short or zero-chunk patterns. **State/persistence:** preserves the wire layout of pattern length/type/chunk size/pool plus subclass payload. **Dependencies/integration:** used by lookup/open response parsing and `LookupIntentInfoOut`. **Risks/tests:** `HAS_NO_POOL_FLAG` changes header length expectations, and chunk size is not validated as power-of-two here despite base comments; tests should cover old no-pool patterns, unknown types, truncated patterns, zero chunk size, and fallback cleanup.

## sources/distributed-fs/beegfs/client_module/source/common/storage/EntryInfo.c

**Purpose:** Serializes and deserializes `EntryInfo`, the minimal metadata needed to identify a directory entry/inode. **APIs/functions:** `EntryInfo_serialize` and `EntryInfo_deserialize`. **Control flow:** serialization writes entry type, feature flags, aligned parent ID, aligned entry ID, aligned file name, owner node/group via `NumNodeID_serialize`, and a 2-byte alignment pad; it warns and dumps stack if an entry ID is too short. Deserialization reads the same sequence, sets `owner.isGroup` from the buddy-mirrored feature flag, validates parent and entry ID lengths, and leaves returned string pointers pointing into the deserialize buffer. **State/persistence:** this is an on-wire compatibility contract with the common/server `EntryInfo.h`; owner node/group must remain same size/type. **Dependencies/integration:** used by lookup, create, revalidate, and inode/chunk routing code. **Risks/tests:** callers must understand deserialized strings are not separately allocated unless duplicated; tests should cover root parent ID empty string, invalid short IDs, buddy-mirrored owner group, and 4-byte alignment.

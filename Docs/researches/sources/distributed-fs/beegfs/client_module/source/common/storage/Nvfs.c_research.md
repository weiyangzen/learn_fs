## sources/distributed-fs/beegfs/client_module/source/common/storage/Nvfs.c

**Purpose:** Implements optional NVIDIA GPUDirect Storage/NVFS registration glue when `BEEGFS_NVFS` is enabled. **APIs/functions:** global `nvfs_ops`, `nvfs_shutdown`, per-CPU `nvfs_n_ops`, `REGISTER_FUNC`, and `UNREGISTER_FUNC`. **Control flow:** registration stores the NVFS DMA ops pointer and clears shutdown; unregistration sets shutdown, waits in `NVFS_HOLD_TIME_MS` increments until `nvfs_count_ops()` drops to zero, then clears the ops pointer. `nvfs_get_ops`/`put_ops` in the header bracket active users with per-CPU counters. **State/persistence:** process-global kernel module state only, not durable; active op counts protect the external ops table lifetime. **Dependencies/integration:** used by `RdmaInfo` and RDMA connection priority when GPU-backed IO is detected. **Risks/tests:** races around unregister and active operations are high risk; tests should simulate registration/unregistration while mapping requests, failed acquire after shutdown, and counter balance.

## sources/distributed-fs/beegfs/client_module/source/common/threading/Thread.c

**Purpose:** Implements a small BeeGFS wrapper around Linux kernel threads with cooperative self-termination state. **APIs/functions:** `Thread_init/uninit`, `Thread_start`, `Thread_join`, `Thread_timedjoin`, `Thread_selfTerminate`, `Thread_sleep`, `__Thread_runStatic`, `Thread_getName`, and `Thread_getCurrentThreadName`. **Control flow:** init sets termination state to already terminated so joining a never-started thread works; start clears that state and calls `kthread_run`; join waits on `isSelfTerminatedChangeCond`; self-terminate sets `shallSelfTerminate` and broadcasts; the static runner calls the routine then marks self-terminated. Sleep first uses interruptible state and then killable state for remaining timeout unless fatal signal is pending. **State/persistence:** thread state is volatile and synchronized by `selfTerminateMutex`. **Dependencies/integration:** used by internal kernel-client service threads. **Risks/tests:** `Thread_start` does not reset `isSelfTerminated` if `kthread_run` returns an error pointer, which can affect joins; tests should cover failed start, timed join, self-terminate wake, and name truncation.

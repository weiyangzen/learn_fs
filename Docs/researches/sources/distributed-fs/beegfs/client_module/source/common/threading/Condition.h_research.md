## sources/distributed-fs/beegfs/client_module/source/common/threading/Condition.h

**Purpose:** Implements a condition-variable-like wrapper around Linux wait queues and BeeGFS mutexes. **APIs/types:** `Condition`, `cond_wait_res_t`, init, uninterruptible wait, killable wait, timed uninterruptible wait, timed interruptible wait, broadcast, and signal. **Control flow:** wait helpers add a wait entry, set task state, unlock the supplied mutex, schedule or schedule_timeout, relock, remove the wait entry, and set task running. Return values distinguish timeout, success, and signal where supported. **State/persistence:** wait queue state is in-memory synchronization only. **Dependencies/integration:** used by node heartbeats, connection pools, and thread termination. **Risks/tests:** callers must always test predicates in loops because wakeups are not tied to a condition internally; tests should cover signal interruption, timeout conversion, and mutex re-locking after wake.

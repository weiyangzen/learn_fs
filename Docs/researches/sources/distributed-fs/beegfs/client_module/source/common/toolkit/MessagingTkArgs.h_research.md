## sources/distributed-fs/beegfs/client_module/source/common/toolkit/MessagingTkArgs.h

**Purpose:** Defines argument containers and flags for `MessagingTk` RPC calls. **APIs/types:** request-response flags for target-state sleep, log-suppression flags, `RRPeer` target/group helpers, `RequestResponseNode`, `MessagingTkBufType`, and `RequestResponseArgs` with prepare/free helpers. **Control flow/state:** `RequestResponseArgs_prepare` sets default single retry, buffer-store response allocation, expected response type, and clears outputs/log flags. `RequestResponseArgs_freeRespBuffers` frees a deserialized response and returns the response buffer either to `NoAllocBufferStore` or kmalloc depending on `respBufType`. **Dependencies/integration:** used by all messaging call paths, target/mirror routing, and no-alloc buffer store management. **Risks/tests:** buffer type must match allocation origin or memory corruption/leaks result; tests should cover cleanup after success and after partial allocation/deserialization failures.

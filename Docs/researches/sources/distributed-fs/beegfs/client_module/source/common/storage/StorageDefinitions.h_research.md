## sources/distributed-fs/beegfs/client_module/source/common/storage/StorageDefinitions.h

**Purpose:** Centralizes protocol/shared constants for open flags, setattr flags, entry locks, directory entry types, stat hints, lock request types, settable attributes, and data-state bit packing. **APIs/types:** defines `OPENFILE_ACCESS_*`, `SETATTR_CHANGE_*`, `ENTRYLOCKTYPE_*`, `DirEntryType` and test macros, `EntryLockRequestType`, `SettableFileAttribs`, `DataState`, `ACCESS_FLAGS_MASK`, `DATA_STATE_MASK`, and shift constants. **Control flow/state:** no functions; constants are consumed by messages, metadata operations, locking, and stat conversion. **Dependencies/integration:** comments explicitly require synchronization with common/server headers, including `FileInodeStorageData.h` for access/data-state packing. **Risks/tests:** numeric drift breaks wire/protocol compatibility; tests should compile/assert key enum and mask values against generated/common references.

## sources/distributed-fs/beegfs/client_module/source/common/storage/Path.h

**Purpose:** Defines an in-memory parsed path as a list of string components plus an absolute-path flag. **APIs/types:** `Path_init`, `Path_initFromString`, `Path_uninit`, `Path_parseStr`, `Path_isPathStrAbsolute`, component accessors, `Path_getPathAsStrCopy`, and absolute flag getters/setters. **Control flow:** parsing delegates to `StringTk_explode` on `/`; string reconstruction counts total size, prefixes `/` for absolute paths, joins components with slashes, and omits a trailing slash by placing the final NUL over the last separator. **State/persistence:** owns a `StrCpyList` of copied elements and returns newly allocated path strings to callers. **Dependencies/integration:** used by metadata/path operations and string-list toolkit. **Risks/tests:** empty paths and repeated slashes depend on `StringTk_explode` behavior; tests should cover absolute root, relative paths, empty component lists, and caller freeing reconstructed strings.

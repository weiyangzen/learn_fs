## sources/distributed-fs/beegfs/client_module/source/common/nodes/NodeTree.c

**Purpose:** Implements an rb-tree keyed by numeric node ID for `Node*` lookup and ordered traversal. **APIs/functions:** `NodeTree_init`, `NodeTree_uninit`, `NodeTree_find`, `NodeTree_getNext`, `NodeTree_insert`, and `NodeTree_erase`. **Control flow:** insert walks the rb-tree by `NumNodeID.value`, rejects duplicate IDs, links the node, colors the tree, and increments size; erase finds by ID, removes from rb-tree, decrements size, and `Node_put`s; uninit postorder-walks all entries and drops refs. **State/persistence:** volatile in-memory index with no internal locking; size is maintained alongside the rb-root. **Dependencies/integration:** uses embedded `Node._nodeTree.rbTreeElement`, Linux rb-tree APIs, and node krefs. **Risks/tests:** callers must hold any external store lock and have taken a ref before insert if the tree owns one; tests should cover duplicate insert, erase missing/present, ordered next traversal, and uninit ref release.

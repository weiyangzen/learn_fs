# sources/distributed-fs/openafs/src/WINNT/afsd/cm_dns_private.h

This private header supports the non-`DNSAPI_ENV` manual DNS client in `cm_dns.c`. It defines socket aliases for kernel versus user builds, packet buffer size, AFS server list limits, DNS packet header structures, query-tail structures, resource-record header structures, numeric DNS RR types/classes, and helper prototypes for QNAME encoding and parsing. These structures model RFC 1034/1035 packet layouts closely enough for AFSDB and A record lookup in legacy Windows environments.

Key types are `DNS_HDR`, `DNS_QTAIL`, `DNS_RR_HDR`, `DNS_AFSDB_RR_HDR`, and `DNS_A_RR_HDR`, each with pointer typedefs used by packet parser code. Constants include `BUFSIZE` at 2048 bytes, `MAX_AFS_SRVS` at 20, `DNS_FLAG_RD` for recursive queries, common RR types (`A`, `CNAME`, `MX`, `AFSDB`, etc.), and IN/CS/CH/HS/wildcard classes. `AFS_SRV_LIST` is a simple count plus hostname array for legacy service lists, though the current code fills caller arrays directly.

The control-flow role is purely structural: `send_DNS_AFSDB_Query` and `send_DNS_Addr_Query` cast the raw buffer to these headers, `putQName` writes encoded names, `skipRRQName` advances across compressed or uncompressed names, and `processReplyBuffer_*` casts answer sections to the RR header types to extract class, TTL, preference, hostnames, and IPv4 addresses. The header also hardcodes `DNS_A_RR_HDR_LEN` as 10 rather than using `sizeof`, acknowledging packet packing/alignment mismatch.

There is no persistent state. Dependencies are C networking types, stdio/string headers, and the manual parser in `cm_dns.c`; modern DNS API builds largely bypass this header except for include availability. Risks include C structure padding if used incorrectly, insufficient bounds checking in callers, only partial DNS compression handling, and assumptions about IPv4-only records. Test signals are legacy builds that disable `DNSAPI_ENV`, manual AFSDB query parsing, compressed-name responses, and A record extraction from packets.

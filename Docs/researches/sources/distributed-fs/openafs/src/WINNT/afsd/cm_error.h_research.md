# sources/distributed-fs/openafs/src/WINNT/afsd/cm_error.h

This header defines the Windows cache manager's internal `CM_ERROR_*` code range. `CM_ERROR_BASE` is `0x66543200`, and the file assigns stable numeric offsets for cache-manager conditions that are not represented directly by platform errors or raw Rx/AFS protocol errors. These codes are consumed throughout `afsd` by connection analysis, SMB/redirector mapping, ioctl handling, buffer store/fetch logic, directory logic, DNS fallback, and user-visible status conversion.

The error set covers object discovery (`NOSUCHCELL`, `NOSUCHVOLUME`, `NOSUCHFILE`, `NOSUCHPATH`, `PATH_NOT_COVERED`, `NOT_A_DFSLINK`), retry and server state (`TIMEDOUT`, `RETRY`, `ALLBUSY`, `ALLOFFLINE`, `ALLDOWN`, `EMPTY`), authorization/token failures (`NOACCESS`, `NOMORETOKENS`, `BADPASSWORD`, `BADLOGONTYPE`, `GSSCONTINUE`), filesystem semantics (`TOOBIG`, `EXISTS`, `CROSSDEVLINK`, `NOTDIR`, `ISDIR`, `READONLY`, `QUOTA`, `SPACE`, `NOTEMPTY`), SMB/RPC integration (`BADSMB`, `BADTID`, `NOIPC`, `TIDIPC`, `RPC_MOREDATA`), filename/path interpretation (`BADNTFILENAME`, `AMBIGUOUS_FILENAME`, `INEXACT_MATCH`, `TOO_MANY_SYMLINKS`), byte-range and sharing behavior (`LOCK_CONFLICT`, `SHARING_VIOLATION`, `RANGE_NOT_LOCKED`, `LOCK_NOT_GRANTED`), cache/buffer state (`TOOFEWBUFS`, `TOOMANYBUFS`, `NOTINCACHE`, `BUFFERTOOSMALL`, `BUFFER_OVERFLOW`), and protocol/data integrity (`INVAL_NET_RESP`, `BADFORMAT`, `BULKSTAT_FAILURE`).

There is no control flow or persisted state in this file, but the numeric assignments are persistent ABI within the client: logs, error mappers, retry policy, and callers switch on these constants. Integration points include `cm_MapRPCError`, `smb_MapNTError`, `cm_Analyze`, background daemon retry lists, buffer error marking, and directory/cache lookup special cases. Risks include changing numeric values, adding duplicates, or omitting new codes from mapping and retry switch statements. Test signals are compile-time switch coverage, correct NT/SMB/POSIX mapping, retry classification for transient codes, and log readability through `cm_conn` error string conversion.

# sources/distributed-fs/openafs/src/WINNT/afssvrcpa/resource.h

## Purpose
Defines resource IDs for the OpenAFS server Control Panel applet.

## Important APIs, Types, And Functions
String IDs cover icon-load error, title, execution error, and app name; `IDI_AFSD` identifies the icon.

## Control Flow
No runtime flow.

## State And Persistence
No state declared.

## Dependencies And Integration Points
Consumed by CPL implementation and resource/localization scripts.

## Risks And Edge Cases
IDs start at zero, so resource tooling/localization must match exactly.

## Test Signals
Resource compile and runtime string/icon load.

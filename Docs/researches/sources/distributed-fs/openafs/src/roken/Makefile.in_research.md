# sources/distributed-fs/openafs/src/roken/Makefile.in

Purpose: builds OpenAFS' bundled `librokenafs` portability library from selected Heimdal roken sources plus configured replacement objects.

Important APIs/types/functions: make targets `all`, `buildtools`, `install`, `dest`, `clean`, `librokenafs.la`, `librokenafs.a`, generated `roken.h`, installed headers `base64.h`, `roken.h`, and `roken-common.h`; object list `LT_objs`; upstream source root `external/heimdal/roken`.

Control flow: includes OpenAFS config/libtool/pthread make fragments, assembles static and optional shared libraries, installs headers into `TOP_INCDIR`, and compiles upstream sources with explicit rules because they live outside this directory. `roken.h` is generated by concatenating local prelude, upstream template, and local postlude.

State/persistence: outputs libtool objects, `librokenafs.a`, optional `librokenafs` shared library, generated `err.h` and `roken.h`, and installed copies under top-level include/library directories or install destinations.

Dependencies/integration: consumes `ROKEN_LTLIBOBJS`, `LT_CCRULE`, libtool wrappers, and Heimdal upstream roken files. It feeds OpenAFS userspace portability needs.

Risks: explicit source rules can go stale when upstream roken adds replacements; generated header ordering is critical; shared-library install removes `.la` files deliberately; `CFLAGS_NOERROR` for `snprintf` masks warnings. Test signals are successful buildtools/all/install targets and consumers compiling against generated `roken.h`.

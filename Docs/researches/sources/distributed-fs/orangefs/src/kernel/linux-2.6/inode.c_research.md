# sources/distributed-fs/orangefs/src/kernel/linux-2.6/inode.c

Purpose: Implements OrangeFS/PVFS2 inode and address-space operations: page reads, optional readpages/direct-IO stubs, invalidate/release page hooks, truncate/setattr/getattr, file inode operation tables, and inode-cache lookup/initialization by PVFS object handle.

Important APIs and functions: `pvfs2_address_operations` exports `.readpage`, optional `.readpages`, `.invalidatepage`, `.releasepage`, and `.direct_IO`. `read_one_page`, `pvfs2_readpage`, and `pvfs2_readpages` back pagecache reads through `pvfs2_inode_read`. `pvfs2_truncate`, `pvfs2_setattr`, `pvfs2_getattr`, `pvfs2_getattr_lite`, and `convert_to_pvfs2_mask` map VFS metadata operations to OrangeFS client operations. `pvfs2_file_inode_operations` provides file inode operations and xattr/ACL hooks. `pvfs2_handle_hash`, `pvfs2_set_inode`, `pvfs2_test_inode`, `pvfs2_iget_common`, and `pvfs2_get_custom_inode_common` control inode identity, cache lookup, and operation-table assignment.

Control flow: Page reads map the page, issue `pvfs2_inode_read` at the page offset, zero any unread part, flush dcache, set uptodate or error, unmap, and unlock. Readpages iterates the supplied list, adds pages to the cache, and invokes `read_one_page`. Setattr first runs VFS permission/size checks, updates local inode fields through the kernel helper appropriate to the target version, adjusts ctime/mtime for truncate semantics, calls `pvfs2_inode_setattr`, and performs ACL chmod if needed. Getattr propagates mount `noatime`/`nodiratime` flags, refreshes all attributes via `pvfs2_inode_getattr`, fills `kstat`, and marks bad inodes on non-interrupt failures. `pvfs2_iget_common` uses `iget5_locked`/`iget4_locked` when available so the inode cache is keyed by PVFS handle+fsid rather than only by a potentially colliding scalar inode number; new unlocked inodes are read from OrangeFS before use. `pvfs2_get_custom_inode_common` obtains an inode, initializes ownership/times/block fields, attaches file/dir/symlink operation tables, and initializes ACLs for newly created objects.

State and persistence: In-memory inode state mirrors persistent OrangeFS object attributes. Size, mode, timestamps, owner/group, block size, rdev, mapping operations, PVFS handle/fsid private data, and ACL state are initialized or refreshed here. Persistence occurs through `pvfs2_inode_setattr`, `pvfs2_inode_getattr`, and `pvfs2_truncate_inode`; dirty timestamps are coordinated with code in file and directory operations. `pvfs2_backing_dev_info` advertises no dirty accounting/writeback, matching the module's explicit client-core I/O model.

Dependencies and integration points: Depends on Linux pagecache/address-space APIs, `generic_fillattr`, `setattr_copy`/`inode_setattr`, truncate helpers, `iget*` APIs, xattr/ACL hooks, and backing-device interfaces. OrangeFS dependencies include `pvfs2_inode_read`, `pvfs2_inode_getattr`, `pvfs2_inode_setattr`, `pvfs2_truncate_inode`, `copy_attributes_to_inode` indirectly through lookup paths, `PVFS2_I`, `pvfs2_inode_initialize`, handle conversion helpers, and file/dir/symlink operation tables from neighboring modules.

Risks: Direct I/O is advertised through an address-space hook but always returns `-EINVAL`; this may only exist to let the kernel accept `O_DIRECT`, but callers expecting actual direct-IO semantics will fail. Readpages ignores individual read errors and returns 0 after processing the list. The fallback non-`iget4/5` branch appears stale: `pvfs2_khandle_to_ino(ref->khandle)` passes a value where the header expects a pointer and lacks a visible semicolon. `pvfs2_get_custom_inode_common` returns `inode` after the `error:` label without always dropping a partially initialized unsupported-mode inode. Debug handle strings are allocated without consistent NULL checks. Marking bad inodes on getattr failures is intentionally avoided for `-EINTR` but aggressive for other transient-looking errors.

Test signals: Test page reads for full, short, EOF, and error pages; readpages list handling; mmap-triggered faults; invalidate/release hooks; setattr size changes, truncates, chmod with ACLs, and timestamp edge cases; getattr with mount noatime/nodiratime propagation and `-EINTR`; inode-cache collisions across different handles with identical scalar hashes; creation of regular files, directories, and symlinks through `pvfs2_get_custom_inode_common`; unsupported mode handling; and builds across all `iget*`, truncate, invalidatepage, xattr, and ACL feature macros.

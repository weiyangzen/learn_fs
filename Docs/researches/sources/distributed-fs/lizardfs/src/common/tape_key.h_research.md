# sources/distributed-fs/lizardfs/src/common/tape_key.h

Purpose: defines a serializable key identifying a tape copy by file identity and version-like attributes. Important type/API: `TapeKey` with `uint32_t inode`, `uint32_t mtime`, and `uint64_t fileLength`, generated by `LIZARDFS_DEFINE_SERIALIZABLE_CLASS`. Control flow: macro-generated methods serialize fields in declared order. State/persistence: field tuple can be used as a persistent or wire key for tape operations. Dependencies: `serialization_macros.h`. Integration points: tape server/master lookup and copy tracking. Risks: 32-bit `mtime` has long-term range limits; schema changes affect key compatibility. Test signals: no direct tests in this subset.

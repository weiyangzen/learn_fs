# sources/distributed-fs/lizardfs/src/common/ring_buffer_unittest.cc

Purpose: tests the basic FIFO behavior of `RingBuffer`. Important APIs/functions: `RingBuffer<int, 7>`, `empty`, `full`, `push_back`, `back`, `size`, `front`, and `pop_front`. Control flow: the test fills a seven-element ring, checks each pushed value becomes the back and size grows, verifies full state, pops all values from the front in original order, and verifies empty state. State/persistence: no persistent state; single local ring fixture. Dependencies: GoogleTest and `ring_buffer.h`. Integration points: documents expected semantics for bounded queue users. Risks: does not exercise wraparound with interleaved push/pop after partial draining, `operator[]`, move-only types, or assertion failure paths. Test signals: minimal but useful smoke coverage for capacity and FIFO order.

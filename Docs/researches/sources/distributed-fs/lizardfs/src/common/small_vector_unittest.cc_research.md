# sources/distributed-fs/lizardfs/src/common/small_vector_unittest.cc

Purpose: validates `small_vector` behaves like `std::vector` for representative operations. Important test cases: `GeneralBehaviour`, `InsertTest`, `EraseTest`, `IteratorTest`, and `InitializerList`. Control flow: constructs small and heap-spilling vectors, copies/moves them, inserts ranges and single elements, erases elements/ranges, checks random-access iterator behavior, and initializes nested small vectors. State/persistence: local in-memory containers only. Dependencies: GoogleTest, `small_vector.h`, STL algorithms/numeric. Integration points: regression coverage for a utility used in performance-sensitive common code. Risks: does not test allocator alignment, swap, shrink-to-fit, exception safety, non-trivial destructors under all move paths, or serialization integration. Test signals: good API compatibility smoke coverage.

# sources/distributed-fs/lizardfs/src/common/serialization_unittest.cc

Purpose: exercises core `serialization.h` round trips for common types and containers. Important test cases: strings, `std::vector<uint32_t>`, `std::vector<std::string>`, nested map/map/set, custom allocator vectors, unique pointers, arrays, sets, maps, and rejection of deserialization into a non-empty string. Control flow: most tests call shared `serializeTest` helpers; specialized tests manually serialize, deserialize, and assert values or exceptions. State/persistence: only local byte buffers; confirms stable in-memory binary layout behavior. Dependencies: `gtest`, `unittests/serialization.h`, `serialization.h`. Integration points: provides regression coverage for a framework used by packet, metadata, and ACL code. Risks: does not cover malformed size caps, unterminated strings, invalid booleans, duplicate map keys, or `small_vector`/`compact_vector` in this file. Test signals: useful baseline round-trip coverage with some precondition checking.

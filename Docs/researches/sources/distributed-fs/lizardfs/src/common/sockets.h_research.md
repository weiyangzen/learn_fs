# sources/distributed-fs/lizardfs/src/common/sockets.h

Purpose: declares the common socket abstraction API and portable TCP error macros. Important APIs: `socketinit`, `socketrelease`, TCP helpers (`tcpsocket`, `tcpresolve`, `tcpnonblock`, bind/connect/listen/accept/poll/read/write/close functions), vector and single `tcppoll`, and UDP helpers. Control flow: callers use C-style functions around native socket descriptors, with return codes and `tcpgetlasterror`/`tcpsetlasterror` for error reporting. State/persistence: no C++ object ownership; descriptors are caller-owned. Dependencies: platform socket headers and `pollfd` definitions. Integration points: low-level network foundation for RPC, chunk I/O, tests, and servers. Risks: API is broad and C-style, making ownership and timeout semantics caller responsibility; macros map only selected errors; IPv6 is not represented. Test signals: no direct header tests.

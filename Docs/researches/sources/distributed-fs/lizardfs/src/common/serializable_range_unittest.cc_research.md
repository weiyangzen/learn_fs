# sources/distributed-fs/lizardfs/src/common/serializable_range_unittest.cc

Purpose: validates that `SerializableRange` serializes identically to a vector. Important APIs/functions: `makeSerializableRange`, `serialize`, and GoogleTest expectations comparing byte buffers. Control flow: creates a vector of strings, serializes equivalent full ranges and subranges, and compares each result to serialization of an explicit vector containing the same elements. State/persistence: no persistent state; tests byte-vector outputs. Dependencies: `serializable_range.h`, serialization framework, `gtest`. Integration points: protects packet-building helpers that rely on range serialization compatibility. Risks: only vector iterators and strings are covered; no invalid iterator/lifetime cases or non-random-access ranges are tested. Test signals: good compatibility signal for the intended vector-subrange use case.

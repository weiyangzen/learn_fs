# sources/distributed-fs/lizardfs/src/common/serialization_macros_unittest.cc

Purpose: tests serialization macro generation, macro counting, packet helpers, and enum bounds. Important APIs/types: static asserts for `MORE_THEN_ONE_ARG` and `COUNT_ARGS`, generated `SomeClass`, generated `Class`, `LIZARDFS_DEFINE_PACKET_VERSION`, `LIZARDFS_DEFINE_PACKET_SERIALIZATION`, and `LIZARDFS_DEFINE_SERIALIZABLE_ENUM_CLASS`. Control flow: class tests instantiate generated constructors and serialize/deserialize a structured object; packet tests serialize a non-empty packet, verify/remove the header, and deserialize body fields, plus an empty packet case; enum tests round-trip valid values and reject an out-of-range byte. State/persistence: validates byte-level packet and object serialization contracts but writes no persistent data. Dependencies: `gtest`, `moosefs_string`, test packet helpers, protocol constants, in/out pair helpers. Integration points: protects macro APIs used throughout protocol and metadata definitions. Risks: does not test maximum arity, zero-argument failure modes, or schema evolution; generated equality for the sample omits string/vector fields, relying on in/out helper behavior for full verification. Test signals: strong for representative macro use cases.

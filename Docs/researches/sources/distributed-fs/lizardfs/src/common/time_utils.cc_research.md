# sources/distributed-fs/lizardfs/src/common/time_utils.cc

Purpose: implements monotonic timing utilities and timeout calculations. Important functions/classes: fallback `SteadyClock::now`, `Timer` constructor/reset/elapsed/lap methods, integer duration helpers, and `Timeout` deadline/remaining/expired methods. Control flow: `Timer` records a start time from a steady clock; elapsed and lap compute differences, with lap resetting the start; `Timeout` stores a duration, clamps remaining time to zero once elapsed exceeds timeout, and treats zero remaining as expired. State/persistence: state is only `Timer::startTime_` and `Timeout::timeout_`; no persistence. Dependencies: `<chrono>`, optional `clock_gettime(CLOCK_MONOTONIC)`, `platform.h`. Integration points: network timeouts, token bucket, write executor response timers. Risks: integer casts truncate fractional units, fallback requires `clock_gettime`, and `Timeout::expired` becomes true for zero-duration timeouts immediately. Test signals: `time_utils_unittest.cc` checks steady arithmetic and approximate elapsed/remaining values.

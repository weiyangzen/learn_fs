# sources/distributed-fs/lizardfs/src/common/vector_range_unittest.cc

Purpose: tests mutable and const `vector_range` behavior. Important tests: `BasicOperations`, `Assign`, and `ConstVectorRange`. Control flow: creates ranges over `std::vector` and `small_vector`, copies/moves range wrappers, verifies iteration against underlying data, mutates a range through assignment/push/pop/erase/clear/insert, checks underlying vector restoration, validates assignment size synchronization, and reads a const range. State/persistence: local vectors and external size variables only. Dependencies: GoogleTest, `small_vector.h`, `vector_range.h`. Integration points: coverage for code that treats vector subranges as first-class containers. Risks: does not test invalid offsets, assignment from a full vector object, range invalidation after outside insert/erase, or exception safety. Test signals: good coverage for common mutable subrange operations.

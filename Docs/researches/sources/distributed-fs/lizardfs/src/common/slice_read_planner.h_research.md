# sources/distributed-fs/lizardfs/src/common/slice_read_planner.h

Purpose: declares `SliceReadPlanner`, the factory/scheduler for slice read plans. Important APIs/types: `PartIndexContainer`, `ScoreContainer`, constructor with `bandwidth_overuse`, `prepare`, `setScores`, `isReadingPossible`, and `buildPlanFor`. Control flow: caller supplies requested slice parts and available chunk part types, optionally scores servers/parts, checks possible read, then builds a concrete standard/XOR/EC `ReadPlan`. State/persistence: stores current slice type, requested parts, weighted available parts, scores, overuse ratio, flags, and part-index mapping. Dependencies: `flat_map`, `goal.h`, `slice_read_plan.h`, `xor_read_plan.h`, `ec_read_plan.h`, `small_vector`. Integration points: read path planning before dispatching chunkserver reads. Risks: planner is stateful and not thread-safe, scores must be set before `prepare` to affect sorting, and concrete plan type depends on slice type classification. Test signals: no direct unit test in this subset.

# sources/distributed-fs/lizardfs/src/common/user_groups.h

Purpose: encodes and decodes group-cache identifiers using the high bit of a 32-bit group id. Important APIs/constants: `kSecondaryGroupsBit`, `isGroupCacheId`, `encodeGroupCacheId`, and `decodeGroupCacheId`. Control flow: functions are `constexpr` bit operations: test high bit, set high bit, or clear high bit. State/persistence: encoded values may be persisted or passed through permission/group-cache APIs as tagged IDs. Dependencies: `<cstdint>`, `platform.h`. Integration points: user/group permission caches and ACL checks that distinguish real group IDs from cache handles. Risks: reduces usable raw group id range by one high bit and can collide if real IDs use bit 31; no runtime validation. Test signals: no direct tests in this subset.

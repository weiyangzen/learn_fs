# sources/distributed-fs/lizardfs/src/common/slice_read_plan.h

Purpose: defines the base read plan for reading selected parts from one slice, with post-processing for part alignment. Important APIs/types: `SliceReadPlan`, `RequestedPartInfo`, overrides `isReadingFinished`, `isFinishingPossible`, `postProcessRead`, and `to_string`. Control flow: completion returns true when enough parts for recovery are available or every requested part has arrived; feasibility returns true when enough operations remain for recovery or no unreadable part intersects requested parts; post-processing zero-pads each requested part to `buffer_part_size`. State/persistence: plan state includes `slice_type`, requested part metadata, inherited read operations/buffer pointers from `ReadPlan`, and buffer part size; no disk persistence. Dependencies: `read_plan.h`, `slice_traits.h`, `small_vector`. Integration points: produced by `SliceReadPlanner` and specialized by XOR/EC plan subclasses. Risks: assumes available/unreadable parts have correct slice type and may assert; buffer pointer invariants are asserted but not runtime-checked in release builds. Test signals: no direct unit test in this subset.

# sources/distributed-fs/lizardfs/src/common/serializable_range.h

Purpose: wraps an iterator range so it can be serialized like a vector without copying into a temporary container. Important APIs/types: `SerializableRange<Iterator>`, `makeSerializableRange(const Range&)`, and `makeSerializableRange(begin,end)`. Control flow: `serializedSize` writes the element count plus each element size; `serialize` writes a `uint32_t` count followed by serialized elements in iterator order. State/persistence: holds begin/end iterators by value; serialized output matches vector layout used by `serialization.h`. Dependencies: `serialization.h`, `iterator`, and `platform.h`. Integration points: efficient packet or metadata serialization of subranges. Risks: no deserialization counterpart, iterator category must support `std::distance` semantics, and callers must keep the underlying range alive and unchanged during serialization. Test signals: `serializable_range_unittest.cc` compares output with equivalent vectors for full and partial ranges.

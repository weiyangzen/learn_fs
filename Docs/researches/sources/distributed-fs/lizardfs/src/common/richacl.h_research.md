# sources/distributed-fs/lizardfs/src/common/richacl.h

Purpose: declares the `RichACL` model used to represent NFSv4/RichACL permissions, POSIX-derived file masks, inheritance flags, and ACE lists. Important APIs/types: `RichACL::Ace` contains compact bitfield `type`, `flags`, `mask`, and `id`; top-level methods expose mode conversion, permission checks, mask application, POSIX ACL conversion, inheritance, string conversion, and serialization through `LIZARDFS_DEFINE_SERIALIZE_METHODS`. Control flow: callers build or deserialize an ACL, optionally mutate masks or ACEs, then use `checkPermission`, conversion helpers, or inheritance helpers. State/persistence: persistent state is owner/group/other masks, ACL flags, and `ace_list_`; the serialized wire/storage order is fixed by the macro. Dependencies: `AccessControlList`, `serialization_macros.h`, `sys/stat.h`, and exception support. Integration points: used by ACL xattr converters, POSIX ACL translation, string parsing, metadata serialization, and permission checks. Risks: bitfield widths silently truncate unsupported flags/masks, ACE order is semantically significant, and `checkPermission` uses goto labels to model owner/everyone matching. Test signals: direct coverage comes through `richacl_string_unittest.cc`; deeper permission/inheritance behavior depends on tests outside this subset.

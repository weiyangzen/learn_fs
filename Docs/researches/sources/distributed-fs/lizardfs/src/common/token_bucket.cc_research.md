# sources/distributed-fs/lizardfs/src/common/token_bucket.cc

Purpose: implements a simple token bucket rate limiter. Important functions: `reconfigure`, `attempt`, `updateBudget`, `verifyClockSteadiness`, and getters. Control flow: reconfiguration first accrues budget up to the previous settings, then updates rate/ceiling and optionally budget; `attempt` asserts positive cost, updates budget based on elapsed nanoseconds, returns the lesser of requested cost and current budget, and subtracts it. State/persistence: in-memory `rate_`, `budget_`, `budgetCeil_`, and `prevTime_`; no persistence. Dependencies: `time_utils.h`, `massert`, `<algorithm>`. Integration points: throttling logic where resources accrue over time. Risks: no locking, double arithmetic can accumulate rounding error, negative rates/ceilings are not rejected, and `time.count()` is cast through `int64_t` after using a double-duration. Test signals: `token_bucket_unittest.cc` covers initial empty bucket, accrual, ceiling, repeated attempts, reconfiguration, and monotonic clock assertion.

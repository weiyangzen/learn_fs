# sources/distributed-fs/lizardfs/src/common/sockets.cc

Purpose: implements a cross-platform IPv4 TCP/UDP socket helper layer inherited from MooseFS/LizardFS. Important APIs/functions: socket init/release, TCP resolve/bind/connect/listen/accept/address helpers, nonblocking setup, poll/select wrappers, timeout read/write loops, and UDP resolve/listen/read/write helpers. Control flow: address helpers use `getaddrinfo` or numeric fill; connect-with-timeout sets nonblocking mode and waits for `POLLOUT` then checks `SO_ERROR`; `tcptoread`/`tcptowrite` poll repeatedly until requested byte counts complete or timeout/error; poll can map to `select` when configured. State/persistence: no owned state; functions mutate OS socket descriptors and process errno/WSA error state. Dependencies: POSIX/WinSock headers, `poll`, `select`, `fcntl`, `getaddrinfo`. Integration points: `ServerConnection`, `WriteExecutor`, module mocks, network servers, and packet I/O. Risks: IPv4-only `sockaddr_in`, `tcpclose` calls shutdown before close which may report errors on unconnected sockets, UDP read uses uninitialized `templeng` before `recvfrom`, UDP write rejects packets over 512 bytes, and timeout loops reuse the full timeout per poll rather than a global deadline. Test signals: no direct socket unit tests in this subset; exercised indirectly by server connection tests.

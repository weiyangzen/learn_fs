# sources/distributed-fs/lizardfs/src/common/tape_copy_state.h

Purpose: defines the lifecycle enum for tape copies. Important type/API: `TapeCopyState` enum class with values `kInvalid`, `kCreating`, and `kOk`, generated with serialization helpers by `LIZARDFS_DEFINE_SERIALIZABLE_ENUM_CLASS`. Control flow: serialization stores the enum as a `uint8_t`; deserialization rejects numeric values greater than or equal to the value count. State/persistence: the ordinal order is the wire/storage contract. Dependencies: `serialization_macros.h`. Integration points: tape copy metadata, `TapeCopy`, `TapeCopyLocationInfo`, and status APIs. Risks: reordering values breaks compatibility; adding values requires compatibility handling for older readers. Test signals: enum macro behavior is tested generically in `serialization_macros_unittest.cc`, not specifically for this enum.

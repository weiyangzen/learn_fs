# sources/distributed-fs/lizardfs/src/common/server_connection.h

Purpose: declares synchronous server connection abstractions. Important APIs/types: `ServerConnection`, `ReceiveMode`, `kDefaultTimeout`, constructors from host/port or `NetworkAddress`, virtual `sendAndReceive`, static `sendAndReceive` for caller-owned sockets, `setTimeout`, and `KeptAliveServerConnection`. Control flow: users construct a connection, optionally adjust timeout, then send packets and receive typed responses; the kept-alive subclass starts background NOP transmission and overrides send/receive for write synchronization. State/persistence: `ServerConnection` owns a socket descriptor and timeout; subclass owns atomic run flag, mutex, condition variable, and thread. Dependencies: `NetworkAddress`, packet `MessageBuffer`, threading primitives. Integration points: common RPC utility for tests, admin tools, and modules needing direct server communication. Risks: copy semantics are not explicitly deleted, raw fd ownership is manual, and subclass lifetime must stop the background thread before base closes the socket. Test signals: direct tests exercise receive-mode behavior and expected type checks.

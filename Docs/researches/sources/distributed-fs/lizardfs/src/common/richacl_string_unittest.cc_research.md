# sources/distributed-fs/lizardfs/src/common/richacl_string_unittest.cc

Purpose: verifies RichACL textual round trips and parser rejection behavior. Important APIs/types: GoogleTest `TEST(RichACL, CorrectString)` and `TEST(RichACL, IncorrectString)`, `RICHACL_FULL_MASK`, `RichACL::toString`, and `RichACL::fromString`. Control flow: the positive test constructs an ACL with ACL flags, owner/group/other masks, user/group/everyone ACEs, compares the exact canonical string, parses it back, and checks equality; it also checks unsorted mask character input normalizes to canonical order. The negative test iterates malformed strings and expects `FormatException`. State/persistence: no persistent state; builds in-memory ACL fixtures. Dependencies: `gtest`, `richacl.h`. Integration points: guards the human-readable ACL representation used by diagnostics and possible CLI/config surfaces. Risks: only string format is covered, not permission semantics, xattr conversion, or mask-application algorithms; one adjacent string literal in the malformed list is concatenated by C++ and may reduce intended coverage. Test signals: strong for canonical formatting, weak for full RichACL semantics.

# sources/distributed-fs/lizardfs/src/common/tape_copy_location_info.h

Purpose: defines a serializable pair of tape server identity and tape copy state. Important type/API: `TapeCopyLocationInfo` with fields `TapeserverListEntry tapeserver` and `TapeCopyState state`, generated by `LIZARDFS_DEFINE_SERIALIZABLE_CLASS`. Control flow: macro-generated constructors and serialization methods operate in field order. State/persistence: binary layout is tapeserver entry followed by state byte. Dependencies: `serialization_macros.h`, `tape_copy_state.h`, `tapeserver_list_entry.h`. Integration points: responses listing where tape copies live and what state they are in. Risks: schema changes affect wire compatibility; enum bounds validation depends on `TapeCopyState` macro-generated deserializer. Test signals: no direct tests in this subset, macro machinery covered elsewhere.

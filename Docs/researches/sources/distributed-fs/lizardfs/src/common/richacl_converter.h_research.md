# sources/distributed-fs/lizardfs/src/common/richacl_converter.h

Purpose: declares the RichACL xattr conversion namespace and exception classes. Important APIs/types: `ConversionException`, `ExtractionException`, `extractObjectFromNFS`, `extractObjectFromRichACL`, `objectToRichACLXattr`, and `objectToNFSXattr`. Control flow: callers pass raw xattr buffers into extraction functions or a `RichACL` object into object-to-xattr builders; conversion failures are surfaced as LizardFS exceptions. State/persistence: no local state; function contracts define conversion boundaries between persistent xattr bytes and in-memory `RichACL`. Dependencies: `richacl.h`, exception macros, and `platform.h`. Integration points: used wherever ACL xattrs are imported/exported for metadata or client interoperability. Risks: API exposes raw pointers and sizes, so callers must preserve buffer lifetime and correct lengths; namespace lacks comments documenting endian differences, which are implemented in the `.cc`. Test signals: no direct header test, but downstream converter and ACL users should exercise it.

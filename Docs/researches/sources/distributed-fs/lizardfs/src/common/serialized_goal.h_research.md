# sources/distributed-fs/lizardfs/src/common/serialized_goal.h

Purpose: defines a small serializable representation of a storage goal. Important type/API: `SerializedGoal` with fields `uint16_t id`, `std::string name`, and `std::string definition`, generated by `LIZARDFS_DEFINE_SERIALIZABLE_CLASS`. Control flow: macro-generated constructors and serialize/deserialize methods forward fields in declared order. State/persistence: the field order is the binary contract for any packet/storage use of serialized goals. Dependencies: `serialization_macros.h`. Integration points: likely used for goal lists sent between master, clients, or tools. Risks: string sizes rely on global serialization caps; changes to field order or type would break compatibility. Test signals: no direct test in this subset, but macro mechanics are covered by serialization macro tests.

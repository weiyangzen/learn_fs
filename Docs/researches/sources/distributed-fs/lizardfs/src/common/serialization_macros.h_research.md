# sources/distributed-fs/lizardfs/src/common/serialization_macros.h

Purpose: supplies preprocessor helpers that generate serializable structs, enum serializers, and packet serialization namespaces. Important APIs/macros: `LIZARDFS_DEFINE_SERIALIZABLE_CLASS`, `SERIALIZABLE_CLASS_BEGIN/BODY/END`, `LIZARDFS_DEFINE_SERIALIZE_METHODS`, `LIZARDFS_DEFINE_SERIALIZABLE_ENUM_CLASS`, `LIZARDFS_DEFINE_PACKET_SERIALIZATION`, and `LIZARDFS_DEFINE_PACKET_VERSION`. Control flow: generated class bodies create constructors, member declarations, and methods forwarding fields to `serialization.h`; enum deserialization validates numeric values against argument count; packet macros build namespace-scoped `serialize`, `build`, and `deserialize` helpers with packet version checks. State/persistence: generated serialization order is declaration order, making macro argument ordering a storage/wire contract. Dependencies: generated macro arity helpers, `serialization.h`, and packet helper functions provided elsewhere. Integration points: used by small metadata structs, protocol packet definitions, and tests. Risks: maximum supported macro arity is fixed by generated helpers, zero-argument counting is not supported, macro errors are hard to diagnose, and typo `MORE_THEN_ONE_ARG` is part of public macro API. Test signals: `serialization_macros_unittest.cc` validates argument counting, class generation, packet serialization, empty packets, and enum bounds.

# sources/distributed-fs/lizardfs/src/common/special_inode_defs.h

Purpose: defines inode numbers and names reserved for LizardFS virtual/special files. Important constants: `SPECIAL_INODE_BASE`, `SPECIAL_INODE_ROOT`, `SPECIAL_INODE_MASTERINFO`, stats/oplog/history/tweaks/file-by-inode/meta trash/undel/reserved inode IDs, corresponding special file names, and `MAX_REGULAR_INODE`. Control flow: no functions; consumers compare inode numbers or names against these constants. State/persistence: values are part of filesystem-visible compatibility, separating regular inode range from special virtual inode range. Dependencies: `platform.h`. Integration points: metadata server, mount layer, special file handling, and path lookup. Risks: changing constants would break compatibility; macro names have no type safety; root inode is outside the high special range. Test signals: no direct tests in this subset.

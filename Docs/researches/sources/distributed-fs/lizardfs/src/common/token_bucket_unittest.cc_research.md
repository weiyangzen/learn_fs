# sources/distributed-fs/lizardfs/src/common/token_bucket_unittest.cc

Purpose: validates token bucket accrual, ceiling, repeated consumption, reconfiguration, and monotonic-time assertions. Important helpers/tests: `TestCase`, `timepointInc`, `doTests`, `tester`, and tests for empty initial budget, short waits, hitting ceiling, many attempts, changing rate, reducing ceiling, and clock steadiness. Control flow: constructs a bucket at `t0`, configures rate/ceil, advances synthetic timepoints rather than sleeping, and compares exact returned double values. State/persistence: local in-memory bucket state. Dependencies: GoogleTest and `token_bucket.h`. Integration points: regression safety for throttling behavior. Risks: exact floating comparisons work for simple decimal cases but may be brittle for more complex rates; negative rate/ceil cases are not covered. Test signals: strong unit-level coverage for intended behavior.

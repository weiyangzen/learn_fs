# sources/distributed-fs/lizardfs/src/common/richacl_compat.cc

Purpose: implements compatibility transformation that applies RichACL file masks to an ACE list so standard NFSv4 permission evaluation gives the same result as mask-aware RichACL evaluation. Important APIs/functions: `RichACL::applyMasks`, `changeMask`, `moveEveryoneAcesDown`, `propagateEveryone`, `applyMasks2AceList`, `setOtherPermissions`, `setOwnerPermissions`, `isolateOwnerClass`, and `isolateGroupClass`. Control flow: `applyMasks` exits unless `kMasked` is set, moves EVERYONE entries downward, propagates inherited permissions into specific identities, clips allow ACEs by owner/group/other masks, synthesizes explicit allow/deny entries, clears `kWriteThrough`/`kMasked`, and shrinks storage. State/persistence: mutates `ace_list_`, ACE flags, ACE masks, and ACL flags in place; no external persistence except serialized ACL state later. Dependencies: `richacl.h` and assertions. Integration points: called by `objectToNFSXattr` before exporting ACLs as NFS xattrs. Risks: algorithms assume meaningful ACE ordering and often special-case the last EVERYONE ACE; mutation while iterating is subtle; one branch appears to clear `kInheritOnlyAce` from `last_ace.mask` rather than `last_ace.flags`, which deserves review. Test signals: no direct unit test in this subset; string tests do not validate mask compatibility semantics.

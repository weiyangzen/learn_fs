# sources/distributed-fs/lizardfs/src/common/serialization_macros_generate.sh

Purpose: generates `serialization_macros_generated.h` for a configured maximum number of macro parameters. Important behavior: accepts exactly one argument `<max number of parameters to be supported>`, emits recursive `APPLY1_N`, `APPLY2_N`, `VARS_COMMAS_N`, `COUNT_ARGS`, `MORE_THEN_ONE_ARG`, and `PICK_NTH_` macros. Control flow: `set -e` exits on failures, validates argument count, writes header preamble, loops from 1 to `MAX` to generate macro families, then prints a success marker. State/persistence: writes generated header text to stdout; callers redirect output into the header. Dependencies: POSIX shell, `seq`, basename. Integration points: build/maintenance workflow for serialization macro arity. Risks: no atomic output handling inside script, no validation that MAX is numeric, generated API has no zero-argument support, and typo in `MORE_THEN_ONE_ARG` persists for compatibility. Test signals: generated output is indirectly tested by `serialization_macros_unittest.cc`.

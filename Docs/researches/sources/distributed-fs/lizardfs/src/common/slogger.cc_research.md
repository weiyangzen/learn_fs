# sources/distributed-fs/lizardfs/src/common/slogger.cc

Purpose: implements LizardFS logging adapters over spdlog and legacy C syslog-style entry points. Important functions: `log_level_from_syslog`, `lzfs_add_log_file`, `lzfs_add_log_stderr`, `lzfs_add_log_syslog`, `lzfs_set_log_flush_on`, `lzfs_drop_all_logs`, `lzfs_pretty_syslog`, `lzfs_pretty_errlog`, `lzfs_silent_syslog`, and `lzfs_silent_errlog`. Control flow: logger add functions create spdlog rotating file, stderr, or syslog loggers and set patterns/levels; variadic C functions format into fixed buffers and dispatch to every registered spdlog logger. Errlog variants preserve `errno` and append `strerr(errno)`. State/persistence: global spdlog registry stores loggers; rotating file sinks persist log files. Dependencies: spdlog, syslog defs, `mfserr`, `cfg`, errno/stdarg. Integration points: old C-style logging and new C++ `lzfs::log_*` template wrappers. Risks: `log_level_from_syslog` indexes with `min(priority, size)` and can access one past the array for priority >= size; formatted buffers assume non-negative `vsnprintf` length in errlog paths; logger names use paths and may collide. Test signals: no direct logging tests in this subset.

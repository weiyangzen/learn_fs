# sources/distributed-fs/lizardfs/src/common/unique_queue.h

Purpose: provides a thread-safe FIFO queue that stores each element at most once. Important APIs/types: `UniqueQueue<T>::put`, `get`, and `UniqueQueueEmptyException`. Control flow: `put` locks, inserts into a `std::set`, and enqueues the set iterator only if insertion was new; `get` locks, throws if empty, otherwise moves the front element out, pops the iterator queue, erases the set entry, and returns the element. State/persistence: owns a set for uniqueness, a queue of set iterators for FIFO order, and a mutex; no persistence. Dependencies: `set`, `queue`, `mutex`, `Exception`. Integration points: work queues where duplicate pending tasks should collapse. Risks: ordering is insertion FIFO only for unique live elements, `T` must be set-orderable, moving from a `const` set element may copy rather than move for many types, no blocking wait API, and no size/empty methods. Test signals: no direct tests in this subset.

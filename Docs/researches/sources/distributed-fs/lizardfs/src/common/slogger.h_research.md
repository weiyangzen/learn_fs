# sources/distributed-fs/lizardfs/src/common/slogger.h

Purpose: declares modern C++ and legacy C logging APIs. Important APIs/types: `LoggerPtr`, `lzfs::log_level::LogLevel`, templated `lzfs::log`, level-specific `log_trace/debug/info/warn/err/critical`, logger add/drop/flush functions, and extern-C `lzfs_*syslog`/`errlog` wrappers with printf attributes. Control flow: C++ logging snapshots all registered spdlog loggers into a `small_vector` before logging, avoiding old GCC issues with lambdas and parameter packs. State/persistence: logging state lives in spdlog's global registry and configured sinks; header itself is stateless. Dependencies: spdlog sinks, `small_vector`, `syslog_defs`. Integration points: repository-wide logging, C modules, and file/syslog/stderr sink setup. Risks: templated logging fans out to all registered loggers and may be expensive; format string validation depends on spdlog/printf attributes for different APIs; syslog sink is disabled on Windows. Test signals: no direct tests in this subset.

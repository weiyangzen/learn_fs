# sources/distributed-fs/lizardfs/src/common/slice_traits.h

Purpose: provides inline classification and geometry helpers for standard, tape, XOR, and erasure-coded slice/chunk parts. Important APIs/namespaces: `isStandard`, `isTape`, `isXor`, `isEC`, `xors::getSliceType`, `xors::ChunkPartType`, `ec::getSliceType`, `ec::ChunkPartType`, `getNumberOfDataParts`, `getNumberOfParityParts`, `requiredPartsToRecover`, `getDataPartIndex`, `getStripeSize`, `getNumberOfBlocks`, and `chunkLengthToChunkPartLength`. Control flow: type values are interpreted by ranges in `Goal::Slice::Type`; geometry functions derive data/parity counts and per-part block/byte lengths using stripe arithmetic. State/persistence: no state; constants encode supported XOR and EC ranges and become compatibility contract. Dependencies: `chunk_part_type.h`, `goal.h`, `MFSBLOCKSIZE`, `MFSBLOCKSINCHUNK`. Integration points: read planning, chunk layout, EC/XOR recovery, tape/standard classification. Risks: heavy use of asserts for range validation, inline formulas must stay aligned with `Goal::Slice::Type` encoding, and EC2 heuristics are embedded policy. Test signals: no direct unit test in this subset.

# sources/distributed-fs/lizardfs/src/common/ring_buffer.h

Purpose: provides a fixed-capacity circular FIFO-style container with random access by logical offset. Important APIs/types: `RingBuffer<T, Capacity>`, `push_back`, `pop_front`, `front`, `back`, `operator[]`, `size`, `capacity`, `empty`, and `full`. Control flow: the buffer stores `Capacity + 1` elements to distinguish full from empty; `start_` points at the front and `end_` at the next insertion slot; helper functions wrap indices modulo `N`. State/persistence: all state is in the embedded `std::array<T, N>` plus integer cursors; no heap allocation beyond `T` internals and no serialization. Dependencies: `array`, `cassert`, `platform.h`. Integration points: useful for bounded queues in hot paths. Risks: preconditions are enforced only by `assert`, so release builds can overrun logical constraints; capacity is compile-time only; no iterator API or thread safety. Test signals: `ring_buffer_unittest.cc` covers basic fill, full detection, FIFO pop, and empty detection.

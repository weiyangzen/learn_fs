# sources/distributed-fs/lizardfs/src/common/serialization_macros_generated.h

Purpose: generated macro arity support for `serialization_macros.h`. Important APIs/macros: `APPLY1_1` through `APPLY1_20`, `APPLY2_2` through `APPLY2_40`, `VARS_COMMAS_2` through `VARS_COMMAS_40`, `COUNT_ARGS`, `MORE_THEN_ONE_ARG`, and `PICK_NTH_`. Control flow: macro expansion recursively applies one-argument or type/name-pair macros with separators, extracts variable names from type/name lists, and counts supplied arguments by selecting a positional parameter. State/persistence: no runtime state; this file fixes the supported macro arity and generated class field count limit. Dependencies: generated from `serialization_macros_generate.sh` and included by `serialization_macros.h`. Integration points: all macro-generated serializable classes, packet helpers, and enum helpers. Risks: manual edits would desynchronize generator and generated output, no support for empty variadic lists, and exceeding 20 fields or 40 raw macro arguments fails at preprocessing time. Test signals: `serialization_macros_unittest.cc` statically asserts argument counting and exercises generated serializable classes/packets.

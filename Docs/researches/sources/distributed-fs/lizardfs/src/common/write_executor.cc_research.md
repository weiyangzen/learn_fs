# sources/distributed-fs/lizardfs/src/common/write_executor.cc

Purpose: implements the client-side executor for writing data through a chunkserver chain. Important functions: constructor/destructor, `addChunkserverToChain`, `addInitPacket`, `addDataPacket`, `addEndPacket`, `sendData`, `receiveData`, `serverTimedOut`, `increaseUnconfirmedPacketCount`, and `processStatusMessage`. Control flow: construction registers write activity on the head; chain members are added before running; `addInitPacket` sorts chain by chunkserver version and serializes either legacy or current write-init format, then marks the executor running; data packets compute CRC and queue header plus caller-owned data pointer; send drains queued buffers through `MultiBufferWriter`; receive fills `MessageReceiveBuffer`, parses `LIZ_CSTOCL_WRITE_STATUS`, decrements unconfirmed packet count, and throws on unknown or excessive statuses. State/persistence: owns pending packet list, writer, receive buffer, timeout, unconfirmed count, chain metadata, and references stats; data payload memory is not owned. Dependencies: protocol `cltocs`/`cstocl`, CRC, sockets, version constants, request logging, exceptions. Integration points: `mount/chunk_writer` manages executors by fd and consumes statuses. Risks: queued data pointers must remain valid until sent, `sendData` assumes nonblocking socket semantics, timeout resets on any received bytes not necessarily valid status, and destructor unregisters all chain stats. Test signals: no direct unit test in this subset.

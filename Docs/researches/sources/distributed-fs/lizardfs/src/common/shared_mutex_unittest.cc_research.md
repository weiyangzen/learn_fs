# sources/distributed-fs/lizardfs/src/common/shared_mutex_unittest.cc

Purpose: stress-tests reader/writer exclusion for `shared_mutex`. Important APIs: `shared_lock<shared_mutex>` for readers and `std::unique_lock<shared_mutex>` for writers. Control flow: spawns 100 reader threads and 10 writer threads with randomized sleeps; readers increment an atomic reader count and assert no writer is active; writers increment an exclusive count and assert no readers and only one writer. State/persistence: local shared counters only. Dependencies: GoogleTest, threads, atomics, list, `shared_mutex.h`. Integration points: regression signal for code using this mutex in concurrent paths. Risks: randomized timing can be flaky or insufficient to expose rare scheduling bugs; no fairness or starvation assertions. Test signals: useful concurrency smoke test.

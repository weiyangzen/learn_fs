# sources/distributed-fs/lizardfs/src/common/richacl_converter.cc

Purpose: converts `RichACL` objects to and from on-disk RichACL xattr format and NFSv4 ACL xattr format. Important APIs/functions: `extractObjectFromNFS`, `extractObjectFromRichACL`, `objectToRichACLXattr`, `objectToNFSXattr`, plus helpers for padded NFS names, uid/gid lookup, and wrapper structs matching xattr layouts. Control flow: NFS extraction reads an ACE count, parses big-endian packet fields using datapack helpers, maps OWNER/GROUP/EVERYONE names or uid/gid strings into ACE identifiers, then recomputes masks from ACL decisions. RichACL extraction reads little-endian wrapper fields and converts an incompatible special-who flag bit to LizardFS `kSpecialWho`. Export builds either little-endian RichACL wrappers or NFS records after `applyMasks(owner_id)`. State/persistence: produces byte vectors for xattrs and reconstructs transient ACL state; uses platform user/group databases when available. Dependencies: `portable_endian.h`, `datapack.h`, `pwd.h`, `grp.h`, `richacl_converter.h`. Integration points: bridges metadata ACL objects to filesystem xattrs and NFS clients. Risks: C-style casts over unaligned buffers, lookup-dependent uid/gid name conversion, inconsistent use of padded owner length as serialized length in NFS export, and limited validation of ACE type/flags. Test signals: no direct converter test in this subset.

# sources/distributed-fs/lizardfs/src/common/shared_mutex.h

Purpose: implements a pre-C++17 reader/writer mutex and an RAII shared lock. Important APIs/types: `shared_mutex::lock`, `unlock`, `lock_shared`, `unlock_shared`, and template `shared_lock<SharedMutex>`. Control flow: exclusive lock waits until no readers and no exclusive owner; shared locks wait while an exclusive owner exists or any exclusive waiter is queued, giving writers priority; unlock wakes one writer first, otherwise all readers. State/persistence: tracks `shared_count_`, `exclusive_waiting_`, `exclusive_`, mutex, and two condition variables; no persistence. Dependencies: `<mutex>`, `<condition_variable>`. Integration points: code needing `std::shared_mutex`-like behavior on older compilers. Risks: no timed/try locks, no recursive behavior, writer priority can block new readers while writers wait, and `shared_lock` is copyable by default unless compiler-generated copy is avoided by use. Test signals: `shared_mutex_unittest.cc` stress-checks mutual exclusion with reader and writer threads.

# sources/distributed-fs/lizardfs/src/common/richacl_string.cc

Purpose: implements compact textual serialization and parsing for RichACLs and ACEs. Important APIs/functions: `RichACL::toString`, `RichACL::Ace::toString`, `RichACL::fromString`, plus local parsers for ACL flags, ACE flags, masks, types, and identifiers. Control flow: `toString` emits `FLAGS|OWNER|GROUP|OTHER|ACE/...` with masks/flags in canonical table order; parsing walks delimiter-separated fields, accepts unsorted but recognized flag/mask characters, converts `O/G/E/uN/gN` identifiers, and throws `FormatException` on missing fields or unknown symbols. State/persistence: text is a stable diagnostic/config representation of masks, flags, and ACE list; parsing creates a new ACL. Dependencies: `richacl.h`, static lookup arrays derived from RichACL constants. Integration points: tests, debugging, config-like representations, and round-trip validation. Risks: `writeType` appends numeric `type` as a char-like value on unknown types, numeric identifier parsing uses `substr(start, delim)` rather than length but still usually stops at delimiters through `stoull`, and unsupported flags are not preserved. Test signals: `richacl_string_unittest.cc` validates canonical string output, unsorted input normalization, round-trip equality, and malformed input throws.

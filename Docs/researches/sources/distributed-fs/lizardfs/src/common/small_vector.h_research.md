# sources/distributed-fs/lizardfs/src/common/small_vector.h

Purpose: implements a `std::vector`-compatible container with embedded preallocated storage for up to `N` elements. Important types/APIs: `detail::static_preallocator<T,N>` and `small_vector<T,N>` constructors, copy/move assignment, `shrink_to_fit`, `swap`, and inherited vector methods. Control flow: the allocator returns local byte-array storage for allocations `<= N`; `small_vector` reserves `N` on construction, moves heap-backed vectors by base move assignment, and moves local-backed vectors element-by-element. State/persistence: stores vector metadata in the base plus local allocator buffer; no serialization except support in `serialization.h`. Dependencies: STL vector/allocator/array, type traits, assertions. Integration points: hot-path small containers in slice planning, logging fanout, serialization, and flat containers. Risks: local allocator can satisfy only one small allocation at a time and relies on vector allocation behavior; allocator data alignment uses `uint8_t` array and may be insufficient for over-aligned `T`; move/swap assumptions are libstdc++-specific in comments. Test signals: `small_vector_unittest.cc` compares behavior with `std::vector` for construction, move, insert, erase, iterators, and initializer lists.

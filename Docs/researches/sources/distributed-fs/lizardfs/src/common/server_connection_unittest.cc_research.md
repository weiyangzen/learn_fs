# sources/distributed-fs/lizardfs/src/common/server_connection_unittest.cc

Purpose: verifies `ServerConnection` response filtering and packet type validation. Important fixtures/APIs: local `NopResponder` derived from `ModuleMock`, `respondToCurrentClient`, `buildMooseFsPacket`, and `ServerConnection::sendAndReceive`. Control flow: `NopResponder` sends 20 `ANTOAN_NOP` packets then a response whose type is request type plus one. Tests confirm default mode skips NOPs across multiple calls, `kReceiveFirstMessage` fails when the first response is NOP, correct expected type succeeds, and incorrect expected type throws. State/persistence: no persistent state; starts a mock server. Dependencies: GoogleTest, module mock, protocol packet helpers. Integration points: validates synchronous connection behavior used by RPC-style clients. Risks: does not cover timeouts, connection failures, keepalive subclass behavior, partial writes/reads, or socket closure. Test signals: good focused coverage for NOP filtering.

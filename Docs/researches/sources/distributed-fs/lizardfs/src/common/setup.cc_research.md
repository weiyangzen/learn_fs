# sources/distributed-fs/lizardfs/src/common/setup.cc

Purpose: provides process environment initialization and a global verbosity variable. Important APIs/state: `prepareEnvironment()` and `int gVerbosity`. Control flow: `prepareEnvironment` attempts to construct `std::locale("")`; if current locale settings are invalid, it unsets common locale environment variables (`LANG`, `LC_*`, `LANGUAGE`) so later locale use falls back safely. State/persistence: mutates process environment with `unsetenv`; `gVerbosity` is global process state. Dependencies: `<locale>`, `<cstdlib>`, `platform.h`. Integration points: called early by executables to avoid locale initialization failures and to share verbosity level. Risks: environment mutation is process-wide and not thread-safe if called late; invalid locale details are swallowed; no logging of changed variables. Test signals: no direct unit test in this subset.

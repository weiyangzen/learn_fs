# sources/distributed-fs/lizardfs/src/common/vector_range.h

Purpose: exposes a subrange of an underlying vector-like container through a vector-like API, with mutable and const specializations. Important APIs/types: `vector_range<V,S>` constructors, assignment, `assign`, iterators, size/capacity, `resize`, element access, `push_back`, `pop_back`, `insert`, `erase`, `clear`, and const-only specialization for `const V`. Control flow: mutable range operations insert/erase directly in the underlying vector at `[offset_, offset_ + size_)` and update an external size reference; const specialization only exposes read operations and stores size by value. State/persistence: no owned storage; holds a reference to data, fixed offset, and size reference/value. Dependencies: STL algorithms, limits, assertions. Integration points: manipulating variable-length fields embedded inside a larger vector while keeping an external length field synchronized. Risks: offset is fixed and can become invalid if external code mutates the vector before the range; assignment from `const vector_type&` appears to use `x.size_` even though vector has `size()`, suggesting a template path bug; no bounds validation on construction. Test signals: `vector_range_unittest.cc` covers mutable operations, size synchronization, and const range reads.

# sources/distributed-fs/lizardfs/src/common/time_utils.h

Purpose: declares monotonic clock aliases, `Timer`, and `Timeout`. Important APIs/types: `SteadyClock`, `SteadyTimePoint`, `SteadyDuration`, `Timer::reset`, `startTime`, `elapsedTime`, `lap`, integer elapsed/lap accessors, and `Timeout::deadline`, `remainingTime`, integer remaining accessors, `expired`. Control flow: callers instantiate timers or timeouts and query monotonic elapsed/remaining values. State/persistence: in-object timepoint and duration only. Dependencies: `<chrono>`, `<ratio>`, optional custom `SteadyClock` when standard steady clock is unavailable. Integration points: shared timing primitive across networking, rate limiting, and write status timeout logic. Risks: no virtual clock injection for deterministic unit testing; integer helpers may lose precision; thread safety is caller-managed. Test signals: direct coverage in `time_utils_unittest.cc`.

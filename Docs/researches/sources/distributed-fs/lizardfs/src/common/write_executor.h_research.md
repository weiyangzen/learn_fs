# sources/distributed-fs/lizardfs/src/common/write_executor.h

Purpose: declares `WriteExecutor`, the object that queues write-init/data/end packets, sends them to a chain head, and receives write statuses. Important APIs/types: nested `Status`, constructor with chunkserver stats/head fd/chunk identity, deleted copy operations, `addChunkserverToChain`, `addInitPacket`, `addDataPacket`, `addEndPacket`, `sendData`, `receiveData`, `serverTimedOut`, accessors for pending count/server/chunk type/fd. Control flow: callers build the chain and init packet before data packets, repeatedly call `sendData` when fd writable and `receiveData` when readable, and check timeout while unconfirmed packets remain. State/persistence: object owns protocol buffers and socket-facing state but not the socket descriptor or data payloads; updates shared `ChunkserverStats`. Dependencies: `ChunkPartType`, `ChunkTypeWithAddress`, `ChunkserverStats`, `MessageReceiveBuffer`, `MultiBufferWriter`. Integration points: mount write pipeline and chunkserver chain replication. Risks: lifecycle is stateful and assert-enforced, no internal locking, fd ownership is external, and status structure has no validation beyond protocol deserialization. Test signals: no direct tests in this subset.

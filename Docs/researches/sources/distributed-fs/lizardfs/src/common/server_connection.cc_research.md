# sources/distributed-fs/lizardfs/src/common/server_connection.cc

Purpose: implements blocking-with-timeout request/response helpers over LizardFS sockets, plus a keepalive variant that sends NOP packets periodically. Important functions/classes: `sendRequestGeneric`, `receiveRequestGeneric`, `ServerConnection::connect`, static and instance `sendAndReceive`, `KeptAliveServerConnection::sendAndReceive`, destructor, and `startNopThread`. Control flow: send loops poll for writable state and uses `MultiBufferWriter`; receive loops poll for readable state, fills `MessageReceiveBuffer`, optionally discards `ANTOAN_NOP`, validates expected packet type, and returns message body. Constructors resolve/connect nonblocking sockets; keepalive starts a thread that sends `ANTOAN_NOP` every second under a mutex shared with writes. State/persistence: owns `fd_`, timeout, keepalive thread state, condition variable, and mutex; no persistent disk state. Dependencies: socket wrappers, packet helpers, `Timeout`, receive buffer, exceptions. Integration points: clients/tools that perform synchronous master/chunkserver RPCs. Risks: keepalive thread exceptions are not caught, reads are not synchronized with NOP sending except writes are serialized, destructor joins without checking thread start failure, and expected-type mismatch throws generic `Exception`. Test signals: `server_connection_unittest.cc` covers NOP filtering and expected response type validation.

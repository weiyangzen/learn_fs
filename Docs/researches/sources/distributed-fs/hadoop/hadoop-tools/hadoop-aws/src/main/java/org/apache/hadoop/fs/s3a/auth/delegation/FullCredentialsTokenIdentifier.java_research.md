## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/FullCredentialsTokenIdentifier.java

Purpose: concrete token identifier for full-credential delegation tokens. It subclasses `SessionTokenIdentifier` because the serialized payload shape is the same: URI, encryption secrets, and `MarshalledCredentials`; only the token kind differs. Important APIs are the empty service-loader constructor and constructor taking URI, owner, renewer, marshalled credentials, encryption secrets, and origin. Control flow delegates entirely to the superclass with `FULL_TOKEN_KIND`. State and persistence are inherited from `SessionTokenIdentifier`, including writable credential serialization and expiry reporting. Dependencies are `MarshalledCredentials`, Hadoop `Text`, and delegation constants. Integration points are `FullCredentialsTokenBinding.createTokenIdentifier()` and token service-loader decoding. Risks are mostly class/kind correctness: subclasses must have a distinct kind, and using full credentials increases secret exposure compared with session tokens. Test signal is the full-token kind and round-trip coverage in `TestS3ADelegationTokenSupport`.

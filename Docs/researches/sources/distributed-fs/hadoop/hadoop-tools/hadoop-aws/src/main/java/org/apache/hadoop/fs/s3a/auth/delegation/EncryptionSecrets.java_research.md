## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/EncryptionSecrets.java

Purpose: serializable/writable container for encryption algorithm, key, and KMS encryption context propagated inside S3A delegation tokens. Important APIs are constructors, `write()`, `readFields()`, Java `readObject()`, `getEncryptionAlgorithm()`, `getEncryptionKey()`, `getEncryptionContext()`, presence predicates, `getEncryptionMethod()`, `equals()`, `hashCode()`, and log-safe `toString()`. Control flow writes a `serialVersionUID` gate then three strings; read validates version and max lengths for algorithm/key, reconstructing transient `S3AEncryptionMethods` via `init()`. State persists in token bytes and Java serialization; the enum method is transient and rebuilt. Dependencies are Hadoop `Writable`, `Text`, `LongWritable`, `S3AEncryptionMethods`, and commons `StringUtils`; it avoids AWS SDK classes. Integration points are `AbstractS3ATokenIdentifier`, `EncryptionSecretOperations`, and S3A encryption request setup. Risks include sensitive key material in serialized tokens, wire compatibility requiring version changes for incompatible formats, unlimited context read compared with bounded key fields, and invalid algorithm names causing IO failures. Tests cover round trips and delegation-token encryption propagation.

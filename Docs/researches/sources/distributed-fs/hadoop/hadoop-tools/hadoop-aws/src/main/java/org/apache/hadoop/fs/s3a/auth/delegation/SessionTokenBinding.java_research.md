## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/SessionTokenBinding.java

Purpose: binding that either mints AWS STS session credentials for delegation tokens or forwards existing parent session credentials. Important APIs are lifecycle methods, `deployUnbonded()`, `bindToTokenIdentifier()`, `getDescription()`, `getUserAgentField()`, `prepareSTSClient()`, `getDuration()`, `createTokenIdentifier()`, `createEmptyIdentifier()`, and protected state accessors used by `RoleTokenBinding`. Control flow starts by reading duration/endpoint/region and building the parent AWS provider chain. `maybeInitSTS()` runs once: resolve parent credentials, detect session credentials, and either build an STS client or mark forwarding mode. New token creation requests STS session credentials when possible; otherwise it logs once and marshals current session credentials. Bound mode validates exact identifier class and exposes a session-only `MarshalledCredentialProvider`. State includes invoker, one-time STS init flag, optional STS client, duration, endpoint/region, parent auth chain, forward warning flag, expiration, and optional token identifier. Dependencies include AWS credentials/STS SDK, S3A retry/invoker/provider factory, marshalled credentials, and delegation constants. Risks include one-shot STS init after transient failures, parent chain changing from session to non-session, unknown duration for forwarded credentials, and close ordering. Test signals include `ITestSessionDelegationTokens`, `ITestSessionDelegationInFilesystem`, load tests, and delegated MR tests.

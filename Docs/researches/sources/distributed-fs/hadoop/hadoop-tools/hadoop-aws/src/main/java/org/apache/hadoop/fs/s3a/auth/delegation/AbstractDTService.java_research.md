## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/AbstractDTService.java

Purpose: common Hadoop `AbstractService` base for S3A delegation-token services and bindings. Important APIs are `bindToFileSystem()`, getters for canonical URI, owner, store context, policy provider, `requireServiceState()`, `requireServiceStarted()`, and `serviceInit()`. Control flow enforces lifecycle ordering: construct, bind to filesystem while not initialized, initialize, start, operate, stop. Binding captures the canonical S3A URI, owner UGI from `StoreContext`, callback `DelegationOperations`, and store context before normal service initialization. State is in memory only and is intentionally immutable after first bind; `serviceInit()` fails if no canonical URI was supplied. Dependencies are Hadoop service lifecycle, UGI, `StoreContext`, and preconditions. Integration points are `S3ADelegationTokens` and every concrete `AbstractDelegationTokenBinding`. Risks include misuse of lifecycle order, double binding, and invoking getters before bind/init. Test signals are delegation integration helpers that instantiate token support and assert double-bind/start behavior.

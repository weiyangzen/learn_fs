## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/DelegationBindingInfo.java

Purpose: tiny value/builder object returned by a token binding after deployment. Important APIs are `getCredentialProviders()` and `withCredentialProviders()`. Control flow is direct: bindings create an instance, attach a non-null `AWSCredentialProviderList`, and `S3ADelegationTokens` later reads it to configure S3A AWS clients. State is one in-memory provider list; there is no serialization or durable persistence. Dependencies are `AWSCredentialProviderList` and `requireNonNull`. Integration points are `AbstractDelegationTokenBinding.deploy()` and `S3ADelegationTokens.getCredentialProviders()`. Risks are intentionally small: missing provider list yields later "Not yet bonded" or empty-provider validation failures in the orchestrator, and the object has no immutability beyond private field access. Test signals are indirect through all delegation binding tests because every successful bound or unbonded deployment must return a non-empty provider list.

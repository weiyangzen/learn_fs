## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/commit/CommitConstants.java

Purpose: public unstable constants for S3A committer names, marker paths, metadata suffixes, capabilities, configuration keys, defaults, conflict modes, UUID behavior, magic marker headers, and summary/statistics options. Important constants include `MAGIC`, `BASE`, `.pending`, `.pendingset`, committer factory/name keys, `COMMITTER_NAME_*`, staging conflict modes, thread counts, abort-pending-upload settings, UUID require/generate flags, `_SUCCESS`, magic capability names, and summary report directory. Control flow is absent. State is immutable constants; persistence occurs through Hadoop configuration, generated metadata filenames, magic path layout, xattrs/headers, and success markers. Dependencies are minimal: Hadoop annotations and S3A xattr prefix. Integration points span all committers, magic path handling, factories, filesystem capabilities, tests, and user configuration docs. Risks include configuration compatibility, default changes altering operational semantics, concurrent-write hazards when aborting pending uploads, broad public exposure despite unstable annotation, and keeping defaults/docs synchronized. Test signals include magic path tests, staging conflict tests, factory tests, and protocol integration suites.

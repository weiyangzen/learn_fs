## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/DelegationTokenIOException.java

Purpose: typed `IOException` for S3A delegation-token failures with stable diagnostic strings used by callers and tests. Important APIs are constructors plus constants `TOKEN_WRONG_CLASS` and package-visible `TOKEN_MISMATCH`. Control flow is simply exception construction. State is serializable exception state via `IOException`; no custom persistence beyond `serialVersionUID`. Dependencies are Java IO only. Integration points include token class conversion, token lookup mismatches, token decoding failures, fetcher failures, and role/session binding validation. Risks are low but diagnostic-string compatibility matters because tests and user-facing errors match these messages. Test signals include wrong-class/mismatch assertions in delegation-token support tests and fetcher/token-binding integration failure paths.

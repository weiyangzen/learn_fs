## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/S3ADtFetcher.java

Purpose: `DtFetcher` implementation allowing `hadoop dtutil` to fetch S3A delegation tokens. Important APIs are `getServiceName()`, `isTokenRequired()`, and `addDelegationTokens()`. Control flow normalizes a URL to an `s3a://` URI when needed, opens the filesystem with the supplied configuration, asks it for a delegation token, throws if none is produced, then stores the token in the supplied `Credentials` under its service. State is absent except local token handling; persistence is Hadoop credentials serialization owned by the caller. Dependencies are Hadoop `FileSystem`, `Credentials`, UGI security state, S3A constants, and `DelegationTokenIOException`. Integration points are command-line token acquisition and secure YARN/MR workflows. Risks include opening arbitrary configured filesystems, disabled delegation tokens causing fetch failure, URL normalization ambiguity, and security-mode dependence in `isTokenRequired()`. Test signals are indirect through delegated MR job and filesystem delegation integration tests.

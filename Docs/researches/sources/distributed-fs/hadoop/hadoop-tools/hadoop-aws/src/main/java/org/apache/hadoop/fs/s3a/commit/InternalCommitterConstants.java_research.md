## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/commit/InternalCommitterConstants.java

Purpose: private unstable constants for committer internals: factory class names, UUID config keys, Spark/MR job-id keys, thread keepalive, and shared diagnostic error strings. Important constants include `THREAD_KEEP_ALIVE_TIME`, `FS_S3A_COMMITTER_UUID`, `FS_S3A_COMMITTER_UUID_SOURCE`, concrete factory class names, `E_DEST_EXISTS`, `E_BAD_PATH`, `E_NORMAL_FS`, `E_WRONG_FS`, `E_NO_MAGIC_PATH_ELEMENT`, `SPARK_WRITE_UUID`, `JAVA_IO_TMPDIR`, `E_NO_SPARK_UUID`, and `MR_JOB_ID`. Control flow is absent. State is immutable constants; persistence is through Hadoop configuration and error messages. Dependencies are concrete committer factory classes and selected public commit constants. Integration points include `AbstractS3ACommitter.buildJobUUID()`, `CommitUtils`, magic path validation, factory selection, and staging conflict handling. Risks include factory class-name compatibility, Spark UUID behavior coupling, and error-string reliance in tests. Test signals are factory tests, Spark UUID/requirement tests, magic path validation, and staging conflict tests.

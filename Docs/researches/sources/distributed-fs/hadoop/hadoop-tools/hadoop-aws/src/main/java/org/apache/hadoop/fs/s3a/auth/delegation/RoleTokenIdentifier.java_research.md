## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/RoleTokenIdentifier.java

Purpose: concrete token identifier for role-based S3A delegation tokens. It shares the `SessionTokenIdentifier` wire payload but uses `ROLE_TOKEN_KIND` so the service loader and binding can distinguish role credentials from normal session credentials. Important APIs are the empty constructor and the constructor accepting URI, owner, renewer, marshalled credentials, encryption secrets, and origin. Control flow delegates to the superclass with the role kind. State and persistence are inherited: Hadoop token fields, S3A URI, encryption secrets, UUID/origin, and marshalled AWS session credentials. Dependencies are `MarshalledCredentials`, Hadoop `Text`, and delegation constants. Integration points are `RoleTokenBinding` and `S3ADelegationTokens.lookupToken()` kind checks. Risks include exact class checks rejecting wrong subclasses and operational confusion if a token for the right service has a different kind. Test signal is role-token round-trip coverage in `TestS3ADelegationTokenSupport` and role delegation integration tests.

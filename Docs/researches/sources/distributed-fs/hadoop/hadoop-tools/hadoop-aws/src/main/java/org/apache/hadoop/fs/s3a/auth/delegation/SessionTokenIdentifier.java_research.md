## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/SessionTokenIdentifier.java

Purpose: concrete token identifier that carries AWS session credentials in S3A delegation tokens. Important APIs are constructors, `write()`, `readFields()`, `getExpiryTime()`, `getMarshalledCredentials()`, and `toString()`. Control flow serializes common S3A token fields through `AbstractS3ATokenIdentifier`, then appends `MarshalledCredentials`; reading reverses that order. State persists in Hadoop token bytes and includes marshalled access key/secret/session token/expiration plus URI/encryption/origin inherited from the base class. Dependencies are `MarshalledCredentials`, Hadoop `Text`, and delegation constants. Integration points are `SessionTokenBinding`, `FullCredentialsTokenIdentifier`, `RoleTokenIdentifier`, token service loader decoding, and S3A credential provider binding. Risks include transitive AWS class loading through `MarshalledCredentials` as noted in comments, requirement that subclasses declare distinct token kinds, and secret exposure inherent to serialized credentials. Test signals include session token kind, decode, no-renewer, round-trip, and role/full subclass round-trip tests.

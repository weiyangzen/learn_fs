## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/commit/CommitUtils.java

Purpose: static helper methods for S3A committer validation and job-ID extraction. Important APIs are `verifyIsMagicCommitPath()`, `verifyIsMagicCommitFS()`, `verifyIsS3AFS()`, `getS3AFileSystem()`, `validateCollectionClass()`, and `extractJobID()`. Control flow verifies filesystem type and magic capability before committers operate, logs full filesystem details on non-magic errors, casts to S3A only after checks, validates homogeneous collection element classes, and extracts job identifiers in priority order: committer UUID, Spark write UUID, then MR job ID. State and persistence are absent, though values come from configuration. Dependencies are S3A FS, Hadoop `Path`/`Configuration`, internal constants, and `ValidationFailure`. Integration points are `AbstractS3ACommitter`, magic committer setup, tests, and diagnostics. Risks include strict class equality in collection validation, noisy but useful logs on magic mismatch, and job-ID extraction needing to match UUID selection logic. Test signals include magic path, committer factory, and staging/magic protocol tests.

## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/DelegationOperations.java

Purpose: future-proof callback interface for delegation-token operations not already exposed by `StoreContext`. Currently it extends `AWSPolicyProvider` without adding methods. Control flow and state are absent; it exists to stabilize signatures for external delegation-token binding implementations. Dependencies are limited to the local policy-provider interface. Integration points are `AbstractDTService.bindToFileSystem()`, which stores a `DelegationOperations` reference, and `S3ADelegationTokens.createDelegationToken()`, which asks it for read/write AWS policy rules. Risks are contractual rather than algorithmic: because the interface is intentionally extensible, external implementations must track unstable API changes, and incomplete policy behavior propagates into role-token issuance. Test signals are indirect in delegation integration tests where S3A store operations provide policy statements used to create restricted role tokens.

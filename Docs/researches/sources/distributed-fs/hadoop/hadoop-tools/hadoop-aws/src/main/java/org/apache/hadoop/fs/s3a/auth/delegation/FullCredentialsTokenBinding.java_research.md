## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/FullCredentialsTokenBinding.java

Purpose: delegation-token binding that embeds full long-lived AWS credentials rather than minting STS session credentials, mainly for non-STS deployments and design validation. Important APIs are `deployUnbonded()`, `createTokenIdentifier()`, `bindToTokenIdentifier()`, and `createEmptyIdentifier()`. Control flow loads credentials from filesystem configuration via `S3AUtils.getAWSAccessKeys()` or from environment variables, validates any non-empty credential type, returns a `MarshalledCredentialProvider` for unbonded clients, and creates `FullCredentialsTokenIdentifier` when requested. Bound deployments convert the incoming identifier to the exact full-token class and expose its marshalled credentials. State includes cached `MarshalledCredentials` and diagnostic origin text; token persistence is inherited from `SessionTokenIdentifier`. Dependencies include `MarshalledCredentials`, `MarshalledCredentialProvider`, `S3xLoginHelper`, and delegation constants. Integration points are `S3ADelegationTokens` and tests for full-token round trips. Risks are security-sensitive because long-lived secrets are serialized into Hadoop tokens, and credential discovery order may surprise operators. Test signals include `TestS3ADelegationTokenSupport.testFullTokenIdentifierRoundTrip()`.

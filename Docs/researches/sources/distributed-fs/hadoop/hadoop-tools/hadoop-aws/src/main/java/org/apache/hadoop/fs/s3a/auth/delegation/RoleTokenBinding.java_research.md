## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/RoleTokenBinding.java

Purpose: session-token binding variant that assumes a configured IAM role and optionally restricts it with a generated policy before embedding session credentials in a role token. Important APIs are `serviceInit()`, `bindToTokenIdentifier()`, `createTokenIdentifier()`, `createEmptyIdentifier()`, `getDescription()`, and `bindingName()`. Control flow reads `fs.s3a.assumed.role.arn`, validates it when issuing a token, serializes an optional `RoleModel.Policy`, prepares an STS client inherited from `SessionTokenBinding`, fails if parent credentials are already session-only, calls `requestRole()`, and creates a `RoleTokenIdentifier`. Bound mode exposes session-only marshalled credentials and records expiration. State includes configured role ARN plus inherited session binding state. Dependencies include AWS STS credentials, role model JSON, marshalled credentials, and delegation constants. Integration points are role delegation tests, assumed-role S3A operation tests, and `S3ADelegationTokens` policy generation. Risks include missing ARN, parent credential type incompatibility, policy JSON correctness, STS duration/permission failures, and sensitive session credentials in tokens. Test signals include `ITestRoleDelegationTokens` and `ITestRoleDelegationInFilesystem`.

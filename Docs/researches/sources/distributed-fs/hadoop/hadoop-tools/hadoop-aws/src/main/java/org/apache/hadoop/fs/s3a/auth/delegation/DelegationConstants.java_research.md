## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/DelegationConstants.java

Purpose: unstable public constants for S3A delegation-token configuration, token kinds, binding class names, defaults, and common errors. Important constants alias assumed-role STS endpoint/region/duration/provider/role-ARN settings, define `fs.s3a.delegation.token.binding`, binding implementation class names, token name/kind `Text` values, `STS_STANDARD`, and `E_NO_SESSION_TOKENS_FOR_ROLE_BINDING`. Control flow is absent. State is immutable static constants; persistence is through Hadoop XML/configuration keys and serialized token kind text. Dependencies are S3A `Constants` and Hadoop `Text`. Integration points span `S3ADelegationTokens`, `SessionTokenBinding`, `RoleTokenBinding`, `FullCredentialsTokenBinding`, and core-default documentation. Risks include requirement that values remain synchronized with `core-default.xml`, class-name compatibility for configured bindings, and token-kind stability for service-loader decoding. Test signals appear in token-kind unit tests, role/session delegation integration tests, and configuration-driven filesystem delegation tests.

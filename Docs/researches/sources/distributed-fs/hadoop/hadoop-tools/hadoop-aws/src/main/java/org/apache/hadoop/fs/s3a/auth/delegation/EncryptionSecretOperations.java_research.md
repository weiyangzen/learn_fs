## sources/distributed-fs/hadoop/hadoop-tools/hadoop-aws/src/main/java/org/apache/hadoop/fs/s3a/auth/delegation/EncryptionSecretOperations.java

Purpose: helper methods that interpret serialized `EncryptionSecrets` for request-time S3 encryption options while keeping the secrets container free of AWS SDK dependencies. Important APIs are `getSSECustomerKey()`, `getSSEAwsKMSKey()`, and `getSSEAwsKMSEncryptionContext()`. Control flow checks encryption method and presence of key/context, returning `Optional` values only for SSE-C or SSE-KMS/DSSE-KMS where applicable. State and persistence are absent. Dependencies are `S3AEncryptionMethods` and `EncryptionSecrets`. Integration points are S3A request builders that attach SSE-C keys, KMS keys, and KMS encryption context after a delegation token has propagated encryption settings. Risks include method/secret mismatch silently returning empty, and correctness depending on `EncryptionSecrets.init()` reconstructing the enum after deserialization. Test signals are token round-trip tests with SSE-S3/DSSE-KMS contexts and filesystem delegation tests asserting encryption secrets propagate.

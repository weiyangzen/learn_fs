# sources/distributed-fs/hadoop/hadoop-hdfs-project/hadoop-hdfs/src/main/java/org/apache/hadoop/hdfs/server/datanode/fsdataset/impl/FsVolumeImpl.java

`FsVolumeImpl` represents one local DataNode storage volume. It owns per-volume block-pool slices, disk and reserved-space accounting, reference counting, block file creation/movement, block iteration, directory scanning, health checks, lazy-persist target paths, metrics, and a per-volume cache worker pool.

Important APIs include `obtainReference`, `getCapacity`, `getAvailable`, `getDfsUsed`, `getBlockPoolUsed`, `newBlockIterator`, `loadBlockIterator`, `compileReport`, `check`, `loadLastPartialChunkChecksum`, `createTemporary`, `createRbw`, `append`, `convertTemporaryToRbw`, `addFinalizedBlock`, `updateRURCopyOnTruncate`, `moveBlockToTmpLocation`, `hardLinkBlockToTmpLocation`, and `copyBlockToLazyPersistLocation`. State includes `bpSlices`, `storageLocation`, `currentDir`, `DF usage`, `ReservedSpaceCalculator`, `reservedForReplicas`, `CloseableReferenceCount`, metrics, same-disk tiering mount data, and `cacheExecutor`.

Construction validates storage location, creates reserved-space and capacity helpers, initializes metrics/base URI/cache executor, and records mount information for same-disk tiering. `FsVolumeReferenceImpl` increments the refcount on creation and decrements on close; closing the volume marks the reference count closed and asks the dataset to interrupt pipeline writers using the volume.

Capacity reporting subtracts reserved space, DFS-used bytes, and outstanding replica write reservations. With same-disk tiering enabled, capacity is multiplied by `MountVolumeMap` ratios and non-DFS usage subtracts counterpart DISK/ARCHIVE DFS usage on the same mount. Block creation reserves bytes before tmp/RBW file creation and releases on failure. Finalization delegates to `BlockPoolSlice`, preserves last partial checksums, releases reservations, and returns a finalized replica. Append moves finalized files into RBW, loads checksum state, decrements old DFS accounting, and reserves future bytes.

`BlockIteratorImpl` walks finalized block directories in sorted order, validates block directory placement, finds metadata files, populates generation stamp and length, and persists JSON cursor files atomically. `compileReport` recursively scans finalized directories, pairs block and metadata filenames, verifies expected directory layout, and emits `ScanInfo` entries for the directory scanner.

Persistent state is block-pool directory contents, finalized/rbw/tmp/lazypersist subdirectories, block/meta files, and iterator cursor files. Dependencies include `FsDatasetImpl`, `BlockPoolSlice`, `FileIoProvider`, `DataStorage`, `DatanodeUtil`, `ReservedSpaceCalculator`, `ReplicaBuilder`, replica classes, Jackson, Hadoop `DF`, and metrics.

Risks include leaked references blocking volume removal, incorrect reservation accounting after failures, stale capacity ratios, last-partial-checksum mistakes, scanner cursor corruption, crash behavior of same-mount hard-link moves, and bypassing `FileIoProvider`. Tests should cover reference lifecycle, capacity math, tmp/RBW/finalized transitions, append checksum state, recovery truncate/copy, iterator save/load, compileReport pairing, block-pool deletion, lazy-persist activation, and shutdown metrics cleanup.

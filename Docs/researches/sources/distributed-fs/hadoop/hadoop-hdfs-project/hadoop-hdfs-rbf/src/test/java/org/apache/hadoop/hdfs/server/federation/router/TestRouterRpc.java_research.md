## sources/distributed-fs/hadoop/hadoop-hdfs-project/hadoop-hdfs-rbf/src/test/java/org/apache/hadoop/hdfs/server/federation/router/TestRouterRpc.java

Purpose: the main multi-nameservice integration suite for `RouterRpcServer` and Router proxying. It validates that Router client and Namenode protocol APIs behave like the backing NameNodes while aggregating data across two nameservices and preserving federation path semantics.

Important APIs and types include `MiniRouterDFSCluster`, `RouterContext`, `RouterRpcServer`, `RouterRpcClient`, `ClientProtocol`, `NamenodeProtocol`, `MockResolver`, `FileSubclusterResolver`, `FederationRPCMetrics`, `NamenodeBeanMetrics`, `RBFMetrics`, `DFSClient`, `DistributedFileSystem`, snapshot APIs, cache admin APIs, erasure coding APIs, datanode reports, block stats, caller context, proxy UGI, and low-level block operations such as `addBlock`, `getAdditionalDatanode`, and `complete`. The class exposes protected setters/getters and helpers used by subclasses, plus `compareResponses()` to assert Router and NameNode failure equivalence.

Control flow: `globalSetUp()` builds a two-nameservice cluster with six datanodes per nameservice, independent datanodes, caller context enabled, IP proxy users, short DN report cache expiry, and adjusted heartbeat timing. `testSetup()` installs mock locations, clears files, creates NameNode fixtures, selects a Router and NameNode, and creates a per-test file. Tests then cover service lifecycle, listing union and ordering, large directory paging mixed with mount points, mount/file conflicts, same-namespace versus cross-namespace rename, chmod/chown/replication/truncate/mkdir/append/concat, block locations, additional datanode, storage policy get/set/unset/list/defaults, snapshots and snapshot diff/listing, Namenode protocol version/block key/block listing/transaction/safemode/saveNamespace operations, lease renewal for replicated and EC files, disabled namespace handling, exception path rewriting, corrupt replicated block aggregation, EC policy lifecycle and stats, Namenode metrics caching, RBF metrics without state store, cache pools/directives, groups lookup, cached datanode reports, caller context propagation, balancer bandwidth, content summary with snapshots, node usage disabling, non-ASCII listing order, async handler caller-context isolation, and executor initialization.

State and persistence behavior spans MiniDFS filesystem metadata, mock resolver mount registrations, Router metrics caches, datanode report caches, snapshots, cache pools/directives, EC policy state, NameNode safemode, block manager corrupt state, and caller context thread-local state. Cleanup resets caller context per test; class teardown shuts down the cluster.

Dependencies and integration points are broad: Router RPC modules, NameNode protocol proxy creation, MiniDFS internals, state-free `MockResolver`, audit logs, JSON metrics, block manager test utilities, and Hadoop security. Risks covered include Router/NameNode semantic drift, incorrect aggregate metrics, stale caches, wrong exception paths, namespace leakage, caller context contamination, and protocol operations choosing the wrong nameservice. Test signals are extensive equality checks against NameNode responses, filesystem existence/status assertions, metrics counter deltas, JSON field checks, intercepted exceptions, audit-log content checks, and wait-based cache refresh assertions.

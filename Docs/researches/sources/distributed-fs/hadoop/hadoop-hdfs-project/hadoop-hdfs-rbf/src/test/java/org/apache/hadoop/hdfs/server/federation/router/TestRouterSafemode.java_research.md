## sources/distributed-fs/hadoop/hadoop-hdfs-project/hadoop-hdfs-rbf/src/test/java/org/apache/hadoop/hdfs/server/federation/router/TestRouterSafemode.java

Purpose: tests `RouterSafemodeService` and Router behavior while safemode is entered automatically, manually, or due to stale state-store cache. It uses a standalone `Router` with state store, RPC, admin, safemode, and metrics services rather than a full MiniDFS cluster.

Important APIs and types include `Router`, `RouterSafemodeService`, `RouterServiceState`, `RouterAdmin`, `RouterAdminServer`, `MountTableResolver`, `EnterSafeModeRequest`, `StateStoreUnavailableException`, `StandbyException`, and RBF config keys for safemode extension, expiration, check period, and cache TTL. Static setup deletes the state store, builds a state-store configuration, sets short timing values and ephemeral RPC/admin/http addresses, then enables required Router services.

Control flow: each test creates, initializes, and starts a Router. `testSafemodeService()` checks service lifecycle states. `testRouterExitSafemode()` asserts startup safemode and waits extension plus check period for transition to `RUNNING`. `testRouterEnterSafemode()` waits out startup safemode, stops state-store cache updates, waits expiration, and expects safemode reentry. `testRouterRpcSafeMode()` verifies write RPCs throw `StandbyException` while in safemode. `testRouterManualSafeMode()` wires RouterAdmin to the live admin port, enters and leaves safemode via CLI, and checks state persistence across update intervals. `testRouterNotInitMountTable()` disables the mount-table resolver, verifies a non-safemode read reports mount-table unavailability, then enters safemode and verifies the same read reports safemode instead.

State and persistence behavior includes Router service state, safemode flags, state-store cache freshness, admin-driven manual safemode, and resolver disabled state. The test relies on timing intervals and `GenericTestUtils.waitFor` to observe transitions.

Dependencies and integration points are Router admin protocol, state-store cache update service, mount-table resolver, Router RPC read/write gating, and Hadoop service lifecycle. Risks covered include premature safemode exit, failure to reenter on stale cache, wrong exception precedence, manual safemode not sticking, and service lifecycle regressions. Test signals are `RouterServiceState` equality, safemode booleans, CLI return codes, and expected exception classes/messages.

## sources/distributed-fs/hadoop/hadoop-hdfs-project/hadoop-hdfs-rbf/src/test/java/org/apache/hadoop/hdfs/server/federation/router/TestRouterRPCMultipleDestinationMountTableResolver.java

Purpose: integration coverage for `MultipleDestinationMountTableResolver` and Router RPC behavior when a mount entry targets more than one subcluster. It starts a three-nameservice `StateStoreDFSCluster` using the multiple-destination resolver and enables ACLs in NameNode configuration.

Important APIs and types include `MountTable`, `MountTableResolver`, `MountTableManager`, `DestinationOrder`, `RouterRpcServer`, `RouterClientProtocol`, `DistributedFileSystem`, `RouterAdmin`, `ContentSummary`, ACL/xattr/storage-policy/EC APIs, `GetDestinationRequest/Response`, and `RemoteMethod`. `setupOrderMountPath()` installs `/mount` mapping `ns0` and `ns1` to `/tmp`, sets the destination order, creates directories/files through the Router, and reloads resolver cache. `resetTestEnvironment()` removes the mount and cleans NameNode paths after tests.

Control flow tests destination order families (`SPACE`, `HASH_ALL`, `RANDOM`, `HASH`, `LOCAL`) and checks whether directory operations should invoke all destinations. Shared helpers apply owner, permission, storage policy, EC policy, xattrs, replication, and unset operations at mount, directory, and file levels; they verify propagation to all expected backing NameNodes. Additional tests cover ACL propagation, `getDestination` results for files, missing files, and directories, multi-destination directory detection excluding files and symlinks, snapshot path rewriting, rename semantics across multi-destination directories, quota clear/set via `RouterAdmin`, content-summary quotas including near-`Long.MAX_VALUE`, fault-tolerant invocation when a subcluster is down, writes with unavailable subclusters, and rejection of renames with mismatched source/target location counts.

State and persistence behavior uses the state-store mount table plus resolver cache reloads. Quota tests interact with `RouterQuotaUpdateService`; admin commands persist quota definitions and cache refresh exposes them through `ContentSummary`. The suite also mutates live MiniDFS availability by shutting down and restarting NameNodes.

Dependencies and integration points include Router admin RPC, client protocol routing, mount table state store, NameNode filesystem metadata, ACL/xattr/EC/storage policy subsystems, snapshot APIs, and fault-tolerant destination selection. Risks covered include partial propagation, wrong destination selection, incorrect mount-path rewriting, overflow-like quota aggregation, unavailable subclusters, and unsafe multi-destination renames. Test signals are exact backend metadata assertions, collection comparisons, exception interception, and filesystem existence checks.

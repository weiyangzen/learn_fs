## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/Stat.java

`Stat` wraps the platform `stat(1)` command to produce `FileStatus` metadata, especially for lstat-style symlink behavior not historically available in Java. Construction stores original, stripped/qualified, and plain paths, block size, dereference flag, and sets `LANG=C` for predictable output. `getExecString()` builds Linux or FreeBSD/Mac command formats; `parseExecResult()` parses length, type, modification/access times, octal permissions, owner, group, and symlink target into a `FileStatus`. State is the parsed `FileStatus` after `run()`. Dependencies include `Shell`, `FsPermission`, `FileStatus`, path qualification, and platform booleans. Integration is used by `RawLocalFileSystem` when native stat support is available. Risks include parsing localized or unexpected stat output despite `LANG=C`, paths with commas in output fields, symlink target parsing assumptions, unsupported platforms, process-spawn overhead, and race conditions if the file changes while stat runs. Tests should cover Linux/Mac command generation, file/directory/symlink/dangling symlink parsing, not-found and cyclic-link errors, permissions with extra FreeBSD digits, and platform availability guards.

## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/RawLocalFileSystem.java

`RawLocalFileSystem` is the concrete raw `file:///` implementation. It converts `Path` to `File`, maintains a working directory and default block size, and implements open, create, append, concat, rename, truncate, delete, list, mkdirs, status, permission/owner/time updates, symlinks, path handles, and path capabilities. `LocalFSFileInputStream` wraps `FileInputStream`, tracks position/statistics, supports positioned reads and async vectored reads via `AsynchronousFileChannel` and `AsyncHandler`; `LocalFSFileOutputStream` wraps `FileOutputStream`, applies permissions, tracks write statistics, and implements `Syncable`. Control flow uses Java file APIs first, with NativeIO and shell fallbacks for permissions/stat, Windows-specific rename handling for empty directories, and copy fallback for failed renames. File status may use a deprecated Java/`ls` path or the `Stat` command depending on platform support. State includes mutable working directory, default block size, a static deprecated-status switch, stream counters aggregated on close, and OS filesystem metadata. Dependencies are broad: `FileSystem`, `FileUtil`, `FsPermission`, `NativeIO`, `Shell`, `Stat`, `IOStatistics`, vector-read utilities, NIO file attributes, and path capability validation. Integration is the raw delegate for `LocalFileSystem` and local tests/tools. Risks include TOCTOU races around exists/create/delete/list, rename fallback copying rather than atomic rename, platform-specific permission parsing, static status mode affecting all instances, asynchronous vector reads needing buffer release on failure, path-handle validity relying on mtime granularity, `createNonRecursive()` not creating parents but also not explicitly checking parent existence before stream creation, and symlink behavior gated by global configuration. Tests should cover local CRUD, append/truncate/sync, permissions on POSIX and Windows, stat/native fallback, symlinks and dangling links, path handles, capability probes, vectored read completion/failure, rename edge cases, and IOStatistics aggregation.

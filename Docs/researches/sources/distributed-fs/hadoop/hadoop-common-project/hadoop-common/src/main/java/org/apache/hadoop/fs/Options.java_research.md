## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/Options.java

`Options` groups reusable option types for filesystem operations. `CreateOpts` provides typed varargs for block size, buffer size, replication, bytes per checksum, checksum options, progress callbacks, permissions, and parent creation, with validation and exact-class duplicate detection through `getOpt()`/`setOpt()`. `Rename` encodes NONE/OVERWRITE/TO_TRASH as byte values. `ChecksumOpt` merges default, user checksum type, and legacy bytes-per-checksum settings. `HandleOpt` models path-handle validity constraints (`changed`, `moved`) and provides resolver helpers. Later nested contracts define checksum combine modes and standard open/create option keys for builder APIs, including read policies and conditional overwrite semantics. State is per immutable option instance and static constant sets. Dependencies include `FsPermission`, `Progressable`, `DataChecksum`, Java streams/functions, and path-handle/file-status APIs. Integration spans `FileSystem`, `FileContext`, builders, object-store commit protocols, and handle creation. Risks include exact-class matching in `CreateOpts` versus assignable matching in `HandleOpt`, `Rename.valueOf(byte)` relying on enum order, and many string option contracts requiring consistent recognition by implementations. Tests should cover duplicate detection, checksum precedence, byte-code mapping, handle option presets, standard option set immutability, and unsupported must/optional create options in concrete filesystems.

## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PartHandle.java

`PartHandle` is an opaque serializable reference to an uploaded multipart part. It requires `bytes()` and `equals(Object)`, and provides `toByteArray()` by consuming the remaining bytes of the returned `ByteBuffer`. It has no state itself; implementations decide byte stability and equality semantics. It integrates with `MultipartUploader.putPart()` and `complete()` where maps of part number to handle identify uploaded content. Dependencies are `Serializable` and `ByteBuffer`. Risks include mutable or position-sensitive `ByteBuffer` implementations causing `toByteArray()`/equals surprises, and lack of a required `hashCode()` declaration even though equals is required. Tests should cover concrete handle byte round trips, read-only buffer behavior, equality/hash consistency, and completion with reordered part handles.

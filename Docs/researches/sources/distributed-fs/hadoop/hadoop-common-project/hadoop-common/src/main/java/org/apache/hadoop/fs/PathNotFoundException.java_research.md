## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PathNotFoundException.java

`PathNotFoundException` maps path absence to ENOENT/ENOFILE semantics. It extends `PathIOException`, defaulting to "No such file or directory", and provides constructors with a cause, custom error, or custom error plus cause. State and formatting are inherited. Integration includes open/status/list operations and remote exception wrapping where callers want a Hadoop-specific not-found type instead of plain `FileNotFoundException`. Risks include inconsistent use between Java `FileNotFoundException` and this type in local filesystem code, and cause-only constructors using the generic EIO message from the parent rather than the default not-found string. Tests should cover all constructors, formatted messages, cause propagation, and concrete filesystem not-found behavior.

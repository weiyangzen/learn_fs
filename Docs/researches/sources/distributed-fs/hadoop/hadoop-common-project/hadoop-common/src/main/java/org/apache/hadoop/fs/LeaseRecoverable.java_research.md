## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/LeaseRecoverable.java

`LeaseRecoverable` is a small filesystem capability interface for filesystems that can recover writer leases and report whether a file is closed. Its public API is `recoverLease(Path)` and `isFileClosed(Path)`, both throwing `IOException` and optionally `UnsupportedOperationException` when unsupported. It has no internal state or persistence; implementations are expected to bind the methods to filesystem-specific metadata services, such as HDFS lease recovery. Dependencies are only `Path` and Java IO. Integration is capability-oriented: callers can probe or cast filesystem implementations before invoking recovery. Risks center on ambiguous return semantics, because `recoverLease()` returns true when no recovery is needed as well as when a closed state is reached. Tests should cover unsupported filesystems, closed files, active leases, retry/idempotency behavior, and propagation of server-side IO failures.

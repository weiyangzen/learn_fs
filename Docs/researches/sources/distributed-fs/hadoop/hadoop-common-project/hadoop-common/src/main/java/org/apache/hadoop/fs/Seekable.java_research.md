## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/Seekable.java

`Seekable` defines stream seeking APIs: `seek(long)`, `getPos()`, and private-audience `seekToNewSource(long)` for switching replicas or data sources. It contains no implementation state but imposes stream-position semantics on implementers. Integration is with `FSInputStream`, `FSDataInputStream`, local and distributed input streams, and consumers needing random access. Dependencies are Java IO and Hadoop annotations. Risks include negative seeks, seeking past EOF, inconsistent source-switch semantics, and concurrency with positioned reads. Tests should cover initial/current position, negative and EOF-boundary seeks, subsequent reads after seek, `seekToNewSource()` return behavior, and interaction with buffered wrappers.

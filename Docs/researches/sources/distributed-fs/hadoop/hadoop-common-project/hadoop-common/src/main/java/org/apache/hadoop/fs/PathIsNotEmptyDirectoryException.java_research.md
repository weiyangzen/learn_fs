## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PathIsNotEmptyDirectoryException.java

`PathIsNotEmptyDirectoryException` is a delete/rm-oriented exception for non-recursive removal of non-empty directories. It extends `PathExistsException` and fixes the error string to "Directory is not empty". It has no extra fields or logic. Integration is with filesystem delete implementations, though some local code paths still throw generic `IOException` for this condition. Risks include inconsistent use across filesystems and no declared `serialVersionUID` unlike many neighboring exceptions. Tests should exercise non-recursive delete on non-empty directories and verify whether concrete implementations use this specific type or a generic exception.

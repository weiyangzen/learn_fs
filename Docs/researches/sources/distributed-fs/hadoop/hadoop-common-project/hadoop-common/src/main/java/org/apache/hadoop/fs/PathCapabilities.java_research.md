## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PathCapabilities.java

`PathCapabilities` is the path-scoped counterpart to `StreamCapabilities`. It defines `hasPathCapability(Path, String)` where `true` is an explicit support guarantee and `false` can mean unknown, unsupported, or path-dependent uncertainty. The interface has no state or persistence. It integrates with `FileSystem`/`FileContext` capability probes and well-known strings in `CommonPathCapabilities`; helper validation lives in `org.apache.hadoop.fs.impl.PathCapabilitiesSupport`. Dependencies are `Path` and `IOException`. Risks include callers overinterpreting `false`, inconsistent case/validation of capability strings, and capabilities that are globally supported but unavailable under particular paths. Tests should cover argument validation, known capability positives in concrete filesystems, default false behavior, and failure propagation for path resolution.

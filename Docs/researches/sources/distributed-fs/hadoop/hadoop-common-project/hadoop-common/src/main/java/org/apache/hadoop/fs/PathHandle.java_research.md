## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PathHandle.java

`PathHandle` is a public evolving functional interface for opaque serializable references to filesystem entities. It requires `ByteBuffer bytes()` and `equals(Object)`, and supplies `toByteArray()` by reading remaining bytes from the returned buffer. Handles may embed metadata for later resolution or verification independent of namespace changes, depending on implementation. There is no interface state; concrete classes such as `LocalFileSystemPathHandle` and `RawPathHandle` define persistence. Integration points include `FileSystem.getPathHandle`, `open(PathHandle, ...)`, multipart completion, and handle option policies. Risks mirror `PartHandle`: position-sensitive buffers, mutable byte storage, missing explicit `hashCode()` contract, and backend-specific validity semantics. Tests should verify byte stability, serialization, equality/hash consistency, and behavior after content or namespace changes for each filesystem.

## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PathIOException.java

`PathIOException` is the POSIX-like base `IOException` for path-related failures. It stores the original path string, optional operation, optional target path, and optional fully-qualified path, and formats messages as operation plus quoted path plus optional target/error/cause/fq path. It deliberately stores strings instead of `Path` to avoid losing original URI text. Public APIs include constructors, fluent `withFullyQualifiedPath()`, `getPath()`, `getTargetPath()`, `setOperation()`, and `setTargetPath()`. State is mutable after construction through setters. Integration is broad across Hadoop FS exceptions and NativeIO tests. Risks include `getPath()` reparsing invalid original strings, mutable message state surprising log aggregation, null path formatting, and cause messages being appended manually in addition to exception chaining. Tests should cover formatting combinations, fully-qualified path inclusion, target path parsing, subclass defaults, and serialization compatibility.

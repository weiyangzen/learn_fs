## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PathPermissionException.java

`PathPermissionException` maps EPERM/operation-not-permitted conditions into the Hadoop path exception hierarchy. It extends `PathIOException`, defaults to "Operation not permitted", and supports cause/custom error constructors. It is distinct from `PathAccessDeniedException`'s EACCES semantics. State, target path, operation, and fully qualified path handling are inherited. Integration is with authorization checks and native IO error translation. Risks include inconsistent differentiation from access-denied errors and cause-only construction defaulting to parent EIO text. Tests should cover permission failure mapping, constructor messages, and formatting with operations/targets.

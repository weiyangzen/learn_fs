## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/Trash.java

`Trash` is the public facade over pluggable `TrashPolicy` implementations. Constructors create a policy for a `FileSystem` and `Configuration`; instance methods delegate enablement, move, checkpoint, expunge, immediate expunge, current trash directory, and emptier creation. The important static path is `moveToAppropriateTrash()`: it resolves symlinks/mount points, opens the resolved filesystem, retrieves server defaults for trash interval, overlays that interval into a configuration copy when nonzero, and chooses between original filesystem versus resolved filesystem based on the ViewFS localized-trash flag. State is the configured `TrashPolicy` instance only. Dependencies include `FileSystem`, `TrashPolicy`, `ViewFileSystem` constants, and common trash configuration keys. Integration is with shell delete commands, ViewFS mount points, and filesystems whose server-side trash interval overrides client config. Risks include conservative failure when server defaults cannot be read, subtleties around ViewFS path resolution and localized trash, and delegated policy behavior varying by filesystem. Tests should cover disabled trash, already-in-trash returns, server interval override, ViewFS flag branches, checkpoint/expunge delegation, and failure to fetch server defaults preventing deletion.

## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/ParentNotDirectoryException.java

`ParentNotDirectoryException` is a stable public `IOException` raised when a path's parent exists but is not a directory. It has default and message constructors only, no extra state, and no custom formatting. It integrates with directory creation paths such as `RawLocalFileSystem.mkdirsWithOptionalPermission()` and other filesystem implementations that need a specific failure type. Dependencies are only Java IO and Hadoop classification annotations. Risks are low, but callers relying on this exact type need implementations to throw it instead of generic `IOException`. Tests should assert thrown type and message when creating a child below a regular file, especially through local filesystem `mkdirs()` and create paths.

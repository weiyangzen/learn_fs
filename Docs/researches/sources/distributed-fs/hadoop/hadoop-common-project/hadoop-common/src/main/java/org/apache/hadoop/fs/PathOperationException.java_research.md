## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PathOperationException.java

`PathOperationException` represents unsupported path operations, with the fixed message "Operation not supported". It extends `PathExistsException`, which is unusual for ENOTSUP semantics but preserves the path-error formatting family. It has no additional state or control flow. Integration is with filesystem features that are recognized but unavailable for a path, such as append, symlink, or capability-dependent operations. Risks are exception taxonomy confusion and overly broad catches of `PathExistsException`. Tests should validate thrown type for unsupported operations and inherited message formatting with operation names set by callers.

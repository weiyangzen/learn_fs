## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/StorageStatistics.java

`StorageStatistics` is an abstract stable base for per-filesystem or per-`FileContext` counters. It defines common operation-name constants through `CommonStatisticNames`, a simple immutable `LongStatistic` name/value pair, a statistic set name, optional scheme binding via `getScheme()`, and abstract methods to iterate tracked long statistics, get a named long value, check tracking, and reset. State in the base class is only the immutable statistics name; concrete subclasses own counters. Dependencies include `StoreStatisticNames` and Java `Iterator`. Integration is with filesystem instrumentation, diagnostics, and tests that read common operation counters. Risks include non-snapshot iterator semantics, naming collisions in custom statistics, reset concurrency in implementations, and consumers assuming all common names are always tracked. Tests should verify concrete counter increments, `isTracked()` behavior, reset, scheme overrides, and iterator stability under updates.

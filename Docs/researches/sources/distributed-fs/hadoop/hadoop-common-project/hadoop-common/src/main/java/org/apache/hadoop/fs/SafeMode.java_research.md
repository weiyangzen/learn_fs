## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/SafeMode.java

`SafeMode` is a filesystem capability interface for metadata services that can enter, leave, force-exit, or query safe mode. It provides a default one-argument `setSafeMode(SafeModeAction)` delegating to `setSafeMode(action, false)` and a required two-argument form whose `isChecked` flag controls whether to check only the active metadata node/name node. No state or persistence exists in the interface; implementations persist safe-mode state in their backend control plane. Dependencies are `SafeModeAction` and `IOException`. Integration allows non-HDFS filesystem implementations to expose HDFS-like safe-mode controls without importing HDFS constants. Risks include action semantics differing by implementation, ambiguous boolean return versus exceptions, and HA active/first-node interpretation. Tests should cover default delegation, each action, checked versus unchecked behavior, unsupported implementations, and IO failure propagation.

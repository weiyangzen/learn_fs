## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/MD5MD5CRC32FileChecksum.java

`MD5MD5CRC32FileChecksum` represents Hadoop's legacy aggregate checksum: an MD5 over per-block MD5s of chunk CRCs. It stores bytes-per-CRC, CRCs-per-block, and an `MD5Hash`, implements `FileChecksum`, serializes through `Writable`, and exposes `getAlgorithmName()`, `getLength()`, `getBytes()`, `getChecksumOpt()`, `readFields()`, `write()`, and `toString()`. Control flow is straightforward serialization/deserialization plus checksum type parsing from algorithm suffixes. Default `getCrcType()` is CRC32 and subclasses override it for CRC32C. Dependencies include `MD5Hash`, `WritableUtils`, `Options.ChecksumOpt`, and `DataChecksum`. Risks include `md5` null causing `write()` or `toString()` failures after the default constructor until fields are read, and strict suffix parsing for algorithm names. Tests should cover writable round trips, length constants, checksum option construction, algorithm parsing failures, and subclass-specific algorithm strings.

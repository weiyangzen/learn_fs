## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/LocalFileSystemPathHandle.java

`LocalFileSystemPathHandle` is the concrete `PathHandle` for local files. It stores a string path and an optional modification time, serializes them through `FSProtos.LocalFileSystemPathHandleProto`, and verifies a resolved `FileStatus` by checking presence and, when bound, modification time equality. State is immutable after construction, with `mtime` represented as nullable `Long` internally from an `Optional<Long>`. It integrates with `RawLocalFileSystem.open(PathHandle, ...)` and `createPathHandle()`, which chooses whether content changes are allowed. Dependencies include protobuf `ByteString`, `ByteBuffer`, `FileStatus`, and `InvalidPathHandleException`. Risks include path strings being location-based rather than inode-based, so moves are unsupported; modification time granularity can miss rapid content changes; `bytes()` sets `path` without null validation. Tests should cover serialization round trips, stale mtime rejection, unbound handles that allow content changes, null byte buffers, equality/hash behavior, and opening through the raw local filesystem.

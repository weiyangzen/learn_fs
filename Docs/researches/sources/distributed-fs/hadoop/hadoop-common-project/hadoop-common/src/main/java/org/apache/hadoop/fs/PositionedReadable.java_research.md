## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PositionedReadable.java

`PositionedReadable` defines thread-oriented positional read operations for streams. Required APIs are `read(position, byte[], offset, length)` and two `readFully()` overloads; default APIs expose vector-read tuning (`minSeekForVectorReads()` = 16 KiB, `maxReadSizeForVectorReads()` = 1 MiB) and `readVectored()` overloads that delegate to `VectoredReadUtils`, with an optional release callback. There is no state in the interface; implementers must preserve or document stream-position effects and thread safety. Dependencies include `FileRange`, `ByteBuffer`, `IntFunction`, `Consumer`, `EOFException`, and size constants. Integration is with `FSDataInputStream`, HBase-style concurrent readers, and raw local async vector IO. Risks include implementations not meeting the stated thread-safety requirement, undefined current position after vector reads, overlapping/invalid ranges, buffer release omissions on failure, and inconsistent handling when a file changes mid-read. Tests should cover positioned reads not advancing `getPos()`, EOF semantics, concurrent reads, vector range validation, buffer release on failure, and capability probes for vector IO.

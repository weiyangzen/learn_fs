## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PathFilter.java

`PathFilter` is a stable single-method public interface for filtering paths in listing/globbing APIs. Its only API is `boolean accept(Path path)`. It has no state, persistence, dependencies beyond `Path`, or control flow. Integration is with `FileSystem.globStatus`, list filtering helpers, and user code supplying custom filters. Risks are low but include filters throwing runtime exceptions, assumptions about qualified versus relative input paths, and performance impact when invoked over large listings. Tests are generally in consumers: glob/listing should apply filters exactly once per candidate, preserve accepted paths, and propagate or handle exceptions consistently.

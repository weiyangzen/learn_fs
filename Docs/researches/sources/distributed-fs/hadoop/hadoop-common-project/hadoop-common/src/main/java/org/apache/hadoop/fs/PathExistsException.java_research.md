## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PathExistsException.java

`PathExistsException` is the POSIX-style EEXISTS base class for path errors where a destination already exists. It extends `PathIOException`, defaulting to "File exists", and also permits a custom error string. It carries no new state. It is the parent for more specific directory/type/operation exceptions in this package, so message formatting and path/target/operation behavior come from `PathIOException`. Integration is with create, mkdir, rename, and delete operations. Risks include subclasses such as `PathOperationException` inheriting from an "exists" class even when semantically ENOTSUP, which can surprise broad exception handlers. Tests should assert exact messages and subclass relationships used by filesystem operations.

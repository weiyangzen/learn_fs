## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PathIsDirectoryException.java

`PathIsDirectoryException` is a compact EISDIR-specific subtype of `PathExistsException`. Its constructor fixes the error string to "Is a directory"; all message formatting and path state are inherited. It is intended for operations that require a file but encounter a directory, such as open-for-write or append paths in concrete filesystems. There is no control flow or persistence. The main dependency is the exception hierarchy. Risks are consistency risks: some local filesystem paths still throw generic `IOException` in similar situations, so caller handling may vary by implementation. Tests should assert this exception where APIs promise POSIX path errors and verify formatted messages through inherited `PathIOException` behavior.

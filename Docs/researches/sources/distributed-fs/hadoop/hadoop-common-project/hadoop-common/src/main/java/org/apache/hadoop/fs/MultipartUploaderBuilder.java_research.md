## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/MultipartUploaderBuilder.java

`MultipartUploaderBuilder` is a generic builder contract for creating a `MultipartUploader`. It extends `FSBuilder<S,B>` and defines fluent setters for permission, buffer size, replication, block size, create/overwrite/append modes, checksum options, and `build()`. It contains no implementation state; concrete filesystem builders must validate and persist chosen parameters until construction. Dependencies include `FsPermission`, `Options.ChecksumOpt`, `FSBuilder`, and Java validation annotations. Integration mirrors Hadoop output stream builder APIs while targeting multipart upload implementations. Risks include mutually incompatible mode combinations (`create()` plus `append()`), unvalidated negative sizes/replication in implementations, and builder generic misuse. Tests should focus on concrete builders: fluent self-type returns, parameter validation, unsupported append behavior, checksum propagation, and build-time IO errors.

## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/RawPathHandle.java

`RawPathHandle` is a private unstable generic serialized wrapper for unknown-origin `PathHandle` bytes. It stores a transient read-only `ByteBuffer`, can copy bytes from another handle, returns read-only duplicates, compares by handle bytes, and implements custom Java serialization with a maximum serialized size of 1 MiB. `readObject()` validates length, reads the byte array, and wraps it; `readObjectNoData()` rejects malformed streams. State is only the byte buffer and is intended to be opaque. Dependencies include Java object serialization, `ByteBuffer`, and `PathHandle`. Integration is with APIs that need to preserve a handle without understanding backend-specific semantics. Risks include equals comparing current remaining bytes, zero-length handles for null inputs, and deserialized buffers not being read-only until returned through `bytes()`. Tests should cover null/empty handles, direct and array-backed buffers, serialization round trips, oversize/negative length rejection, equality with other `PathHandle` implementations, and immutability of returned buffers.

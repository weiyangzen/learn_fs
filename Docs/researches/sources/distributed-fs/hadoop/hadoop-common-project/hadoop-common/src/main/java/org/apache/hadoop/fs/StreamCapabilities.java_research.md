## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/StreamCapabilities.java

`StreamCapabilities` defines string-based capability probes for input/output streams. Constants cover hflush/hsync, readahead, dropbehind, unbuffer, byte-buffer reads, positioned byte-buffer reads, IOStatistics, vectored IO and sliced buffers, abortable streams, and IOStatistics context support. The required API is `hasCapability(String)`. A deprecated enum mirrors hflush/hsync for older callers. There is no state or persistence in the interface. Integration is with streams such as `RawLocalFileSystem` input/output streams, `StreamCapabilitiesPolicy`, and path capability strings. Risks include case sensitivity, constants intentionally being strings so typos silently return false, deprecated HFLUSH guidance saying HSYNC is the stronger probe, and capability claims that do not match implemented interfaces. Tests should cover known capability strings in concrete streams, lower-case normalization where implementations choose it, typo/unknown false behavior, and policy enforcement for claimed capabilities.

## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PartialListing.java

`PartialListing<T extends FileStatus>` represents either a successful partial directory listing or a deferred remote exception. Constructors enforce exactly one of listing data or `RemoteException` through `Preconditions.checkArgument(partialListing == null ^ exception == null)`. `get()` returns the list or unwraps and throws the remote exception; `getListedPath()` exposes the listed parent; `toString()` includes all fields. State is immutable references to the path, list, and optional exception, with no defensive copy. Dependencies include `RemoteException`, Commons `ToStringBuilder`, Hadoop `Preconditions`, and `FileStatus`. Integration is with batched/asynchronous listing APIs where multiple partial results must be combined. Risks include list mutability escaping, null path acceptance, and caller confusion because failure is raised only when `get()` is invoked. Tests should cover success/failure exclusivity, remote exception unwrapping, singleton listings for files, and combining multiple partial listings.

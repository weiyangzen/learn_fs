## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/MD5MD5CRC32GzipFileChecksum.java

`MD5MD5CRC32GzipFileChecksum` is the CRC32/Gzip-polynomial variant of `MD5MD5CRC32FileChecksum`. It adds no new data fields, delegates construction to the base class, and overrides `getCrcType()` to return `DataChecksum.Type.CRC32`. Its persistence and algorithm-name behavior are inherited. Integration is mainly backward compatibility with checksum names understood by older Hadoop releases. Dependencies are `MD5Hash` and `DataChecksum`. Risks are limited to base-class serialization/null-state behavior and the fact that this subtype is semantically equivalent to the base default. Tests should assert CRC32 type, inherited `ChecksumOpt`, algorithm naming, and serialization compatibility with consumers expecting the base checksum.

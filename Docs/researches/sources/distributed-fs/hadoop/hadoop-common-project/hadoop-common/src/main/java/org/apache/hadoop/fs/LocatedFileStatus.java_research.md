## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/LocatedFileStatus.java

`LocatedFileStatus` extends `FileStatus` with block location metadata for APIs such as `listLocatedStatus()` and `getFileBlockLocations()`. It provides a default constructor for serialization, a copy constructor from `FileStatus`, deprecated and current constructors carrying ACL/encryption/erasure-coded flags, `getBlockLocations()`, and a protected lazy setter. Control flow is minimal; constructors copy base status fields and optionally preserve symlinks. State consists of all inherited file metadata plus a `BlockLocation[]` reference that is not defensively copied. Dependencies include `BlockLocation`, `FileStatus`, `Path`, `FsPermission`, and file status attribute flags. Integration is central to HDFS/object-store listing paths that combine metadata and placement. Risks include mutable location arrays escaping, runtime wrapping of unexpected symlink IOExceptions, and equality/hash/compare ignoring locations because they delegate to `FileStatus`. Tests should verify constructor field preservation, symlink propagation, location getter/setter behavior, and equality semantics.

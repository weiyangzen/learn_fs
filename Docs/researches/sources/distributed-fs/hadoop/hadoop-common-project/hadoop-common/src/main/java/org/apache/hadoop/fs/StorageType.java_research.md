## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/StorageType.java

`StorageType` enumerates storage media used by HDFS and quota/reporting code: `RAM_DISK`, `SSD`, `DISK`, `ARCHIVE`, `PROVIDED`, and `NVDIMM`. Each value records whether it is transient and RAM-backed. APIs expose default `DISK`, empty array, list views, movable/quota-supporting non-transient types, ordinal parsing, string parsing with uppercase normalization, same-disk-tiering allowance for `DISK`/`ARCHIVE`, and per-type configuration lookup under `dfs.datanode.storagetype.`. State is enum constants plus cached `VALUES`. Dependencies include `Configuration` and `StringUtils`. Integration includes `QuotaUsage`, storage policies, datanode configuration, and block placement. Risks include ordinal parsing coupling to enum order, newly added transient types changing quota lists, repeated allocation in `getNonTransientTypes()`, and string parsing throwing for invalid user input. Tests should cover all type attributes, parsing, quota/movable lists, same-tiering policy, and configuration key composition.

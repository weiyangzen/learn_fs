## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/MD5MD5CRC32CastagnoliFileChecksum.java

This checksum class specializes `MD5MD5CRC32FileChecksum` for CRC32C using the Castagnoli polynomial. It only supplies constructors and overrides `getCrcType()` to return `DataChecksum.Type.CRC32C`; serialization, length, algorithm naming, and bytes are inherited. There is no extra state beyond inherited `bytesPerCRC`, `crcPerBlock`, and MD5 digest. Integration is with HDFS file checksum APIs and clients parsing algorithm names to distinguish CRC32 from CRC32C. Dependencies are `MD5Hash` and `DataChecksum`. Risks are compatibility and naming risks: callers rely on inherited `getAlgorithmName()` appending `CRC32C`. Tests should validate algorithm name, `ChecksumOpt`, writable round trips through the base class, and parsing via `getCrcTypeFromAlgorithmName()`.

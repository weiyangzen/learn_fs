## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/QuotaUsage.java

`QuotaUsage` is a public evolving value object for directory namespace and storage quota accounting. Its builder initializes unset quotas to `-1`, allocates arrays sized to `StorageType.values()`, copies provided arrays, and sets file/directory count, namespace quota, space consumed/quota, and per-storage-type consumed/quota values. Public APIs expose getters, type-quota availability tests, equality/hash, formatted string output, static quota headers, storage-type headers, and human-readable formatting. State is mutable only through protected setters for `ContentSummary` compatibility; array references from the builder are assigned directly after builder-managed copies. Dependencies include `StorageType`, `StringUtils.TraditionalBinaryPrefix`, arrays/lists, and classification annotations. Integration is with `ContentSummary`, quota commands, and storage policy reporting. Risks include ordinal coupling to `StorageType`, array length assumptions in builder copy methods, negative quota semantics (`-1` unset versus `0`), and formatting widths used by CLI parsers/tests. Tests should cover builder defaults, per-type quota support, human and raw formatting, equality/hash with arrays, header generation, and behavior when storage types are added.

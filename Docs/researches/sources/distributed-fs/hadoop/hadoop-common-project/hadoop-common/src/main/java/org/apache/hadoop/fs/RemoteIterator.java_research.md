## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/RemoteIterator.java

`RemoteIterator<E>` is a minimal iterator-like interface whose `hasNext()` and `next()` can throw `IOException` while fetching remote data. `next()` may also throw `NoSuchElementException`. It carries no state itself and deliberately does not extend `Iterator` because Java's `Iterator` cannot throw checked IO exceptions. Integration is pervasive in listing APIs such as `listFiles`, `listLocatedStatus`, and object-store paginated listings. Risks include callers treating it as a normal iterator and not handling IO on either method, implementations with non-idempotent `hasNext()`, and resource cleanup being implementation-specific. Tests should cover pagination, `hasNext()`/`next()` error propagation, no-element behavior, and closing/cleanup where concrete iterators also own resources.

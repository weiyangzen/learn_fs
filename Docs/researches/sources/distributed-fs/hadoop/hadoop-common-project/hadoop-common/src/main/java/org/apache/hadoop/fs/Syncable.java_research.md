## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/Syncable.java

`Syncable` is a stable public interface for Hadoop stream flush/sync semantics. `hflush()` flushes client buffers so new readers can see data; `hsync()` is closer to POSIX fsync by pushing data toward durable storage. The interface has no state and leaves exact semantics to the Hadoop filesystem specification and implementations. Integration includes output streams such as `RawLocalFileSystem.LocalFSFileOutputStream`, HDFS streams, and `StreamCapabilities.HSYNC` probes. Risks include filesystem-specific durability differences, streams claiming sync support without implementing the interface, and applications assuming `hflush()` implies disk durability. Tests should cover visibility after `hflush()`, durability or file descriptor sync behavior after `hsync()` where testable, error propagation, and capability consistency.

## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/LocalFileSystemConfigKeys.java

`LocalFileSystemConfigKeys` centralizes private unstable configuration constants for local, raw local, and checksum filesystem behavior. It extends `CommonConfigurationKeys` and defines keys/defaults for file block size, replication, stream buffer size, bytes per checksum, and client write packet size. There is no control flow, mutable state, or persistence. Dependencies are classification annotations and the broader common configuration hierarchy. Integration is through code that reads `file.blocksize`, `file.replication`, `file.stream-buffer-size`, `file.bytes-per-checksum`, and `file.client-write-packet-size`. Risks are compatibility risks: changing names or defaults alters long-standing local filesystem behavior. Test signals are configuration field coverage tests and local filesystem create/checksum tests that verify these defaults are honored.

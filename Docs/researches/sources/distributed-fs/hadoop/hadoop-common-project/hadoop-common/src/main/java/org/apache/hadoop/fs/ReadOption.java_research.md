## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/ReadOption.java

`ReadOption` is a stable public enum for read-time behavior flags. It currently has one value, `SKIP_CHECKSUMS`, intended for formats with their own checksums or tests that need checksum bypass. There is no state, control flow, persistence, or dependency beyond annotations. Integration is with filesystem/open APIs that accept read options and checksum-aware filesystems such as `ChecksumFileSystem`. Risks include implementations silently ignoring the option, callers using it in production and losing corruption detection, and future enum additions affecting switch statements without default handling. Tests should cover checksum verification enabled/disabled paths, option propagation through open APIs, and unsupported filesystem behavior.

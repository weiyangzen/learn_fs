## sources/distributed-fs/hadoop/hadoop-common-project/hadoop-common/src/main/java/org/apache/hadoop/fs/PathAccessDeniedException.java

`PathAccessDeniedException` is a `PathIOException` subtype corresponding to EACCES. It supplies constructors for the default "Permission denied" message, a cause, or a custom error plus cause. It has no additional state beyond `PathIOException` path/operation/target formatting fields. Integration is with filesystem operations that fail due to access checks and with tests/assertions expecting POSIX-like error classes. Dependencies are inherited from `PathIOException`. Risks are mainly consistency risks: implementations must distinguish EACCES from EPERM (`PathPermissionException`) and generic IO. Tests should validate formatted messages, cause propagation, and correct use in permission-denied paths.

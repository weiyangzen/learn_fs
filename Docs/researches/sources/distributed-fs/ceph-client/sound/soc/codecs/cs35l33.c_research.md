# sources/distributed-fs/ceph-client/sound/soc/codecs/cs35l33.c

## Purpose

`cs35l33.c` is the ALSA SoC codec and I2C driver for the Cirrus Logic CS35L33 smart amplifier. It binds an I2C device, validates the chip ID, applies a small register patch, exposes a single ASoC DAI with playback and capture, and manages power, clocks, DAPM routing, interrupt handling, and runtime PM for the amplifier, boost converter, and monitor ADC paths.

## Important APIs, Types, And Functions

The central state object is `struct cs35l33_private`, which stores component state, `struct cs35l33_pdata`, regmap, reset GPIO, calibration state, internal MCLK, `VA`/`VP` regulators, and TDM/soft-ramp flags. Register access is constrained by `cs35l33_volatile_register`, `cs35l33_writeable_register`, and `cs35l33_readable_register` using an 8-bit `REGCACHE_MAPLE` regmap. The ASoC surface is `soc_component_dev_cs35l33` and `cs35l33_dai`; DAI operations cover startup constraints, tristate, format, `hw_params`, and TDM slot routing.

## Control Flow

Probe allocates state, initializes I2C regmap, enables supplies, parses platform data or OF, requests IRQ/reset GPIO, validates ID with `cirrus_read_device_id`, reads revision, applies `cs35l33_patch`, disables MCLK/TDM output, enables runtime PM autosuspend, and registers the component. Component probe applies platform boost, amp-drive, soft-ramp, IMON, HG/class-H, and interrupt-mask settings. DAPM events sequence boost, SDIN, SDOUT, amplifier calibration, and MCLK/global power-down. `hw_params` maps MCLK/rate pairs to ADSP rate fields and configures TDM RX depth.

## State And Persistence Behavior

Hardware register state is cached through regmap and restored on runtime resume. Runtime suspend marks the cache dirty, disables supplies, and clears `amp_cal`; resume reenables regulators, releases reset, waits boot delay, and syncs cache. Persistent software state includes platform data, internal MCLK, TDM mode, soft-ramp enablement, and calibration state.

## Dependencies And Integration Points

The file depends on Linux I2C, regmap, regulators, GPIO, runtime PM, ASoC component/DAI/DAPM APIs, `cirrus_legacy.h`, public `include/sound/cs35l33.h`, and local `cs35l33.h`. OF integration uses `cirrus,cs35l33` plus boost, ramp, IMON, and `cirrus,hg-algo` child properties.

## Risks And Test Signals

Strict MCLK/rate tables and 8-bit-only TDM slots can reject board configurations. IRQ request failure is only a warning, so fault reporting may be absent. Several regmap writes ignore return values. Useful tests are probe/revision detection, supported and unsupported `hw_params`, DAPM power transitions, TDM slot routing, runtime suspend/resume cache sync, and interrupt handling for amp short, calibration, thermal, clock, and monitor-overflow faults. No tests were run for this research pass.

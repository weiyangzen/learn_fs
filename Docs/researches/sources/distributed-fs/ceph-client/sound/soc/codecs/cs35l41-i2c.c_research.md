# sources/distributed-fs/ceph-client/sound/soc/codecs/cs35l41-i2c.c

## Purpose

`cs35l41-i2c.c` is the I2C transport wrapper for the CS35L41 codec family driver. It does not implement codec behavior itself; it allocates `struct cs35l41_private`, creates an I2C regmap, wires device and IRQ fields, and delegates probe/remove/PM behavior to the shared CS35L41 core.

## Important APIs, Types, And Functions

The main functions are `cs35l41_i2c_probe` and `cs35l41_i2c_remove`. Match tables cover I2C IDs `cs35l40`, `cs35l41`, `cs35l51`, `cs35l53`, OF compatibles `cirrus,cs35l40` and `cirrus,cs35l41`, and ACPI ID `CSC3541`. `cs35l41_i2c_driver` uses `pm_ptr(&cs35l41_pm_ops)` and is registered with `module_i2c_driver`.

## Control Flow

Probe gets optional platform hardware config, devm-allocates private state, stores `dev` and `client->irq`, installs client data, initializes `cs35l41_regmap_i2c`, and calls shared `cs35l41_probe(cs35l41, hw_cfg)`. Remove fetches private state and calls `cs35l41_remove`.

## State And Persistence Behavior

This file owns only transport-level setup. Codec state, supplies, reset GPIO, DSP/firmware state, controls, IRQ handling, and PM live in the shared CS35L41 implementation. Devm allocation leaves minimal local cleanup.

## Dependencies And Integration Points

It depends on Linux I2C, ACPI, OF, module, platform data, slab allocation, `cs35l41.h`, `cs35l41-lib.c` for `cs35l41_regmap_i2c`, and `cs35l41.c` for shared probe/remove/PM.

## Risks And Test Signals

The I2C ID table includes related parts not listed in OF, so shared-core identification must handle them. IRQ is passed without local validation, and absent platform data must be handled by the core. Test signals are modalias/OF/ACPI matching, regmap allocation, entry into shared probe, IRQ propagation, delegated remove, and shared PM callback use. No tests were run.

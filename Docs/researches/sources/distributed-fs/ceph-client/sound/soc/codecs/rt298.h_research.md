# sources/distributed-fs/ceph-client/sound/soc/codecs/rt298.h

`rt298.h` is the register-definition header for the RT298 codec. It supplies HDA node IDs, encoded verb macros, vendor index registers, mux and mixer masks, clock selectors, unsolicited response commands, and DAI IDs.

The important API surface includes `VERB_CMD()`, power and pin-widget macros, SPK/HPO/ADC muxes, EAPD, amp gains, record/front mixer switches, DAC/ADC stream formats, coefficient access, HP/MIC sense, and unsolicited enable commands. Index registers include digital filter, power, I2S, clock, DC gain, mic detection, IRQ, wind filter, VAD, combo-jack, PLL, depop, and IRQ flag controls. The enum declares `RT298_AIF1`, `RT298_AIF2`, and `RT298_AIFS`.

There is no executable state. The header drives `rt298.c` probe, DAPM, jack, DAI, and PM behavior. Risks are wrong bit shifts, assuming RT286 compatibility where RT298 has extra VAD/filter/unsolicited registers, and exposing mux values that are only partly surfaced by controls. Test signals include compile coverage, ALSA control operation, unsolicited jack setup, and machine-driver DAI/clock selector validation.

# sources/distributed-fs/ceph-client/sound/soc/codecs/nau8822.c

## Purpose
Implements the ASoC codec driver for the Nuvoton NAU8822 stereo codec. It provides stereo playback and capture controls, EQ byte access, a broad DAPM graph for headphones, speakers, AUX outputs, input PGAs, boost mixers, digital loopback, PLL/MCLK clock configuration including optional `mclk`, DAI format and PCM parameter setup, bias sequencing, suspend/resume cache handling, and I2C/OF registration.

## Important APIs, Types, And Functions
The main registration objects are `nau8822_i2c_driver`, `soc_component_dev_nau8822`, and DAI `nau8822-hifi`. DAI callbacks are `nau8822_hw_params`, `nau8822_mute`, `nau8822_set_dai_fmt`, `nau8822_set_dai_sysclk`, and `nau8822_set_pll`. Clock helpers include `nau8822_calc_pll` and `nau8822_config_clkdiv`. EQ controls use `nau8822_eq_get` and `nau8822_eq_put`. Component callbacks include `nau8822_probe`, `nau8822_suspend`, `nau8822_resume`, and `nau8822_set_bias_level`.

## Control Flow
I2C probe allocates private data, obtains optional clock `mclk`, initializes the I2C regmap, resets the codec, stores the device, and registers the component/DAI. Component probe sets update bit 8 in registers that require it for simultaneous volume updates and optionally configures speaker bridge-tied-load mode from OF property `nuvoton,spk-btl`. `set_dai_sysclk` records clock ID/frequency and uses PLL when optional MCLK exists but its rate differs from requested sysclk. `set_pll` skips unchanged settings, disables PLL if `freq_out` is zero, otherwise writes N/K/scaler values and enables PLL. `hw_params` configures BCLK dividers in master mode, validates format/rate, writes word length and sample-rate fields, then chooses MCLK or PLL clock divider settings.

DAPM routes stereo DACs to left/right output mixers, headphone/speaker/AUX outputs, stereo ADCs from boost mixers and input PGAs, mic bias to capture PGAs, and optional digital loopback from ADCs to DACs. Conditional PLL supplies are used when the clocking register selects PLL.

## State And Persistence
`struct nau8822` stores device, regmap, optional `mclk`, cached PLL parameters including last input/output frequencies, current sysclk, and divider/clock source ID. Hardware register state is cached through regmap RBTREE. Bias PREPARE enables optional MCLK and sets low reference impedance; STANDBY disables MCLK when leaving active bias, enables I/O and analog bias, and ramps reference impedance after OFF; OFF clears the three power management registers. Suspend forces bias off and marks cache dirty; resume syncs cache and forces STANDBY.

## Dependencies And Integration Points
The driver depends on Linux I2C, common clock framework, regmap, PM, OF, and ASoC component/DAI/DAPM/control frameworks. Device-tree compatible is `nuvoton,nau8822`, with optional `mclk` and `nuvoton,spk-btl` property. Machine drivers bind to `nau8822-hifi`.

## Risks
PLL input is constrained to 8-33 MHz and generated F2 to 90-100 MHz. `nau8822_calc_pll` mutates `scal_sel` as both loop bound and selected index, which is fragile if refactored. `hw_params` ignores the return value from `nau8822_config_clkdiv`, so a PLL divider mismatch can be logged but not propagated to PCM setup. Optional MCLK enable/disable is tied to bias transitions. EQ byte controls manually allocate and endian-convert data.

## Test Signals
Signals include successful probe/reset with and without optional MCLK, playback/capture at supported 8-48 kHz rates and 16/20/24/32-bit formats, direct MCLK and synthesized PLL sysclk paths, codec-master BCLK divider behavior, mute toggling, EQ get/put round trips, OF `nuvoton,spk-btl` speaker mode, DAPM route activation, and suspend/resume regcache restoration.

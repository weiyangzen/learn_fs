# sources/distributed-fs/ceph-client/sound/soc/codecs/rt5575.h

`rt5575.h` defines the RT5575 device ID, DSP mapping offset, key logical registers, boot bits, DAI IDs, and private driver state.

Important constants cover boot, ID, mixer/prompt/speaker/mic volume, WNC/mode/I2S/sleep/algorithm/pinmux/GPIO/DSP bus controls, software interrupt, boot error, DSP ready/command registers, and EFUSE data/PID registers. `RT5575_BOOT_MASK` and `RT5575_BOOT_SPI` control whether probe loads firmware over SPI. The DAI enum provides `RT5575_AIF1` through `RT5575_AIF4`; `struct rt5575_priv` stores the I2C client, component, and two regmaps.

There is no executable flow in the header. It shapes probe, firmware loading, controls, EFUSE reads, and DAI registration in `rt5575.c`. Risks include sparse masks encouraging magic values in the C file, only one named boot mode, and no locking fields in private state for future concurrent operations. Test signals include compile coverage, ID/boot register validation, DAI enum alignment, and mapped regmap reads/writes.

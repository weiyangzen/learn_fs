# sources/distributed-fs/ceph-client/sound/soc/codecs/cs35l34.c

## Purpose

`cs35l34.c` is the ALSA SoC codec and I2C driver for the Cirrus Logic CS35L34 amplifier. It initializes the I2C device, validates identity, configures regulators/reset/IRQ, registers an ASoC component and DAI, manages DAPM power sequencing, maps clocks and TDM slots, applies platform boost/amplifier options, and handles critical fault interrupts.

## Important APIs, Types, And Functions

`struct cs35l34_private` holds component state, `struct cs35l34_platform_data`, regmap, `VA`/`VP` supplies, internal MCLK, TDM mode flag, and reset GPIO. Register behavior is described by volatile/readable/precious callbacks, with interrupt status registers marked precious. DAPM handlers include `cs35l34_sdin_event`, `cs35l34_main_amp_event`, and `cs35l34_mclk_event`; DAI handlers include TDM slot, DAI format, `hw_params`, tristate, and sysclk setup. Bus lifecycle is handled by I2C probe/remove plus runtime PM callbacks.

## Control Flow

I2C probe initializes regmap, regulators, platform data or OF, IRQ, reset, ID/revision validation, critical interrupt unmasking, runtime PM, and component registration. Component probe powers blocks down, mutes the amp, and applies platform settings for boost peak/inductor, gain zero-cross, ADSP drive, digital ramp, inversion, I2S input location, and TDM edge. DAPM events power SDIN/global state, program boost voltage, mute/unmute, and poll `PDN_DONE` on MCLK power-down.

## State And Persistence Behavior

Runtime suspend enables cache-only mode, marks regcache dirty, asserts reset, and disables supplies. Resume reenables supplies, releases reset, waits startup delay, and syncs regcache. Software state persists MCLK, TDM mode, and parsed platform options.

## Dependencies And Integration Points

The driver depends on I2C, regmap, regulators, GPIO, runtime PM, OF, IRQ, ASoC APIs, `cirrus_legacy.h`, local `cs35l34.h`, and public `include/sound/cs35l34.h`. OF uses `cirrus,cs35l34` and boost voltage/current/inductor plus drive, ramp, zero-cross, inversion, and TDM/I2S properties.

## Risks And Test Signals

Missing `cirrus,boost-ind-nanohenry` fails OF probe. IRQ request failure logs but does not abort. Some register errors are ignored, and `PDN_DONE` timeout is logged rather than returned. TDM slot routing is hard-coded and 8-bit-only. Test signals include probe, property validation, supported sysclk/rate pairs, TDM routing, DAPM boost/mute transitions, runtime PM cache sync, and IRQ handling for thermal, amp, calibration, and boost faults. No tests were run.

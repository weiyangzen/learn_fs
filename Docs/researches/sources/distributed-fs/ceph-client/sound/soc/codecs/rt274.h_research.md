# sources/distributed-fs/ceph-client/sound/soc/codecs/rt274.h

`rt274.h` is the RT274 register-definition header. It provides HDA node IDs, the `VERB_CMD(V, N, D)` address encoder, encoded verb-register macros, vendor index register names, bit masks, clock/PLL source constants, and DAI IDs used by `rt274.c`.

The important API surface is symbolic rather than functional: macros such as `RT274_SET_AUDIO_POWER`, `RT274_DAC_FORMAT`, `RT274_ADC_FORMAT`, `RT274_GET_HP_SENSE`, `RT274_UNSOLICITED_HP_OUT`, and `RT274_I2S_CTRL1` are the driver-facing register API. The enum declares `RT274_AIF1` and `RT274_AIFS`.

There is no runtime control flow or storage in the header. Its definitions control how probe, DAPM, jack detection, stream formatting, PLL, TDM, and PM replay in `rt274.c` target hardware. Risks are silent misaddressing from wrong node IDs or bit shifts and tight coupling to vendor-index register layout. Test signals are compile coverage plus runtime verification of power, pin sense, stream format, I2S, TDM, and PLL/BCLK source paths.

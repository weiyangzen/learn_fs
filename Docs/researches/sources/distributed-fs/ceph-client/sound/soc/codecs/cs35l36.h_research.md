# sources/distributed-fs/ceph-client/sound/soc/codecs/cs35l36.h

## Purpose

`cs35l36.h` is the local register and bit-field header for the CS35L36/CS35L37 ASoC codec driver. It defines the 32-bit register map, interrupt masks, PLL/ASP/PDM/boost/VPBR fields, revision and OTP identifiers, protected test-key values, PAC memory constants, supported PCM formats, and an external PAC patch symbol.

## Important APIs, Types, And Functions

The header defines constants for reset, OTP, PAC, power, PLL, ASP, SoundWire-related selectors, monitor ADCs, boost, VPBR/VBBR, class-H, PDM, interrupt, and PAC program-memory registers. Important masks cover ASP clock provider/inversion/format, RX/TX width and slots, PLL source/frequency, PCM input, global enable/FS, boost limits, critical errors, release bits, A0/B0 revision IDs, L36/L37 OTP detection, VPBR fields, and `CS35L36_RX_FORMATS`/`CS35L36_TX_FORMATS`. It declares `cs35l36_a0_pac_patch`.

## Control Flow And State

There is no executable control flow, but the constants drive regmap access, probe identity checks, revision patching, PAC programming, PLL setup, ASP DAI format and `hw_params`, DAPM sequencing, VPBR application, 10V safety clamping, IRQ release cycles, and remove-time interrupt mask reset.

## Dependencies And Integration Points

The header includes `<linux/regmap.h>`, relies on ALSA PCM macros from the inclusion context, and pairs with public `include/sound/cs35l36.h` platform data. It is local to `cs35l36.c` and any compilation unit providing the PAC patch symbol.

## Risks And Test Signals

The sparse 32-bit address space and protected test-key writes make incorrect addresses or missing relock operations risky. Some boost macros are named `CS35L35_`, which is confusing in a CS35L36 file. Default interrupt masks encode safety posture. Compile/link success, 32-bit regmap access, A0/B0 patch application, PLL/ASP writes, IRQ mask reset, and chip-version detection are main validation signals. No tests were run.

# sources/distributed-fs/ceph-client/sound/soc/codecs/cs35l34.h

## Purpose

`cs35l34.h` provides the local CS35L34 register map, clock values, PCM capability masks, interrupt definitions, power-control masks, boost/class-H/brownout/TDM register fields, and protection-release bits used by `cs35l34.c`.

## Important APIs, Types, And Functions

The header defines constants only. Major groups include `CS35L34_CHIP_ID`, register addresses through `CS35L34_OTP_TRIM_STATUS`, power-control bits, ADSP/MCLK clock fields, amplifier volume/protection bits, boost voltage/current masks, TDM RX/TX location and enable registers, four banks of interrupt mask/status bits, `CS35L34_RATES`, and `CS35L34_FORMATS`.

## Control Flow And State

The C file uses these constants for regmap callbacks, probe defaults, platform-data programming, DAI sysclk/sample-rate setup, TDM slot routing, DAPM power transitions, `PDN_DONE` polling, and interrupt release cycles. The header stores no mutable state but encodes hardware state layout.

## Dependencies And Integration Points

It relies on ALSA PCM macros from the including context and pairs with public `include/sound/cs35l34.h` platform data. It is local to the codec implementation.

## Risks And Test Signals

Incorrect masks can cause wrong boost voltage/current, missed interrupts, bad TDM routing, or failed power-down detection. Similar mask/status names make confusion possible. Compile success, expected regmap access, boost/MCLK/ADSP writes, TDM routing, and IRQ decode/release are primary validation signals. No tests were run.

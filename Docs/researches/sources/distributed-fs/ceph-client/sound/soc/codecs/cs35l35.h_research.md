# sources/distributed-fs/ceph-client/sound/soc/codecs/cs35l35.h

## Purpose

`cs35l35.h` is the local register, bit-field, and private-state header for the CS35L35 codec driver. It also defines `struct cs35l35_private` and the static `VA`/`VP` supply-name table used by the implementation.

## Important APIs, Types, And Functions

The header defines register ranges, chip ID, 8-bit register addresses, power-down bits, serial-port fields, clock-source fields, RX/TX depth/location fields, boost converter coefficients, class-H controls, protection release bits, interrupt status masks, and PCM formats. `struct cs35l35_private` stores device, public platform data, regmap, regulators, sysclk/SCLK, PDM/I2S flags, clock role, reset GPIO, and `pdn_done`.

## Control Flow And State

The macros drive probe, component probe, DAI setup, DAPM events, and IRQ handling in `cs35l35.c`. The header stores no mutable state directly except defining the private struct layout and supply names copied during probe.

## Dependencies And Integration Points

It depends on public `include/sound/cs35l35.h` platform data and Linux/ASoC types available through the including C file. It is implementation-local rather than a broad external API.

## Risks And Test Signals

Changing this file can alter both hardware programming and private object layout. Wrong depth/location or interrupt masks can break capture layout or safety reporting. Validation signals include compile success, regulator lookup, private-state initialization, regmap callbacks, DAI format negotiation, and IRQ bit decoding. No tests were run.

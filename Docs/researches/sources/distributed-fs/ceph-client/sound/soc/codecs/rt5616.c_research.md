# sources/distributed-fs/ceph-client/sound/soc/codecs/rt5616.c

`rt5616.c` is the ASoC I2C driver for Realtek RT5616, a stereo analog codec with microphone inputs, ADC/DAC paths, headphone and line outputs, private-register paging, PLL support, depop sequencing, and one bidirectional DAI.

`struct rt5616_priv` stores component/regmap, optional MCLK, sysclk source/rate, per-DAI LRCK/BCLK/master state, and PLL source/input/output state. The regmap uses an 8-bit register/16-bit value layout plus `rt5616_ranges` to expose private registers through `RT5616_PRIV_INDEX`/`RT5616_PRIV_DATA`. Probe validates device ID `0x6281`, resets hardware, powers VREF/MB/BG, applies a private-register init patch, sets LDO voltage, and registers the component.

Runtime control flow includes DAPM input boosts, record mixers, ADCs, digital interface, DAC mixers, output mixers, HP/line amps, and charge pump. Event handlers manage ADC mute, boost op stages, charge-pump depop, headphone unmute/mute, and line-out power/mute. DAI `hw_params` computes clock dividers from sysclk and LRCK using `rl6231_get_clk_info()`, validates frame size and sample format, and programs I2S length and ADDA divider. PLL setup uses `rl6231_pll_calc()` for MCLK or BCLK sources. Bias transitions enable/disable MCLK, power references in standby, and clear power registers when off. Shutdown mutes HP and line outputs.

State persists through maple regcache, private-register range cache, clock/PLL fields, and DAPM power state. Suspend marks regcache dirty and resume syncs it. Dependencies include I2C, regmap ranges, ASoC, optional MCLK, OF matching, and `rl6231`. Risks include ordered depop sequences with sleeps, limited DAI polarity support, BCLK2 treated like BCLK1 for PLL source programming, and clock-balance assumptions. Test signals include probe/ID failure, private patch writes, playback/capture rates/formats, MCLK/PLL sysclk paths, invalid format rejection, DAPM routes, pop/noise checks, suspend/resume, bias-off clearing, and shutdown mute writes.

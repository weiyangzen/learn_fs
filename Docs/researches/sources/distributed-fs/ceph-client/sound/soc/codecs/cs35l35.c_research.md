# sources/distributed-fs/ceph-client/sound/soc/codecs/cs35l35.c

## Purpose

`cs35l35.c` is the ALSA SoC codec/I2C driver for the Cirrus Logic CS35L35 amplifier. It supports PCM and PDM DAIs, configures boost/class-H/monitor paths from platform data or device tree, applies a revision-A0 errata patch, manages shared reset and regulators, exposes audio/advisory controls, and handles protection interrupts including `PDN_DONE` completion.

## Important APIs, Types, And Functions

State is `struct cs35l35_private` from `cs35l35.h`, including device, platform data, regmap, regulators, sysclk/SCLK, PDM/I2S flags, clock-consumer role, reset GPIO, and `pdn_done`. Register callbacks mark status/PLL/OTP registers volatile and precious. DAPM helpers are `cs35l35_sdin_event`, `cs35l35_main_amp_event`, and `cs35l35_wait_for_pdn`. PCM and PDM DAIs share format and `hw_params` logic, while startup functions apply different rate constraints and PDM mode bits.

## Control Flow

Probe initializes regmap/regulators/platform data, enables supplies, handles optional/shared reset, requests shared IRQ, validates ID/revision, applies errata, masks critical interrupts, powers down blocks, mutes the amp, and registers two DAIs. Component probe applies boost voltage/current/inductor, stereo/advisory routing, shared boost, serial drive, class-H algorithm fields, and monitor capture depth/location/scaling. `hw_params` maps sysclk/rate to clock config, applies an A0 weak-FET erratum, programs playback depth, and validates I2S SCLK/FS ratio by clock role.

## State And Persistence Behavior

There are no runtime PM callbacks; regulators remain enabled until remove or probe error. Persistent software state includes parsed platform data, sysclk/SCLK, mode flags, clock role, and completion state. `CS35L35_VALID_PDATA` marks valid zero-valued platform fields and relies on masked writes to avoid leaking the marker bit.

## Dependencies And Integration Points

The file depends on I2C, regmap, regulators, GPIO, OF, completions, IRQ, ASoC APIs, `cirrus_legacy.h`, public `include/sound/cs35l35.h`, and local `cs35l35.h`. OF covers boost settings, stereo/shared boost, external boost, class-H child data, and monitor-signal-format arrays.

## Risks And Test Signals

The valid-marker pattern is fragile. Class-H parsing duplicates `classh-bst-max-limit`, and VBSTMON depth programming uses `vpmon_dpth`, both worth review. `PDN_DONE` depends on IRQ delivery. Shared reset requires board-level validation. Test signals include probe/errata application, PCM and PDM DAI registration, sysclk/rate validation, SCLK ratio checks, DAPM `PDN_DONE`, stereo advisory controls, monitor routing, and IRQ releases for amp/thermal/boost/VPBR/monitor faults. No tests were run.

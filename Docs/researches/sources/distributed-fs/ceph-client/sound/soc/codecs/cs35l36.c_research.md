# sources/distributed-fs/ceph-client/sound/soc/codecs/cs35l36.c

## Purpose

`cs35l36.c` is the ALSA SoC codec/I2C driver for CS35L36/CS35L37-family Cirrus Logic amplifiers. It uses 32-bit register addressing, configures PLL and ASP audio, supports monitor capture muxes, applies revision-specific errata and PAC trim flows, parses boost/VPBR/IRQ board data, clamps unsafe 10V settings, and handles critical protection interrupts.

## Important APIs, Types, And Functions

`struct cs35l36_private` stores device, platform data, regmap, supplies, PLL source, chip version, revision, LDM state, and reset GPIO. Register callbacks cover the sparse 32-bit map and PAC memory. Controls expose PCM volume/ramp, analog gain, zero-cross, PDM LDM ramp switches, and custom `LDM Select`. DAPM widgets route channel mux, boost/class-H/main amp, six ASP TX paths, and monitor muxes. Key functions are `cs35l36_set_dai_fmt`, `cs35l36_pcm_hw_params`, `cs35l36_dai_set_sysclk`, `cs35l36_component_set_sysclk`, `cs35l36_pac`, `cs35l36_apply_vpbr_config`, and `cs35l36_irq`.

## Control Flow

I2C probe initializes regmap/regulators/platform data, releases reset, validates chip ID, reads revision and OTP variant, applies A0/B0 errata, runs B0 PAC, applies VPBR config, derives IRQ polarity, requests IRQ, unmasks critical interrupts, logs L36/L37 identity, and registers the component. Component probe applies A0 DCM workarounds, PCM inversion, multi-amp Hi-Z, monitor polarity, boost config, temperature/IRQ settings, 10V clamping, and disables `SYNC_GLOBAL_OVR`. DAI format configures provider mode, gated/continuous clocks, I2S/DSP_A, and inversion. `hw_params` programs global FS and ASP frame width. Component sysclk programs PLL reference and handles PDM clock-source switching with LDM noise-gate delay changes.

## State And Persistence Behavior

There is no runtime PM; supplies remain enabled while bound and are disabled on remove/error. Regmap caches large 32-bit defaults and treats interrupts/PAC memory as volatile where needed. Persistent software state includes revision, chip version, selected PLL source, LDM state, parsed platform data, and reset GPIO. Test-key unlock/lock sequences protect sensitive register writes.

## Dependencies And Integration Points

The driver depends on I2C, regmap, regulators, GPIO, IRQ trigger metadata, OF, ASoC APIs, public `include/sound/cs35l36.h`, and local `cs35l36.h`. OF requires boost voltage/current/inductor and may include multi-amp, DCM, inversion, polarity, IRQ, temperature, boost-select, and `cirrus,vpbr-config` child properties.

## Risks And Test Signals

OF missing required boost properties fails probe. Valid-marker fields must be masked. `hw_params` may succeed without a matching global FS table entry. The boost-overvoltage IRQ path appears to use the temperature-error release bit and merits datasheet review. Test signals include A0/B0 probe, PAC completion, L36/L37 clamping, IRQ polarity, PLL references, ASP formats, FS/frame width writes, PDM switching with LDM, DAPM PLL-unlock warnings, and critical IRQ releases. No tests were run.

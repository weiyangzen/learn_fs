# sources/distributed-fs/ceph-client/sound/soc/codecs/rt5575.c

`rt5575.c` is the ASoC I2C component driver for Realtek ALC5575/RT5575. It exposes four symmetric playback/capture AIFs, simple generic input/output DAPM routes, volume/switch controls, device-ID validation, optional SPI firmware boot, and EFUSE private ID logging.

State is held in `struct rt5575_priv`: I2C client, component pointer, raw DSP regmap, and logical component regmap. The logical regmap forwards reads/writes to the DSP regmap with `RT5575_DSP_MAPPING`. Probe allocates both regmaps, verifies `RT5575_DEVICE_ID`, reads boot mode, and if SPI boot is selected requires `CONFIG_SND_SOC_RT5575_SPI`, configures DSP bus registers, calls the SPI firmware loader, releases DSP reset, triggers `RT5575_SW_INT`, and polls for completion. Component probe saves the component and logs EFUSE private ID.

The exposed ASoC surface is deliberately simple: four DAIs support 1-8 channels, 8 kHz to 192 kHz, and 8/16/20/24/32-bit samples; DAPM routes all captures from `INPUT` and all playbacks to `OUTPUT`; controls cover speaker, mic, mix, and prompt volumes/switches. Dependencies include I2C, regmap, ASoC, OF matching, and the optional SPI helper. Risks include generic DAPM not modeling real power, collapsed SPI-load errors, no PM hooks, and subtle `regmap_read_poll_timeout()` use on `SW_INT`. Test signals include ID rejection, SPI and non-SPI boot paths, firmware loading and SW interrupt clearing, EFUSE logging, all four DAIs, controls, and missing firmware handling.

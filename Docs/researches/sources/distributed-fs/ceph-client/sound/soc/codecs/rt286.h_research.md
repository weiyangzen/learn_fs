# sources/distributed-fs/ceph-client/sound/soc/codecs/rt286.h

`rt286.h` defines the RT286/RT288 HDA node IDs, encoded verb addresses, vendor index registers, mixer/mux/clock bit fields, GPIO verbs, and DAI IDs used by the RT286 driver.

Its key API is macro-based. `VERB_CMD()` creates regmap keys. Macros cover audio/node power, SPK/HPO/ADC muxes, MIC and pin widgets, EAPD, amp gains, record/front mixers, stream formats, coefficient access, GPIO mask/direction/data, and HP/MIC sense. Index constants cover bias, power, I2S, clock divider, DC gain, IRQ, PLL, combo-jack, GPIO, and depop control. The enum provides `RT286_AIF1`, `RT286_AIF2`, and `RT286_AIFS`.

The header has no executable flow. `rt286.c` uses it to implement probe defaults, DAPM routes, jack detection, clock setup, and PM replay. Risks are silent hardware misrouting from wrong verb construction, value enums that expose only a subset of possible ADC mux values, and unsafe assumptions that similar RT286/RT298 constants are interchangeable. Test signals include compile coverage, DAI ID matching, GPIO quirk validation, and ALSA control/mux runtime checks.

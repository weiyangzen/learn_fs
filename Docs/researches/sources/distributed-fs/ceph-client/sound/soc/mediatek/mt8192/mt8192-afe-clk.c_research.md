# sources/distributed-fs/ceph-client/sound/soc/mediatek/mt8192/mt8192-afe-clk.c

This file owns MT8192 AFE clock discovery, parent selection, top-level AFE clock enable/disable, APLL tuner control, and per-I2S/TDM master-clock divider programming. `aud_clks[CLK_NUM]` maps enum values from `mt8192-afe-clk.h` to device-tree clock names. Public APIs include `mt8192_init_clock()`, `mt8192_afe_enable_clock()`, `mt8192_afe_disable_clock()`, APLL enable/disable helpers, APLL selection helpers, `mt8192_mck_enable()`, `mt8192_mck_disable()`, and `mt8192_set_audio_int_bus_parent()`.

Probe calls `mt8192_init_clock()`, which allocates `afe_priv->clk`, obtains each named CCF clock, and looks up the `apmixedsys`, `topckgen`, and `infracfg` syscon regmaps. Runtime resume enables infra audio clocks, parents top audio muxes to the 26 MHz or APLL sources, and enables `aud_afe_clk`; runtime suspend disables in reverse. APLL enable paths select the APLL mux tree, enable the 22M/24M and tuner clocks, program tuner registers, and set `AFE_HD_ENGEN_ENABLE`. MCLK enable chooses APLL1 for non-8-kHz-family rates and APLL2 for 8-kHz-family rates, parents the per-I2S mux, enables the divider, and sets the divider rate.

State lives in `struct mt8192_afe_private` as clock arrays and syscon regmaps, plus hardware CCF enable counts, mux parents, tuner bits, and divider rates. Integration points are runtime PM in `mt8192-afe-pcm.c` and DAPM event handlers in the I2S/TDM DAI files. Risks include missing DT clocks being stored as NULL but later dereferenced, and incomplete error unwinding after partial clock enable failures. Test signals are runtime suspend/resume, APLL1/APLL2 sample-rate families, `set_sysclk()` divisibility failures, and DAPM paths that enable I2S/TDM MCLKs.

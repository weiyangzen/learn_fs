# sources/distributed-fs/ceph-client/sound/pci/es1968.c

## Purpose

This file implements the ALSA PCI driver for ESS Maestro 1, Maestro 2, and Maestro 2E audio devices. It drives the Maestro APU and wavecache hardware as PCM playback/capture engines, exposes an AC97 mixer, optional MPU-401, optional gameport, optional hardware-volume input events, and optional TEA575x radio support.

## Important APIs, Types, and Functions

`struct es1968` is the card state, including module configuration, chip type, clock, DMA arena, AC97/rawmidi handles, indirect register caches, APU allocation map, active substream list, Bob timer state, PM state, optional gameport/input/radio fields, and work item for hardware volume. `struct esschan` is per-open PCM state with assigned APUs, APU modes, DMA and mix buffers, format flags, current pointers, period accounting, Bob timer frequency, and list linkage. Low-level helpers include `maestro_write/read()`, `apu_set/get_register()`, `wave_set/get_register()`, and AC97 bus callbacks. DMA arena management is handled by `snd_es1968_init_dmabuf()`, `snd_es1968_new_memory()`, `snd_es1968_free_memory()`, and `snd_es1968_hw_params/free()`.

## Control Flow

Probe creates the ALSA card, clamps total DMA size, enables PCI, enforces a 28-bit DMA mask, requests I/O and IRQ, initializes locks/lists/APU maps, applies PM allowlist policy, initializes hardware, optionally sets up radio support, creates PCM and AC97 mixer devices, conditionally enables MPU-401, creates optional gameport/input devices, starts IRQs, measures clock when needed, and registers the card. PCM creation allocates one low DMA arena and writes wavecache PCMBAR registers. Playback open allocates one APU pair; capture open allocates one input-mixer pair, one SRC pair, and a 1 KiB mix buffer. Prepare programs APUs and wavecache. Trigger starts/stops APUs and manages Bob timer clients. Sound IRQs drive period accounting by walking active substreams and calling `snd_es1968_update_pcm()`.

## State and Persistence Behavior

Stream runtime persists in `esschan` instances linked from `chip->substream_list`. DMA memory is a single contiguous low-memory allocation split into aligned chunks and coalesced on free. APU and Maestro indirect registers are cached in `apu_map` and `maestro_map`. AC97 state is owned by ALSA AC97. PM is only enabled by policy; suspend stops Bob and suspends AC97, while resume reinitializes hardware, restores PCMBAR, restarts IRQs, resumes AC97, reprograms existing streams, and restarts Bob if needed.

## Dependencies and Integration Points

The driver integrates with PCI, ALSA PCM and AC97, MPU-401 UART, optional gameport, optional Linux input for hardware keys, optional V4L2/TEA575x radio, DMA allocation APIs, workqueues, mutexes/spinlocks, and low-level I/O. It depends on Maestro APU/wavecache behavior and a constrained DMA address range.

## Risks and Test Signals

Risks include DMA arena fragmentation, low 28-bit address requirements, Bob timer period-accounting sensitivity, machine-specific PM failures, hardware-volume work racing with suspend, and radio configuration changing init flow. Test all PCI IDs, AC97 mixer access, playback/capture stream counts, concurrent starts/stops, DMA arena exhaustion/reuse, Bob period callbacks, clock measurement, allowlisted suspend/resume, MPU denylist behavior, optional input/gameport/radio paths, and TEA575x detection.

## Purpose
`sources/distributed-fs/ceph-client/Documentation/devicetree/bindings/rtc/atmel,at91sam9260-rtt.yaml` is a Linux devicetree YAML schema for the `Atmel AT91 RTT` real-time clock binding. It is not executable Ceph or kernel logic; it is a hardware-description ABI used by DTS authors, dt-schema, and Linux subsystem drivers so that board descriptions match what the driver will parse at probe or early boot.

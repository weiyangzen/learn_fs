# sources/distributed-fs/ceph-client/Documentation/devicetree/bindings/media/nxp,imx8mq-mipi-csi2.yaml

**Purpose:** Defines the Devicetree JSON-schema ABI for `NXP i.MX8MQ MIPI CSI-2 receiver`. It is a MIPI CSI-2 receiver/bridge media graph binding in the Ceph client Linux source snapshot, constraining how board DTS/DTB files describe media hardware so Linux media, V4L2 mem2mem, platform, clock, reset, power-domain, IOMMU, and graph helpers can bind the correct driver resources. The source description says: This binding covers the CSI-2 RX PHY and host controller included in the NXP i.MX8MQ SoC. It handles the sensor/image input and process for all the input imaging devices.

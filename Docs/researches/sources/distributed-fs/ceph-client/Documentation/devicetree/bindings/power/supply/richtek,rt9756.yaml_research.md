# sources/distributed-fs/ceph-client/Documentation/devicetree/bindings/power/supply/richtek,rt9756.yaml

## Purpose
`sources/distributed-fs/ceph-client/Documentation/devicetree/bindings/power/supply/richtek,rt9756.yaml` defines the Linux Devicetree YAML schema for `Richtek RT9756 Smart Cap Divider Charger`, a charger or external-power-supply binding. The schema description says: The RT9756/RT9757 is a high efficiency and high charge current charger. The efficiency is up to 98.2% when VBAT = 4V, IBAT = 2A in DIV2 mode and 99.1% when VBAT=4V, IBAT=1A in bypass mode. The maximum charger current is up to 8A in DIV2 mode and 5A in bypass mode. The device integrates smart cap divider topology, direct charging mode, external over-voltage protection control, an input reverse blocking NFET and 2-way regulation, a dual phase charge pump core, 8-Channel high speed ADCs and USB BC 1.2 detection. RT9770 is almost the same with RT9756/57, only BC 1.2 detection function is removed to shrink the die... It is declarative ABI documentation and validation input, not executable driver code. Its job is to keep DTS/DTB nodes aligned with the resources, child nodes, and electrical or timing constraints expected by the matching kernel subsystem before a driver probes hardware.

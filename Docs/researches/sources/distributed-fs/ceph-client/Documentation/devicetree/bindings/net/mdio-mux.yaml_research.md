## Purpose
`sources/distributed-fs/ceph-client/Documentation/devicetree/bindings/net/mdio-mux.yaml` defines the Linux Devicetree YAML schema for `Common MDIO bus multiplexer/switch properties.`, a MDIO mux binding. The schema description says: An MDIO bus multiplexer/switch will have several child busses that are numbered uniquely in a device dependent manner. The nodes for an MDIO bus multiplexer/switch will have one child node for each child bus. It is declarative ABI documentation and validation input, not executable networking code. ## Risks
Primary risks are Devicetree ABI drift, incomplete compatible coverage, wrong fallback ordering, and resource shape changes that still compile but break driver probe or link bring-up. Tightening required properties can reject existing board files; loosening them can hide missing clocks, resets, interrupts, PHY links, port nodes, or MDIO addresses. Child-node schemas need special care because port numbering, PHY package topology, MDIO mux selectors, NFC transport GPIOs, and switch CPU/user-port layout must match driver tables. This schema allows unknown top-level properties. It has 3 top-level properties and 4 distinct nested property names, so broad edits should be checked against all compatibles and DTS users, not just the filename's nominal device.

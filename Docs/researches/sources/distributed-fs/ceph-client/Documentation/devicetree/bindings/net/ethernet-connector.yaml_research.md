## Purpose
`sources/distributed-fs/ceph-client/Documentation/devicetree/bindings/net/ethernet-connector.yaml` defines the Linux Devicetree YAML schema for `Generic Ethernet Connector`, a Ethernet connector binding. The schema description says: An Ethernet Connector represents the output of a network component such as a PHY, an Ethernet controller with no PHY, or an SFP module. It is declarative ABI documentation and validation input, not executable networking code. Its purpose is to keep DTS/DTB nodes aligned with the resources and topology expected by the matching kernel subsystem before drivers probe hardware.

## Risks
Primary risks are Devicetree ABI drift, incomplete compatible coverage, wrong fallback ordering, and resource shape changes that still compile but break driver probe or link bring-up. Tightening required properties can reject existing board files; loosening them can hide missing clocks, resets, interrupts, PHY links, port nodes, or MDIO addresses. Child-node schemas need special care because port numbering, PHY package topology, MDIO mux selectors, NFC transport GPIOs, and switch CPU/user-port layout must match driver tables. This schema allows unknown top-level properties. It has 2 top-level properties and 2 distinct nested property names, so broad edits should be checked against all compatibles and DTS users, not just the filename's nominal device.

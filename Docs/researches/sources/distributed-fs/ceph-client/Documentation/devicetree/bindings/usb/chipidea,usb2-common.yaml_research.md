## Risks
Main risks are ABI drift around compatible fallback order, MMIO and IRQ resources, PHY/transceiver phandles, `dr_mode`, FIFO/endpoint tuning, VBUS/ID GPIOs, clocks/resets, and child-port layout; changing compatible ordering or removing fallback strings; broadening a schema so invalid board nodes pass; tightening a schema so existing DTBs fail; and mismatches between YAML clock/reset/regulator/PHY names and driver lookup tables. Multi-role USB and Type-C bindings are especially sensitive to graph endpoints, role-switch dependencies, connector children, and wakeup semantics. UFS bindings are sensitive to per-SoC clock arrays, ICE register resources, PHY lane counts, and reset/power sequencing. The closure profile allows additional top-level properties.

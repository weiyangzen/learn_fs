Main risks are ABI drift around I2C addresses, interrupt polarity, connector child nodes, graph ports/endpoints, `mode-switch`/`orientation-switch` flags, SBU/SS lane routing, supplies, and role-switch integration; changing compatible ordering or removing fallback strings; broadening a schema so invalid board nodes pass; tightening a schema so existing DTBs fail; and mismatches between YAML clock/reset/regulator/PHY names and driver lookup tables. UFS bindings are sensitive to per-SoC clock arrays, ICE register resources, PHY lane counts, and reset/power sequencing.

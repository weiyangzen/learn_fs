# sources/distributed-fs/ceph-client/Documentation/devicetree/bindings/media/microchip,xisc.yaml

**Purpose:** Defines the Devicetree JSON-schema ABI for `Microchip eXtended Image Sensor Controller (XISC)`. It is a camera capture interface media graph binding in the Ceph client Linux source snapshot, constraining how board DTS/DTB files describe media hardware so Linux media, V4L2 mem2mem, platform, clock, reset, power-domain, IOMMU, and graph helpers can bind the correct driver resources. The source description says: The eXtended Image Sensor Controller (XISC) device provides the video input capabilities for the Microchip AT91 SAM family of devices. The XISC has a single internal parallel input that supports RAW Bayer, RGB or YUV video. The source can be either a demuxer from a CSI2 type of bus, or a simple direct bridge to a parallel sensor. The XISC provides one clock output that is used to clock the demuxer/bridge.

**State and persistence behavior:** The file stores no mutable runtime state and performs no persistence itself. Its persistent effect is ABI stability for DTS files and shipped DTBs: compatible strings, child-node names, phandle relationships, address ranges, cell counts, and media graph topology are long-lived hardware descriptions. Any change to required properties, resource ordering, child object schemas, or unknown-property policy can invalidate existing board descriptions even though no kernel state is written by the YAML.

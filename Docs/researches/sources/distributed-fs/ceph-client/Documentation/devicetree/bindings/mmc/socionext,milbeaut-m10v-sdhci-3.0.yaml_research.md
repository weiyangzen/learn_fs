**Purpose:** Defines the Devicetree JSON-schema contract for `SOCIONEXT Milbeaut SDHCI controller`. In this tree it is a MMC/SD/SDHCI storage host controller binding: it constrains how DTS authors describe hardware, and it gives Linux OF/platform code a stable ABI for matching drivers, acquiring resources, and validating board descriptions with dt-schema. The source description says: The SOCIONEXT Milbeaut SDHCI controller is a specialized SD Host Controller found in some of Socionext's Milbeaut image processing SoCs. It features a dedicated "bridge controller." This bridge controller implements special functions like reset control, clock management for various SDR modes (SDR12, SDR25, SDR50) and physical pin property settings.

**Risks:** Main risks are ABI drift, under-specified compatibles, required resources that do not match real SoC integration, wrong `#*-cells` counts, stale examples, and conditional branches that validate one variant while rejecting another valid one. For mux and common schemas, over-permissive closure can hide misspelled properties while over-tight closure can reject legitimate inherited properties.

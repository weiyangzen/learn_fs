# sources/distributed-fs/ceph-client/include/uapi/linux/cxl_mem.h

Purpose: defines ioctl ABI for CXL memory device command discovery and mailbox command submission. Important APIs and types include `CXL_MEM_QUERY_COMMANDS`, `CXL_MEM_SEND_COMMAND`, the append-only CXL command ID list, command-name/deprecation arrays, `struct cxl_command_info`, flags for enabled/exclusive commands, `struct cxl_mem_query_commands`, and `struct cxl_send_command` with raw opcode, input payload, output payload, and device return value. Control flow is userspace first querying supported commands, allocating enough command-info slots or payload buffers, then sending supported IDs with exact or variable in/out sizes; raw commands include a hardware opcode. State is live driver/hardware command availability, mailbox ownership, labels/logs/health/firmware state, and potentially exclusive kernel-managed resources. Dependencies include ioctl encoding, `linux/types.h`, CXL memory-device driver, and CXL mailbox specifications. Risks include enum reordering ABI breaks, unsafe raw commands, deprecated poison/media commands, variable buffer sizing, little-endian payload interpretation, reserved field validation, and exclusive command races. Test signals include zero-count and bounded query paths, enabled/exclusive flag handling, invalid IDs/opcodes, variable output truncation, raw command privilege checks, deprecated command rejection, and 32-bit pointer compatibility.

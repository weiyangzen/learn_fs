# sources/distributed-fs/ceph-client/include/uapi/linux/cec.h

Purpose: defines the public HDMI Consumer Electronics Control ABI used by media CEC adapters and userspace tools. Important APIs and types include `struct cec_msg`, `struct cec_caps`, `struct cec_log_addrs`, connector/event structs, `CEC_ADAP_*`, `CEC_TRANSMIT`, `CEC_RECEIVE`, `CEC_DQEVENT`, mode/capability flags, helper predicates, and the large opcode/operand table consumed by CEC tooling. Control flow is ioctl-driven: userspace discovers adapter caps, sets physical and logical addresses when permitted, configures filehandle initiator/follower mode, transmits commands with optional reply matching, receives messages/events, and interprets tx/rx status bits. State is kernel adapter and filehandle state; persistent external state is HDMI topology, logical address claims, vendor IDs, and CEC 2.0 feature data. Dependencies include `linux/types.h`, `linux/string.h`, media CEC core, DRM connector metadata, and cec-ctl code generation. Risks are UAPI layout drift, invalid message lengths over `CEC_MAX_MSG_SIZE`, broadcast reply misuse, lost event accounting, raw/passthrough policy confusion, and opcode table formatting changes. Test signals include CEC ioctl selftests, cec-compliance, transmit retry/status coverage, logical address fallback, monitor modes, hotplug connector updates, and parser regeneration.

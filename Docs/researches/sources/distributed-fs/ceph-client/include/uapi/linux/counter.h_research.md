# sources/distributed-fs/ceph-client/include/uapi/linux/counter.h

Purpose: defines the Counter character-device ABI for component watches and event delivery. Important APIs and types include component type/scope enums, `struct counter_component`, event type enum, `struct counter_watch`, `COUNTER_ADD_WATCH_IOCTL`, `COUNTER_ENABLE_EVENTS_IOCTL`, `COUNTER_DISABLE_EVENTS_IOCTL`, `struct counter_event`, and standardized count direction/mode/function/signal/action/polarity enums. Control flow is watch configuration followed by event streaming: userspace queues one or more watches, enables them atomically, reads timestamped events containing component values/status, and disables monitoring when done. State is per-open queued and enabled watch sets, device counter state, and event queues; persistent device state remains hardware-owned. Dependencies include `linux/ioctl.h`, `linux/types.h`, Counter sysfs component IDs, and counter drivers. Risks include mismatched sysfs IDs, stale watch queues, event loss, timestamp/value alignment, unsupported channel multiplexing, and ioctl replacement semantics. Test signals include queue/enable/replace/disable cycles, read event layout, multiple event channels, component ID discovery from sysfs, unsupported component errors, and 32-bit ABI alignment.

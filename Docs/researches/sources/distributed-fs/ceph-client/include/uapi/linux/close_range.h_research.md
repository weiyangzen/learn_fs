# sources/distributed-fs/ceph-client/include/uapi/linux/close_range.h

Purpose: exposes flags for the `close_range(2)` syscall. Important APIs are `CLOSE_RANGE_UNSHARE`, which first unshares the file descriptor table, and `CLOSE_RANGE_CLOEXEC`, which marks descriptors close-on-exec rather than closing them. Control flow is syscall-level: userspace passes a first/last descriptor range plus flags and the kernel applies close or cloexec semantics, optionally after fdtable copy-on-write. State affected is per-process file descriptor table state and descriptor flags; no persistent storage exists. Dependencies are the syscall implementation and libc wrappers. Risks include conflicting or unsupported flag combinations, races in multithreaded programs without `UNSHARE`, accidentally closing control descriptors, and ABI expansion requiring unknown-flag rejection. Test signals include boundary ranges, `UINT_MAX` last descriptor, threaded shared fdtable cases, CLOEXEC-only behavior through exec, unknown flags, and sparse fd tables.

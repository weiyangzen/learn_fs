# sources/distributed-fs/ceph-client/include/uapi/linux/cryptouser.h

Purpose: defines the crypto user configuration/reporting netlink ABI. Important APIs and types include crypto message IDs for new/delete/update/get algorithm and RNG deletion, `CRYPTO_MAX_NAME`, `enum crypto_attr_type_t`, `struct crypto_user_alg`, deprecated stats structs, per-algorithm report structs for hash/cipher/blkcipher/AEAD/compress/RNG/akcipher/KPP/acomp/signature, and `CRYPTO_REPORT_MAXSIZE`. Control flow is userspace requesting or modifying crypto algorithm registrations and receiving algorithm metadata attributes describing type-specific capabilities. State is the kernel crypto algorithm registry, module ownership/refcounts, priorities, flags, and larval algorithms during lookup. Dependencies include `linux/types.h`, crypto netlink core, and algorithm implementations. Risks include deprecated stat commands lingering in userspace, fixed name truncation, report max size not covering newer report structs, priority update policy, and exposing module/driver names accurately. Test signals include `GETALG` dumps for each algorithm class, new/delete/update permission checks, deprecated stat rejection, long names, larval lookup reporting, and netlink attribute policy validation.

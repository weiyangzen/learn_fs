# sources/distributed-fs/ceph-client/include/uapi/linux/chio.h

Purpose: describes the ioctl ABI for the SCSI media changer character device. Important APIs and types include element type constants `CHET_*`, `struct changer_params`, `changer_vendor_params`, `changer_move`, `changer_exchange`, `changer_position`, `changer_element_status`, `changer_get_element`, `changer_set_voltag`, status/flag bits, and `CHIO*` ioctl numbers. Control flow is userspace querying changer geometry, selecting source/destination element type/unit pairs, moving or exchanging media, positioning the picker, querying element status, initializing element state, and setting/clearing volume tags. State is changer hardware state and driver-maintained current picker/status; persistence is on the media changer labels and slots, not the header. Dependencies include ioctl encoding and user pointers for status buffers; integration points are SCSI changer devices and backup/tape management tools. Risks include invalid element ranges, stale volume tags, partial status buffer sizing, unimplemented picker ioctls, and physical media motion errors. Test signals include ioctl ABI tests with sg/emulated changers, boundary element IDs, invert flags, status/detail consistency, tag set/clear paths, and error propagation from SCSI sense data.

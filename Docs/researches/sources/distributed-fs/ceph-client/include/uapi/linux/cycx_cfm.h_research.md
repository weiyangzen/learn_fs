# sources/distributed-fs/ceph-client/include/uapi/linux/cycx_cfm.h

Purpose: defines the Cyclades Cyclom 2X WAN firmware module file format and boot command constants. Important APIs and types include CFM version/signature, image and descriptor size limits, firmware boot command IDs, adapter and code IDs, `struct cycx_fw_info`, `struct cycx_firmware`, and `struct cycx_fw_header`. Control flow is firmware loading: userspace or driver validates signature/version/checksum, inspects adapter compatibility and memory/code/data offsets, loads reset/data/code buffers, sets boot segment/data/default parameters, and starts the board. State is adapter firmware image, dual-port memory contents, and runtime WAN board firmware state. Dependencies include the Cyclom 2X WAN driver and firmware files matching this format. Risks include unchecked variable-size `image[]`, checksum/offset overflow, unsupported adapter IDs, stale maximum image size, and firmware/hardware version mismatch. Test signals include firmware parser validation, corrupt checksum/signature rejection, boundary image sizes, offset/size bounds, adapter compatibility checks, and boot command sequencing on supported hardware or mocks.

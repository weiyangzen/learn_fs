# sources/distributed-fs/ceph-client/include/uapi/linux/coda.h

Purpose: defines the Coda distributed filesystem UAPI between the kernel module, the Venus userspace cache manager, mount helpers, and pioctl callers. Important APIs and types include Coda file ID and attribute structs, directory entries, `coda_in_hdr`/`coda_out_hdr`, operation codes, input/output unions, downcall structs, `ViceIoctl`, `PioctlData`, `coda_mount_data`, kernel version constants, and cache invalidation flags. Control flow is RPC-like: VFS operations generate upcalls to Venus, Venus replies with output unions, and Venus can issue downcalls to purge/replace cached users, files, directories, or FIDs. State spans kernel cnode/name caches, Venus cache state, open backing files or paths, access-intent tracking, and mount device fd association. Dependencies include Linux time/pid/user pointer types, ioctl encoding, Coda kernel module, and the Venus daemon. Risks are 32/64-bit layout and pointer placeholders, variable trailing data bounds, version negotiation, stale FID cache invalidation, `CODA_NOCACHE` handling, and legacy platform typedef compatibility. Test signals include mount negotiation, all VFS upcalls, downcall cache purges, pioctl buffer limits, access intent read/write/mmap paths, long names, and mixed 32-bit userspace on 64-bit kernels.

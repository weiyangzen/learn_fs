# sources/distributed-fs/ceph-client/include/uapi/linux/dlm_plock.h

Purpose: defines the misc-device protocol for DLM-backed POSIX file locks. Important APIs and types include `DLM_PLOCK_MISC_NAME`, version constants, operation IDs for lock/unlock/get/cancel, close flag `DLM_PLOCK_FL_CLOSE`, and `struct dlm_plock_info`. Control flow is userspace lock manager cooperation: kernel/filesystem submits plock operations with pid, nodeid, fsid, inode number, byte range, ownership, exclusive/wait flags, and receives `rv` completion results. State is distributed POSIX byte-range lock state across cluster nodes plus pending wait/cancel operations; persistence depends on filesystem/lock manager recovery, not this header. Dependencies include `linux/types.h`, DLM plock device, clustered filesystems such as GFS2, and userspace `dlm_controld`. Risks include owner/range identity mismatches, cancel races, close cleanup flags, node recovery ordering, and version drift between kernel and daemon. Test signals include shared/exclusive byte-range locks across nodes, blocking/waiting lock completion, cancellation, close release, lock get queries, node failure recovery, and fsid/inode uniqueness.

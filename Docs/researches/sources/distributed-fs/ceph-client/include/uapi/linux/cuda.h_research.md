# sources/distributed-fs/ceph-client/include/uapi/linux/cuda.h

Purpose: lists command byte values for Apple CUDA microcontroller operations used on legacy PowerMac systems. Important APIs are command constants for warm start, autopoll, 6805 address, time/PRAM get/set, powerdown/powerup time, reset, IPL, auto rate, device list, and I2C get/set. Control flow is message-based: platform ADB/CUDA drivers issue these command IDs as the second byte in CUDA packets and interpret controller replies. State lives in the CUDA microcontroller, PRAM/RTC, ADB autopoll configuration, power-management settings, and attached device list. Dependencies are legacy Macintosh CUDA/ADB platform drivers. Risks include issuing reset/power commands unintentionally, command values differing across controllers, missing reply validation, and obsolete architecture build coverage. Test signals include PowerMac CUDA driver compile tests, RTC/PRAM get/set, autopoll enable/disable, reset/power command gating, and emulated or hardware ADB device-list operations.

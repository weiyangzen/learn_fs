# sources/distributed-fs/ceph-client/include/uapi/linux/coff.h

Purpose: documents the Linux i386 COFF object/executable file layout for legacy loaders and tools. Important APIs and types include endian extraction macros, file, optional a.out, section, shared-library, line-number, symbol, auxiliary, and relocation structs, magic numbers, section names, section flags, and default alignments. Control flow is binary parsing: consumers read byte arrays from packed COFF fields via `COFF_SHORT/COFF_LONG`, validate `COFF_I386MAGIC`, then walk optional header, sections, raw data, relocations, line numbers, symbols, and aux entries using file offsets. State is only serialized object-file metadata; the kernel does not maintain runtime state through this header. Dependencies are legacy COFF loader/tooling and endian assumptions. Risks include trusting file offsets/counts, structure padding assumptions, signed/unsigned conversion from char arrays, optional header size misuse, unsupported endian variants, and obsolete format exposure. Test signals include malformed COFF fuzzing, magic validation, section count/offset bounds, optional header size variance, relocation table parsing, and cross-endian macro checks.

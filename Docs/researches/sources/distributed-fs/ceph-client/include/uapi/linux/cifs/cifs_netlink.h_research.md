# sources/distributed-fs/ceph-client/include/uapi/linux/cifs/cifs_netlink.h

Purpose: defines the CIFS generic-netlink family used for SMB witness notification registration and delivery. Important APIs include family/multicast names, `enum cifs_genl_attributes`, `enum cifs_genl_commands`, witness notification type constants, and witness resource state constants. Control flow is userspace registering or unregistering witness subscriptions with registration ID, network/share/IP and optional Kerberos/user credential attributes; the kernel sends `CIFS_GENL_CMD_SWN_NOTIFY` events for resource, client move, share move, or IP change notifications. State is live netlink subscription and CIFS witness registration state, plus server resource availability. Dependencies are generic netlink and CIFS client witness code. Risks include leaking credential attributes, stale registrations after reconnect, interpreting notify vs registration attributes incorrectly, and enum order ABI drift. Test signals include netlink policy validation, register/unregister lifetimes, multicast group reception, Kerberos and password paths, each notification type, resource unavailable/available transitions, and reconnect failover behavior.

# sources/distributed-fs/ceph-client/include/uapi/linux/cn_proc.h

Purpose: defines process event messages carried over the connector netlink interface. Important APIs and types include `enum proc_cn_mcast_op`, event bitmask enum, `PROC_EVENT_ALL`, `struct proc_input`, `valid_event()`, and `struct proc_event` with fork, exec, id, sid, ptrace, comm, coredump, exit, and ack payloads. Control flow is userspace sending listen/ignore requests, optionally selecting event types, and kernel publishing timestamped events with pid/tgid identity fields. State is subscription state in connector plus transient task lifecycle events; no durable state is kept. Dependencies include `linux/types.h`, connector IDs from `connector.h`, pid namespaces semantics, and process lifecycle hooks. Risks include lost events under pressure, event mask omissions when adding new events, pid/tgid namespace interpretation, union layout compatibility, and `comm[16]` truncation. Test signals include event subscription filtering, fork/exec/exit ordering, nonzero exit and coredump coverage, UID/GID changes, ptrace attach/detach, namespace behavior, and netlink loss handling.

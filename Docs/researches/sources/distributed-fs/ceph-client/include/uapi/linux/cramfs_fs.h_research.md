# sources/distributed-fs/ceph-client/include/uapi/linux/cramfs_fs.h

Purpose: describes the on-disk Compressed ROMFS/cramfs filesystem format. Important APIs and types include signature/magic constants, bitfield widths, `CRAMFS_MAXPATHLEN`, `struct cramfs_inode`, `struct cramfs_info`, `struct cramfs_super`, supported feature flags, block-pointer flags, and direct-pointer shift. Control flow is mount/parser flow: read the superblock, validate magic/signature/flags, interpret root inode and directory entries, map inode offsets divided by four, and decode compressed or direct block pointer tables. State is entirely serialized filesystem image metadata and compressed data; runtime mount state is managed elsewhere. Dependencies include `linux/types.h`, `linux/magic.h`, page/block-size assumptions, and cramfs kernel and mkcramfs tooling. Risks include bitfield layout/endian assumptions, unsupported feature flags, maximum path/name truncation, block pointer flag masking, shifted root offset handling, and malformed image bounds. Test signals include cramfs image mount tests, mkcramfs warnings for field widths, holes and direct block pointers, sorted directory images, corrupted flags/magic, and fuzzed inode offsets.

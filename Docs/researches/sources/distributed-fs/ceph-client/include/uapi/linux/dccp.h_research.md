# sources/distributed-fs/ceph-client/include/uapi/linux/dccp.h

Purpose: defines UAPI packet headers, option numbers, feature numbers, cmsg types, queue policies, and socket options for Datagram Congestion Control Protocol. Important APIs and types include `struct dccp_hdr`, extended sequence/ack/request/response/reset subheaders, `enum dccp_pkt_type`, `dccp_packet_hdr_len()`, reset codes, DCCP option and CCID constants, feature-number enum, `enum dccp_cmsg_type`, queue policy enum, and `DCCP_SOCKOPT_*`. Control flow is packet parsing and socket configuration: kernel and userspace interpret base header bitfields according to byte order, compute subheader length from packet type, negotiate features/CCIDs, and set service, checksum coverage, CCID, and queue policy options. State is per-socket DCCP connection, sequence/ack windows, congestion-control state, service list, and transmit queue policy. Dependencies include `linux/types.h`, `asm/byteorder.h`, DCCP networking stack, and RFC 4340/CCID specs. Risks include bitfield endian mistakes, 24-bit vs 48-bit sequence parsing, checksum coverage misuse, option length bounds, deprecated packet size option, and service-list limits. Test signals include packet header layout tests on both endian variants, socket option get/set, feature negotiation, reset-code handling, option fuzzing, cmsg priority queueing, and CCID2/CCID3 interoperability.

# sources/distributed-fs/ceph-client/include/uapi/linux/cyclades.h

Purpose: preserves obsolete Cyclades serial-driver ioctl constants and monitor structure for source compatibility, while explicitly warning that support has been removed. Important APIs are `struct cyclades_monitor` and `CYGET*`/`CYSET*` ioctl command numbers for thresholds, timeouts, flow control, RTS/DTR inversion, poll cycle, CD1400 version, and wait controls. Control flow in supported historical drivers was ioctl-based monitoring and tuning; in current code this header should only compile legacy userspace with warnings. State would have been serial port interrupt/character counters and driver thresholds/timeouts, but no active kernel state is guaranteed. Dependencies are legacy Cyclades serial driver users. Risks include applications assuming removed functionality still works, ioctl number collisions in private code, and build logs hiding the warning. Test signals are compile-only compatibility, confirmation that current kernels reject unsupported ioctls cleanly, and audits of legacy tools for migration away from this header.

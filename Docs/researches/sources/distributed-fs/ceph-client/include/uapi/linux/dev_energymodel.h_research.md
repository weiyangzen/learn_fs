# sources/distributed-fs/ceph-client/include/uapi/linux/dev_energymodel.h

Purpose: auto-generated YNL UAPI for the `dev-energymodel` generic-netlink family, exposing performance-domain and performance-state energy model data. Important APIs include family name/version, perf-state and perf-domain flag enums, perf-domain/perf-table/perf-state attribute enums, command IDs for dumping domains and tables plus create/update/delete notifications, and multicast group `event`. Control flow is netlink dump and notify: userspace requests domains, then tables for a domain ID, and listens for lifecycle updates as energy models are registered or changed. State is kernel energy model data for performance domains, CPUs, frequency/performance/power/cost tuples, and flags for inefficiency/artificial units. Dependencies include generated netlink specs, energy model core, scheduler/thermal consumers, and YNL regeneration tooling. Risks include editing generated output directly, attribute numbering drift from YAML, unit ambiguity when microwatts flag is absent, stale domain IDs after notifications, and inefficient-state filtering interpretation. Test signals include YNL spec conformance, dump round trips, multicast event delivery, artificial/inefficient flag reporting, hotplug domain updates, and regeneration diffs from `dev-energymodel.yaml`.

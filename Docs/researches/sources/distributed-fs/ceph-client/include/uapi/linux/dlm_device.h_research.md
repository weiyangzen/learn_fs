# sources/distributed-fs/ceph-client/include/uapi/linux/dlm_device.h

Purpose: defines the low-level `/dev/dlm` userspace device ABI used mostly by libdlm. Important APIs and types include `DLM_USER_LVB_LEN`, device version constants, `struct dlm_lock_params`, `dlm_lspace_params`, `dlm_purge_params`, `dlm_write_request`, `dlm_device_version`, `dlm_lock_result`, command IDs, and user lockspace flags. Control flow is write/read based: userspace writes versioned requests for lock, unlock, query, create/remove lockspace, purge, or deadlock handling, then reads results carrying user callback addresses/params, LKSB copies, BAST mode, and optional LVB offsets. State is open device session state, lockspaces, outstanding lock requests, persistent/orphan locks, lock value blocks, and AST/BAST delivery queues. Dependencies include `linux/dlm.h`, user pointer ABI, DLM device driver, and libdlm callback dispatch. Risks include 32/64-bit pointer handling via `is64bit`, variable trailing `name[]`, user callback pointer trust, version mismatch, LVB offset bounds, and persistent lock cleanup. Test signals include version negotiation, lockspace create/remove, lock/unlock callbacks, BAST delivery, compat userspace, long resource names, purge by node/pid, and forced/autofree lockspace behavior.

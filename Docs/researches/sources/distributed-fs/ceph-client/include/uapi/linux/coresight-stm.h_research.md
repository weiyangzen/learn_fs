# sources/distributed-fs/ceph-client/include/uapi/linux/coresight-stm.h

Purpose: exposes user-visible flags and option values for CoreSight System Trace Macrocell transactions. Important APIs are `STM_FLAG_TIMESTAMPED`, `STM_FLAG_MARKED`, `STM_FLAG_GUARANTEED`, and option enum values `STM_OPTION_GUARANTEED` and `STM_OPTION_INVARIANT`. Control flow is trace-write configuration: userspace or kernel clients request timestamped/marked/guaranteed semantics when writing STM channels, while the STM driver maps those bits to hardware transaction behavior. State is hardware trace sink/source configuration and emitted trace stream, not persisted by the header. Dependencies include `linux/const.h` bit macros and CoreSight STM drivers. Risks include treating guaranteed writes as cheap when they may stall, unsupported option handling, bit-position ABI drift, and trace loss under invariant mode. Test signals include STM character-device writes with each flag, trace decode validation, guaranteed vs invariant timing behavior, disabled sink handling, and build checks for bit macros.

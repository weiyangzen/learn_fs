# sources/distributed-fs/ceph-client/include/uapi/linux/coredump.h

Purpose: defines the socket handshake ABI between the kernel coredump path and a userspace coredump server. Important APIs and types include feature bits `COREDUMP_KERNEL`, `COREDUMP_USERSPACE`, `COREDUMP_REJECT`, `COREDUMP_WAIT`, `struct coredump_req`, `struct coredump_ack`, versioned minimum sizes, and `enum coredump_mark` result markers. Control flow is request/ack negotiation: kernel sends supported feature mask and max ack size, userspace responds with a bounded size and subset mask, and kernel writes a one-byte marker indicating success or validation failure. State is transient per-coredump negotiation plus the external coredump generation choice; no durable state is held by the header. Dependencies include `linux/types.h`, coredump socket plumbing, and process dump logic. Risks include conflicting mask combinations, size negotiation bugs, unsupported feature bits, userspace reading too little or too much, and server wait/deadlock behavior. Test signals include min/max ack size validation, unsupported bit rejection, kernel vs userspace vs reject selection, wait behavior, marker byte delivery, and backward-compatible struct-size probes.

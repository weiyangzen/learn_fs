# sources/distributed-fs/ceph-client/include/uapi/linux/const.h

Purpose: supplies C/assembly-safe constant, bit, alignment, and rounding macros for UAPI headers. Important APIs include `_AC`, `_AT`, `_UL`, `_ULL`, `_BITUL`, `_BITULL`, C-only `_BIT128`, `__ALIGN_KERNEL`, `__ALIGN_KERNEL_MASK`, `__KERNEL_DIV_ROUND_UP`, and `__KERNEL_DIV_ROUND_CLOSEST`. Control flow is compile-time macro expansion: assembly sees raw constants while C receives typed casts/suffixes and GNU statement-expression rounding. State and persistence are absent. Dependencies are compiler preprocessing, `__ASSEMBLY__`, `__typeof__`, and users such as devlink/coresight bit masks. Risks include assembler incompatibility for C-only constructs, signed division corner cases, shift overflow, 128-bit compiler support, and macro double-evaluation assumptions. Test signals include headers_check, assembly and C consumers, 32-bit/64-bit bit mask generation, negative rounding tests, alignment power-of-two expectations, and build coverage with GCC/Clang.

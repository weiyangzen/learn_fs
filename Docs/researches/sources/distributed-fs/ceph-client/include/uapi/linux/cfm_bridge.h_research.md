# sources/distributed-fs/ceph-client/include/uapi/linux/cfm_bridge.h

Purpose: exposes bridge Connectivity Fault Management constants for Ethernet CFM/CCM frame construction and parsing. Important APIs and types are frame length/offset constants, TLV type constants, `struct br_cfm_common_hdr`, and enums for CFM opcode, MEP domain, MEP direction, and CCM interval. Control flow is data-plane protocol handling rather than functions: bridge CFM code builds or validates CCM PDUs using these fixed offsets and interval/domain values. State is external bridge MEP/MA configuration and received CCM sequence/status information; this header stores no state. Dependencies include `linux/types.h` and `linux/if_ether.h`, integrating with bridge CFM netlink/configuration code and Ethernet frame parsing. Risks include off-by-one offsets in packed frames, assuming VLAN header length from `ETHER_HEADER_LENGTH`, unsupported interval values, and TLV length mismatches. Test signals include bridge CFM packet encoding tests, CCM receive validation, VLAN and non-VLAN frame paths, interval configuration rejection, and interoperability captures against IEEE 802.1ag/Y.1731 peers.

# sources/distributed-fs/ceph-client/include/uapi/linux/cgroupstats.h

Purpose: defines the taskstats generic-netlink extension that reports per-cgroup task state counters. Important APIs and types include `struct cgroupstats`, `CGROUPSTATS_CMD_GET/NEW`, `CGROUPSTATS_TYPE_CGROUP_STATS`, and the `CGROUPSTATS_CMD_ATTR_FD` selector. Control flow is userspace passing a cgroup file descriptor through taskstats netlink and receiving counters for sleeping, running, stopped, uninterruptible, and IO-waiting tasks. State is sampled kernel task state aggregated by cgroup at request time; there is no persisted snapshot in the header. Dependencies include `linux/types.h` and `linux/taskstats.h`, and integration is through taskstats family command numbering starting at `__TASKSTATS_CMD_MAX`. Risks are enum insertion breaking unversioned commands, ambiguous task-state classification, stale FD/cgroup lifetime races, and 8-byte alignment assumptions. Test signals include taskstats cgroup queries on v1/v2 cgroups, empty and busy cgroups, FD invalidation, netlink attribute policy checks, and ABI size/alignment checks on 32-bit and 64-bit builds.

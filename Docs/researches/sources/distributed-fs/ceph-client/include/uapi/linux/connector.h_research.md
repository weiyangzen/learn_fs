# sources/distributed-fs/ceph-client/include/uapi/linux/connector.h

Purpose: defines the generic connector netlink message envelope and registered connector IDs. Important APIs and types include `CN_IDX_*`/`CN_VAL_*` routing identifiers, `CN_NETLINK_USERS`, `CONNECTOR_MAX_MSG_SIZE`, `struct cb_id`, and flexible-array `struct cn_msg`. Control flow is connector clients registering an `(idx,val)` pair and userspace/kernel exchanging `cn_msg` envelopes with sequence, acknowledgement, length, flags, and payload bytes. State is connector callback registration and netlink socket subscription state; payload state belongs to subsystem-specific protocols such as proc events, CIFS, w1, device mapper, DRBD, or Hyper-V KVP/VSS. Dependencies include `linux/types.h`, netlink connector core, and subsystem-specific payload headers. Risks include ID collisions, payload length validation, sequence/ack misuse, maximum message enforcement, and flexible-array parsing errors. Test signals include connector registration conflicts, oversized message rejection, proc/cifs payload round trips, multicast subscription behavior, and 32/64-bit structure layout checks.

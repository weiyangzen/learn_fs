# sources/distributed-fs/ceph-client/include/uapi/linux/counter/microchip-tcb-capture.h

Purpose: provides driver-specific Counter component and event-channel numbers for the Microchip TCB capture driver. Important APIs are `COUNTER_MCHP_EXCAP_RA`, `COUNTER_MCHP_EXCAP_RB`, and event channel constants for CV, RA, RB, and RC. Control flow is userspace combining these constants with the generic Counter watch ABI to monitor CV changes/overflow, RA capture, RB capture, or RC compare events. State is TCB timer/capture register state and queued generic Counter events. Dependencies include the generic `counter.h` ABI, the microchip-tcb-capture driver, and hardware register semantics for RA/RB/RC/CV. Risks include confusing extension IDs with event channel IDs, channel aliasing where CV and RA both use channel 0 for different event types, and driver/hardware generation drift. Test signals include watching each documented event, verifying capture extension values, overflow handling, RC compare notification, and sysfs component IDs matching these constants.

# sources/distributed-fs/ceph-client/include/uapi/linux/dlm.h

Purpose: defines the core userspace-facing Distributed Lock Manager types for lockspaces and lock status blocks. Important APIs and types are opaque `dlm_lockspace_t`, `struct dlm_lksb`, status block flags `DLM_SBF_*`, and lockspace flags such as `DLM_LSFL_NEWEXCL` with lock modes/flags imported from `dlmconstants.h`. Control flow is DLM lock/unlock/convert operations returning request status and lock IDs through the LKSB, then invoking AST/BAST callbacks in the library/device interface. State is cluster lockspace membership, lock resources, granted/convert/wait queues, lock value blocks, and assigned lock IDs. Dependencies include `linux/dlmconstants.h`, `linux/types.h`, DLM kernel subsystem, userspace libdlm, and cluster communication. Risks include LVB pointer lifetime, interpreting asynchronous `sb_status`, conversion deadlock demotion, invalid value-block state, and deprecated/reserved flags. Test signals include lock acquisition/conversion/unlock, NOQUEUE behavior, LVB read/write and invalidation, deadlock demotion, alternate mode reporting, lockspace create exclusivity, and cluster node failure scenarios.

# sources/distributed-fs/ceph-client/tools/arch/x86/include/asm/inat.h

## Purpose
Defines the compact instruction-attribute encoding used by the x86 decoder. It classifies opcodes by prefix, escape map, group table, immediate form, ModRM requirements, VEX/EVEX/XOP legality, 64-bit validity, and REX2 variants.

## APIs, Types, and Functions
Important constants include `INAT_OPCODE_TABLE_SIZE`, prefix IDs such as `INAT_PFX_REX`, `INAT_PFX_EVEX`, `INAT_PFX_REX2`, immediate IDs such as `INAT_IMM_VWORD`, and flags such as `INAT_MODRM`, `INAT_FORCE64`, `INAT_VEXOK`, `INAT_EVEXONLY`, `INAT_NO_REX2`, and `INAT_INV64`. It declares lookup APIs `inat_get_opcode_attribute()`, `inat_get_escape_attribute()`, `inat_get_group_attribute()`, `inat_get_avx_attribute()`, and `inat_get_xop_attribute()`, plus inline predicates for every attribute class.

## Control Flow, State, and Persistence
The header itself has no mutable state. Its bit layout drives decoder branches in `insn.c`: prefix scanning checks `inat_is_legacy_prefix()`, opcode decoding follows escape/group tables, and immediate/displacement parsing uses `inat_has_immediate()`, `inat_immediate_size()`, and `inat_has_moffset()`.

## Dependencies and Integration
Depends on `inat_types.h`. The concrete tables are generated by `gen-insn-attr-x86.awk` into `inat-tables.c` and searched by `lib/inat.c`. `insn.h` and `insn.c` rely on the inline accessors rather than direct bit masks.

## Risks and Test Signals
Risks are silent decode corruption if the bit packing changes without updating generators and table users, incomplete EVEX/REX2 metadata, and incorrect last-prefix variant selection. Test signals are decoder round trips over opcode-map fixtures, build-time table generation, and focused cases for grouped opcodes, VEX-only opcodes, EVEX scalable operand size, and invalid 64-bit opcodes.

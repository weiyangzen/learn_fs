# sources/distributed-fs/ceph-client/tools/perf/pmu-events/arch/x86/icelakex/virtual-memory.json

## Purpose

`virtual-memory.json` defines 22 Ice Lake X core PMU events for data and instruction TLB misses, page-walk activity, and TLB flushes. It provides perf aliases for diagnosing address translation overhead across load, store, and instruction-fetch paths.

## Schema And API Surface

Entries use core PMU event fields: `EventName`, `EventCode`, `UMask`, `BriefDescription`, `PublicDescription`, `Counter`, and sometimes `CounterMask` and `SampleAfterValue`. The event families are `DTLB_LOAD_MISSES`, `DTLB_STORE_MISSES`, `ITLB_MISSES`, and `TLB_FLUSH`. Representative aliases include `DTLB_LOAD_MISSES.STLB_HIT`, `DTLB_LOAD_MISSES.WALK_ACTIVE`, `DTLB_LOAD_MISSES.WALK_COMPLETED_4K`, `DTLB_STORE_MISSES.WALK_PENDING`, `ITLB_MISSES.WALK_COMPLETED_2M_4M`, and `TLB_FLUSH.STLB_ANY`.

## Control Flow And Integration

The file participates in the Ice Lake X event table generated by `jevents.py`. At runtime, perf resolves these aliases to core PMU encodings and applies any counter mask or sampling default. They are building blocks for virtual-memory and topdown metrics that estimate time lost to page walks or STLB misses. The declarations do not call code directly but are consumed by perf's alias and metric expression evaluators.

## State And Persistence

No mutable state exists in the file. Persistent state is the mapping from alias to event encoding and counter constraints. Runtime state is per-thread or per-core counter data, depending on how perf opens the event. `SampleAfterValue` influences default sampling period for events that can be used in record/report workflows.

## Dependencies

The file depends on Ice Lake X core PMU event definitions and on any metrics that reference the aliases. It integrates with perf list, perf stat, and potentially perf record when sampling TLB miss events.

## Risks

Translation events are sensitive to page size distinctions and naming. Confusing `WALK_ACTIVE`, `WALK_PENDING`, and `WALK_COMPLETED` can break derived stall estimates. Missing or wrong `CounterMask` values can change cycle-counting semantics. Metrics may reference related names such as walk duration, so alias compatibility with metric formulas should be verified when changing event names.

## Test Signals

Use `jq` and `jevents.py` generation as structural checks. Runtime tests can compare TLB miss and walk counters under workloads with small pages, huge pages, and high address-footprint scans. `perf list` should show all DTLB, ITLB, and TLB flush aliases for Ice Lake X.

# sources/distributed-fs/ceph-client/tools/testing/selftests/kho/x86.conf

`x86.conf` provides x86-specific settings for the Kexec Handover VM test. It is sourced by `vmtest.sh`.

It defines `QEMU_CMD=qemu-system-x86_64`, 8250 serial console Kconfig, `KERNEL_IMAGE="bzImage"`, and `KERNEL_CMDLINE="console=ttyS0"`.

There is no executable flow beyond variable assignment. Dependencies are `qemu-system-x86_64`, x86 kernel image layout, and 8250 serial output. Integration is the arch-specific branch of the KHO VM test.

Risk is mostly missing or misconfigured serial output, which would hide the success marker. Pass signal is QEMU boot and `KHO restore succeeded` in the serial log.

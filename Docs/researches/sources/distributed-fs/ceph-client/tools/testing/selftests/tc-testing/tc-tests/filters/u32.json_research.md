# sources/distributed-fs/ceph-client/tools/testing/selftests/tc-testing/tc-tests/filters/u32.json

Purpose: 15 u32 classifier tests for source-IP matching, invalid `indev`, custom hashtables, invalid handles/table IDs, linked tables, sample bucket calculation, class/table reference protection, recursive table deletion, and IDR leak stress.

APIs and control flow: Uses `$TC filter add|replace|delete|show`, `$TC qdisc`, `$TC class`, and `$TC -b -`. Commands exercise `u32 match`, `flowid`, `divisor`, `handle`, `ht`, `link`, `hashkey`, `sample`, and `classid`. Verification checks expanded handles, hash-table divisors, bucket IDs, and residual references.

State/dependencies: Kernel u32 hashtable/classifier state is the core persistence surface. Requires `nsPlugin`, u32, DRR, gact, and tc batch support.

Risks/test signals: Output varies by iproute2, so regexes allow alternate handle forms. Seven cases expect success and eight expect exit `2`. The stress loop creates/deletes a filter 2048 times to detect IDR lifetime leaks.

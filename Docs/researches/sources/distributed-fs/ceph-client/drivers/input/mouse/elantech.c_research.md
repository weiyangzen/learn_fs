# sources/distributed-fs/ceph-client/drivers/input/mouse/elantech.c

`elantech.c` implements the Elantech PS/2 touchpad protocol family and, when supported, routes newer devices to the `elan_i2c` SMBus companion path. It detects Elantech hardware via a PS/2 "magic knock", queries firmware/capability registers, selects hardware-version-specific packet decoders, configures absolute mode, exposes low-level debug/register sysfs attributes, and reports absolute, semi-multitouch, full multitouch, buttonpad, rocker, and optional TrackPoint events through the input subsystem.

Important APIs include `elantech_detect()`, `elantech_init()`, `elantech_init_ps2()`, `elantech_init_smbus()`, register helpers, `elantech_query_info()`, and `elantech_process_byte()`. Control flow is detect, reset/query, choose SMBus or PS/2, configure absolute mode, set input ranges, create sysfs and optional TrackPoint device, then validate and dispatch complete packets by hardware version.

State is per-device in `psmouse->private`: cached registers, parity table, multitouch coordinates, geometry, TrackPoint input, quirks, and queried hardware info. Dependencies include libps2, psmouse core, input-mt, DMI, I2C/software nodes, `elan_i2c`, and `psmouse_smbus`. Risks are revision-specific register writes, false detection, CRC/signature mismatch, live sysfs register mutation, SMBus breadcrumb cleanup, and cursor-jump workarounds. Test signals are hardware-version logs, input abs/MT/buttonpad/TrackPoint events, sysfs group lifecycle, resume reconnect, PS/2 fallback, and SMBus companion creation with PS/2 input suppressed.

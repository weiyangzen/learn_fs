# sources/distributed-fs/ceph-client/drivers/input/misc/mma8450.c

Purpose: polling I2C input driver for Freescale MMA8450 accelerometer, reporting 12-bit signed ABS_X/Y/Z samples.

Important APIs/types/functions: SMBus byte/block access, input polling, I2C/OF match. Main routines are register read/write helpers, `mma8450_poll`, open, close, and probe.

Control flow: probe verifies SMBus support, checks WHO_AM_I for `0xc6`, allocates input, installs open/close, sets ABS ranges, sets up polling with default/max intervals, and registers input. Open configures axes and active +/-2G mode then delays 100 ms. Poll exits if no XYZ data-ready bit, otherwise reads six bytes, reconstructs signed 12-bit values, reports axes, and syncs. Close writes standby/reset-like control values.

State/persistence: only the I2C client is stored in input drvdata. Hardware is active while input is open. No explicit PM hooks.

Dependencies/integration: I2C ID `mma8450`, compatible `fsl,mma8450`, input ABS polling.

Risks: block reads do not verify the returned byte count. Negative chip-ID reads are reported as mismatch. Fixed configuration only; close ignores write failures.

Test signals: chip-ID match/mismatch, data-ready skip, 12-bit conversion, open/close writes, poll intervals, short block reads, and OF/I2C matching.

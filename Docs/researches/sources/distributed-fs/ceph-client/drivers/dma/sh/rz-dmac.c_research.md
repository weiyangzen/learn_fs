# sources/distributed-fs/ceph-client/drivers/dma/sh/rz-dmac.c

Purpose: implements the Renesas RZ/G2L, RZ/V2H, and RZ/T2H DMAC as a DMAengine provider using hardware link-mode descriptors. It supports memcpy and slave SG transfers, optional ICU request-number programming for newer SoCs, pause/resume, residue reporting, and per-channel threaded IRQ completion.

Important APIs/types/functions: key types are `struct rz_dmac`, `struct rz_dmac_chan`, `struct rz_dmac_desc`, `struct rz_lmdesc`, `struct rz_dmac_info`, and `struct rz_dmac_icu`. DMAengine hooks are `rz_dmac_alloc_chan_resources`, `rz_dmac_free_chan_resources`, `rz_dmac_prep_dma_memcpy`, `rz_dmac_prep_slave_sg`, `rz_dmac_config`, `rz_dmac_terminate_all`, `rz_dmac_issue_pending`, `rz_dmac_tx_status`, `rz_dmac_device_pause`, `rz_dmac_device_resume`, and `rz_dmac_device_synchronize`. Important internal helpers are `rz_lmdesc_setup`, `rz_dmac_prepare_desc_for_memcpy`, `rz_dmac_prepare_descs_for_slave_sg`, `rz_dmac_xfer_desc`, `rz_dmac_enable_hw`, `rz_dmac_disable_hw`, and `rz_dmac_set_dma_req_no`.

Control flow: probe selects SoC data from the compatible, parses `dma-channels` and optional `renesas,icu`, maps base registers and either DMARS extension registers or ICU integration, requests the optional error IRQ and each channel IRQ, deasserts reset, creates one coherent ring of 64 link-mode descriptors per channel, registers OF DMA translation, initializes DMAengine hooks, writes default common-channel control, and registers the engine. Channel resource allocation preallocates up to 16 `rz_dmac_desc` objects into `ld_free`. Prep functions move a descriptor from `ld_free` to `ld_queue`, fill source/destination/length/SG metadata, and hand it to virt-dma. `issue_pending` marks virt-dma descriptors issued, sets `channel->desc`, converts the queued software descriptor into link-mode descriptor entries, writes request mapping through DMARS or ICU, enables hardware, and moves it to `ld_active`. The hard IRQ clears channel END or resets the channel on error; the threaded IRQ completes the active virt descriptor, returns its software object to `ld_free`, and immediately starts the next queued descriptor when present.

State and persistence: all state is in memory and hardware registers. Each channel stores its current software descriptor, fixed-size descriptor allocation count, peripheral addresses, CHCFG/CHCTRL, MID/RID, three software lists (`ld_free`, `ld_queue`, `ld_active`), and a coherent cyclic ring of `struct rz_lmdesc` with `head` and `tail` pointers. The controller owns a `modules` bitmap of allocated request IDs, reset control, base/ext register mappings, and optional ICU device reference. No persistent data is written.

Dependencies and integration points: uses DMAengine, `virt-dma`, OF DMA, Renesas ICU helpers from `irq-renesas-rzv2h.h` and `irq-renesas-rzt2h.h`, reset controls, DMA coherent memory, runtime PM, and I/O polling. OF DMA specs are one cell: low 10 bits carry MID/RID and bits 10-15 carry channel config fields used to derive CHCFG transfer mode, address mode, level, and HIEN. Generic RZ devices use DMARS registers; V2H/T2H use ICU callbacks.

Risks: `rz_dmac_xfer_desc` expects `channel->desc` to have been set before it obtains `vchan_next_desc`; that coupling is easy to break. The link descriptor ring is fixed at 64 entries, while the prep path does not visibly reject SG lists longer than the ring. Residue computation walks the descriptor ring until `CRLA` and can return zero after a full-ring guard, so ring corruption or stale headers can mask residue. `ld_free` is also checked as a completed-cookie list in residue logic, which relies on descriptor objects retaining cookies after reuse. Error IRQ handling clears hardware but does not complete or poison active virt descriptors. Probe cleanup computes the already-probed channel count with `i ? i - 1 : 0`, making off-by-one cleanup worth testing.

Test signals: validate probe on generic DMARS and ICU-backed compatibles, channel request filtering and duplicate MID/RID exclusion, memcpy and slave SG issue/completion, SG counts near and above the 64-link ring size, pause/resume polling, residue during active link-mode transfers, terminate while IRQ thread is pending, reset assert/deassert error paths, and optional error IRQ absence. Kernel static analysis should watch list transitions among `ld_free`, `ld_queue`, `ld_active` and coherent ring pointer arithmetic.

# sources/distributed-fs/ceph-client/drivers/net/wireless/realtek/rtw88/rtw8821a.h

`rtw8821a.h` is the minimal public header for RTL8821A/RTL8811A support. It declares `extern const struct rtw_chip_info rtw8821a_hw_spec;`, the immutable chip profile consumed by bus modules such as `rtw8821au.c`.

There is no runtime control flow or stored state in the header. Bus glue includes it, places `&rtw8821a_hw_spec` into match-table private data, and common rtw88 probe later uses that pointer to initialize firmware, tables, power sequences, and chip operations.

The only dependency is visibility of `struct rtw_chip_info` through including rtw88 headers. Risks are include-order mistakes, missing `rtw8821a.c` in the build, or declaration/definition drift. Test signals are module builds and successful probe from a bus module using the exported chip-info symbol.

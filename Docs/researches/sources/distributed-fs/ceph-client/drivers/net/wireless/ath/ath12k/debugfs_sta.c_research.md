# sources/distributed-fs/ceph-client/drivers/net/wireless/ath/ath12k/debugfs_sta.c

Purpose: Adds per-link station debugfs files for ath12k extended RX peer statistics. It formats rate, packet, byte, preamble, TID, RU, duration, and L4 counters from `ath12k_rx_peer_stats`, and exposes a write-only reset control.

Important APIs and functions: `ath12k_debugfs_link_sta_op_add()` creates `rx_stats` and `reset_rx_stats` under a station link debugfs directory when extended RX stats are enabled. `ath12k_dbg_sta_dump_rx_stats()` is the read handler for `rx_stats`. `ath12k_dbg_sta_reset_rx_stats()` parses a boolean write and resets peer RX stats. `ath12k_dbg_sta_dump_rate_stats()` formats EHT/HE/VHT/HT/legacy MCS, NSS, GI, BW, and per-BW/GI/NSS/MCS rate matrix counters. `fops_rx_stats` and `fops_reset_rx_stats` wire these handlers into debugfs.

Control flow: The add path runs under the wiphy lock, resolves the `ath12k` radio for the vif/link, checks `ath12k_debugfs_is_extd_rx_stats_enabled()`, and creates the files. The read path guards the wiphy, validates that the link still belongs to the station, dereferences the link STA, allocates a 16 KiB buffer, gets the device DP object, locks `dp->dp_lock`, finds the DP link peer by address, and copies formatted counters into userspace with `simple_read_from_buffer()`. The reset path parses `true`/`false` from userspace, rejects false, locks the wiphy, validates link liveness, resolves the DP object, calls `ath12k_dp_link_peer_reset_rx_stats()`, and returns the written byte count.

State and persistence: Reads do not mutate counters. Reset clears per-peer RX statistics stored under the DP link peer. The debugfs file private data is `struct ieee80211_link_sta *`, so link teardown races are controlled through wiphy locking plus DP locking. The stats are runtime-only and disappear with peer removal, radio teardown, or driver reload.

Dependencies and integration points: Depends on mac80211 link station/vif structures, ath12k MLO link maps, `ath12k_sta_to_ahsta()`, `ath12k_get_ar_by_vif()`, DP peer lookup/reset helpers from `dp_cmn.h`, debugfs gating from `debugfs.h`, and RX stats structures populated by the RX data path. It integrates with mac80211 station debugfs callbacks via the exported `ath12k_debugfs_link_sta_op_add()`.

Risks: The `he_rates_avail` parameter is computed but not used by `ath12k_dbg_sta_dump_rate_stats()`, suggesting stale formatting logic. The fixed 16 KiB buffer may truncate if counter formatting grows, because `scnprintf()` prevents overflow but not loss of data. The code indexes `pream_cnt[6]` for 11BE while other preambles use lower indices, so it relies on HAL enum layout. Returning `-ENOENT` while holding scoped guards depends on cleanup attributes behaving as expected. Counter formatting under `dp_lock` can hold a spinlock while doing many `scnprintf()` calls, which is safe for memory but can increase softirq-off latency.

Test signals: Enable extended RX stats and verify per-link `rx_stats` appears only for live ath12k links; read while traffic exercises EHT/HE/VHT/HT/legacy rates, TIDs, RU allocation, and L4 counters; reset with `1` and verify counters clear; write `0` and malformed data and expect errors; remove a station/link while reading/resetting and expect `-ENOENT` without crashes; test MLO stations with multiple link IDs; and inspect output for truncation under maximum populated rate matrices.

# sources/distributed-fs/ceph-client/drivers/net/wireless/mediatek/mt76/mt7996/mac.c

Purpose: Implements mt7996 MAC datapath and maintenance logic: RX descriptor decoding, TXWI/TXP construction, TX completion and status accounting, WED/NPU/RRO receive processing, station airtime/RSSI polling, MIB/noise/stat updates, reset recovery, coredump collection, DFS radar control, and TWT agreement scheduling.

Important APIs, types, and functions: RX path entry points are `mt7996_rx_check()`, `mt7996_queue_rx_skb()`, `mt7996_mac_fill_rx()`, `mt7996_mac_fill_rx_rate()`, and mesh/header translation helper `mt7996_reverse_frag0_hdr_trans()`. TX construction uses `mt7996_tx_prepare_skb()`, `mt7996_mac_write_txwi()`, `mt7996_mac_write_txwi_8023()`, `mt7996_mac_write_txwi_80211()`, and WED buffer initializer `mt7996_wed_init_buf()`. Completion/status handling uses `mt7996_mac_tx_free()`, `mt7996_txwi_free()`, `mt7996_mac_add_txs_skb()`, and `mt7996_mac_add_txs()`. RRO helpers include page cache/map functions, `mt7996_rro_msdu_page_add()`, `mt7996_rro_rx_process()`, `mt7996_rro_msdu_page_map_free()`, and token cleanup. Maintenance functions include `mt7996_mac_reset_work()`, `mt7996_mac_full_reset()`, `mt7996_mac_restart()`, `mt7996_reset()`, `mt7996_mac_dump_work()`, `mt7996_mac_work()`, `mt7996_mac_update_stats()`, and DFS/TWT helpers.

Control flow: Normal RX dispatch inspects packet type. TX-free, TX-status, MCU event, and firmware monitor packets are consumed internally; normal frames are parsed by `mt7996_mac_fill_rx()` and then passed to `mt76_rx()`. RX parsing selects PHY by descriptor band, validates running state and descriptor groups, resolves WCID including MLO link remapping, fills checksum/decrypt/FCS/MIC/radiotap/rate/AMPDU metadata, handles AMSDU and header-translation padding, reconstructs mesh fragment headers where hardware cannot, runs WED/NPU PPE checks for 802.3 frames, and sets reorder metadata for QoS data. TX preparation chooses the WCID/link for MLO and offchannel cases, consumes an mt76 token, optionally rewrites EAPOL link addresses in software, emits TXWI plus TXP descriptors, handles special AddBA TXP format, maps DMA buffer references, and leaves completion to token release. TX-free events clean DMA queues, parse WCID-pair and MSDU-ID records, update retry/fail stats, release tokens, complete skbs, poll station airtime/RSSI, and wake blocked TX. Reset control either performs L1 SER DMA stop/reinit or a full firmware crash recovery with coredump, queue stop, NAPI disable/enable, DMA reset, firmware reload, RRO/WED restart, and mac80211 restart.

State and persistence behavior: Runtime state spans `dev->mt76.token` IDR, TXWI caches, RX token cache, RRO `page_cache`/`page_map`, per-queue `rx_head`, `phy->rx_ampdu_ts`, `phy->ampdu_ref`, `phy->noise`, per-WCID tx stats/rate/AMPDU state, station poll lists, `dev->recovery` flags and counters, TWT list/table masks, MIB counters, and DFS state. No durable persistence is written, but the file maintains hardware-visible descriptor/token/order state and coherent RRO page ownership. Coredump work copies firmware memory regions into coredump buffers before submitting them. TWT agreement state is held in `dev->twt` and per-station link flow arrays until teardown.

Dependencies and integration points: The file depends on mt76 DMA/token/queue/page-pool helpers, mac80211 station/vif/TWT/AMPDU APIs, connac3 radiotap and PPE decode helpers, MCU commands for BA/rate/RDD/TWT/reset, WED/NPU acceleration hooks, register definitions for RXD/TXD/TXS/RRO/MIB/DFS, Linux NAPI/sk_buff/DMA sync primitives, coredump support, and DFS regulatory state from cfg80211. It integrates with `main.c` through station/TWT/AMPDU callbacks and with `init.c` through MAC/RRO/reset initialization and unregister cleanup.

Risks and edge cases: Descriptor parsing is field- and group-order sensitive; malformed RXD lengths are guarded but can still expose edge cases in padding/header translation. MLO link resolution must not dereference missing link structures; several paths rely on RCU. `mt7996_mac_sta_poll()` computes RSSI and airtime from WTBL registers and contains a suspicious fourth RSSI extraction mask (`GENMASK(31, 14)`) that should be reviewed against hardware layout. Token accounting is central: leaked tokens block TX, while premature release can complete the wrong skb. RRO processing mixes DMA sync, page-pool ownership, sequence-window signatures, and skb construction; bad length or missing token handling can leak buffers or corrupt `rx_head`. Reset work must avoid NAPI/worker races and has different skip rules for WED RRO and NPU queues. TWT scheduling assumes individual implicit agreements with 256 us duration units and simple gap placement in a shared list. DFS state transitions must match regulatory CAC/active/disabled states.

Test signals: Cover normal RX for legacy/HT/VHT/HE/EHT rates, checksum/decrypt flags, FCS/MIC errors, AMSDU and mesh A4 cases, header translation failures including VLAN, multicast fragment drops, WED/NPU PPE metadata, TXWI generation for 802.3/802.11/mgmt/beacon/AddBA/EAPOL/MLO, TX-free version 5/7 records, TXS rate/stat updates, AMPDU auto-start, RRO page add/process/free with multi-page MSDUs and bad signatures, L1 SER reset, full WDT coredump reset, DFS CAC/active/stop transitions, periodic MIB/noise updates, and TWT accept/reject/teardown flows.

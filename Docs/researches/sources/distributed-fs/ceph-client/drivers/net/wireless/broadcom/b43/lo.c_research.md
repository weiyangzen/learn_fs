# sources/distributed-fs/ceph-client/drivers/net/wireless/broadcom/b43/lo.c

This file implements G-PHY local oscillator calibration for b43. It measures feedthrough, searches I/Q LO control pairs, caches calibrations per RF/baseband attenuation, updates hardware power-control DC lookup tables, and performs periodic expiry/refresh.

Important functions include `b43_find_lo_calib()`, `b43_lo_write()`, `lo_measure_feedthrough()`, `lo_txctl_register_table()`, `lo_measure_txctl_values()`, `lo_read_power_vector()`, `lo_measure_gain_values()`, `lo_measure_setup()`, `lo_measure_restore()`, `lo_probe_possible_loctls()`, `lo_probe_loctls_statemachine()`, `b43_calibrate_lo_setting()`, `b43_get_calib_lo_settings()`, `b43_gphy_dc_lt_init()`, `b43_lo_g_adjust()`, `b43_lo_g_adjust_to()`, `b43_lo_g_maintenance_work()`, `b43_lo_g_cleanup()`, and `b43_lo_g_init()`.

Calibration suspends the MAC, saves core/PHY/radio registers, sets up measurement state, refreshes TX bias/magnification if stale, computes gain from RF/baseband attenuation and loopback capability, probes nearby LO I/Q pairs until feedthrough stops improving, restores registers and channel, reenables the MAC, and returns a calibration record. Adjustment retrieves or creates the calibration for current/requested attenuation and writes it to `B43_PHY_LO_CTL`. Hardware power-control mode reads a SHM power vector, recalibrates affected lookup-table entries, updates the cached 32-word DC table, and writes it back to PHY table registers. Maintenance either updates power-vector/DC state or expires and recalibrates software-power-control cache entries.

State lives in `struct b43_txpower_lo_control`: attenuation lists, DC lookup table, calibration list, timestamps, TX bias/magnification, and power vector. Dependencies include `phy_g.h`, b43 MAC suspend/enable, PHY/radio/SHM helpers, SPROM board flags, dummy transmissions, channel switching, and debug LO logging. Risks are hardware register restore mistakes, sleeping context requirements, magic threshold sensitivity, channel-6 measurement with required restoration, allocation failure preventing calibration, and table-size assumptions. Test signals include stable G-PHY TX power, LO debugfs output, no stuck MAC, restored channel, bounded calibration list expiry, and DC table updates after power-vector changes.

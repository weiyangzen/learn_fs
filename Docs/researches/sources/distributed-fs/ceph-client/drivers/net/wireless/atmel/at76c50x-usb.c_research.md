# sources/distributed-fs/ceph-client/drivers/net/wireless/atmel/at76c50x-usb.c

This file implements the USB mac80211 driver for Atmel AT76C503/AT76C505-family 802.11b adapters. It binds many USB IDs to board types, requests and parses board-specific firmware, downloads internal DFU and external firmware when needed, initializes USB bulk URBs, registers `struct ieee80211_hw`, and translates mac80211 operations to Atmel USB vendor/class control messages and bulk transfers.

Important entry points are `at76_probe()`, `at76_disconnect()`, `at76_mod_init()`, and `at76_mod_exit()`. Firmware flow uses `at76_load_firmware()`, `at76_usbdfu_download()`, `at76_load_internal_fw()`, `at76_load_external_fw()`, and `at76_get_op_mode()`. Device command flow uses `at76_set_card_command()`, `at76_wait_completion()`, `at76_set_mib()`, `at76_get_mib()`, and setters for radio, preamble, RTS, fragmentation, power management, autorate, and WEP. mac80211 integration is via `at76_ops`, especially `at76_mac80211_tx()`, `at76_mac80211_start()`, `at76_mac80211_stop()`, `at76_hw_scan()`, `at76_config()`, `at76_bss_info_changed()`, and `at76_set_key()`.

Probe first loads firmware into kernel memory, checks current device op mode, may download internal firmware and let the device re-enumerate, may download external firmware, allocates the mac80211 private object, reads MAC/regulatory hardware config, fills defaults, and calls `ieee80211_register_hw()`. Runtime startup submits the RX URB, sends `CMD_STARTUP`, enables radio, pushes MIB values, and starts passive monitor scanning. Scans send `CMD_SCAN`, poll with delayed work, complete through `ieee80211_scan_completed()`, and rejoin a cached BSSID if present. TX uses a single outstanding bulk URB, includes a join-before-auth workaround, builds an Atmel TX header, stops/wakes queues, and reports TX status from the URB callback. RX uses a single bulk URB and a tasklet that strips the Atmel RX header, builds `ieee80211_rx_status`, guesses scan-channel frequency from beacon/probe response IEs, and hands the skb to mac80211.

State lives in `struct at76_priv`: USB device/pipes/URBs, RX/TX skbs, bulk buffer, mutex, work items, tasklet, WEP keys, channel/BSSID/ESSID, scan/radio/promisc flags, power settings, regulatory domain, firmware version, and mac80211 registration status. Firmware blobs are cached in static `firmwares[]` under `fw_mutex` until module exit. Hardware state persists in firmware MIBs and command state, not on disk.

Dependencies include Linux USB, firmware loader, LED triggers, workqueues/tasklets/timers, skbuff APIs, cfg80211/mac80211, and the protocol layouts in `at76c50x-usb.h`. Main risks are incomplete firmware validation, hidden startup errors because `start()` returns 0, a likely TX skb leak/stall if `usb_submit_urb()` fails after assigning `priv->tx_skb`, racy promisc state by design, missing scan timeout, and WEP-only hardware key support. Test signals include firmware download/re-enumeration, successful mac80211 registration, RX/TX traffic, scan completion, association via the auth join workaround, WEP set/unset, missing-firmware and USB-timeout paths, unplug during active URBs, and clean module unload.

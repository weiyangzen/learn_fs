# sources/distributed-fs/ceph-client/drivers/net/wireless/intel/iwlwifi/pcie/gen1_2/internal.h

Purpose: Defines the private internal contract for the gen1/gen2 iwlwifi PCIe transport. It contains RX/TX descriptor structures, allocator state, interrupt/debug/reset enums, the large `iwl_trans_pcie` transport-private state object, inline queue/interrupt/DMA helpers, and prototypes shared across PCIe RX, TX, IRQ, firmware-load, debug, D3, and probe/remove implementation files.

Important APIs/types: RX types include `iwl_rx_mem_buffer`, `iwl_rx_transfer_desc`, completion descriptors, `iwl_rxq`, and `iwl_rb_allocator`. TX types include `iwl_pcie_txqs`, TSO header/page metadata, queue-index helpers, TFD/TB helpers, and command allocation wrappers. `struct iwl_trans_pcie` stores almost all PCIe transport state: RX queues and pools, context-info v1/v2 pointers, PRPH scratch/info/IML DMA, transport pointer, NAPI device, ICT, IRQ masks/vectors, register locks, PNVM/reduced-power DRAM regions, TX queues, firmware/reset/imr wait states, ME presence work, command pool, power-management flags, and coredump/debug fields.

Inline control behavior: `IWL_TRANS_GET_PCIE_TRANS()` accesses transport-private memory; `iwl_pcie_clear_irq()` clears MSI-X automask bits; `iwl_get_closed_rb_stts()` abstracts old vs AX210+ receive status formats; queue helpers wrap/decrement indexes according to max TFD queue size and gen2 command windowing; `iwl_txq_stop()` and `iwl_trans_pcie_wake_queue()` update stopped bits and notify opmode; `iwl_txq_crosses_4g_boundary()` detects hardware-sensitive DMA spans; TSO helpers recover DMA addresses from page trailers.

Interrupt control flow: `_iwl_disable_interrupts()` clears `STATUS_INT_ENABLED`, masks and acknowledges legacy INTx/MSI interrupts or writes MSI-X FH/HW masks and clears cached masks. `_iwl_enable_interrupts()` sets status and restores initial masks for legacy or MSI-X. `iwl_enable_fw_load_int()`, `iwl_enable_fw_load_int_ctx_info()`, and `iwl_enable_rfkill_int()` select the minimal interrupt causes needed for firmware copy, context-info alive/reset, or RF-kill wake. Public wrappers take `irq_lock` with BH disabled.

State and persistence: The header declares persistent state rather than owning executable storage. Important persisted fields include RX free/used lists and status DMA, queue used/stopped bitmaps, context-info and firmware-load DMA pointers, PRPH scratch/info, PNVM/reduced-power data regions, interrupt masks and vector topology, transport/opmode down flags, firmware reset and IMR state machines, wait queues, RF-kill debug override, ME/CSME detection, command allocation cache, and PM/LTR capability flags.

Dependencies/integration: Includes Linux spinlock/interrupt/skbuff/wait/pci/timer/cpu headers plus iwlwifi FH/CSR/transport/debug/IO/opmode/driver/context-info headers. Prototypes connect to RX, ICT, TX/HCMD, error dump, debugfs, firmware monitor, D3 suspend/resume, NIC access, PRPH/MMIO access, firmware start/alive/stop, PCI probe/remove, MSI-X configuration, PNVM DMA cleanup, and gen2 command enqueue implementations.

Risks: Because this is a shared private header, structure layout or semantic changes can break many transport files. Locking expectations are implicit for `irq_lock`, `reg_lock`, `mutex`, allocator locks, wait queues, and NIC access release annotations. Interrupt mask polarity differs between legacy and MSI-X paths. RX status interpretation differs by device family. Queue index wrapping assumes power-of-two max queue sizes. DMA boundary constraints matter even with 32-bit `dma_addr_t`. Several documentation comments contain stale wording (`ctxt_info_v2` comment says v1 devices, duplicate `ctxt_info_dma_addr`), so comments are not always authoritative.

Test signals: Compile all PCIe transport variants, sparse/lockdep for NIC access and interrupt locking, KUnit or fault-injection for queue index helpers, 4 GB boundary detection, RX status format selection, interrupt enable/disable masks for legacy/MSI-X/context-info/RF-kill, queue stop/wake opmode callbacks, TSO page DMA address calculation, firmware section counting/free helpers, RF-kill debug override, PM/LTR getters, and ABI-sensitive struct initialization paths in probe/start/stop/free code.

# sources/distributed-fs/ceph-client/drivers/net/wireless/realtek/rtw88/rtw8821c.h

`rtw8821c.h` defines RTL8821C private structures and constants used by `rtw8821c.c`. It provides HCI-specific packed efuse tails for PCIe, USB, and SDIO, the common `struct rtw8821c_efuse`, the exported `rtw8821c_hw_spec` declaration, a mirrored BB write helper, MAC/PHY timing constants, PHY status extraction macros, register offsets, coexistence control pins, and RF register 0x18 masks.

Runtime control is limited to `_rtw_write32s_mask()`, which writes a mask/data pair to a baseband path register and its `+0x200` mirror. The `rtw_write32s_mask()` macro wraps it with a build-time range assertion. The other macros drive efuse parsing, RX PHY report decoding, MAC initialization, channel programming, and coexistence switching in the C file.

Persistent state represented here is efuse data programmed into hardware and copied into driver structures. Constants do not store state but directly affect hardware register writes. Dependencies are kernel byteorder/bit helpers and rtw88 register access helpers. Risks include packed bitfield/offset drift, endian assumptions, PHY status buffer alignment, and wrong RF18 bit definitions. Test signals include known efuse dump decoding for PCIe/USB/SDIO, PHY page 0/1 decoding, mirrored-write compile checks, and channel-switch register verification.

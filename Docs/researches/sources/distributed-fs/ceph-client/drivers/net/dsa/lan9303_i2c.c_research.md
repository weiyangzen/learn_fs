# sources/distributed-fs/ceph-client/drivers/net/dsa/lan9303_i2c.c

Purpose: I2C transport wrapper for LAN9303 managed-mode switches. It creates an I2C regmap, selects indirect PHY access, and delegates behavior to `lan9303-core.c`.

Important APIs/types/functions: `struct lan9303_i2c` embeds `i2c_client` and `struct lan9303`. `lan9303_i2c_regmap_config` uses 8-bit register addresses, 32-bit little-endian values, no cache, and the shared register access table. Probe/remove/shutdown are registered through `module_i2c_driver()`.

Control flow: probe allocates wrapper state, initializes `devm_regmap_init_i2c()`, stores clientdata, fills `chip.dev`, assigns `lan9303_indirect_phy_ops`, and calls `lan9303_probe()`. Remove and shutdown call shared lifecycle helpers; shutdown clears clientdata.

State and persistence: devm-managed wrapper state follows the I2C client lifetime. Regmap is uncached, so configuration persists only in hardware and the shared core state.

Dependencies and integration: Linux I2C, OF match `"smsc,lan9303-i2c"`, regmap I2C, and LAN9303 shared core. Legacy I2C id is `"lan9303"`.

Risks and test signals: I2C arbitration during EEPROM loading/reset, endian/width mismatch, and indirect PHY access failures. Test regmap init, shared probe, OF/I2C match, unload/removal, and shutdown cleanup.

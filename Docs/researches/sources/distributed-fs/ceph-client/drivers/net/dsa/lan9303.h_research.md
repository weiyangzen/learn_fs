# sources/distributed-fs/ceph-client/drivers/net/dsa/lan9303.h

Purpose: internal LAN9303 contract between bus front-ends and the shared DSA core.

Important APIs/types/functions: includes regmap/device/DSA and public `linux/dsa/lan9303.h`; declares `lan9303_register_set`, `lan9303_indirect_phy_ops`, and lifecycle functions `lan9303_probe()`, `lan9303_remove()`, `lan9303_shutdown()`.

Control flow: none at runtime. Transport drivers allocate/fill `struct lan9303`, initialize regmap and PHY ops, then call the declared lifecycle functions.

State and persistence: no state is owned here; all state is in caller-owned `struct lan9303` and hardware registers.

Dependencies and integration: used by `lan9303_i2c.c`, `lan9303_mdio.c`, and the shared core. A new transport would include this header and satisfy the same fields.

Risks and test signals: declaration/signature drift can break both transports. Build with I2C and MDIO variants enabled.

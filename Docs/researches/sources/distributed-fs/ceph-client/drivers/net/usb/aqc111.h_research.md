# sources/distributed-fs/ceph-client/drivers/net/usb/aqc111.h

Purpose: Defines the register map, feature masks, descriptors, private state, and tuning tables used by the AQC111/AQC112 USB Ethernet driver. It is the hardware contract for `aqc111.c`.

Important APIs, types, and constants: Core command selectors include `AQ_ACCESS_MAC`, `AQ_FLASH_PARAMETERS`, `AQ_PHY_POWER`, `AQ_WOL_CFG`, and `AQ_PHY_OPS`. MAC register constants cover RX control, node ID, multicast filter array, medium status, monitor mode, PHY reset/power, VLAN table control/data, RX bulk-in queue controls, checksum offload controls, DMA controls, pause watermarks, firmware version, MAC path, and bulk-out control. Feature masks define supported netdev features: `AQ_SUPPORT_FEATURE`, `AQ_SUPPORT_HW_FEATURE`, and `AQ_SUPPORT_VLAN_FEATURE`. `struct aqc111_wol_cfg` is the packed hardware WoL command payload. `struct aqc111_data` is the per-device driver state. Descriptor constants define TX length/drop-pad/VLAN/MSS fields, RX packet descriptor checksum/VLAN/drop/length bits, and RX descriptor header packet-count/offset fields.

Control flow: The header is not executable, but its constants drive all register control flow in `aqc111.c`. Reset and link reset program SFR registers with these bit definitions; RX/TX fixups decode or emit descriptors with the masks and shifts here; ethtool feature changes map to checksum and VLAN bits; suspend/resume uses monitor, WoL, RX path, DMA, and PHY config bits.

State and persistence: `struct aqc111_data` persists while the USB interface is bound and stores software shadows for hardware RX control, PHY capabilities/power/WoL configuration, current link speed, autonegotiation state, advertised speed, checksum status, and firmware version. `AQC111_BULKIN_SIZE[]` is a static table of RX bulk queue control settings selected for normal high-speed rates, 100M, and jumbo-packet operation.

Dependencies and integration: Depends on netdevice feature flags, bit operations, packed structure layout, virt-independent little-endian handling in the C file, VLAN constants, and Linux Ethernet MTU conventions. The header is included only by `aqc111.c`, so changes are tightly coupled to that driver's register programming.

Risks and test signals: Risks include incorrect masks/shifts corrupting descriptors or PHY config, static bulk queue tuning table mismatch with firmware expectations, feature masks advertising unsupported hardware offloads, and layout drift in the packed WoL configuration. Test signals include compile checks for all bit definitions used by `aqc111.c`, descriptor round trips for representative packet lengths/VLAN/MSS values, WoL payload size verification, MTU-dependent bulk-in table selection, and feature negotiation tests that compare advertised software features with actual register writes.

# sources/distributed-fs/ceph-client/drivers/net/usb/mcs7830.c

## Purpose
`mcs7830.c` is a `usbnet` minidriver for Moschip MCS7730/MCS7830/MCS7832 USB Ethernet adapters and a Sitecom LN-030 variant. It configures vendor HIF registers, exposes MII controls, manages multicast filtering, strips the RX status byte, and reports link changes from interrupt packets.

## Important APIs, Types, And Functions
`struct mcs7830_data` stores an 8-byte multicast hash and cached config byte in usbnet private data. Register helpers are `mcs7830_get_reg()`, `mcs7830_set_reg()`, and `mcs7830_set_reg_async()`. MAC helpers read/write `HIF_REG_ETHERNET_ADDR`. `mcs7830_read_phy()` and `mcs7830_write_phy()` serialize through `dev->phy_mutex`, program PHY command registers, poll ready, and read/write `HIF_REG_PHY_DATA`.

`mcs7830_set_autoneg()` advertises 10/100 half/full plus pause and restarts autonegotiation. `mcs7830_get_rev()` detects rev C or newer by probing register 22, and `mcs7830_rev_C_fixup()` writes the pause threshold. `mcs7830_data_set_multicast()` builds the CRC hash or sets promiscuous/all-multicast flags. `mcs7830_apply_base_config()` restores MAC, PHY, filter, config, and rev-C settings after bind or reset-resume.

## Control Flow
`mcs7830_bind()` retries reading the MAC, initializes filters, applies base config, installs netdev/ethtool ops, reserves one extra RX byte for status, initializes MII callbacks, derives PHY ID from the MAC, and gets endpoints. `mcs7830_rx_fixup()` rejects tiny frames, trims the trailing status byte, updates error counters from status bits, and returns whether payload remains. `mcs7830_status()` maps interrupt status to carrier changes. `mcs7830_reset_resume()` reapplies base config then resumes usbnet.

## State And Persistence Behavior
Runtime state is the cached filter/config, usbnet MII state, and netdev MAC. Hardware state includes MAC address, PHY advertisement/BMCR, multicast hash, HIF config, and pause threshold. MAC address changes are refused while the interface is running.

## Dependencies And Integration Points
The file depends on usbnet, USB vendor control messages, ethtool, MII helpers, CRC/Ethernet helpers, and module USB registration. It integrates through `driver_info`, custom netdev ops, ethtool ops, and usbnet PM callbacks.

## Risks And Test Signals
Risks include short PHY polling timeouts, intentionally forced all-multicast behavior, incomplete register dump behavior noted by the TODO, and status-byte parsing. Tests should cover MAC read retries, autoneg restart, rev-C fixup, multicast hash changes, RX error counters for each status bit, link interrupts, reset-resume, and MAC-set rejection while up.

# sources/distributed-fs/ceph-client/drivers/net/usb/pegasus.c

## Purpose
`pegasus.c` is a standalone USB Ethernet driver for ADMtek Pegasus and Pegasus II adapters. It owns netdev allocation, fixed endpoint validation, URB management, RX tasklet retry, interrupt handling, MII/EEPROM access, device-specific reset/configuration, carrier polling, ethtool, Wake-on-LAN, suspend/resume, and dynamic USB ID extension.

## Important APIs, Types, And Functions
The runtime object is `pegasus_t` from `pegasus.h`. Device arrays are generated by macro-including `pegasus.h`. Control access uses `get_registers()`, `set_registers()`, and `set_register()`, with async receive-mode updates through `update_eth_regs_async()`. PHY access flows through `__mii_op()`, `read_mii_word()`, `write_mii_word()`, `mdio_read()`, and `mdio_write()`. EEPROM reads use `read_eprom_word()` and `get_node_id()`.

Setup functions include `set_ethernet_addr()`, `reset_mac()`, `enable_net_traffic()`, `setup_pegasus_II()`, `mii_phy_probe()`, and `get_interrupt_interval()`. Data path functions are `read_bulk_callback()`, `rx_fixup()`, `write_bulk_callback()`, `intr_callback()`, and `pegasus_start_xmit()`.

## Control Flow
Probe rejects a known Belkin Bluetooth collision, verifies bulk-in/bulk-out/interrupt-in endpoints, allocates netdev and URBs, initializes tasklet/work, installs ops, reads EEPROM interrupt interval, resets the MAC, sets MAC address, applies Pegasus II quirks, probes PHY, disables WoL, registers the netdev, and starts carrier polling. Open submits RX and interrupt URBs, enables traffic based on MII link partner data, sets carrier, and starts queue. TX writes a 16-bit length into a fixed TX buffer and submits bulk OUT. RX validates status/length trailers, passes valid frames to `netif_rx()`, and resubmits or schedules the tasklet on failure.

## State And Persistence Behavior
Runtime state includes URBs, RX SKB, fixed TX buffer, cached Ethernet registers, MII info, feature flags, chip type, PHY ID, WoL options, carrier work, and unplug/RX-fail flags. Persistent state is mostly EEPROM-derived MAC and interrupt interval; EEPROM write code is compiled out. The `devid` parameter mutates spare sentinel entries before driver registration.

## Dependencies And Integration Points
The file depends on USB core, netdevice, ethtool, MII, tasklets, delayed work, module parameters, and `pegasus.h`. It integrates through `pegasus_netdev_ops`, ethtool ops, and a direct `usb_driver`.

## Risks And Test Signals
Risks include fixed endpoint assumptions, index coupling between ID arrays, legacy private ioctls, static TX buffer serialization, tasklet retry under low memory, limited stall recovery, vendor GPIO quirks, and chip-specific RX data adjustment. Tests should cover endpoint rejection, blacklist behavior, MAC fallback, PHY probing, Pegasus II setup, RX status parsing, interrupt counters, TX timeout unlink, WoL, suspend/resume, and `devid` parsing.

# sources/distributed-fs/ceph-client/drivers/net/usb/ipheth.c

Purpose: Implements the Apple iPhone USB Ethernet/tethering driver for paired iOS devices using a vendor-specific USB interface. It supports legacy RX framing and a limited iOS NCM-like RX mode while sending TX frames as plain Ethernet payloads.

Important APIs and types: `struct ipheth_device` owns the USB device/interface, netdev, one TX URB, one RX URB, coherent TX/RX buffers, a control buffer, endpoint addresses, delayed carrier work, pairing confirmation, the chosen RX parser, and RX buffer length. Main functions are `ipheth_probe()`, `ipheth_disconnect()`, `ipheth_open()`, `ipheth_close()`, `ipheth_tx()`, `ipheth_rx_submit()`, `ipheth_rcvbulk_callback()`, `ipheth_rcvbulk_callback_legacy()`, `ipheth_rcvbulk_callback_ncm()`, `ipheth_sndbulk_callback()`, `ipheth_carrier_set()`, `ipheth_get_macaddr()`, and `ipheth_enable_ncm()`.

Control flow: Probe allocates an Ethernet netdev, locates altsetting 1 and reverse common bulk endpoints, allocates a control buffer, requests the MAC address with vendor request `0x00`, attempts vendor request `0x04` to enable NCM RX, selects either a legacy 1516-byte RX buffer/parser or a 64 KiB NCM parser, allocates coherent URB buffers, registers the netdev, and leaves carrier and TX queues off until device traffic confirms pairing. Open sets interface number 2 to altsetting 1, performs a carrier query if pairing has been confirmed, submits one RX URB, and schedules periodic carrier polling. RX callback ignores empty URBs and a known four-byte control frame, parses data through the selected parser, marks pairing confirmed, and resubmits RX. Legacy parsing skips two bytes of IP alignment before building an skb. NCM parsing validates fixed iOS NTH16/NDP16 headers, walks up to 22 DPE entries until a null DPE, validates datagram bounds, and emits each Ethernet frame. TX copies skb data into the coherent TX buffer, submits one bulk OUT URB, stops the queue until completion, and updates software stats. Carrier work sends vendor request `0x45`; positive carrier wakes TX when no TX URB is in progress, otherwise it stops queue/carrier.

State and persistence behavior: Runtime state is per netdev and not persisted. The `confirmed_pairing` flag gates carrier checks until at least one valid bulk-in event has arrived, preventing noisy checks before pairing. One TX URB serializes transmit by stopping the queue; one RX URB is continuously resubmitted while open. Disconnect unregisters the netdev, kills URBs, frees coherent buffers and control buffer, and clears interface data.

Dependencies and integration points: Integrates directly with USB core, netdev/etherdevice APIs, ethtool link reporting, delayed work, and CDC NCM header definitions. It matches Apple vendor-specific interface class/subclass/protocol, not product IDs, and disables hub-initiated LPM.

Risks and test signals: Important risks are NCM bounds validation, queue recovery on URB errors, delayed carrier work racing close/disconnect, single-URB TX serialization, and devices that require pairing before any control request succeeds. Tests should cover paired versus unpaired devices, legacy mode when NCM enable fails, NCM multi-datagram URBs, malformed signatures/DPE indices/lengths, zero-length and control-frame RX drops, TX timeout unlink, carrier on/off transitions, open/close without killing RX in close, and disconnect while work or URBs are active.

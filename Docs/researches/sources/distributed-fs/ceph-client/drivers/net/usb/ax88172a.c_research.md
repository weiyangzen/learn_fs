# sources/distributed-fs/ceph-client/drivers/net/usb/ax88172a.c

Purpose: Adds support for ASIX AX88172A USB 2.0 Ethernet devices with phylib-managed internal or external PHYs. It is linked into the `asix` composite driver and exports `ax88172a_info` for the product table in `asix_devices.c`.

Important APIs, types, and functions: `struct ax88172a_private` owns the MDIO bus, connected PHY device, PHY name string, PHY address, last programmed medium mode, embedded-PHY selection, and AX framing RX state. Main functions are `ax88172a_bind()`, `ax88172a_reset()`, `ax88172a_stop()`, `ax88172a_unbind()`, `ax88172a_adjust_link()`, `ax88172a_init_mdio()`, `ax88172a_remove_mdio()`, `ax88172a_reset_phy()`, `ax88172a_rx_fixup()`, and no-op interrupt `ax88172a_status()`. It installs `ax88172a_netdev_ops` and `ax88172a_ethtool_ops`.

Control flow: Bind discovers endpoints, allocates private state, reads the MAC address, installs netdev and ethtool ops, reads `AX_CMD_SW_PHY_STATUS` to determine internal versus external PHY mode, reads the selected PHY address, resets the PHY/MAC path, sets 2 KiB RX URB size for AX framing, and registers an MDIO bus. Reset repeats PHY reset, clears RX control, writes IPG defaults, rewrites the MAC address, restores default RX control, logs medium state, builds a PHY name from the MDIO bus ID and PHY address, connects phylib with `ax88172a_adjust_link()`, resumes the PHY, and starts it. Link adjustment computes ASIX medium mode from phylib speed/duplex and writes it only when changed. Stop stops and disconnects the PHY; unbind unregisters MDIO and frees private state.

State and persistence: The private state persists while the USB interface is bound. `oldmode` avoids redundant medium-mode writes. `phydev` is connected only after reset succeeds and is disconnected during stop. RX framing state is stored per device and passed to `asix_rx_fixup_internal()` so partial AX-framed packets can span URBs. Hardware state includes selected PHY path, software reset mode, RX_CTL, IPG registers, node ID, and medium mode.

Dependencies and integration: Depends on `asix_common.c` for register access, MDIO bus read/write wrappers, RX/TX AX framing, multicast, EEPROM, WoL, and MAC address helpers. Integrates with usbnet through `struct driver_info ax88172a_info`, phylib through `mdiobus_register()`, `phy_connect()`, `phy_start()`, and `phy_do_ioctl_running`, and the ASIX product table through an extern declaration in `asix.h`.

Risks and test signals: Risks include unsupported PHY selection values, MDIO registration cleanup after bind failures, repeated reset connecting multiple PHY instances if stop was not called, missing cleanup of partial RX fixup state on unbind, reset timing sensitivity, and medium-mode mismatch for unusual PHY speed/duplex reports. Test internal and external PHY modes, invalid PHY selection, bind failure at MAC/PHY/MDIO stages, reset then stop/unbind, phylib link polling and speed/duplex changes, RX AX framing shared with common helper, WoL/EEPROM ethtool operations inherited from common code, and module linkage through the ASIX demo-board USB ID.

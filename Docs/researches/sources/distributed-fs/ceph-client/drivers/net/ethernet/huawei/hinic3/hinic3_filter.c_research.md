# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_filter.c

This file synchronizes netdev unicast/multicast address lists and RX mode flags to firmware. The main exported functions are `hinic3_set_rx_mode_work` and `hinic3_clean_mac_list_filter`. Control flow is workqueue-based: `ndo_set_rx_mode` sets flags and queues work; the worker compares netdev UC/MC lists to driver lists, marks filters for hardware sync/unsync, clones entries into temporary add/delete lists, calls `hinic3_set_mac`/`hinic3_del_mac`, rolls back states on failures, and then updates firmware RX mode with default UC/MC/BC plus promisc/allmulti if requested or forced. State lives in `nic_dev->uc_filter_list`, `mc_filter_list`, filter states, `rx_mod_state`, and update flags. Dependencies include netdev address-list locking, `hinic3_nic_cfg.c` MAC and RX-mode commands, and NIC feature bits for promisc/allmulti support. Risks are allocation failure under `GFP_ATOMIC`, rollback complexity, deleting default MACs accidentally, and VF limitations around promiscuous fallback. Test signals are multicast joins/leaves, `ip link set promisc/allmulticast`, MAC filter overflow paths, VF behavior, and cleanup on device remove.

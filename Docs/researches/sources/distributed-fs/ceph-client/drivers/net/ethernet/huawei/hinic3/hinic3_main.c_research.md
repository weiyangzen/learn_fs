# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_main.c

This file is the NIC auxiliary service driver and netdev construction path. Probe registers for hardware events, resets NIC resources, allocates `net_device` with max queue count, initializes `hinic3_nic_dev`, NIC IO, software defaults, netdev/ethtool ops, feature flags, firmware default features, periodic work, carrier state, and finally registers the netdev. Software init chooses random MAC for VFs or firmware MAC for PFs, programs the default MAC, enables RSS if supported, allocates TX/RX queue objects and interrupt-coalescing arrays. Event handling maps NIC link events and common fault/heartbeat/watchdog events to carrier on/off and module messages. Periodic work reports TX-timeout fault events. State includes `nic_dev` workqueue, delayed periodic work, VLAN bitmap, queue arrays, RSS state, feature capabilities, intr coalescing, filter lists, and carrier/link flags. Dependencies include low-level auxiliary APIs, hw/common/NIC config, NIC IO, RSS, TX/RX, netdev and ethtool ops. Risks include remove ordering: netdev unregister, delayed/work cancellation, feature clearing, MAC deletion, and IO free must not race with open paths. Test signals are `register_netdev`, link-event carrier changes, VF random MAC behavior, RSS/feature negotiation, and module load/unload.

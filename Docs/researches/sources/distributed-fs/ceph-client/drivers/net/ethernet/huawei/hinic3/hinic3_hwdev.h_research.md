# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_hwdev.h

This header defines the central hinic3 PCI and hardware-device objects. `struct hinic3_pcidev` stores PCI device pointer, mapped BAR bases, doorbell metadata, auxiliary devices, mutex, and service state. `struct hinic3_hwdev` ties together hwif, config management, AEQ/CEQ, mailbox, cmdqs, PF-to-management channel, workqueue, common feature bitmap, channel lock, init-state bits, and chip-present flag. It also defines event service/type enums, fault level/source values, `HINIC3_SRV_EVENT_TYPE`, `struct hinic3_event_info`, and `struct hinic3_adev` for auxiliary services. Exported APIs are `hinic3_init_hwdev`, `hinic3_free_hwdev`, and `hinic3_set_api_stop`. State here is long-lived and is the integration point between PCI probe and NIC auxiliary probe. Dependencies include Linux auxiliary bus and PCI, plus firmware service-type constants. Risks are lifetime coupling: auxiliary devices and workqueues must not outlive `hwdev`, and event callbacks must be unregistered before free. Test signals are auxiliary probe/remove ordering, shutdown with blocked waiters, and service event delivery.

# sources/distributed-fs/ceph-client/drivers/net/ethernet/freescale/gianfar.c

## Purpose
`gianfar.c` is the main Freescale/NXP Gianfar, TSEC, eTSEC, and FEC Ethernet MAC driver. It binds OF platform devices, maps queue-group register blocks, configures MAC/DMA/filer hardware, attaches phylib, registers a `net_device`, and implements the normal Linux data path for TX, RX, NAPI, interrupts, MTU changes, feature toggles, timestamping, suspend/resume, and wake-on-LAN.

## Important APIs, types, and functions
The public driver entry points are the platform driver `gfar_driver`, `gfar_probe()`, `gfar_remove()`, the `gfar_netdev_ops` table, and the exported helpers `startup_gfar()`, `stop_gfar()`, and `gfar_mac_reset()` used by ethtool support. Device-tree and resource setup is handled by `gfar_of_init()` and `gfar_parse_group()`. Runtime open/close flows use `gfar_enet_open()`, `init_phy()`, `gfar_request_irq()`, `startup_gfar()`, `gfar_close()`, `stop_gfar()`, and `gfar_free_irq()`. TX is centered on `gfar_start_xmit()` and `gfar_clean_tx_ring()`. RX is centered on `gfar_receive()`, `gfar_poll_rx_sq()`, `gfar_clean_rx_ring()`, `gfar_get_next_rxbuff()`, `gfar_process_frame()`, and `gfar_alloc_rx_buffs()`. Error, reset, and PM paths use `gfar_error()`, `gfar_interrupt()`, `gfar_timeout()`, `gfar_reset_task()`, `reset_gfar()`, `gfar_suspend()`, `gfar_resume()`, and `gfar_restore()`.

## Control flow
Probe starts by parsing the OF node to decide single-queue/single-group versus multi-queue/multi-group mode. It allocates an `alloc_etherdev_mq()` netdev, creates per-TX and per-RX queue objects, maps register blocks, parses IRQs, reads MAC/PHY/TBI and hardware capability properties, detects errata, initializes NAPI instances, assigns netdev and ethtool operations, enables supported checksum/VLAN/headroom features, programs default ring sizes and interrupt coalescing values, initializes the hardware, registers the netdev, records WOL capabilities, names IRQs, and seeds the receive filer table.

Opening the device attaches to the PHY, requests IRQs, resets the MAC, allocates coherent descriptor rings plus software skb/page tracking arrays, initializes descriptors, writes descriptor base registers, clears `GFAR_DOWN`, starts DMA, enables interrupts, starts phylib, enables NAPI, and wakes TX queues. Closing cancels pending reset work, stops netdev queues, marks the device down, disables NAPI, halts DMA, stops and disconnects the PHY, frees DMA/skb/page resources, and releases IRQs.

The TX path maps the skb head and fragments into one or more TxBDs, optionally prepends the hardware frame control block for checksum/VLAN/timestamp work, works around checksum errata by falling back to `skb_checksum_help()`, updates byte queue limits, publishes descriptors with `gfar_wmb()`, stores the skb in the software ring, updates free descriptor counts under the per-queue lock, and pokes `TSTAT` to restart DMA. TX completion runs from NAPI, waits for the final descriptor to lose `TXBD_READY`, unmaps DMA, extracts hardware TX timestamps when requested, frees the skb, advances dirty indices, restores descriptor availability, and wakes stopped subqueues.

The RX path masks RX interrupts and schedules NAPI. The poller clears RX events, drains ready RxBDs up to budget, builds skbs from page-backed buffers, reuses the free half of reusable pages when possible, handles multi-descriptor frames, accounts and drops malformed frames, removes FCB/padding/FCS, attaches RX checksum, VLAN, and timestamp metadata, submits packets through GRO, replenishes descriptors in batches, updates last-free-RxBD flow-control pointers, completes NAPI, and unmasks RX interrupts.

## State and persistence behavior
All state is in kernel memory and scoped to the platform device and netdev lifetime. `struct gfar_private` stores hardware capability flags, errata flags, PHY/TBI nodes, queue arrays, group register mappings, RMON overflow state, hash register pointers, WOL settings, cached filer tables, pause/autoneg flags, timestamp flags, and reset/down state bits. Each TX queue keeps descriptor pointers, skb ring indices, free counts, BQL accounting data, coalescing config, stats, and a spinlock. Each RX queue keeps descriptors, page buffers, clean/use/allocation indices, an in-progress skb for fragmented receives, coalescing config, stats, and the last-free-BD register pointer. There is no disk persistence; settings survive only until driver removal, though WOL and ethtool state may be visible across suspend/resume while the netdev exists.

## Dependencies and integration points
The file integrates Linux platform/OF probing, phylib and fixed PHY support, net_device operations, NAPI, IRQ core, DMA mapping, skb/page APIs, VLAN acceleration, checksum offload, hardware timestamping, byte queue limits, GRO, power management, and optional netpoll. It consumes register and structure definitions from `gianfar.h` and exposes `gfar_ethtool_ops` from `gianfar_ethtool.c`. Device-tree properties such as model, `queue-group`, `phy-handle`, `tbi-handle`, `bd-stash`, `rx-stash-len`, `rx-stash-idx`, `fsl,magic-packet`, and `fsl,wake-on-filer` determine much of the runtime shape.

## Risks and edge cases
The highest-risk areas are descriptor ownership, DMA ordering, and reset coordination. The driver relies on power-of-two rings, wrap bits, `gfar_wmb()`, and careful software ring indices; mistakes can corrupt DMA ownership or leak mappings. Reset, MTU, coalescing, feature, and timestamp changes all serialize through `GFAR_RESETTING` and may stop/start the whole device. RX page reuse depends on page reference counts and pfmemalloc checks. TX timestamping changes descriptor layout and DMA unmap length. Errata workarounds alter checksum behavior and DMA halt polling. WOL filer programming temporarily replaces the normal filer table, so resume must restore cached rules. Error interrupts can schedule asynchronous reset while the normal close path is running.

## Test signals
Useful coverage includes OF probe for `gianfar` and `fsl,etsec2`, one and two queue-group devices, PHY attach failures, fixed PHY, SGMII/TBI setup, open/close loops, TX with linear and fragmented skbs, checksum and VLAN offload on/off, hardware TX/RX timestamp enable/disable, jumbo MTU changes, RX fragmented frames, RX errors and allocation failure counters, interrupt coalescing, netpoll, multicast/promiscuous changes, TX timeout recovery, suspend/resume with no WOL, magic-packet WOL, filer unicast WOL, and RMON overflow accounting.

# sources/distributed-fs/ceph-client/drivers/net/ethernet/aquantia/atlantic/hw_atl/hw_atl_llh.c

Purpose: Implements the low-level hardware access layer for Atlantic NIC registers. Each exported helper converts a named hardware operation into `aq_hw_read_reg()`, `aq_hw_write_reg()`, `aq_hw_read_reg_bit()`, `aq_hw_write_reg_bit()`, or `aq_hw_read_reg64()` calls using the address, mask, and shift definitions from `hw_atl_llh_internal.h`.

Important APIs, types, and functions: The file exports register wrappers for temperature sensor control (`hw_atl_ts_*`), SMBus status/data (`hw_atl_smb0_*`), global CPU semaphores/scratchpads/reset (`hw_atl_reg_glb_cpu_sem_*`, `hw_atl_glb_soft_res_*`, `hw_atl_scrpad*`), DMA/stat counters, interrupt status/mapping/masking, RX descriptor DMA (`hw_atl_rdm_*`, `hw_atl_reg_rx_dma_*`), RX packet buffer and receive filters (`hw_atl_rpb_*`, `hw_atl_rpf*`), RX offload and LRO (`hw_atl_rpo_*`), TX descriptor DMA/offload/buffer/scheduler (`hw_atl_tdm_*`, `hw_atl_tpb_*`, `hw_atl_tpo_*`, `hw_atl_tps_*`), indirect MSM MAC/PHY register access, PCI reset-disable, PTP clock reads, L3/L4 filters, firmware semaphores, and MDIO interface registers. Indexed helpers such as `hw_atl_itr_irq_map_*()`, `hw_atl_rpf_rpb_user_priority_tc_map_set()`, and `hw_atl_rpo_lro_max_num_of_descriptors_set()` use static address/mask/shift tables where the hardware packs multiple queue or LRO fields into shared registers.

Control flow: There is almost no algorithmic flow; calls are direct register access transactions. Setters perform read-modify-write through `aq_hw_write_reg_bit()` when touching a bitfield, or full-register writes when the hardware field owns the whole register. Getters read either raw registers or masked bitfields. A few helpers loop across fixed word counts, notably IPv6 L3/L4 address clear/set helpers, which write four 32-bit source or destination words in reverse array order for IPv6 programming. `hw_atl_rdm_rx_dma_desc_cache_init_tgl()` is one of the few stateful operations in this file: it reads the descriptor cache init bitfield and writes the opposite value to toggle hardware initialization.

State and persistence behavior: The file itself has no durable software state. All persistent effects are hardware register effects on the Atlantic device: descriptor base/tail pointers, interrupt routing/masks, packet buffer thresholds, filter entries, offload enables, reset bits, semaphores, and firmware-visible scratch registers. Static lookup arrays inside functions are constant metadata. Ordering and synchronization are delegated to higher layers and the MMIO helpers; callers are responsible for programming sequences, polling, and lock context.

Dependencies and integration points: Includes `hw_atl_llh.h` for prototypes, `hw_atl_llh_internal.h` for register metadata, and `../aq_hw_utils.h` for MMIO helper primitives. It is the shared hardware primitive layer consumed by Atlantic generation-specific files, firmware utilities, filter setup, ring setup, interrupt setup, reset code, PTP logic, and diagnostics. `hw_atl_utils.c` depends on its global reset, semaphore, scratchpad, MAC/PHY, and statistic helpers.

Risks: The largest risk is register metadata drift. A wrong address, mask, shift, or indexed-table entry silently writes the wrong hardware bit, which can misroute interrupts, corrupt descriptor rings, disable offloads, or break reset/firmware handshakes. Indexed functions do not bounds-check queue/filter/LRO indices; callers must enforce the documented ranges. Read-modify-write helpers can race if multiple call sites touch different fields in the same register without serialization. Full-register writes, such as interrupt masks, RSS data, descriptor base/tail, and LRO enable words, require callers to preserve unrelated bits when needed. IPv6 address ordering is intentionally reversed relative to the input array and should be kept aligned with upper-layer filter encoding.

Test signals: Build coverage should catch prototype drift with `hw_atl_llh.h`. Hardware or emulation tests should cover reset, link bring-up, interrupt routing for RX/TX queues, descriptor ring enable/tail updates, RSS key/table programming, VLAN/L2/L3/L4 filter programming, checksum/LRO/LSO toggles, loopback modes, PTP clock reads, and MDIO/firmware semaphore paths. Register dump comparisons before and after programming are useful because this file is a thin mapping layer.

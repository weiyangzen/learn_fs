# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_mbox.h

This header defines mailbox message layout, state, and exported transport APIs. It provides 64-bit header bitfields for source function, status, source, AEQ id, msg id, command, message length, module, segment length, no-ack, data type, sequence id, last flag, and direction. It defines message direction, ACK/no-ACK, inline/DMA data, AEQ selection, message descriptors/channels, send mailbox write-back state, event states, DMA message/queue structures, and `struct hinic3_mbox` locks and buffers. Exported APIs cover AEQ receive handling, init/free, send to management with ACK, response to management, and no-ack send. State here is transport state shared by common, NIC, config, and management commands. Dependencies are bitfield helpers, mutexes, DMA types, and `mgmt_msg_params`. Integration points include `hinic3_hwdev.c` AEQ callback setup and every firmware command wrapper. Risks are header bit widths matching firmware exactly, lock hierarchy correctness, and buffer ownership during teardown. Test signals are command responses, management ACKs, multi-segment payloads, and VF/PF source filtering.

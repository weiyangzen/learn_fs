# sources/distributed-fs/ceph-client/drivers/net/ethernet/microchip/vcap/vcap_model_kunit.h

## Purpose
`vcap_model_kunit.h` is the small public interface for the autogenerated Microchip VCAP KUnit model. It lets test code import the synthetic VCAP array and statistics block without exposing the generated implementation tables.

## Important APIs, Types, and Data
- Declares `extern const struct vcap_info kunit_test_vcaps[]`.
- Declares `extern const struct vcap_statistics kunit_test_vcap_stats`.
- Uses include guard `__VCAP_MODEL_KUNIT_H__`.
- Assumes including code has visibility of `struct vcap_info` and `struct vcap_statistics` from the VCAP API headers.

## Control Flow
The header has no control flow. It provides link-time access to constants defined in `vcap_model_kunit.c`.

## State and Persistence
No state is owned here. The declared objects are immutable model data in the companion C file.

## Dependencies and Integration Points
- Integrates KUnit tests with the generated model by publishing only top-level symbols.
- Must remain consistent with `vcap_model_kunit.c`; symbol name drift breaks link-time resolution.
- SPDX is BSD-3-Clause, matching the autogenerated model header licensing.

## Risks and Edge Cases
- The header does not include `vcap_api.h` itself, so include order matters if a consumer needs complete struct declarations rather than compatible incomplete declarations.
- Because the file is generated, manual expansion of the interface should be coordinated with the generator.

## Test Signals
- Successful KUnit build/link of VCAP tests is the primary signal.
- Missing type declarations or unresolved symbols indicate include-order or generation drift.

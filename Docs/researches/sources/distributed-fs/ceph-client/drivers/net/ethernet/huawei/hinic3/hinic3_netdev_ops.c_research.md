# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_netdev_ops.c

This file implements `net_device_ops` for opening/closing the interface, queue resources, feature changes, MTU/MAC/VLAN operations, stats, timeout reporting, RX mode scheduling, and xmit binding. Open initializes NIC IO resources, allocates queue IRQs, allocates QP and TX/RX resources, initializes/configures QPs, requests queue IRQs/NAPI, configures MTU/DCB/RSS, enables vport/port, starts TX queues, checks link, and marks `HINIC3_INTF_UP`. Close clears that bit, brings vport/port down, flushes TX/QP resources, tears down IRQs/QP contexts/resources, but notably does not free `num_qps` IRQ inventory or NIC IO resources in the visible close path. Feature changes call firmware for LRO, VLAN strip, and VLAN filter while csum/TSO are software feature state. State includes queue parameters, IRQ arrays, VLAN bitmap, interface flag, link status, netdev features, stats, and filter work flags. Dependencies include hw/NIC config, NIC IO, RSS, TX/RX, and IRQ helpers. Risks are open/close resource symmetry, partial-error rollback, firmware failure leaving netdev features adjusted, and VLAN bitmap indexing. Test signals are repeated `ip link set up/down`, MTU/MAC/VLAN changes, feature toggles, tx timeout path, stats under traffic, and RSS-disabled single-queue mode.

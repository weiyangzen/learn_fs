# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_hw_comm.h

This header declares the common management-command API and interrupt moderation shape. `struct hinic3_interrupt_info` carries MSI-X index, low-latency fields, coalescing flag, pending limit, coalescing timer, and resend timer. Exported functions cover direct and read-modify-write interrupt configuration, function reset, common feature negotiation, global attributes, function-service used state, DMA attributes, WQ page size, cmdq depth, RX/TX flush, BDF context, firmware time sync, root context setup/cleanup, and firmware version readout. State is not stored here, but the interfaces mutate firmware/device state and `hwdev` fields in implementation. Dependencies are firmware ABI structs in `hinic3_hw_intf.h` and `struct hinic3_hwdev`. Integration points include hardware-device init/free, queue IRQ init, ethtool, NIC IO context setup, and PCI probe BDF reporting. Risks are callers passing inconsistent queue depths or interrupt values and assuming all operations are available after chip removal. Test signals include successful `hinic3_init_hwdev`, adaptive interrupt moderation updates, and teardown flush completion.

# Research: sources/distributed-fs/ceph-client/drivers/net/ethernet/agere/et131x.h

## Purpose
`et131x.h` is the private hardware-definition header for the Agere ET1310/ET131x driver. It gives `et131x.c` a typed MMIO layout for the controller and defines bit masks, index encodings, EEPROM config offsets, MAC/RXMAC/TXMAC/RXDMA/TXDMA/MMC/MAC-stat registers, and PHY vendor register constants.

## Important APIs, Types, and Definitions
The header exposes no callable functions. Its major types are `struct global_regs`, `struct txdma_regs`, `struct rxdma_regs`, `struct txmac_regs`, `struct rxmac_regs`, `struct mac_regs`, `struct macstat_regs`, `struct mmc_regs`, and the top-level `struct address_map`. Important constants include LBCIF EEPROM bits, `ET_PM_PHY_SW_COMA`, `ET_PMCSR_INIT`, interrupt masks, `ET_RESET_ALL`, DMA index/wrap masks, RX/TX DMA controls, MAC config bits, RX packet filter bits, MMC controls, and PHY vendor registers such as `PHY_CONFIG`, `PHY_INTERRUPT_STATUS`, and `PHY_LED_2`.

## Control Flow
The header shapes driver control flow by making MMIO access field based from `adapter->regs`. Reset writes `global.sw_reset` and `mac.cfg1`; DMA setup writes `txdma.*` and `rxdma.*`; RX/TX enable uses `rxdma.csr`, `txdma.csr`, `rxmac.ctrl`, and `txmac.ctl`; MII operations sequence the `mac.mii_mgmt_*` registers; interrupts are read and masked through `global.int_status` and `global.int_mask`. `INDEX10()`, `INDEX12()`, and `INDEX4()` isolate ring indexes while preserving wrap bits.

## State and Persistence Behavior
This file defines volatile hardware state, not persistent storage. EEPROM access bits describe a path to nonvolatile data, but persistence is handled by the device and `et131x.c`. Register state is restored after probe, reset, link changes, MTU changes, resume, and PHY coma exit. The padded `address_map` assumes a stable PCI BAR layout.

## Dependencies and Integration Points
The definitions are consumed by `et131x.c` and rely on Linux integer types plus MMIO accessors in the including C file. PHY definitions complement generic MII constants from `include/linux/mii.h`. The `address_map` must match the ET131x BAR layout because every hardware operation dereferences it.

## Risks and Edge Cases
The register structs rely on natural 32-bit layout and explicit padding rather than generated offsets. The large `address_map` unused arrays make accidental layout drift hard to detect without offset checks. DMA wrap constants mix descriptor index and wrap state in one integer, which is easy to misuse. Interrupt and MAC/PHY bit masks encode hardware-specific behavior, so small changes can alter reset, PHY coma, jumbo, flow-control, or interrupt behavior.

## Test Signals
Compile-time offset/size review, sparse `__iomem` checking, successful ethtool register dumps, MDIO reads/writes, interrupt mask/unmask behavior, RX/TX ring wrap under traffic, reset, PHY coma transitions, jumbo MTU programming, multicast hash programming, and MAC-stat carry interrupts.

# Research: sources/distributed-fs/ceph-client/drivers/net/ethernet/agere/et131x.c

## Purpose
`et131x.c` is the Linux PCI Ethernet driver implementation for Agere/ATT ET1310 and ET131x 10/100/1000 Base-T controllers. It owns PCI probe/remove, netdev registration, MDIO/PHY integration, MAC/RXMAC/TXMAC setup, RX/TX DMA ring allocation, NAPI interrupt processing, multicast filtering, MTU changes, power-management suspend/resume, and ethtool register dumping.

## Important APIs, Types, and Functions
Key private structures are defined in this file: `struct et131x_adapter`, `struct rx_ring`, `struct fbr_lookup`, `struct tx_ring`, `struct tcb`, `struct rfd`, and `struct ce_stats`. These combine netdev/PCI/PHY pointers, MMIO base, locks, packet filters, DMA coherent rings, software queues, timer state, and accumulated hardware statistics.

Important entry points are PCI probe/remove (`et131x_pci_setup()`, `et131x_pci_remove()`), netdev ops (`et131x_open()`, `et131x_close()`, `et131x_tx()`, `et131x_tx_timeout()`, `et131x_change_mtu()`, `et131x_multicast()`, `et131x_stats()`), NAPI/IRQ (`et131x_isr()`, `et131x_poll()`), MDIO/PHY helpers, EEPROM helpers, hardware setup helpers, and DMA data-path helpers such as `nic_rx_pkts()`, `et131x_handle_recv_pkts()`, `nic_send_packet()`, and `et131x_handle_send_pkts()`.

## Control Flow
Probe enables PCI, requests BARs, sets DMA masks, allocates a netdev, reads/repairs EEPROM state, maps BAR0, resets hardware, allocates coherent TX/RX rings and RFDs, registers NAPI, creates/registers an MDIO bus, connects the PHY, configures hardware, exits PHY coma, and registers the netdev. Open starts the error timer, requests a shared IRQ, enables NAPI, enables TX/RX DMA, and starts phylib. Close stops phylib and DMA, disables NAPI, frees the IRQ, and deletes the timer.

Link changes are driven by phylib through `et131x_adjust_link()`. Link-up exits coma, applies speed-specific PHY fixes, computes pause mode, adjusts jumbo FIFO settings, tunes RX coalescing, and completes MAC config. Link-down frees active sends, resets send state, soft-resets and reconfigures hardware, and cycles TX/RX.

RX uses two hardware free-buffer rings plus a packet-status ring. NAPI drains `nic_rx_pkts()`: compare PSR indexes, read descriptor status, advance PSR full offset, remove an RFD, copy coherent buffer data into an skb, submit to the stack, and return the FBR/RFD. TX uses 64 TCBs and a 512-entry descriptor ring. `nic_send_packet()` maps skb data, writes descriptors and wrap indexes, queues a TCB on the send list, and writes the service request register. Completion reads `new_service_complete`, frees completed TCBs, unmaps DMA, and wakes the netdev queue.

## State and Persistence Behavior
Persistent or semi-persistent state is limited to EEPROM contents, the permanent MAC address, and EEPROM LED option bytes. Runtime state is in `struct et131x_adapter`: flags, link, desired/resolved flow control, packet filter, multicast list, MMIO base, DMA rings, wrap indexes, TCB/RFD queues, NAPI, timer, and stats. Hardware state is reconstructed on probe, link changes, MTU changes, resume, and PHY coma exit. MTU changes free and reallocate DMA memory based on jumbo size.

## Dependencies and Integration Points
The file depends on PCI, DMA mapping, netdevice, ethtool, NAPI, phylib/MDIO, timers, skbuff, CRC32 multicast hashing, random MAC generation, and MMIO accessors. It includes `et131x.h` for register layout. User-visible integration is through PCI binding, netdev operations, ethtool register/link APIs, standard PHY ioctls, MTU changes, multicast/promiscuous flags, and suspend/resume.

## Risks and Edge Cases
If `dev_alloc_skb()` fails in `nic_rx_pkts()`, the function returns after removing an RFD without returning it to the RX list or replenishing the free-buffer ring. TX maps page fragments with `skb_frag_dma_map()` but completion unmaps every descriptor with `dma_unmap_single()`, which is suspicious for page-backed fragments. `et131x_set_packet_filter()` clears local filter bits for promiscuous/filter-zero mode but does not write the registers in that branch. `et131x_open()` starts the timer before `request_irq()` and does not delete it on IRQ failure. MAC error interrupts mostly log warnings rather than immediately resetting.

## Test Signals
Compile with `CONFIG_ET131X`, sparse/clang checks for MMIO and DMA mapping, probe/bind on PCI hardware, MDIO/PHY attach, link up/down, DHCP/ping, ethtool register dump, normal and jumbo MTU changes, multicast/promiscuous transitions, suspend/resume, TX timeout recovery, allocation-failure injection for RX/TX, and gigabit versus 10/100 interrupt coalescing.

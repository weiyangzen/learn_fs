# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_eqs.h

This header declares the event queue model shared by hardware initialization, mailbox, management, and command queues. It defines maximum queue counts, default lengths, element sizes, queue types (`HINIC3_AEQ`, `HINIC3_CEQ`), interrupt modes, consumer-index arm states, `struct hinic3_eq`, AEQ element layout, AEQ/CEQ event enums, callback typedefs, and aggregate `hinic3_aeqs`/`hinic3_ceqs` containers. The important exported functions are queue init/free, callback register/unregister, and dump helpers. State is centered on queue page ownership, MSI-X vector identity, software consumer index, wrapped-bit tracking, per-event callback arrays, and AEQ workqueue. Dependencies are Linux interrupt/workqueue types plus `hinic3_hw_cfg.h` and queue-page helpers. Integration points are `hinic3_hwdev.c` for lifecycle, `hinic3_mbox.c` and `hinic3_mgmt.c` for AEQ callbacks, and cmdq for CEQ callbacks. Risks include enum values matching firmware event types and the fixed element sizes matching hardware descriptors. Test signals are successful callback dispatch for mailbox/mgmt events, CEQ cmdq completions, and clean free paths without use-after-free.

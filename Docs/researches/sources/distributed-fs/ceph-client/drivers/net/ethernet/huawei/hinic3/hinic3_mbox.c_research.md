# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_mbox.c

This file implements mailbox transport between driver, management CPU, and PF/VF functions. Initialization allocates message channels, sync/async DMA queues, a write-back status DMA buffer, a single-thread workqueue, and optional VF-to-PF channel. Sending serializes whole messages with `mbox_send_lock` and segment writes with `mbox_seg_send_lock`, optionally converts management messages to DMA descriptors if firmware lacks segmentation support, writes swabbed header/body dwords into the mailbox MMIO area, triggers hardware, waits for write-back completion, and for ACK messages waits until an AEQ response sets `event_flag`. Receive handling validates sequence, msg id, module, command, segment lengths, and source function, accumulates body data, and marks matching responses complete. State includes send message ID, event flag, response/receive buffers, DMA queue producer/consumer indices, write-back status, and locks. Dependencies are CSR mailbox registers, hwif, AEQ callback registration, wait helpers, and `mgmt_msg_params`. Risks are endian conversion, sequence validation, timeout recovery, DMA queue wrap/full handling, source validation for VFs, and lock ordering. Test signals are all firmware command wrappers, forced mailbox timeouts, multi-segment messages, no-ack sends, and removal waking pending waiters.

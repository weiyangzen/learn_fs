# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_mgmt_interface.h

This header defines the L2 NIC and HILINK firmware ABI. It includes feature negotiation, function table, MAC add/delete/update, VLAN, VLAN offload/filter, SQ consumer-index attributes, QP clear, forced packet drop, vport enable, RX mode flags, DCB state, LRO config/timer, RSS key/context/indir structures, pause config, L2NIC command IDs, ucode command IDs, HILINK port commands, link status, port info, module event structures, wire types, and NIC feature capability bits/default masks. Control flow is through `hinic3_nic_cfg.c`, RSS code, queue setup, ethtool, and event handling. State is firmware wire state; no local storage is defined except command payload shape. Dependencies include common `mgmt_msg_head`, bitfield helpers, and Ethernet address length. Risks are firmware ABI drift, feature-mask mismatch with netdev features, and shared status field naming (`head` vs `msg_head`) causing wrapper mistakes. Test signals are feature negotiation, MAC/VLAN operations, link information in ethtool, RSS programming, LRO/VLAN offload toggles, and link/module events.

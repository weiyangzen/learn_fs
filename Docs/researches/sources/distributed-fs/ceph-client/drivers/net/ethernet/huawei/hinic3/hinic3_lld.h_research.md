# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_lld.h

This header exposes the lower-layer PCI/auxiliary boundary to the NIC service driver. It defines the driver name `hinic3`, declares module-level PCI registration helpers `hinic3_lld_init` and `hinic3_lld_exit`, exposes auxiliary event registration/unregistration, and provides `hinic3_adev_get_hwdev` for service drivers to recover the shared hardware device. State is owned elsewhere: auxiliary devices hold callback pointers and the hwdev pointer. Dependencies are Linux auxiliary bus types and `struct hinic3_event_info`. Integration points are `hinic3_main.c` module init/exit and NIC auxiliary probe/event handling. Risks are callback lifetime and use after auxiliary remove if service drivers do not unregister before freeing private state. Test signals are successful auxiliary driver registration after PCI driver registration, event delivery to NIC, and clean module exit order.

# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_irq.c

This file wires queue-pair MSI-X interrupts to NAPI and adaptive RX interrupt moderation. `hinic3_qps_irq_init` fills each `hinic3_irq_cfg`, assigns CPU affinity, adds/enables NAPI, programs interrupt coalescing, requests IRQs, initializes DIM work, associates queues with NAPI, enables auto-mask, and unmasks MSI-X. The IRQ handler clears the resend timer, increments `total_events`, and schedules NAPI. Polling drains TX completions and RX packets, and when complete updates DIM and reenables MSI-X. DIM work maps net DIM profiles to hinic3 coalescing timer and pending limit, then writes firmware interrupt config. Teardown disables NAPI, clears queue/NAPI association, masks vectors, clears auto-mask, frees IRQs, and syncs DIM work. State includes NAPI structs, affinity masks, per-queue coalescing config, RX DIM state, and event counters. Dependencies include TX/RX pollers, `hinic3_set_interrupt_cfg`, hwif MSI-X helpers, and Linux net DIM. Risks are interrupt reenable ordering, NAPI lifetime during error unwind, DIM writes after queue teardown, and queue-count/vector mismatches. Test signals are packet RX/TX, IRQ affinity, adaptive moderation changes, open/close cycles, and error-injection during IRQ request.

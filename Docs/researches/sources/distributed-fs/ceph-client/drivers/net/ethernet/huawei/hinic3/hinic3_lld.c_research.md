# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_lld.c

This is the PCI lower-layer driver and auxiliary-bus service publisher. Probe flow allocates `hinic3_pcidev`, enables PCI, requests regions, sets DMA mask, maps config/interrupt/management/doorbell BARs, initializes `hinic3_hwdev`, optionally syncs time for PF, attaches supported auxiliary devices, and reports BDF context for PFs. Remove reverses auxiliary detach, hardware-device free, BAR unmap, and PCI uninit. It publishes the NIC auxiliary device when capability says NIC is supported, with event registration APIs and `hinic3_adev_get_hwdev`. State includes mapped BAR pointers, doorbell physical/virtual metadata, auxiliary-device array, pdev mutex, and per-service state bits. Dependencies include PCI IDs, hwdev/cfg/comm APIs, auxiliary bus, SR-IOV simple configure, and ioremap/unmap. Risks are BAR mapping differences for PF/VF, auxiliary-device lifetime, polling service state bits during delete, BDF reporting failure rollback, and shutdown only disabling PCI then setting API stop. Test signals are module load/unload, PF/VF probe, SR-IOV VF creation, auxiliary NIC probe, BDF command success, and remove after partial probe failure.

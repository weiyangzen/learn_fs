# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_nic_cfg.h

This header declares the NIC configuration API and NIC/HILINK data types exposed to netdev, ethtool, RSS, filter, and queue code. It defines MTU limits, VLAN/status constants, NIC event types, SQ CI attribute shape, port autoneg/link-mode enums, port-info command structure, port-enable bits, wire types, transceiver info structures, link error/module events, `hinic3_nic_port_info`, pause config, cached NIC config, and exported firmware wrapper functions. State represented here is mostly command or cached port/pause data; implementation stores feature capability in `nic_io`. Dependencies include hwif predicates, common firmware ABI, and management interface ABI. Integration points include `hinic3_main.c` feature initialization, `hinic3_netdev_ops.c` MTU/MAC/VLAN/features, `hinic3_ethtool.c` link settings, and `hinic3_filter.c` RX mode. Risks are link-mode enum values matching firmware bit positions and callers assuming PF-only commands work for VFs. Test signals are all user-visible netdev config operations and firmware event handling.

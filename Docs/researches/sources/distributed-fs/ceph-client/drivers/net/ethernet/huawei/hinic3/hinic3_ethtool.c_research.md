# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_ethtool.c

This file exposes hinic3 diagnostics and link metadata through `ethtool_ops`. It implements driver info, message-level get/set, link ksettings, and uses `ethtool_op_get_link` for carrier state. Link setting control flow queries firmware for port information and link status, maps hardware link-mode bitmaps to ethtool link mode masks, derives speed/duplex only when the link is up, maps module wire type to ethtool port type, and, for PFs, adds pause-mode advertisement from firmware pause config. Important local types are `hw2ethtool_link_mode` and `hinic3_link_settings`; exported API is `hinic3_set_ethtool_ops`. State changes are limited to `nic_dev->msg_enable`; other data is transient firmware readout. Dependencies include `hinic3_get_mgmt_version`, `hinic3_get_port_info`, `hinic3_get_link_status`, `hinic3_get_pause_info`, PCI naming, and ethtool bitmap APIs. Risks are incomplete hardware-to-ethtool mode coverage, treating firmware query failures as ethtool failures, and VF behavior excluding pause queries. Test signals include `ethtool -i`, `ethtool <dev>`, message-level toggles, link-up/down speed reporting, and pause advertisement on PFs.

# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_nic_dev.h

This header defines the NIC service private state attached to `net_device`. It contains flags for interface-up, MAC filter changes, RSS, RX-mode updates, TX-timeout work, RX mode hardware/forced states, MAC filter entry state machine, RSS hash types, IRQ config, dynamic TX/RX queue parameters, interrupt coalescing info, and the large `struct hinic3_nic_dev`. That struct owns PCI/netdev/hwdev pointers, NIC IO, message level, queue limits, RX buffer/LRO thresholds, VLAN bitmap, queue arrays, RSS key/indir/type, queue MSI-X entries, coalescing config, workqueue/delayed/work items, port-state mutex, UC/MC filter lists, RX mode state, address counts, event flags, and link status. Exported functions bridge to netdev ops, IRQ init, RX mode work, filter cleanup, and ethtool ops. Dependencies include netdevice/VLAN, hardware config/dev, and management feature bits. Risks are lifecycle ordering among netdev unregister, work cancellation, queue teardown, filter cleanup, and feature clearing. Test signals are probe/remove, open/close, RX-mode changes, IRQ/NAPI setup, and stats/feature behavior.

# sources/distributed-fs/ceph-client/drivers/net/ethernet/3com/3c59x.c

## Purpose
This file implements the legacy 3Com 3c59x/3c9xx Ethernet driver for Vortex, Boomerang, Cyclone, Tornado, Hurricane, CardBus, and EISA adapters. It supports programmed-I/O FIFO devices and bus-master descriptor-ring devices, including media selection, MII, ethtool, WOL, VLAN frame handling, PM, PCI, and EISA registration.

## Important APIs, Types, and Functions
- `vortex_chip_info`, `vortex_pci_tbl`, and EISA IDs map hardware IDs to chip flags and I/O sizes.
- Register and descriptor definitions cover command/status, windows, EEPROM, media bits, bus-master controls, RX/TX descriptors, and checksum bits.
- `struct vortex_private` stores rings, DMA addresses, skbs, I/O mappings, media/MII state, timers, options, stats, and locks.
- Probe/open/setup paths: `vortex_init_one()`, `vortex_eisa_probe()`, `vortex_probe1()`, `vortex_open()`, and `vortex_up()`.
- Data paths: `vortex_start_xmit()`, `boomerang_start_xmit()`, `_vortex_interrupt()`, `_boomerang_interrupt()`, `vortex_rx()`, and `boomerang_rx()`.
- Management paths include media timer, TX timeout/error recovery, stats, ethtool, MII ioctl, RX mode, VLAN mode, MDIO bit banging, WOL, suspend/resume, remove, and module cleanup.

## Control Flow
PCI probe enables and maps the device, then common probe allocates the netdev, applies module options, adjusts Vortex PCI latency, initializes locks/MII, allocates coherent rings, reads EEPROM/MAC/capabilities, discovers MII PHYs, chooses FIFO or bus-master ops, enables checksum/SG features, configures WOL, and registers the netdev. Open requests IRQ, fills RX descriptors for bus-master devices, and brings hardware up.

Bring-up selects media, starts the media timer, configures duplex, resets TX/RX, writes station address, programs media/stats/rings/filter/VLAN state, enables RX/TX/stats/interrupts, and starts the queue. FIFO TX writes length/data directly or uses the single DMA engine; Boomerang TX maps skb fragments into descriptors and links them to the download engine. FIFO RX drains `RX_FIFO`; Boomerang RX consumes completed descriptors, copies small packets or swaps buffers, processes checksum status, and recycles descriptors. Interrupts process RX/TX completion, DMA done, stats, host errors, and deferred work up to `max_interrupt_work`.

## State and Persistence
Per-device state persists in `struct vortex_private`: descriptor rings, skb ownership, ring cursors, media options, MII PHY, WOL, EEPROM-derived flags, stats, locks, and power state validity. Hardware state includes EEPROM data, windowed registers, MAC address, RX filter, descriptor pointers, stats counters, MII PHY registers, and PCI power state. Module parameters control debug, media options, full duplex, checksums, flow control, WOL, MMIO, RX copybreak, interrupt budget, watchdog, and Compaq workarounds.

## Dependencies and Integration Points
The driver integrates with PCI, EISA, netdevice ops, DMA mapping, shared IRQs, MII lib, ethtool, VLAN 802.1Q, PCI PM, WOL, netpoll, and legacy module parameters. MDIO is software bit-banged through the physical management register.

## Risks and Edge Cases
The code is quirk-heavy: EEPROM formats differ, all-zero MACs are rejected, Vortex PCI latency needs adjustment, CardBus power bits can be inverted, and MII preamble tracking is global. Severe host errors can reset and reinitialize hardware; comments note assumptions around RX ring fullness. DMA mapping/unmapping paths are complex for fragmented skbs. Lock ordering is documented and must be preserved.

# sources/distributed-fs/ceph-client/drivers/net/ethernet/huawei/hinic3/hinic3_nic_cfg.c

This file is the NIC/HILINK firmware command wrapper layer. It negotiates NIC feature bits; toggles LRO, LRO timer, RX VLAN strip, VLAN filtering, function table/MTU, MAC add/delete/update, SQ CI table, QP resource flush, forced packet drop, RX mode, VLAN add/delete, DCB state, port enable, link status, port information, vport enable, and pause info. Control flow is uniform: populate ABI struct, initialize `mgmt_msg_params`, send through mailbox to `MGMT_MOD_L2NIC` or `MGMT_MOD_HILINK`, check transport error and firmware status, copy output fields where needed. State mutations occur in firmware and in `nic_dev->nic_io->feature_cap` through `hinic3_update_nic_feature`; no persistent local state. Dependencies include mailbox transport, hwif identity helpers, netdev, VLAN constants, and ABI structs. Risks include PF/VF-specific MAC status handling, firmware unsupported statuses, VLAN ID validation using high-bit flags, feature-mask divergence from netdev features, and no transactional grouping for multi-command operations such as LRO state plus timer. Test signals are default MAC provisioning, PF-set VF MAC conflict, VLAN add/remove, link queries, ethtool pause/port info, feature toggles, and open/close flush paths.

# sources/distributed-fs/ceph-client/drivers/net/ethernet/microchip/enc28j60.c

## Purpose

`enc28j60.c` is the SPI netdev driver for the Microchip ENC28J60 10 Mbps Ethernet controller. It implements SPI register and packet-memory access, FIFO setup, TX/RX, threaded interrupt handling, low-power mode, link configuration, multicast/promiscuous filtering, ethtool basics, device-tree matching, and SPI-driver probe/remove.

## Important APIs, Types, And Functions

`struct enc28j60_net` stores netdev/SPI pointers, a mutex, pending TX skb, work items, current register bank, RX next-packet pointer, counters, duplex/filter state, message level, and a reusable SPI transfer buffer. SPI helpers include `spi_read_op`, `spi_write_op`, `spi_read_buf`, `spi_write_buf`, `enc28j60_set_bank`, locked/nolock register helpers, `enc28j60_mem_read`, and `enc28j60_packet_write`.

Hardware setup and PHY functions include `enc28j60_soft_reset`, `enc28j60_hw_init`, `enc28j60_hw_enable`, `enc28j60_hw_disable`, `enc28j60_lowpower`, `enc28j60_phy_read`, and `enc28j60_phy_write`. Netdev operations cover open/close, start_xmit, RX mode, MAC address, timeout, and address validation. Ettool provides driver info, message level, and fixed 10baseT half/full link settings.

## Control Flow

Probe allocates the netdev, initializes private state and work items, probes the chip, assigns a firmware or random MAC address, requests a threaded IRQ, enters low-power mode, and registers the netdev. Open exits low-power, resets/reinitializes the chip, rewrites MAC, enables interrupts/RX, checks link, and starts the queue. Close disables hardware, enters low-power mode, and stops the queue.

TX is deferred: `enc28j60_send_packet` stops the queue, stores the skb, and schedules `tx_work`; `enc28j60_hw_tx` writes the frame to internal TX memory and sets `ECON1_TXRTS`. IRQ handling frees or retries TX based on status flags. RX is handled in the threaded IRQ by reading `EPKTCNT`, parsing the receive status vector, copying valid frames into skbs, advancing `ERXRDPT` with the errata workaround, and decrementing the packet counter.

## State And Persistence

Runtime state is in `struct enc28j60_net`; hardware state is in ENC28J60 registers, internal SRAM FIFO pointers, MAC/PHY settings, and interrupt bits. The device is reset and reprogrammed on each open. No nonvolatile writes are made.

## Dependencies And Integration Points

The driver depends on Linux SPI, netdevice, ethtool, workqueue, threaded IRQ, device property, skbuff, delay, and Ethernet helpers. It includes `enc28j60_hw.h`, binds to `microchip,enc28j60`, and exposes module alias `spi:enc28j60`.

## Risks And Test Signals

Risks include SPI locking discipline, threaded IRQ latency, errata-sensitive RX pointer handling, late-collision retry behavior, unsupported level-triggered IRQ wiring, and restart ordering after TX timeout. Test probe/open/close, MAC changes while down, ethtool link settings, RX FIFO wrap/errors, TX success/error/timeout, multicast/promiscuous filters, and `CONFIG_ENC28J60_WRITEVERIFY`.

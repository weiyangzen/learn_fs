# sources/distributed-fs/ceph-client/drivers/accel/habanalabs/include/goya/asic_reg/pci_nrtr_masks.h

Purpose: defines bit shifts and masks for the Goya PCI north router register block. It is paired with `pci_nrtr_regs.h`; this file supplies field encodings for high-bandwidth and low-bandwidth credits, debug arbiter weights, split/rate-limit configuration, address range filters, regulator enable/result bits, and scrambling controls.

Important APIs/types/functions: there are no functions or types. The exported API is 121 preprocessor constants such as `PCI_NRTR_HBW_MAX_CRED_WR_RQ_MASK`, `PCI_NRTR_SPLIT_CFG_FORCE_STRONG_ORDER_MASK`, `PCI_NRTR_HBW_RANGE_BASE_H_VAL_MASK`, and `PCI_NRTR_RGLTR_RD_EN_MASK`. The 33 register groups match the corresponding `mmPCI_NRTR_*` address macros.

Control flow: this header does not execute. Downstream control flow is MMIO code reading or writing a PCI_NRTR register, composing values with `FIELD_PREP()` or shifts, then issuing `WREG32()`/`RREG32()` against the address from `pci_nrtr_regs.h`.

State and persistence: no in-memory state is kept. Written field values persist only in device registers until hardware reset, firmware reprogramming, or another driver write.

Dependencies and integration: included through `goya_regs.h`, which aggregates Goya ASIC register and mask headers for `goya.c` and `goya_coresight.c`. It depends on the register address layout in `pci_nrtr_regs.h` and on Linux bitfield helpers where callers use masks instead of manual shifts.

Risks: masks encode hardware ABI. A wrong width on range base/mask fields can route PCI transactions into the wrong HBW/LBW aperture. The `WPLIT_WR_TST_TOLEN` name appears autogenerated with a typo and should not be "corrected" independently from hardware collateral. Credit and timeout fields are narrow, so caller-side values must be range checked before packing.

Test signals: build coverage catches missing macro names. Runtime signals are PCI memory traffic under HBW/LBW apertures, router debug/credit counters, successful range-hit behavior, and absence of PCI AXI split, timeout, or ordering errors during stress tests.

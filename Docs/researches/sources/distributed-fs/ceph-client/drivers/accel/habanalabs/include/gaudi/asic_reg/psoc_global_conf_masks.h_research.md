# sources/distributed-fs/ceph-client/drivers/accel/habanalabs/include/gaudi/asic_reg/psoc_global_conf_masks.h

## Purpose
`psoc_global_conf_masks.h` is the autogenerated bitfield contract for Gaudi PSOC global configuration registers. It exposes 305 macros, mostly `*_SHIFT` and `*_MASK` pairs, for boot sequencing, reset control, scratchpads, semaphores, CPU boot messaging, I2C debug, trace address/user fields, interrupts, memory repair, pad configuration, ADC setup, and reset-source/status registers. It complements `psoc_global_conf_regs.h`, which provides the register offsets.

## Important APIs, types, and functions
- Boot and firmware state fields include masks for `PCI_FW_FSM`, `BOOT_SEQ_RE_START`, `BTM_FSM`, `BOOT_SEQ_FSM`, `BOOT_SEQ_TIMEOUT`, SPI image status, boot-state, boot-source, and CPU boot status.
- Reset-related fields cover watchdog, manual, PRSTN, software-all, soft-reset, unit reset, reset masks, reset source, and reset-control selector fields.
- Communication fields cover `SCRATCHPAD`, `SEMAPHORE`, `KMD_MSG_TO_CPU`, and `SPL_SOURCE`.
- Debug/trace fields include `TRACE_ADDR_MSB`, `TRACE_AWUSER`, `TRACE_ARUSER`, `ARUSER`, and `AWUSER` fields used by CoreSight and MMU context preparation.
- Interrupt/status fields cover RAZWI, ADC, timeout, combined timeout/peripheral interrupt fields, AXI errors, target id, outstanding transactions, and mask requests.
- Pad and peripheral fields cover 1.8 V/3.3 V pad config/input, I2C master/slave debug, eMMC voltage status, bootstrap pins, ADC timing, and pad selection.

## Control flow
The header has no control flow. Consumer code uses these masks when composing or extracting fields for PSOC global configuration registers. For example, Gaudi reset code writes `mmPSOC_GLOBAL_CONF_SW_ALL_RST` using `PSOC_GLOBAL_CONF_SW_ALL_RST_IND_SHIFT` and checks reset completion by masking `mmPSOC_GLOBAL_CONF_BTM_FSM` with `PSOC_GLOBAL_CONF_BTM_FSM_STATE_MASK`. CoreSight ETR code masks trace-buffer MSB values with `PSOC_GLOBAL_CONF_TRACE_ADDR_MSB_MASK`, and MMU preparation code programs trace ARUSER/AWUSER fields.

## State and persistence
The header declares no state. It defines how to encode and decode hardware state held in PSOC global config registers. Some fields are transient control pulses, such as reset commands and boot restart indicators. Others are persistent or latched status fields, such as boot status, reset source, scratchpads, semaphore values, pad configuration, and interrupt cause/mask state.

## Dependencies and integration points
This mask header must stay synchronized with `psoc_global_conf_regs.h` and with generated register definitions included by `gaudi_regs.h`. It is consumed by `gaudi.c`, `gaudi_coresight.c`, `gaudi_reg_map.h`, reset paths, firmware loader descriptors, MMU setup, and debug/trace programming. It also has conceptual overlap with Gaudi2 PSOC global config handling, where similarly named masks are used for RAZWI and debug fields.

## Risks and edge cases
- Shift/mask drift is dangerous because code can compile while reading or writing the wrong field in the right register.
- Several masks cover reset and boot sequencing. Incorrect values can prevent recovery, reset the wrong units, or leave PCIe/PSOC in an unexpected state.
- Full-width masks such as non-reset flop values and scratchpad/semaphore fields are easy to treat as unstructured storage; ownership must be coordinated with firmware.
- Directional trace ARUSER/AWUSER fields must match MMU ASID expectations, or trace writes can target the wrong address context.
- Field names in this header do not enforce read-only, write-one-to-clear, pulse, or sticky semantics.

## Test signals
Positive signals include successful boot sequence handoff, correct hard reset completion, valid CPU boot status messaging, working CoreSight ETR trace addressing, stable MMU trace ASID setup, and no unexpected RAZWI/protection interrupts. Negative signals include reset timeout while polling `BTM_FSM`, bad firmware boot status, trace buffer address truncation, wrong scratchpad-based interrupt polling behavior, or interrupt fields that cannot be cleared/masked as expected.

# sources/distributed-fs/ceph-client/drivers/video/fbdev/g364fb.c

## Purpose
`g364fb.c` is a fixed MIPS Magnum/Jazz G364 8-plane framebuffer driver with palette programming, vertical panning, and blanking.

## APIs And Control Flow
It defines fixed register addresses, control bits, static `fb_info`, initdata fix/var defaults, `g364fb_pan_display()`, `g364fb_blank()`, `g364fb_setcolreg()`, and `g364fb_init()`. Init reads ARC-provided resolution from display registers, initializes a simple cursor, derives VRAM size from Jazz R4030 config, fills fb_info, allocates cmap, and registers fbdev.

## State, Dependencies, Integration, Risks
State is direct hardware register state plus static fbdev data. Dependencies are MIPS Jazz mappings and fbdev default IOMEM ops. Risks include fixed address casts, no dynamic device/remove path, a 255-entry cmap while regno 255 is accepted, and 8bpp-only assumptions. Tests should cover palette entry 255, pan bounds, blanking, Jazz-only boot, and registration failure handling.

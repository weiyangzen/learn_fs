# sources/distributed-fs/ceph-client/drivers/media/pci/cx18/cx23418.h

Defines CX23418 firmware command IDs, capture channel IDs, data-exchange commands, APU commands, manager task commands, and firmware error codes used by cx18 mailbox and stream code.

Important constants include `CX18_CREATE_TASK`, `CX18_DESTROY_TASK`, capture start/stop and parameter commands, VBI/index/audio/video commands, `CX18_CPU_DE_SET_MDL_ACK`, `CX18_CPU_DE_SET_MDL`, `CX18_CPU_DE_RELEASE_MDL`, channel type IDs, and `CXERR_*` values.

This is a firmware ABI with no runtime state in the header. Numeric changes are high risk. Test signals are mailbox ping/command success, all capture stream types, VBI setup, MDL exchange, and error-code handling.

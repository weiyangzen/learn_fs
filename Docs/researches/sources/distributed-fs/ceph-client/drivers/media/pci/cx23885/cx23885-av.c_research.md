# sources/distributed-fs/ceph-client/drivers/media/pci/cx23885/cx23885-av.c

Provides deferred AV-core interrupt handling through `cx23885_av_work_handler`. The handler calls the cx25840 subdevice interrupt service routine with `PCI_MSK_AV_CORE`.

If the subdevice reports the interrupt unhandled, the fallback clears flatiron left and right ADC interrupt request flags, then re-enables the AV-core PCI interrupt.

State is hardware interrupt state plus the subdevice `handled` result. Risks include interrupt storms when status is not cleared, NULL subdevice assumptions, and re-enabling too early. Test signals are AV-core interrupts, flatiron fallback behavior, and integrated IR paths sharing the AV mask.

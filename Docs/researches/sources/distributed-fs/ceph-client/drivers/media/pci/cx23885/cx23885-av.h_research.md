# sources/distributed-fs/ceph-client/drivers/media/pci/cx23885/cx23885-av.h

Declares `cx23885_av_work_handler(struct work_struct *work)` for cx23885 AV interrupt work.

The header is included by code that initializes or references the device workqueue handler. It requires `struct work_struct` to be visible through surrounding includes.

Risks are limited to build integration and missing handler wiring. Test signals are compile coverage and AV interrupt work execution on cx25840 or AV-core IR boards.

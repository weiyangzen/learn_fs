# sources/distributed-fs/ceph-client/drivers/media/pci/cx23885/cx23885-417.c

Supports CX23417 MPEG encoder chips attached through cx23885 MC417. It implements MC417 register/memory access, firmware loading/verification, mailbox commands, cx2341x control setup, and a V4L2 MPEG capture node backed by vb2 DMA-SG.

Important APIs include `cx23885_mc417_init`, `mc417_register_read/write`, `mc417_memory_read/write`, `mc417_gpio_set/clear/enable`, `cx23885_417_register`, and `cx23885_417_unregister`. Registration is gated on boards whose port B is `CX23885_MPEG_ENCODER`; stream start initializes firmware, configures codec/VBI/audio/input state, starts encoder capture, then starts TS DMA. Stream stop sends encoder stop and cancels buffers.

State includes firmware memory, `dev->cx23417_mailbox`, GPIO state, `dev->cxhdl`, `dev->v4l_device`, vb2 queue state, and module MPEG buffer parameters. Risks are firmware size/magic mismatch, mailbox timeout/corruption, hardcoded port assumptions, slow MC417 transfer, and error unwinding. Test signals are firmware failure paths, checksum validation, V4L2 MPEG ioctls, streamon/off, input/std/tuner controls, and unload.

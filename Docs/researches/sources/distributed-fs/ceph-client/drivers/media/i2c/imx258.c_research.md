# sources/distributed-fs/ceph-client/drivers/media/i2c/imx258.c

Purpose: V4L2 sub-device driver for Sony IMX258 sensors, including standard and PDAF-compatible variants. It supports three fixed 10-bit Bayer modes, 2-lane or 4-lane CSI-2, 19.2 MHz or 24 MHz input clocks, runtime PM, HDR/WDR control, test patterns, and static crop reporting for the active pixel array.

Important APIs/types/functions: `struct imx258` stores device, subdev, CCI regmap, variant config, controls, current mode, link-frequency tables, lane mode index, CSI-2 flags, mutex, clock, and regulators. `struct imx258_mode`, `struct imx258_link_freq_config`, and `struct imx258_link_cfg` describe mode timing, per-clock link configuration, and lane-specific PLL tables. `link_freq_to_pixel_rate()` converts menu link frequency to pixel rate. Control programming is in `imx258_set_ctrl()`, `imx258_update_digital_gain()`, and `imx258_adjust_exposure_range()`. Format and crop operations are `imx258_set_pad_format()`, `imx258_get_pad_format()`, `imx258_get_selection()`, and enumeration helpers. Streaming and lifecycle are `imx258_start_streaming()`, `imx258_stop_streaming()`, `imx258_set_stream()`, `imx258_power_on()`, `imx258_power_off()`, `imx258_identify_module()`, and `imx258_probe()`.

Control flow: probe initializes the CCI regmap, regulators, legacy sensor clock, clock-specific link-frequency tables, fwnode endpoint, link-frequency bitmap, lane mode, CSI-2 clock flags, and variant config from OF match data. It powers the sensor, validates chip ID `0x0258`, sets the default full-resolution mode, initializes controls under a mutex, creates the media entity, registers the subdev, and enables runtime PM. Setting a format locks the mutex, chooses the nearest supported mode, updates `cur_mode`, link frequency, pixel rate, vblank range/default, and fixed hblank value. Streaming resumes runtime PM, resets the sensor, waits 12 ms, writes PLL registers for the current link/lane mode, common mode registers, variant registers, noncontinuous-clock setting, mode-specific registers, user controls, and then sets `MODE_SELECT = STREAMING`.

State and persistence behavior: `cur_mode`, link-frequency selection, lane mode, CSI-2 flags, flip controls, and V4L2 controls are persistent in driver memory. The sensor hardware is treated as volatile across power cycles; stream start replays PLL/common/variant/mode/control state. Control writes are skipped when the device is not runtime-active. The mutex serializes format, crop, and stream operations. Digital gain is mirrored to GR, GB, R, and B gain registers.

Dependencies and integration points: depends on V4L2 subdev and control frameworks, media entity pads, fwnode endpoint parsing, CCI register helpers, runtime PM, regulators, sensor clock helpers, ACPI ID `SONY258A`, and OF compatibles `sony,imx258` and `sony,imx258-pdaf`. The endpoint must provide supported link frequencies for the selected 19.2 or 24 MHz clock table and 2 or 4 CSI-2 data lanes. Noncontinuous MIPI clock is passed through to `IMX258_CLK_BLANK_STOP`.

Risks: the format list only exposes 10-bit Bayer with flip-adjusted order, so integrations expecting 8-bit or other Bayer orders will fail enumeration. `ARRAY_SIZE(link_freq_menu_items_19_2)` is used when validating link frequencies even for the 24 MHz menu; currently both menus have equal size, but this is a maintenance trap. WDR/HDR programming writes a hard-coded ratio expression and is easy to regress without sensor-specific tests. Stop-streaming deliberately returns success even if standby write fails. Clock and lane combinations change effective maximum frame rate, especially full resolution on 2 lanes.

Test signals: validate probe on 19.2 MHz and 24 MHz boards, 2-lane and 4-lane endpoints, both OF variants, and ACPI matching. Exercise mode switching among 4208x3120, 2104x1560, and 1048x780, confirm link-freq/pixel-rate/vblank/hblank ranges, verify flip-dependent Bayer code reporting, and test stream start register sequencing after runtime suspend. Controls to test include analogue gain, four-channel digital gain, exposure with vblank changes, test pattern, WDR, hflip/vflip, and noncontinuous clock endpoint flag behavior.

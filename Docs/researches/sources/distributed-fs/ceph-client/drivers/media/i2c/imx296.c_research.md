# sources/distributed-fs/ceph-client/drivers/media/i2c/imx296.c

Purpose: V4L2 sub-device driver for Sony IMX296 global shutter sensors, including color IMX296LQ and monochrome IMX296LL detection/forcing. It supports full-resolution or binned/cropped 10-bit output, runtime PM, exposure/gain/blanking/test-pattern controls, sensor temperature/model identification, and source-pad crop/format operations.

Important APIs/types/functions: `struct imx296` stores device resources, clock, supplies, reset GPIO, regmap, selected clock parameters, mono flag, subdev, pad, controls, and hblank/vblank handles. Register helpers `imx296_read()` and `imx296_write()` encode 8/16/24-bit register width in the upper bits of the register constant and use raw regmap access. Control setup is `imx296_ctrls_init()` and control writes are `imx296_s_ctrl()`. Hardware setup and streaming are `imx296_setup()`, `imx296_stream_on()`, `imx296_stream_off()`, and `imx296_s_stream()`. Format/crop state is managed by `imx296_set_format()`, `imx296_set_selection()`, `imx296_init_state()`, and enumeration helpers. Probe support includes `imx296_identify_model()`, `imx296_read_temperature()`, `imx296_subdev_init()`, and runtime PM callbacks.

Control flow: probe verifies SMBus byte-data support, allocates state, gets supplies/reset/input clock, matches the clock against 37.125/54/74.25 MHz parameter tables, creates a regmap with sensor-info marked unreadable for generic cache access, powers on, identifies model either from OF match data or by temporarily leaving standby and reading sensor info plus temperature, initializes subdev/controls/media entity, enables runtime PM, registers the subdev, then enables autosuspend and drops the usage count. Stream start locks active state, resumes PM, writes a large vendor-derived init table, applies ROI registers if cropped, configures binning/window mode from crop versus format size, programs HMAX/VMAX, input-clock timing registers, gain delay and black level, synchronizes controls, exits standby, and starts master mode. Stream stop writes master-stop and standby and schedules autosuspend.

State and persistence behavior: active subdev state stores crop and format. The mono flag determines whether the single exposed code is `MEDIA_BUS_FMT_Y10_1X10` or `MEDIA_BUS_FMT_SBGGR10_1X10`. Control values persist in the V4L2 handler and are replayed on stream start. HBLANK is read-only and derived from fixed HMAX and nominal pixel rate; VBLANK affects VMAX. Exposure is clamped to current VMAX before writing `SHS1`. No file-backed persistence exists.

Dependencies and integration points: depends on regmap raw I2C access, V4L2 controls/subdev/media entity, fwnode device properties, runtime PM, regulator framework, GPIO descriptors, and sensor clock helper for `inck`. OF compatibles are `sony,imx296`, `sony,imx296ll`, and `sony,imx296lq`; the latter two bypass auto-detection. It assumes 10-bit output and a nominal MIPI bit rate around 1188 Mbps reported through pixel-rate controls.

Risks: many initialization registers are undocumented vendor data, making simplification risky. Auto-detection must take the sensor out of standby because sensor-info cannot be read in standby, so probe touches streaming-related state before registration. `v4l2_subdev_init_finalize()` return is not checked in `imx296_subdev_init()`. Binning is documented as allowed only without cropping and marked for double-checking. The regmap access table blocks generic reads of sensor info addresses, and direct raw reads bypass normal typed helpers. Exposure control mutates `ctrl->val` during `s_ctrl`, which can surprise control tests.

Test signals: cover forced and auto-detected color/mono variants, unsupported clock rejection, model/temperature read path, crop alignment to 4 pixels and minimum ROI size, full-frame versus ROI register programming, binning format choices for full-frame 1456x1088 and half sizes, exposure clamping when VBLANK changes, test-pattern enable/disable black-level and auto-black-level behavior, runtime PM error recovery on setup failure, and repeated stream on/off with active-state locking.

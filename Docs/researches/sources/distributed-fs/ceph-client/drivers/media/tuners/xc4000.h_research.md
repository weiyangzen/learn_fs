# sources/distributed-fs/ceph-client/drivers/media/tuners/xc4000.h

Purpose: public attach/config header for Xceive XC4000.

APIs/types: `struct xc4000_config` includes I2C address, default power management, DVB amplitude, smoothed-CVBS option, and IF kHz. Defines `XC4000_TUNER_RESET` and `xc4000_attach()`.

Control flow/state: bridge code calls attach with config; implementation copies fields into shared private state and uses reset callback. Header stores no state.

Dependencies/integration: firmware declarations, DVB frontend/I2C forward declarations, and `CONFIG_MEDIA_TUNER_XC4000` stubs.

Risks/tests: invalid config or missing reset/firmware breaks attach/tune. Test enabled/disabled builds, IF/amplitude/CVBS options, and firmware packaging.

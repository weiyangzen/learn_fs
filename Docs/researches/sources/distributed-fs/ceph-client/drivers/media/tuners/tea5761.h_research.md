# sources/distributed-fs/ceph-client/drivers/media/tuners/tea5761.h

Purpose: public TEA5761 attach/autodetection contract for bridge and tuner-core code.

APIs/types: declares `tea5761_autodetection(struct i2c_adapter *, u8)` and `tea5761_attach(struct dvb_frontend *, struct i2c_adapter *, u8)` when `CONFIG_MEDIA_TUNER_TEA5761` is reachable. Disabled stubs log and return `-EINVAL` or `NULL`.

Control flow/state: this header stores no state. It gates calls to the implementation or disabled stubs at compile time using `IS_REACHABLE`.

Dependencies/integration: includes Linux I2C and DVB frontend headers; used by board drivers that may compile regardless of TEA5761 Kconfig selection.

Risks/tests: build with the symbol enabled, modular, and disabled. Runtime disabled-path tests should fail gracefully with the expected log.

# sources/distributed-fs/ceph-client/drivers/media/tuners/tea5767.c

Purpose: Philips TEA5767 FM radio tuner driver with analog radio tuning, standby, signal/stereo reporting, autodetection, and runtime control configuration.

APIs/functions: exports `tea5767_attach()` and `tea5767_autodetection()`. Tuner ops include `.set_analog_params`, `.set_config`, `.sleep`, `.release`, `.get_frequency`, `.get_status`, and `.get_rf_strength`. Helpers include `set_radio_freq()`, `tea5767_standby()`, `tea5767_read_status()`, `tea5767_signal()`, and `tea5767_stereo()`.

Control flow/state: attach allocates `tea5767_priv`, sets default control bits, initializes I2C props, and installs ops. Tuning builds a five-byte register image from audio mode, port flags, soft mute/high-cut/noise/band/deemphasis/pllref controls, and a divider chosen by crystal and LO mode. `.set_config` copies `struct tea5767_ctrl` into private state.

Dependencies/integration: local `tuner-i2c.h`, `tea5767.h`, Linux I2C, V4L2 tuner constants, and DVB tuner ops. Autodetection rejects all-equal status reads and nonzero chip ID fields.

Risks/tests: bad control data causes wrong frequencies or RF behavior. I2C write errors are logged but not fatal. Test attach, set_config variations, mono/stereo, standby, status/RF strength, and false-positive autodetection.

# sources/distributed-fs/ceph-client/drivers/media/tuners/tea5761.c

Purpose: Philips TEA5761HN FM radio tuner implementation for DVB tuner ops. It attaches after chip autodetection, stores I2C properties plus cached frequency/standby state, and supports analog radio tune, sleep, status, RF strength, and release.

APIs/functions: exports `tea5761_attach()` and `tea5761_autodetection()`. Core callbacks are `set_radio_freq()`, `set_radio_sleep()`, `tea5761_get_frequency()`, `tea5761_get_status()`, `tea5761_get_rf_strength()`, and `tea5761_release()`. `__set_radio_freq()` builds the 7-byte register payload and `tea5761_read_status()` reads the 16-byte status block.

Control flow/state: attach validates ID bytes, allocates `tea5761_priv`, initializes `tuner_i2c_props`, and copies `tea5761_tuner_ops`. Tuning clears standby, calculates a PLL divider from V4L2 62.5 Hz units, programs power/mono/stereo bits, writes over I2C, and caches frequency. Sleep sets standby and reuses the tuning path with mute/power-down semantics.

Dependencies/integration: Linux I2C, V4L2 audio modes, DVB frontend ops, `media/tuner.h`, and local `tuner-i2c.h`/`tea5761.h`. Referenced by tuner type metadata.

Risks/tests: I2C write errors are logged but tuning returns success, so tests need dmesg/status checks. Validate attach/autodetect, FM tune, mono/stereo status, RF strength, sleep/resume, and frequency readback.

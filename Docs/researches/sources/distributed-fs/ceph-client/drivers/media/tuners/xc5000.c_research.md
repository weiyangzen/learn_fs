# sources/distributed-fs/ceph-client/drivers/media/tuners/xc5000.c

Purpose: Xceive XC5000/XC5000C firmware-driven tuner with analog TV, FM radio, digital TV, delayed sleep, suspend, and resume support.

APIs/functions: exports `xc5000_attach()`. Ops include init, sleep, suspend/resume, set_config, digital/analog tune, getters, status/RF strength, and release. Firmware path uses `xc5000_assign_firmware()`, `xc_load_fw_and_init_tuner()`, `xc5000_fwupload()`, validation registers, and retry logic.

Control flow/state: attach creates/reuses shared state, applies IF/xtal/radio/chip/output config, checks product ID, initializes delayed work, and installs ops. Firmware loading selects A vs C blob, validates size, retries upload up to five times, checks checksum/init/PLL where supported, self-calibrates, and defaults to cable mode. Digital/analog/radio paths map requested mode to standard/source/offset, program IF/output amp, tune RF, and cache mode/frequency/bandwidth. Sleep schedules delayed reset unless disabled.

Dependencies/integration: firmware loader, workqueue, I2C, DVB/V4L2, `tuner-i2c.h`, `xc5000.h`, and reset callback.

Risks/tests: hard-coded firmware sizes, delayed sleep races, wrong chip ID, PLL reloads, and radio input configuration. Test both chips, firmware failure paths, digital systems/bandwidths, analog/FM, sleep/suspend/resume, output amplitude, and shared attach/release.

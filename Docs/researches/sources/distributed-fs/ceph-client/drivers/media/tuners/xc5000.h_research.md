# sources/distributed-fs/ceph-client/drivers/media/tuners/xc5000.h

Purpose: public configuration and attach interface for Xceive XC5000/XC5000C tuners.

APIs/types: defines chip IDs, `struct xc5000_config`, reset callback command, radio input constants, and `xc5000_attach()`. Config carries I2C address, IF, radio input, crystal, output amplitude, and chip ID.

Control flow/state: board code passes config to attach and may update some fields through `.set_config`; implementation chooses firmware and reset behavior from these values. Header has no state.

Dependencies/integration: firmware declarations, DVB/I2C forward declarations, and Kconfig stubs.

Risks/tests: incorrect chip ID selects wrong firmware; missing radio input disables FM. Test Kconfig paths, firmware packaging, IF/xtal/output/radio config, and reset callback.

# sources/distributed-fs/ceph-client/drivers/media/tuners/tea5767.h

Purpose: public interface for TEA5767 attach, autodetection, and board-specific control options.

APIs/types: defines `enum tea5767_xtal`, `struct tea5767_ctrl`, `tea5767_autodetection()`, and `tea5767_attach()`. Control fields cover ports, high-cut, stereo noise, soft mute, Japan band, deemphasis, PLL reference, and crystal/LO selection.

Control flow/state: implementation copies the control struct through `.set_config`; the header itself stores no state. Disabled Kconfig stubs log and fail.

Dependencies/integration: includes I2C and DVB frontend types and is consumed by bridge drivers with TEA5767 hardware.

Risks/tests: bitfield control must be initialized by callers. Build enabled/disabled paths and verify control values affect tuning on hardware.

# sources/distributed-fs/ceph-client/drivers/media/tuners/tua9001.c

Purpose: Infineon TUA9001 zero-IF DVB-T tuner implemented as an `i2c_driver` using regmap.

APIs/functions: registers `tua9001_driver` with probe/remove and ID `"tua9001"`. Tuner ops are `tua9001_init()`, `tua9001_sleep()`, `tua9001_set_params()`, and `tua9001_get_if_frequency()`.

Control flow/state: probe reads `tua9001_platform_data`, allocates `tua9001_dev`, creates an 8-bit/16-bit regmap, drives CEN/RXEN/RESETN through frontend callbacks, stores state in client data and `fe->tuner_priv`, and installs ops. Init writes a fixed register table. Set-params accepts only DVB-T, maps 5/6/7/8 MHz bandwidth to register `0x04`, calculates register `0x1f` from frequency, toggles RXEN around writes, and returns zero IF.

Dependencies/integration: Linux I2C driver core, regmap, `math64`, DVB frontend callbacks, and public TUA9001 command IDs.

Risks/tests: probe assumes valid platform data. Unsupported delivery systems/bandwidths fail. Test probe/remove callbacks, init table writes, DVB-T bandwidth mapping, RXEN gating, regmap failures, and IF=0 reporting.

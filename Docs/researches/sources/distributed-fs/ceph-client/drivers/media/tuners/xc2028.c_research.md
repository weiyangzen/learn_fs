# sources/distributed-fs/ceph-client/drivers/media/tuners/xc2028.c

Purpose: firmware-driven Xceive XC2028/XC3028 tuner driver for analog TV, FM radio, and digital TV.

APIs/functions: exports `xc2028_attach()`. Ops include set_config, analog tune, digital tune, sleep, release, frequency, RF strength, and AFC. Firmware machinery includes `load_all_firmwares()`, `seek_firmware()`, `load_firmware()`, `load_scode()`, `check_firmware()`, and `generic_set_freq()`.

Control flow/state: attach obtains shared state, initializes locking/default transfer length, installs ops, and applies config. Config starts asynchronous firmware loading. Firmware parsing builds an in-memory table from the external firmware blob. Tuning locks, checks/loads matching base/std/scode firmware, computes digital offsets, writes RF frequency commands and divisor, invokes bridge callbacks, and caches frequency.

Dependencies/integration: firmware loader, I2C, V4L2/DVB frontend cache, `tuner-i2c.h`, `xc2028.h`, `xc2028-types.h`, and bridge callbacks for reset/clock/I2C flush.

Risks/tests: async firmware state, corrupt/missing firmware, SCODE/demod mismatch, and power-management reloads. Test firmware success/failure, shared attach/release, analog standards/FM, DVB-T/T2/ATSC bandwidths, sleep behavior, signal/AFC, and callback failures.

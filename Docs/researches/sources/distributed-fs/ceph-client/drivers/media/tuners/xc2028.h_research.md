# sources/distributed-fs/ceph-client/drivers/media/tuners/xc2028.h

Purpose: public configuration and attach interface for XC2028/XC3028 tuners.

APIs/types: defines default firmware names, demod IF constants, `enum firmware_type`, `struct xc2028_ctrl`, `struct xc2028_config`, callback command IDs, and `xc2028_attach()`.

Control flow/state: board code passes adapter/address and optional control. Implementation copies control, requests firmware, and uses callback commands for reset, clock reset, and I2C flush. Header has no runtime state.

Dependencies/integration: DVB frontend types and `CONFIG_MEDIA_TUNER_XC2028` enabled/disabled attach path.

Risks/tests: wrong firmware name, max I2C length, demod IF, or callback support breaks tuning. Test firmware packaging and all Kconfig paths.

# sources/distributed-fs/ceph-client/drivers/scsi/53c700.c

Purpose: implements the reusable Linux SCSI core driver for NCR/Symbios 53c700, 53c700-66, and compatible 53c710 chips running in 700-compatible mode. Board-specific wrapper drivers provide the mapped register base, IRQ, clock, and bus wiring parameters; this file supplies SCSI host registration, DMA script setup, command queueing, interrupt-driven script/message handling, synchronous negotiation, tagged queue management, autosense, and error recovery.

Important APIs/types/functions: exported entry points are `NCR_700_detect()`, `NCR_700_release()`, and `NCR_700_intr()`. The SCSI host template is filled with `NCR_700_queuecommand`, `NCR_700_abort`, `NCR_700_host_reset`, `NCR_700_sdev_init`, `NCR_700_sdev_configure`, `NCR_700_sdev_destroy`, and `NCR_700_change_queue_depth`. Core helpers include `NCR_700_chip_setup()`, `NCR_700_chip_reset()`, `NCR_700_start_command()`, `process_script_interrupt()`, `process_message()`, `process_extended_message()`, `process_selection()`, `find_empty_slot()`, `free_slot()`, `NCR_700_scsi_done()`, and `NCR_700_data_residual()`. SPI transport hooks are `NCR_700_set_period()` and `NCR_700_set_offset()`.

Control flow: `NCR_700_detect()` allocates a coherent or noncoherent DMA block for the script, message buffers, status byte, and command slots; patches generated script labels and fixed DMA addresses; initializes slot free lists and host template callbacks; resets/configures the chip; attaches the SCSI host and SPI transport. `NCR_700_queuecommand_lck()` enforces untagged/tagged queue-depth rules, allocates a command slot, maps the command and data SGL, builds script move fragments, negotiates tag use, and calls `NCR_700_start_command()`. `NCR_700_start_command()` patches script command address/count, target ID, message count, and SG entry address, writes SXFER/TEMP/DSP registers, and starts or queues the command depending on host state. `NCR_700_intr()` serializes hardware access under `host_lock`, decodes SCSI/DMA interrupt causes, handles reset/selection timeout/phase mismatch/gross/parity/script interrupts, processes reselection, resumes scripts, and starts one queued slot when the host becomes free.

State and persistence: all state is volatile kernel runtime state. `struct NCR_700_Host_Parameters` owns the patched script memory, DMA addresses, message/status buffers, slot array, host busy/free state, current command, saved fairness cursor, sync clock/min period, free list, and EH completion pointer. Per-device `struct NCR_700_Device_Parameters` stores the internal REQUEST SENSE command buffer, current untagged command, and active depth. Per-target SPI flags store sync-negotiation and tag-negotiation bits. Hardware retains negotiated transfer behavior only until reset; the driver clears and renegotiates after resets, INQUIRY, REQUEST SENSE, and SPI transport parameter changes.

Dependencies and integration: depends on the SCSI midlayer, SCSI error handling, SPI transport class, DMA mapping APIs, generated `53c700_d.h` script symbols, and `53c700.h` register/script patch helpers. Board wrappers call `NCR_700_detect()`, request IRQs pointing at `NCR_700_intr()`, and call `NCR_700_release()` during teardown. The driver creates a per-device sysfs `active_tags` attribute and participates in SPI domain validation for fast chips.

Risks: this code is hardware-race sensitive because selection/reselection can interrupt script progress while the host is busy. Several impossible states use `BUG()`, so corrupted reselection/tag state can crash the kernel. Noncoherent DMA paths require correct sync direction around scripts, message buffers, status, SGLs, commands, and sense buffers. Autosense rewrites the command buffer and stores original status/length in private bytes, which is fragile around unusual CDB lengths. The tag bitmap is target-ID based and comments call out problems for multiple-LUN devices. Error recovery relies on reset completion interrupts and midlayer locking assumptions.

Test signals: compile with representative wrapper drivers, boot/probe on 53c700/53c700-66/53c710 hardware or emulator, run SCSI scan and tagged/untagged I/O, trigger disconnect/reselection under load, force CHECK CONDITION to verify internal autosense, exercise SPI period/offset sysfs changes and domain validation, inject phase mismatch and bus reset, run error-handler abort/host-reset paths, and validate noncoherent/big-endian configurations.

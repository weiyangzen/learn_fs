# sources/distributed-fs/ceph-client/drivers/scsi/esas2r/esas2r_io.c

Purpose: implements request submission to the firmware communication rings, scatter/gather list construction for both legacy SGE and newer PRD firmware APIs, timer-driven heartbeat/reset/discovery maintenance, task-management request submission, bus reset scheduling, and I/O abort marking.

Important APIs/types/functions: public functions are `esas2r_start_request()`, `esas2r_local_start_request()`, `esas2r_start_vda_request()`, `esas2r_build_sg_list_sge()`, `esas2r_build_sg_list_prd()`, `esas2r_timer_tick()`, `esas2r_send_task_mgmt()`, `esas2r_reset_bus()`, and `esas2r_ioreq_aborted()`. Internal helpers are `esas2r_build_prd_iblk()` and `esas2r_handle_pending_reset()`.

Control flow: `esas2r_start_request()` validates adapter mode, power-down state, target presence, and firmware virtual target ID before either completing immediately or enqueueing/starting the request. If reset, flashing, discovery, or existing deferred work blocks the request, it is added to `defer_list`; otherwise `esas2r_local_start_request()` adds it to `active_list` and calls `esas2r_start_vda_request()`. Starting a VDA request advances the inbound-list write pointer with toggle handling, writes the request DMA address and size into the inbound source entry, and updates the hardware write register. Legacy SGE building emits 64-bit VDA SGEs, splits large segments, allocates chained SGL pages, and marks the final entry. PRD building groups SCSI read/write payloads by RAID interleave/I-block boundaries for non-pass-through RAID targets, builds PRD chains per I-block, and sizes the request accordingly. Timer ticks age chip uptime, poll pending chip reset readiness, drive discovery completion, and run heartbeat force-interrupt checks. Task management aborts eligible deferred commands, formats a SCSI task-management request, and either starts it or reports busy during flashing.

State and persistence behavior: state is volatile: request status/list membership, `active_list`, `defer_list`, inbound-list `last_write`, communication toggle bit, SGL page ownership, target virtual IDs, chip uptime/reset timestamps, heartbeat state, and reset flags. It does not persist data, but it enforces ordering around flash and discovery so firmware-visible persistent operations do not race ordinary I/O.

Dependencies and integration points: depends on adapter/request/SG context definitions in `esas2r.h`, VDA SGE/PRD flags from `atvda.h`, target database fields, SCSI CDB opcodes, firmware API mode selected by init, interrupt completion in `esas2r_int.c`, discovery completion in `esas2r_disc.c`, and request builders in `esas2r_vda.c`. It is the low-level producer side of the firmware inbound ring consumed by interrupt completion.

Risks and test signals: risks include inbound ring overflow assumptions, toggle-bit errors, DMA address truncation in legacy SGE paths, SGL exhaustion resume behavior, PRD chain count/length mistakes, I-block math with unusual block/interleave sizes, request deferral starvation during discovery/flash, and heartbeat-triggered reset races. Test signals include zero-length commands, invalid/missing targets, deferred queue draining after reset/discovery, flash commit blocking normal starts, inbound pointer wrap, large SG entries split at `SGE_LEN_MAX`/`PRD_LEN_MAX`, chained SGL allocation failure, READ/WRITE 6/10/12/16 PRD I-block partitioning, heartbeat failure recovery, task management for LUN and target resets, and bus reset suppression while degraded or discovery-pending.

# sources/distributed-fs/ceph-client/drivers/scsi/aacraid/commsup.c

Purpose: implements the common AAC host/adapter communication layer used by the miniports. It owns FIB DMA allocation and setup, FIB allocation/free/init helpers, legacy producer/consumer queue helpers, generic FIB and native HBA send paths, adapter-originated FIB completion, firmware printf handling, asynchronous event notification processing, adapter reset/reinitialization orchestration, SAFW host scan synchronization, the per-adapter command/AIF kernel thread, host-time wellness commands, and IRQ allocation/free helpers for both legacy and SRC-style devices.

Important APIs/types/functions: `aac_fib_setup()`, `aac_fib_map_free()`, `aac_fib_alloc_tag()`, `aac_fib_alloc()`, `aac_fib_free()`, `aac_fib_init()`, `aac_queue_get()`, `aac_consumer_get()`, `aac_consumer_free()`, `aac_fib_send()`, `aac_hba_send()`, `aac_fib_adapter_complete()`, `aac_fib_complete()`, `aac_handle_aif()`, `aac_reset_adapter()`, `aac_scan_host()`, `aac_src_reinit_aif_worker()`, `aac_command_thread()`, `aac_acquire_irq()`, and `aac_free_irq()`. The file depends heavily on `struct aac_dev`, `struct fib`, `struct hw_fib`, `struct aac_queue`, `struct aac_entry`, AIF command structures, native HBA request/response structures, and the `dev->a_ops` adapter operation table supplied by `rx.c`, `sa.c`, or `src.c`.

Control flow: initialization calls `aac_fib_setup()`, which allocates coherent FIB memory, aligns it for PMC/SRC requirements, lays out transport headers and per-FIB DMA addresses, initializes completions and locks, assigns MSI-X vectors, and reserves the last `AAC_NUM_MGT_FIB` entries for management. SCSI or management code initializes a FIB, calls `aac_fib_send()` or `aac_hba_send()`, and the common layer sets handles, transfer state, callbacks, management-FIB accounting, and either queues the FIB through the miniport `adapter_deliver()` operation or serializes it through `sync_fib` when `sync_mode` is active. Completion arrives through `dpcsup.c` or SRC/RX interrupt code, then `aac_fib_complete()` clears reusable state and `aac_fib_free()` returns management FIBs to the free list.

State and persistence: persistent state is mostly shared host/controller memory: the coherent FIB pool, per-FIB transfer headers, queue producer/consumer indexes, command queue pending counters, host response wait completions, the `free_fib` list, and management counters. Runtime state also includes AIF sequencing flags in `dev->fsa_dev[]`, SAFW scan counters and HBA maps, command-thread timers, `adapter_shutdown`, `in_reset`, `sync_fib`, and MSI-X vector assignment. Hardware-visible state persists only until reset or driver teardown; the driver recreates it during `_aac_reset_adapter()`.

Dependencies and integration: integrates the SCSI midlayer through `scsi_add_device()`, `scsi_remove_device()`, `scsi_rescan_device()`, host blocking/unblocking, and `scsi_host_complete_all_commands()`. It integrates PCI DMA through coherent allocation/free, interrupt registration through `request_irq()`/`free_irq()`, timekeeping through `ktime_get_real_ts64()` and BCD wellness updates, and adapter firmware through FIB commands such as `AifRequest`, `SendHostTime`, `ScsiPortCommand64`, `ContainerCommand`, and reset/shutdown commands. It assumes miniports provide correct `adapter_notify`, `adapter_deliver`, `adapter_sync_cmd`, `adapter_restart`, and interrupt mask operations.

Risks and test signals: the reset path frees and rebuilds DMA, queue, FSA, and IRQ resources while completing outstanding waiters, so races around `in_reset`, `fib_lock`, command callbacks, and stopped `aac_command_thread` are high risk. `aac_queue_get()` spins until entries are available, so broken queue indexes or firmware stalls can livelock. Management FIB accounting must be balanced on every wait, timeout, reset, and interrupt path. AIF handling maps firmware events to SCSI add/remove/rescan and has timeout-based sequencing that can suppress or duplicate scans. Native HBA FIBs bypass normal `XferState` semantics and require different completion handling. Test signals include FIB pool shrink on allocation pressure, fast responses, timed-out and interrupted management commands, async callbacks that free FIBs, AIF add/delete/change/JBOD/enclosure events, SAFW scan retry, reset during outstanding sync and async I/O, kdump mode bus scan suppression, MSI-X vector allocation/free, and host-time/wellness command failure paths.

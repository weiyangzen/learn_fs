# sources/distributed-fs/ceph-client/drivers/scsi/aha1542.c

## Purpose
`aha1542.c` implements the Linux SCSI host driver for Adaptec AHA-1542 compatible ISA and ISA PnP adapters. It uses the adapter mailbox/CCB interface, ISA DMA, IRQ handling, coherent DMA memory for mailboxes and command blocks, and a per-command bounce buffer limited to 16 sectors.

## Important APIs, Types, And Functions
`struct aha1542_hostdata` stores BIOS translation mode, round-robin mailbox indices, command pointers by mailbox, and coherent DMA-backed mailbox/CCB arrays. `struct aha1542_cmd` stores the per-command coherent bounce buffer and DMA handle. Important functions include `wait_mask()`, `aha1542_outb()`, `aha1542_out()`, `aha1542_in()`, `makecode()`, `aha1542_test_port()`, `aha1542_hw_init()`, `aha1542_queuecommand()`, `aha1542_interrupt()`, reset handlers, and `aha1542_biosparam()`.

## Control Flow
Module init registers optional PnP support and an ISA driver. Hardware init requests resources, tests the adapter, configures bus timing, rejects AHA-1740 emulation mode, queries DMA/IRQ/SCSI ID, allocates coherent mailbox and CCB arrays, requests IRQ/DMA, adds the host, and scans. Queueing selects a free outgoing mailbox, fills the CCB, sets mailbox status, and sends `CMD_START_SCSI`. Interrupt handling scans incoming mailboxes, frees per-command DMA state, copies auto-sense data, maps host/target status, clears command ownership, and calls `scsi_done()`.

## State And Persistence Behavior
Driver state is volatile host private memory plus coherent DMA objects shared with the adapter. The mailbox arrays form the persistent runtime contract with firmware until driver removal. BIOS translation mode is cached after adapter query and used by `bios_param()`. Per-command bounce buffers are allocated once at command-private init and reused.

## Dependencies And Integration Points
The driver depends on ISA, PnP, legacy DMA channel APIs, coherent DMA mapping, SCSI mid-layer command/request helpers, and the mailbox/CCB definitions in `aha1542.h`. It uses module parameters `isapnp`, `io[]`, `bus_on[]`, `bus_off[]`, and `dma_speed[]`.

## Risks
The driver panics if no free mailbox is found. The bounce buffer size is fixed by `AHA1542_MAX_SECTORS`; correctness relies on `max_sectors` matching allocation. `aha1542_pnp_probe()` can use an out-of-range index if no empty `io[]` slot is found. Interrupt paths print unusual adapter interrupts but do not deeply recover from SCRD/HACC/MBOA beyond clearing the interrupt.

## Test Signals
Relevant signals include successful detection at configured I/O ports, correct inquiry/config responses, mailbox init success, read/write completion through all mailboxes, auto-sense delivery without issuing REQUEST SENSE to hardware, bus/host reset recovery, and BIOS geometry results for both translation modes.

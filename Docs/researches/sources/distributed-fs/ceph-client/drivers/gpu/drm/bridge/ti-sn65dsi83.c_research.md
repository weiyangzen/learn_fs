# sources/distributed-fs/ceph-client/drivers/gpu/drm/bridge/ti-sn65dsi83.c

Purpose: implements TI SN65DSI83 and SN65DSI84 DSI-to-LVDS bridges. The driver attaches to an upstream MIPI DSI host, attaches a downstream LVDS panel bridge, programs the bridge PLL, DSI/LVDS format/timing registers, supports single-link and SN65DSI84 dual-link LVDS, configures LVDS termination and voltage swing from DT, and monitors link errors through IRQ or polling with automatic pipe reset.

Important APIs/types/functions: `struct sn65dsi83` stores DRM bridge, device/regmap, DSI device, panel bridge, enable GPIO, vcc regulator, dual-link flags, per-channel VOD/termination configuration, IRQ, delayed monitor work, and reset work. `sn65dsi83_get_lvds_range()`, `sn65dsi83_get_dsi_range()`, and `sn65dsi83_get_dsi_div()` compute register encodings from mode clock, format bpp, lanes, and dual-link state. `sn65dsi83_atomic_pre_enable()` powers the chip, deasserts reset, reads bridge-state bus format, writes PLL/DSI/LVDS/video timing registers, waits for PLL lock, triggers soft reset, and registers a devm cleanup action. `sn65dsi83_atomic_enable()` clears startup IRQ status and enables IRQ or polling. `sn65dsi83_handle_errors()` reads IRQ status, ignores known noisy PLL-unlock-only reports, disables IRQ if needed, and schedules `sn65dsi83_reset_work()` to reset the DRM pipe. `sn65dsi83_parse_dt()` handles LVDS endpoint properties and dual-link pixel order.

Control flow: probe allocates the bridge, initializes work items, detects model from OF or I2C ID, obtains optional enable GPIO and holds reset low, parses LVDS/panel/regulator DT, initializes regmap, optionally requests IRQ, adds the bridge with LVDS connector type and `pre_enable_prev_first`, then registers and attaches a child DSI device from input port 0. Atomic pre-enable programs clocks and timing from the adjusted CRTC mode and output bus config; atomic enable activates runtime error detection. Atomic disable releases the pre-enable devm action, which disables IRQ or polling, lowers enable, disables the regulator, and marks regcache dirty.

State and persistence: DT-derived persistent state includes dual-link mode, even/odd channel swap, LVDS termination, and VOD swing values. Runtime hardware state includes PLL enable/lock, DSI lane/range/divider, LVDS format/termination/swing, video timing, IRQ enables, and reset state. Error monitoring state is held in delayed work or IRQ and reset work; bridge enter/exit is used to avoid races with unplug/removal. Regmap uses maple caching with readable/writeable/volatile tables and marks cache dirty on power-down.

Dependencies and integration points: depends on DRM bridge atomic helpers, DRM bridge reset helper, MIPI DSI, OF graph/LVDS dual-link helpers, regmap, regulator, GPIO, workqueues, IRQs, and media bus formats. DSI host attach configures RGB888 video burst with omitted HFP/HBP/HSA and no EOT packets. The downstream LVDS panel bridge is acquired from port 2.

Risks: the VOD swing selector compares table min/max against requested ranges in a way that appears inverted for common "range contains candidate" semantics; DT validation should be checked with real bindings. `sn65dsi83_parse_lvds_endpoint()` calls property readers on an endpoint pointer that can be NULL if the channel endpoint is missing. Pre-enable always calls `devm_add_action()` even after PLL-lock failure, so cleanup is registered for partial setup. IRQ/poll reset deliberately resets the whole CRTC pipe and may be disruptive under intermittent link errors. SN65DSI85 and two-single-link LVDS modes are not supported. The driver ignores PLL unlock-only status because known hardware can report it while working.

Test signals: SN65DSI83 single-link and SN65DSI84 dual-link panels; SPWG24, JEIDA24, and SPWG18 bus formats; dual-link odd/even and even/odd pixel order; LVDS termination/VOD DT property combinations; PLL lock timeout handling; IRQ and polling error recovery; noisy PLL-unlock-only systems; mode clock limits 25-154 MHz; DSI lane counts and host attach deferral; and runtime unplug/remove with delayed work pending.

## sources/distributed-fs/ceph-client/drivers/gpu/drm/imagination/pvr_rogue_mmu_defs.h

Purpose: Autogenerated Rogue MMU register-format definition header for BIF data-master encodings, virtual-address page-table indexes, page-size encodings, and PC/PD/PT entry bit fields.

Important APIs/types/functions: Defines constants such as `ROGUE_MMUCTRL_VADDR_*_INDEX_SHIFT`, entry counts/sizes for PC/PD/PT tables, page-size encodings from 4KB through 2MB, PT base/range masks, and valid/read-only/cache/pending/source bits for PT, PD, and PC entries. There are no functions or types.

Control flow: No runtime flow; consumers use constants while constructing or decoding GPU MMU tables.

State and persistence behavior: Encodes hardware page-table entry state. These values determine what is persisted in MMU page tables and how device virtual addresses are decomposed.

Dependencies: It is standalone C preprocessor data and is included by `pvr_vm.h`, which makes the constants visible to VM/MMU code.

Integration points: The PowerVR MMU and VM layers rely on these definitions to create GPU page tables, validate table dimensions, and encode page-table roots and leaf permissions.

Risks: It is autogenerated and marked do-not-edit. Manual changes can corrupt page-table encoding and cause device faults, address aliasing, or access-permission bugs. Mismatch with hardware revision is high risk.

Test signals: Build-time use by MMU code, VM map/unmap tests, page-fault behavior, GPU command execution using mapped BOs, and any hardware conformance tests that inspect MMU entries.

# sources/distributed-fs/ceph-client/drivers/interconnect/mediatek/mt8183.c

Purpose: MT8183 EMI topology driver covering DDR EMI plus CPU, GPU, MMSYS, VPU, display, video, camera, image, and MDP masters.

Important APIs/types/functions: static `mtk_icc_node` objects and `mt8183_emi_icc_nodes[]` map binding IDs to topology. Compatible is `mediatek,mt8183-emi`.

Control flow: common EMI probe/remove register the provider. Multimedia clients mostly route through MMSYS to `SLAVE_DDR_EMI`; CPU/GPU route directly to DDR EMI.

State and persistence: static topology and mutable aggregate fields.

Dependencies/integration: `dt-bindings/interconnect/mediatek,mt8183.h`, DVFSRC EMI helper, `icc_sync_state`.

Risks and test signals: validate binding indexes, MMSYS aggregation, direct memory paths, sync-state behavior, and DVFSRC requests under display/video/camera loads.

# sources/distributed-fs/ceph-client/drivers/interconnect/mediatek/mt8196.c

Purpose: MT8196 EMI topology driver, extending the MediaTek EMI model with multiple MCU ports, GPU, multimedia, VPU, MDLA, storage, PCIe, USB, wireless/network/debug, and HRT ADSP paths.

Important APIs/types/functions: static `mtk_icc_node` entries map MT8196 binding IDs into `mt8196_emi_icc_nodes[]`; compatible is `mediatek,mt8196-emi`.

Control flow: common EMI probe/remove register the topology; votes route through subsystem nodes to normal DDR or HRT DDR endpoints and become DVFSRC requests.

State and persistence: static topology descriptors and mutable aggregate fields.

Dependencies/integration: `dt-bindings/interconnect/mediatek,mt8196.h`, DVFSRC EMI helper, sync-state.

Risks and test signals: test MCU ports, HRT ADSP, PCIe differences from MT8195, sparse array holes, and the Makefile bug that appears to gate this object on the MT8195 config.

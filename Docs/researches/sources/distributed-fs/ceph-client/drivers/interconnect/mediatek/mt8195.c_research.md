# sources/distributed-fs/ceph-client/drivers/interconnect/mediatek/mt8195.c

Purpose: MT8195 EMI topology driver with normal DDR and high-real-time DDR paths for multimedia and debug clients.

Important APIs/types/functions: static nodes include CPU/GPU/MMSYS/VPU/MDLA/storage/network/debug and HRT multimedia nodes. `mt8195_emi_icc` is matched by `mediatek,mt8195-emi`.

Control flow: common probe registers nodes and links. Endpoint type 1 generates normal peak/average DVFSRC requests; endpoint type 2 generates HRT bandwidth requests.

State and persistence: static descriptors with mutable aggregate fields.

Dependencies/integration: MT8195 bindings, DVFSRC helper, interconnect sync-state.

Risks and test signals: test normal vs HRT votes, multimedia HRT routing, sparse arrays, direct peripheral DDR paths, and Makefile interaction with MT8196.

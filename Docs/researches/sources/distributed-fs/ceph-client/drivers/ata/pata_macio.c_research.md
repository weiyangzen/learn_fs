# sources/distributed-fs/ceph-client/drivers/ata/pata_macio.c

`pata_macio.c` is the libata driver for Apple PowerMac MacIO-family PATA controllers: OHare, Heathrow/Paddington, KeyLargo ATA-3/ATA-4, UniNorth/Kauai ATA-6, K2, and Shasta. It supports both macio bus devices and Apple PCI ATA devices, handling timing tables, Open Firmware metadata, PowerMac feature-control reset/enable, DBDMA, media-bay events, PM, and SCSI queue-limit quirks.

`struct pata_macio_priv` stores controller kind, Apple bus id, OF node, bus device pointers, IRQ, cached timing registers for two devices, mapped taskfile/FCR registers, DBDMA table, host, and selected timing table. `struct pata_macio_timing` tables map transfer modes to hardware register values. Timing flows through `pata_macio_set_timings()`, `pata_macio_apply_timings()`, and `pata_macio_dev_select()`. Cable detection uses OF `cable-type`, PowerBook short-cable handling, and K2/Shasta overrides. DBDMA is implemented through `pata_macio_qc_prep()` and custom BMDMA setup/start/stop/status callbacks. `pata_macio_sdev_configure()` applies OHare and K2/Shasta DMA alignment restrictions.

Initialization is gated to PowerMac. The module registers both PCI and macio drivers. Both attach paths allocate private state and call `pata_macio_common_init()`, which identifies controller invariants, builds libata mode masks from timing tables, maps resources, initializes DBDMA/FCR state, resets hardware, applies safe timings, and activates the host. Suspend disables IRQ and hardware; resume resets/enables hardware and resumes libata. Media-bay events freeze or abort the port.

State is substantial and platform-coupled: OF node refs, cached timing registers, DBDMA descriptors, feature-control state, and libata host. Dependencies include macio, PCI, Open Firmware, PowerMac feature calls, DBDMA, media bay, and libata BMDMA/SFF. Risks include timing-table errors, 64K DBDMA boundary splitting, DMA flush timeouts, wrong cable metadata, media-bay races, and PM sequencing. Tests should cover each controller kind, mode masks, DBDMA boundary cases, DMA errors, queue limits, macio/PCI attach, media-bay plug/unplug, and suspend/resume.

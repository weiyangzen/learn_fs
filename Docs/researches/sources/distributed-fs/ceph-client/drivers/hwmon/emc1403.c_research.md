## sources/distributed-fs/ceph-client/drivers/hwmon/emc1403.c

### Purpose

`emc1403.c` supports SMSC/Microchip EMC140x/EMC141x/EMC142x/EMC1438/EMC1442 temperature-monitoring chips. It exposes up to eight temperature channels with limits, hysteresis, alarms, faults, update interval, and a legacy `power_state` sysfs attribute. It uses regmap caching with volatile live measurement/status registers.

### Important APIs, types, and functions

`struct thermal_data` stores chip variant and regmap. Register maps are held in `emc1403_temp_regs`, `emc1403_temp_regs_low`, and `ema1403_temp_map`. Important functions include `emc1403_detect()`, `emc1403_regmap_is_volatile()`, `emc1403_get_temp()`, `emc1403_get_hyst()`, `emc1403_temp_read()`, `emc1403_set_temp()`, `emc1403_set_hyst()`, `emc1403_get_convrate()`, `emc1403_set_convrate()`, `emc1403_is_visible()`, and `emc1403_probe()`.

### Control flow

I2C detection validates manufacturer ID, product ID, and revision. Probe allocates state, initializes regmap, and registers an info-based hwmon device plus the `power_state` group. Temperature reads map a hwmon attribute to high/low registers, combine 0.125 C units, and sign-extend for EMC1428-family chips. Alarm reads use legacy status bits for EMC1402 and separate status registers for later variants. Writes clamp signed or unsigned ranges and update high/low bytes, shared hysteresis, or conversion-rate register.

### State and persistence behavior

Persistent state is in hardware registers and regmap cache. Measurement/status registers are volatile. Limit, hysteresis, conversion-rate, and power-state writes persist on the chip. Visibility is variant-dependent: EMC1402 exposes two channels, EMC1403 three, most others four, and EMC1428-family up to eight.

### Dependencies and integration points

Dependencies include I2C, regmap with maple cache, hwmon info API, sysfs helpers, and util closest-value helpers. Integration points are hwmon attributes and custom `power_state` bit 6 in register `0x03`.

### Risks

Shared hysteresis affects all channels. Product aliases collapse onto a small enum, so signedness and channel count must remain accurate. Regmap volatility omissions would expose stale readings. Detection may reject newer steppings. The conversion table name is misleading but functional.

### Test signals

Verify all ID aliases, channel visibility, signed negative temperatures on EMC1428-family chips, fractional limit read/write, alarm mapping by variant, update interval selection, regmap volatility, and `power_state` toggling.

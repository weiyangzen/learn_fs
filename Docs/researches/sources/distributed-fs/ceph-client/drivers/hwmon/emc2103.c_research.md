## sources/distributed-fs/ceph-client/drivers/hwmon/emc2103.c

### Purpose

`emc2103.c` supports the SMSC EMC2103 temperature monitor and fan controller. It exposes internal/external temperatures, limits and alarms, fan tachometer RPM, divider, target RPM, fan fault, and RPM-control enable. EMC2103-2/-4 variants can expose additional external channels depending on anti-parallel diode mode.

### Important APIs, types, and functions

`struct emc2103_data` stores the I2C client, selected sysfs groups, update lock, cache flags, fan RPM-control state, temperature channel count, cached temperatures/limits/alarms, fan multiplier, tach count, and target count. Important functions are `read_u8_from_i2c()`, `read_temp_from_i2c()`, `read_fan_from_i2c()`, `write_fan_target_to_i2c()`, `read_fan_config_from_i2c()`, `emc2103_update_device()`, temperature/fan/pwm sysfs callbacks, `emc2103_probe()`, and `emc2103_detect()`.

### Control flow

Detection checks SMBus byte support, manufacturer ID `0x5d`, and product ID `0x24` or `0x26`. Probe reads product/config registers to determine channel count and optionally forces APD mode through the `apd` module parameter. It builds a null-terminated group list with base attributes and optional temp3/temp4 groups. Reads refresh every 1.5 seconds. Fan divider writes update range bits, adjust `fan_multiplier`, and rescale fan target to preserve target RPM. Target writes convert requested RPM to tach target; zero disables target control. `pwm1_enable` accepts `0` or `3`.

### State and persistence behavior

The driver caches sensor data for 1.5 seconds. Limits, divider, target count, APD mode, and RPM-control enable persist in chip registers. Sysfs shape is fixed at probe even if APD mode changes externally. Low-level read errors often leave old cached fields in place.

### Dependencies and integration points

Dependencies are I2C SMBus byte operations, hwmon sysfs helpers, jiffies, mutexes, and I2C class scanning at address `0x2e`. It integrates as a classic group-based hwmon driver.

### Risks

Partial I2C read failures can yield stale or mixed cached data. Fan target/divider math must avoid zero and preserve RPM. APD mode is module-wide. Temperature fault uses `-128` as a sentinel. Product ID assumptions control channel capability.

### Test signals

Cover product IDs `0x24`/`0x26`, APD default/forced modes, group count, fractional temperature conversion, min/max writes and alarms, fan tach zero/fault handling, divider target preservation, and `pwm1_enable` validation.

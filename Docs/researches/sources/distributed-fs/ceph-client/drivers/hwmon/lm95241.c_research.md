# sources/distributed-fs/ceph-client/drivers/hwmon/lm95241.c

## Purpose
`lm95241.c` is a hwmon I2C driver for National LM95231/LM95241 temperature sensors with one local and two remote channels. It exposes temperature inputs, remote range min/max controls, diode type selection, fault flags, and update interval.

## APIs, Flow, State, And Risks
`struct lm95241_data` stores the client, cache timestamp, interval, validity flag, six temperature bytes, status, config, remote model, and TruTherm configuration. `lm95241_update_device` refreshes raw temperature/status bytes after the configured interval. Reads convert local as signed and remote as signed or unsigned depending on config range bits; remote min/max report effective range rather than programmable thresholds. Writes to interval choose among 76/182/1000/2700 ms, min/max toggle signed-range bits, and type writes update both remote model and TruTherm registers.

Probe initializes default 1-second conversion, enables remote filters, disables TruTherm, writes remote model, and registers hwmon. Hardware persists config/range, filter, TruTherm, and model bits; cached readings persist in software with no explicit mutex. Dependencies are raw SMBus byte data, hwmon, jiffies, and I2C class scanning.

Risks include unhandled negative SMBus read returns being stored in `u8` cache fields and marked valid, lack of locking around cache/writes, subtle shared bit definitions for remote2 mode/range, and min/max acting as mode selectors. Test probe/detect, cache refresh, SMBus error injection, interval thresholds, signed/unsigned conversion, range toggling, and type writes.

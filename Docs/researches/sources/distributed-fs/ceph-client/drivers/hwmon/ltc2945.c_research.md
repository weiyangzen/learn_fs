# sources/distributed-fs/ceph-client/drivers/hwmon/ltc2945.c

## Purpose
`ltc2945.c` is a hwmon I2C driver for the Linear Technology/ADI LTC2945 power monitor. It exposes VIN and ADIN voltages, sense current, power, min/max thresholds, historical min/max registers, reset-history controls, and fault alarms through a legacy hwmon sysfs attribute group.

## APIs, Flow, State, And Risks
`struct ltc2945_data` stores regmap and shunt resistor micro-ohms. `ltc2945_reg_to_val` converts 24-bit power or 12-bit voltage/current registers into user units using `CONTROL_MULT_SELECT` and shunt resistance; `ltc2945_val_to_reg` reverses this for thresholds. Sysfs callbacks show/store values, reset history, and read/clear fault bits.

Probe initializes regmap, reads optional `shunt-resistor-micro-ohms` defaulting to 1000, rejects zero, clears faults, and registers fixed attributes. Value reads bulk-read raw registers and convert. Threshold writes parse unsigned values, convert, clamp to hardware width, and bulk-write. History reset writes `1`, enters test mode, resets selected min and matching max registers, and clears test mode. Alarm reads clear reported latched fault bits.

Persistent hardware state is thresholds, history, faults, and control bits; software state is only shunt resistance. Dependencies are I2C, regmap, hwmon sysfs helpers, firmware properties, and OF match `adi,ltc2945`. Risks are scaling errors from wrong shunt values, power math depending on control mode, unchecked test-mode set before history reset, read-to-clear alarms, and silent clamping. Test shunt property handling, conversion fixtures, threshold encoding, reset-history failure paths, alarm side effects, and sysfs attribute coverage.

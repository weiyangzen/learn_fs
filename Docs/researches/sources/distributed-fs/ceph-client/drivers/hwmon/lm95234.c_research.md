# sources/distributed-fs/ceph-client/drivers/hwmon/lm95234.c

## Purpose
`lm95234.c` is a hwmon I2C driver for TI/National LM95233 and LM95234 multi-channel temperature sensors. It exposes local and remote temperatures, per-channel enable, max/critical limits, hysteresis, remote diode type, offsets, faults, alarms, and conversion update interval through regmap-backed hwmon callbacks.

## APIs, Flow, State, And Risks
`struct lm95234_data` stores regmap and chip type. `lm95234_read_temp` reads remote unsigned values first and falls back to signed registers when needed. `lm95234_temp_read/write` implement per-channel hwmon attributes; `lm95234_chip_read/write` handle conversion interval; helper functions encode channel-specific critical, alarm, and hysteresis registers. Regmap marks live temperatures/status/model-status volatile and writable configuration/limit registers cacheable.

Probe initializes regmap, clears STOP, repairs remote diode model mismatches if status reports them, and registers hwmon. Visibility hides LM95233 channels above two and hides local-channel remote-only attributes. Writes validate enable/type, update model bits, write offsets in 0.5 C steps, clamp limits, and write shared hysteresis relative to local TCRIT1.

Persistent state is enable bits, conversion rate, model bits, offsets, limits, and shared hysteresis. Dependencies are I2C/regmap/hwmon and class scanning. Risks are channel/register asymmetry, shared hysteresis semantics, unsigned-zero remote fallback, and `channel - 1` offset indexing. Test detection masks/address rules, visibility, signed/unsigned conversions, enable/model/offset/limit writes, update interval mapping, and fault/alarm bits.

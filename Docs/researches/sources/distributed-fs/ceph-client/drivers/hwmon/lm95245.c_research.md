# sources/distributed-fs/ceph-client/drivers/hwmon/lm95245.c

## Purpose
`lm95245.c` is a regmap-backed hwmon I2C driver for TI/National LM95235/LM95245 two-channel temperature sensors. It exposes local critical temperature and remote temperature input, max/critical limits, common hysteresis, remote diode type, offset, fault, alarms, and update interval.

## APIs, Flow, State, And Risks
`struct lm95245_data` stores regmap and current interval. `lm95245_read_conversion_rate` and `lm95245_set_conversion_rate` map hardware rates to 63/364/1000/2500 ms. `lm95245_read_temp/write_temp` handle temperature, limits, common hysteresis, diode type, offset, alarms, and fault. Regmap marks status/live temperature registers volatile, allows config/rate/offset/limit writes, and uses single read/write mode.

Probe creates regmap, reads initial conversion rate, clears STOP, and registers hwmon. Remote input reads signed registers first and switches to unsigned registers for high positive remote temperatures. Writes clamp thresholds, write two-byte offsets, update config2 diode type, and write common hysteresis from the local limit. OF compatibles are provided for `national,lm95235` and `national,lm95245`.

Persistent state is conversion/config, diode/filter config, offset, OS/TCRIT limits, and common hysteresis. Dependencies are I2C, regmap, hwmon, OF, and class scanning. Risks are signed/unsigned remote selection, negative fractional truncation, shared hysteresis, and revision/address detection assumptions. Test OF/I2C probe, regmap policy, conversion-rate mapping, remote conversion edge cases, offset writes, limit clamping, hysteresis behavior, and status-bit mapping.

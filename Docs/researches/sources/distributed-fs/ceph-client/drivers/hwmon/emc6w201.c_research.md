## sources/distributed-fs/ceph-client/drivers/hwmon/emc6w201.c

### Purpose

`emc6w201.c` supports the SMSC EMC6W201 hardware monitor. It exposes six voltage inputs with min/max limits, six temperature inputs with min/max limits, and five fan tachometers with minimum RPM limits using classic hwmon sysfs attributes and periodic I2C register caching.

### Important APIs, types, and functions

`struct emc6w201_data` contains the I2C client, update mutex, cache validity/timestamp, voltage arrays, temperature arrays, and fan arrays. `enum subfeature` indexes `input`, `min`, and `max`. Important helpers are `emc6w201_read16()`, `emc6w201_write16()`, `emc6w201_read8()`, `emc6w201_write8()`, `emc6w201_update_device()`, `in_show()`/`in_store()`, `temp_show()`/`temp_store()`, `fan_show()`/`fan_store()`, `emc6w201_detect()`, and `emc6w201_probe()`.

### Control flow

Detection requires SMBus byte support, company ID `0x5c`, expected version/step bits, expected config reserved bits, and monitoring enabled. Probe allocates state, initializes the mutex, and registers static attributes. Reads refresh cached voltage, temperature, and fan registers when invalid or older than one second. Voltage values scale against per-channel nominal millivolts; temperatures are signed degrees times 1000; fan RPM is `5400000 / count` with zero and `0xffff` treated as stopped/invalid. Writes clamp and convert limit values before writing registers.

### State and persistence behavior

The driver maintains a one-second cache. Limit writes persist to chip registers and update cached arrays. I2C read failures log errors and substitute placeholder values, which can still become valid cached data until the next refresh.

### Dependencies and integration points

Dependencies are I2C class scanning at `0x2c-0x2e`, SMBus byte operations, hwmon sysfs macros, jiffies, and mutexes. Integration is a standard I2C hwmon driver named `"emc6w201"` exposing fixed attributes for all supported channels.

### Risks

Read helpers hide I2C failures as placeholder values, potentially misleading userspace. All channels are always exposed even if board wiring leaves inputs unused. Scaling relies on a fixed nominal-voltage table. Detection rejects monitoring-disabled devices instead of enabling them. Fan limits are minimum-only.

### Test signals

Verify ID/config detection, cache refresh, voltage scaling and limit round trips, signed temperature limit writes, fan count/RPM conversions including zero and `0xffff`, I2C failure behavior, and devm cleanup.

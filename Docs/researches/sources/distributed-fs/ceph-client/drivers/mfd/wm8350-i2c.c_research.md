# sources/distributed-fs/ceph-client/drivers/mfd/wm8350-i2c.c

`wm8350-i2c.c` is the I2C frontend for WM8350-family PMICs. It allocates core state, creates the I2C regmap, stores driver data, and calls the common WM8350 initializer.

`wm8350_i2c_probe()` allocates `struct wm8350`, initializes `devm_regmap_init_i2c()` with exported `wm8350_regmap`, sets client data and `wm8350->dev`, and calls `wm8350_device_init(wm8350, i2c->irq, pdata)`. `wm8350_i2c_id[]` lists `wm8350`, `wm8351`, and `wm8352`; `wm8350_i2c_driver` suppresses bind attributes; `wm8350_i2c_init()` registers at `subsys_initcall()` so consumers can complete boot.

State is limited to devres-managed `struct wm8350`, regmap, and I2C client data. The common core and child platform devices own persistent PMIC behavior after probe. Dependencies include I2C, regmap I2C support, WM8350 core/regmap exports, and platform data.

Risks: this source version has no OF match table; no explicit remove path is present; cleanup of failed core init relies on the core's error handling. Test signals include I2C ID matching for all three names, regmap allocation failure propagation, core identification logs, and child platform-device registration.

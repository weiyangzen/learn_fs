# sources/distributed-fs/ceph-client/drivers/power/supply/rt9471.c

Purpose: implements the Richtek RT9470/RT9470D/RT9471/RT9471D charger over I2C. It registers a USB power supply, an OTG VBUS regulator, sysfs controls for ship mode and BC1.2 port detection, regmap IRQ handling for charger/BC1.2/watchdog/OTG events, and shutdown reset behavior.

Important APIs, types, and functions: `struct rt9471_chip` stores regmap fields, IRQ chip data, OTG regulator, power-supply descriptor, mutex-protected USB type/current state, and device pointers. `enum rt9471_fields` and `rt9471_reg_fields[]` define charger, watchdog, BATFET, BC1.2, status, and device-ID fields. `rt9471_set_value_by_field_range()` and `rt9471_get_value_by_field_range()` map power-supply values through `linear_range` tables. `rt9471_set_ieoc()` toggles termination enable when charge-term current is zero/nonzero. IRQ handlers update VBUS/USB type state, reset watchdog, and notify regulator consumers on OTG faults.

Control flow: probe allocates state, initializes the `var_lock`, configures optional charge-enable GPIO, initializes regmap and regmap fields, validates device ID, applies an initialization register patch including reset, watchdog disable, charge enable defaults, AICR/MIVR/JEITA/BC1.2 settings, adds a regmap IRQ chip, registers the power supply with sysfs groups, registers the OTG regulator, requests selected threaded IRQs, then enables BC1.2 detection by default. Shutdown performs a register reset to leave charger hardware in a normal state.

State and persistence behavior: the driver caches detected USB type and current under `var_lock`; all charger limits and enable flags are hardware register state. `sysoff_enable` writes BATFET disable, and `port_detect_enable` writes BC1.2 detection enable. Shutdown reset intentionally discards runtime programming in favor of known hardware defaults. No external persistent storage is used.

Dependencies and integration points: depends on I2C, optional GPIO, regmap fields, regmap IRQ, power-supply, regulator framework, sysfs, OF compatible `richtek,rt9471`, and device interrupts. The OTG regulator reports failures through `regulator_notifier_call_chain()`.

Risks: initialization uses a broad register patch immediately after device-ID validation, so variant-specific reset side effects need hardware coverage. `rt9471_register_interrupts()` returns the raw `virq` when it is non-positive, which may return 0 rather than a negative errno. `CURRENT_MAX` initially reflects cached USB detection state, so before BC1.2 completion it may be zero/unknown. The checked-out source has duplicated `vsel_reg` in the regulator descriptor. Test signals include supported and unsupported device IDs, init patch verification, BC1.2 port mapping for Apple/Samsung/SDP/CDP/DCP/NSTD states, detach clearing current/type, watchdog reset IRQ, OTG regulator failure notification, sysfs writes for BATFET and port detection, power-supply writable property boundaries, and shutdown register reset.

# sources/distributed-fs/ceph-client/drivers/usb/serial/ch341.c

Purpose: Winchiphead/QinHeng CH341/CH340 USB serial driver for asynchronous serial mode, including baud, line control, modem control, flow control, break, quirks, and reset-resume. The complete 893-line source was read.

Important APIs/types/functions: `struct ch341_private`, `ch341_configure()`, `ch341_detect_quirks()`, `ch341_get_divisor()`, `ch341_set_baudrate_lcr()`, `ch341_open()`, `ch341_set_termios()`, `ch341_set_flow_control()`, `ch341_break_ctl()`, `ch341_simulate_break()`, `ch341_update_status()`, `ch341_read_int_callback()`, and `ch341_reset_resume()`.

Control flow and state: probe configures default 9600 8N1 and detects limited-prescaler/simulated-break quirks. Open applies termios, starts interrupt status, reads initial modem status, then opens generic bulk I/O. Termios computes LCR and divisor from 48 MHz clock, handles B0 DTR/RTS, and writes flow control. Interrupts update modem counters and DCD; reset-resume restores configuration. State is spinlock-protected baud/MCR/MSR/LCR/version/quirks.

Dependencies and integration points: USB serial core, tty termios, serial modem-control semantics, unaligned helpers, jiffies timeout for break simulation, generic `tiocmiwait`, DCD handling.

Risks and test signals: risks include version-specific register semantics, divisor rounding, byte loss from redundant writes, simulated break corrupting input, and quirk detection via `-EPIPE`. Test all IDs, baud limits, termios matrix, flow control, real/simulated break, status interrupts, reset-resume, and disconnect.

# sources/distributed-fs/ceph-client/drivers/usb/serial/ark3116.c

Purpose: ARK Micro 3116 RS232/IrDA USB serial driver that treats the chip as a 16450-style UART accessed through vendor control messages. The complete 734-line source was read.

Important APIs/types/functions: `struct ark3116_private`, `ark3116_write_reg()`, `ark3116_read_reg()`, `ark3116_port_probe()`, `ark3116_open()`, `ark3116_close()`, `ark3116_set_termios()`, `ark3116_tiocmget()`, `ark3116_tiocmset()`, `ark3116_break_ctl()`, `ark3116_read_int_callback()`, and `ark3116_process_read_urb()`.

Control flow and state: probe initializes UART registers, RS232/IrDA mode, and 9600 8N1 defaults. Open starts generic I/O, drains RX, reads initial MSR/LSR, submits interrupt URB, enables interrupts/DMA, and applies termios. Termios computes UART LCR, handshake, divisor, and high-speed override. Interrupts update MSR/LSR and counters; bulk reads consume cached LSR error bits. State persists in private register mirrors guarded by `hw_lock` and `status_lock`.

Dependencies and integration points: USB serial core, tty termios, serial register definitions, generic `tiocmiwait`/`get_icount`, and control endpoint vendor register access.

Risks and test signals: risks include separate interrupt/bulk error ordering, undocumented IrDA registers, unsupported software flow control, and many unchecked setup writes. Test RS232/IrDA IDs, baud/parity/stop/data matrix, modem ioctls, break, LSR error injection, DCD waits, and disconnect with active URBs.

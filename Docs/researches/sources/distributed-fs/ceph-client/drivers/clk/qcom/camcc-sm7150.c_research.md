# sources/distributed-fs/ceph-client/drivers/clk/qcom/camcc-sm7150.c

Purpose: implements the SM7150 camera clock controller. It registers CAMCC PLLs, fixed-factor/postdiv outputs, RCGs, branch gates, and GDSCs for BPS, CAMNOC, CCI, CSIPHY/CSI timers, FD core, ICP, IFE 0/1/lite, IPE 0/1, JPEG, LRME, MCLK0-3, sleep/XO support, and AHB/system clocks.

Important APIs/types/functions: SM7150 uses Fabia PLL0/1/3/4 plus Agera PLL2. Several PLL outputs are fixed-factor `clk_fixed_factor` clocks: PLL0 even/odd, PLL1 even, PLL2 early, PLL3 even, and PLL4 even; PLL2 also has AUX and MAIN postdiv outputs. Parent maps cover XO, always-on XO, chip sleep clock, PLL outputs, and the special PLL2 AUX path. RCGs include shared ops for BPS, CAMNOC, FD, ICP, IFE, IPE, JPEG, LRME, and slow AHB paths, while timer/MCLK/sleep/XO sources use regular ops. `camcc_sm7150_hws` registers fixed-factor outputs separately from `camcc_sm7150_clocks`. `camcc_sm7150_probe()` configures PLLs, forces the GDSC clock on, and registers the descriptor.

Control flow: device-tree matching on `qcom,sm7150-camcc` invokes probe. Probe maps registers, configures Fabia/Agera PLLs, calls `qcom_branch_set_clk_en(regmap, 0xc1a0)` to keep `CAMCC_GDSC_CLK` on, and then calls `qcom_cc_really_probe()`. From that point, CCF rate-setting follows frequency tables and branch enable calls poll halt registers. Power-domain requests flow through the GDSC framework with `camcc_titan_top_gdsc` as parent for the block domains.

State and persistence behavior: no filesystem or driver-private persistent state exists. Static tables define PLL configuration, rate tables, parent maps, branch registers, GDSC registers, and descriptor arrays. Hardware stores the live PLL, RCG, branch, and GDSC state. BPS and IPE domains use `HW_CTRL | POLL_CFG_GDSCR`; IFE domains and top use `POLL_CFG_GDSCR`. The always-on GDSC clock write at probe intentionally leaves a hardware branch enabled for correct power-domain operation.

Dependencies/integration points: depends on `dt-bindings/clock/qcom,sm7150-camcc.h`, CCF, regmap, platform devices, Qualcomm Fabia/Agera PLL support, branch/RCG helpers, and GDSC support. It integrates with camera/media nodes through clock IDs and GDSC power domains. The descriptor spans `.clk_hws`, `.clks`, and `.gdscs`; the regmap maximum is `0xd024`.

Risks: the probe configures `camcc_pll4` using `camcc_pll3_config`, which appears intentional only if PLL3 and PLL4 share identical parameters; future edits must not assume the local variable name is harmless. The always-on `CAMCC_GDSC_CLK` branch is critical for GDSC operation. Parent-map mistakes around `DT_BI_TCXO_AO`, chip sleep, and PLL2 AUX can break low-power and MCLK paths. Shared RCGs must safely transition during disable or camera memory shutdown can fail. Split `clk_hw` and `clk_regmap` arrays must preserve binding indices.

Test signals: build and dt-binding validation for `qcom,sm7150-camcc`; probe logs without PLL, regmap, or GDSC failures; debugfs confirmation that `CAMCC_GDSC_CLK` remains enabled; camera streaming through IFE/IPE/BPS/JPEG/LRME; sleep/XO clock behavior across suspend; MCLK measurement for sensor rates; and GDSC transition tests for BPS, IFE0/1, IPE0/1, and titan top.

# sources/distributed-fs/ceph-client/drivers/clk/rockchip/clk-rk3576.c

Purpose: RK3576 clock-controller driver. It models a newer, larger RK3588-style Rockchip clock tree with core PLLs, separate big/little CPU clocks, top/bus/center/DDR roots, GPU/NPU, NVM/storage, USB/UFS/PHP/PCIe/SATA/PHY, secure non-secure, VI/VO/display, VPU/VDEC/VEPU/JPEG/RGA/EBC, audio/SAI/SPDIF/PDM/ASRC, GMAC/SDIO/SDMMC/DSMC/HSGPIO, PMU, and external/reference clock routing.

Important APIs, types, and functions: `rk3576_pll_rates` and `rk3576_ppll_rates` use RK3588-style PLL parameters. `rk3576_pll_clks` registers BPLL, LPLL, VPLL, AUPLL, CPLL, GPLL, and PPLL, with BPLL/LPLL using `pll_rk3588_core` and PPLL using `pll_rk3588_ddr`. CPU frequency support is split into `rk3576_cpubclk_rates`/`rk3576_cpubclk_data` for `armclk_b` and `rk3576_cpulclk_rates`/`rk3576_cpulclk_data` for `armclk_l`; little-core transitions include CCI pre/post mux programming. `rk3576_clk_branches` is the central branch table, using normal Rockchip branch macros plus `COMPOSITE_DIV_OFFSET`, `MUXGRF`, and `GATE_GRF` for registers spread across CRU, PMU, PHP, secure, and auxiliary GRF spaces. `rk3576_clk_init()` performs all registration.

Control flow: `rk3576_clk_init()` computes the maximum clock ID, obtains PMU0 GRF and IOC GRF regmaps with `syscon_regmap_lookup_by_compatible()`, maps the CRU, creates the provider, allocates `rockchip_aux_grf` entries for PMU0 and IOC GRF, and hashes them into `ctx->aux_grf_table` so GRF-backed muxes/gates can resolve their register maps. It then registers PLLs, registers `armclk_l` and `armclk_b`, registers all branches, initializes resets through `rk3576_rst_init()`, registers the global restart notifier, and publishes the OF provider. The platform-driver probe invokes the same init path for `"rockchip,rk3576-cru"`.

State and persistence: state is hardware register state across CRU, PMU, PHP, secure-ns, PMU0-GRF, IOC-GRF, PLL, reset, and clock-gate/register blocks. Software state consists of the clock provider, aux-GRF table entries, and registered clock hardware. Allocation failure paths unmap the CRU and free the first aux-GRF entry where needed, but successful init is intentionally permanent like most early SoC clock providers. There is no persistent storage and no local suspend/resume syscore implementation despite the include. Critical flags keep core roots, PMU roots, top/bus/center/DDR, secure, selected PHY/reference, display, VPU, SDGMAC, and other essential paths available.

Dependencies and integration points: depends on `dt-bindings/clock/rockchip,rk3576-cru.h`, Rockchip RK3576 reset helpers, common clock framework, OF/platform matching, syscon/regmap for PMU0/IOC GRFs, and Rockchip aux-GRF support. Integration points include CPUfreq for big/little clusters, CCI interconnect clocks, display pixel clocks from HDMI PHY or PLL paths, audio fractional/int clock pools, SAI MCLK-to-IO gates, PMU oscillator/reference routing, PCIe/UFS/USB/PHY references, storage, network, video/camera/display, secure crypto/OTP/TRNG, and restart/reset consumers.

Risks and test signals: risk is dominated by topology size and cross-register routing. Missing PMU0-GRF or IOC-GRF syscon compatibles aborts the whole provider, so DT ordering and compatible names are critical. Aux-GRF memory allocated on the success path is permanent; on the failure path after `ioc_grf_e` allocation failure only `pmu0_grf_e` is freed, which is adequate because `ioc_grf_e` was not allocated, but later registration failures are not handled because helpers are expected not to fail fatally during early init. CPU clock tables must match safe divider/mux sequences, especially CCI pre/post mux changes for little cores. Test signals include provider creation with both GRFs present, `clk_summary` coverage for all large domains, big/little CPU frequency transitions, CCI clock behavior, SAI MCLK GRF gates to IO, PMU/PHY reference muxes, USB/UFS/PCIe/SATA clocks, display pixel clock reparent/no-reparent behavior, secure-ns crypto/OTP/TRNG gates, reset-controller users, and system restart.

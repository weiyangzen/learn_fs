# sources/distributed-fs/ceph-client/drivers/clk/rockchip/clk-rk3568.c

Purpose: RK3568/RK3566 clock-controller driver. It registers two related clock-controller blocks: the main CRU and the PMUCRU. The main CRU supplies CPU, bus, GPU/NPU, DDR, multimedia, storage, PCIe/SATA/USB, GMAC, UART/I2C/SPI/PWM/CAN, and top-level derived clocks; the PMUCRU supplies always-on PMU, oscillator/reference, GPIO0, UART0/I2C0/PWM0, WiFi, USB/MIPI/PCIe PHY reference, HDMI reference, and PMU PLL clocks.

Important APIs, types, and functions: `rk3568_pll_rates` is the shared RK3036-style PLL rate table. `rk3568_pmu_pll_clks` defines PPLL/HPLL under PMUCRU; `rk3568_pll_clks` defines APLL/DPLL/GPLL/CPLL/NPLL/VPLL under CRU. CPU frequency handling uses `rockchip_cpuclk_rate_table`, `rk3568_cpuclk_rates`, and `rk3568_cpuclk_data`, then registers `armclk` with `rockchip_clk_register_armclk()`. `rk3568_clk_branches` and `rk3568_clk_pmu_branches` describe the main and PMU branch graphs with Rockchip macros. Dedicated fracmux descriptors cover I2S, SPDIF, audio PWM, UART0-9, and RTC32K. `rk3568_cru_critical_clocks` and `rk3568_pmucru_critical_clocks` are protected after registration.

Control flow: compatible `"rockchip,rk3568-pmucru"` invokes `rk3568_pmu_clk_init()`, which maps the PMUCRU, initializes `CLKPMU_NR_CLKS`, registers PMU PLLs and PMU branches, installs one PMU soft-reset bank, protects PMU critical clocks, and publishes the provider. Compatible `"rockchip,rk3568-cru"` invokes `rk3568_clk_init()`, which maps the main CRU, sizes the onecell table from the branch IDs, registers main PLLs, registers `armclk` CPU-rate support, registers all main branches, installs 30 soft-reset banks, registers restart, protects critical clocks, and publishes the provider. The platform-driver probe dispatches to the same init functions from OF match data.

State and persistence: state lives in main CRU and PMUCRU MMIO registers: PLL mode/configuration, clock muxes, dividers, fractional dividers, gate bits, MMC delay controls, soft-reset registers, and selected GRF muxes. Software state is provider memory and registered `clk_hw` objects. No disk state exists. There are no local suspend/resume callbacks even though `syscore_ops.h` is included. The driver relies on common-clock enable counts plus explicit critical-clock protection for always-on buses, PMU, CPU, top, USB, PHP, secure-flash, VI/VO, and PLL paths.

Dependencies and integration points: depends on `dt-bindings/clock/rk3568-cru.h`, Rockchip clock/reset helpers, OF MMIO mapping, common clock CPU clock support, and platform/OF matching. It integrates with PMU and main reset controllers, global restart, and clock consumers across CPUfreq, serial, audio, storage, network, display, camera, crypto, USB, PCIe/SATA, GPU/NPU, VPU/RGA/VDEC/VENC, and PHY drivers. `MUXGRF()` is used where clock selection is mediated by system GRF fields.

Risks and test signals: risks include split-provider ordering between PMUCRU and CRU, exact clock ID sizing, CPU clock divider transitions, critical-clock omissions, GRF mux semantics, and descriptor errors in large repeated UART/audio/storage/network blocks. The parent string `"xin_osc0_half "` in the I2S2 parent list includes a trailing space, which is suspicious because it may not match the intended registered fixed factor parent. Test signals include boot/probe of both compatibles, `clk_summary` for PMU and main providers, CPU frequency transitions across the table, UART0 through PMU and UART1-9 through CRU baud checks, I2S/SPDIF fractional rate accuracy, MMC/eMMC sample/drive phase clocks, GMAC0/1 RGMII/RMII speed mux behavior, PCIe/SATA/USB reference clocks, reset-controller users, and restart.

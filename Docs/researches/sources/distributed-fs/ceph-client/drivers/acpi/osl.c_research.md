# sources/distributed-fs/ceph-client/drivers/acpi/osl.c

`osl.c` is Linux's ACPICA OS services layer. It provides root table discovery, printing, ACPI memory mappings, SCI interrupt handling, sleep/stall/timer services, port/memory/PCI config access, deferred execution workqueues, debugger hooks, hotplug scheduling, semaphores, resource conflict checks, cache wrappers, and sleep callback integration.

Important APIs include `acpi_os_initialize()`, `acpi_os_initialize1()`, `acpi_os_terminate()`, `acpi_os_get_root_pointer()`, `acpi_os_map_iomem()`, `acpi_os_unmap_iomem()`, `acpi_os_get_iomem()`, generic-address map/unmap helpers, `acpi_os_install_interrupt_handler()`, `acpi_os_remove_interrupt_handler()`, `acpi_os_execute()`, `acpi_os_wait_events_complete()`, `acpi_hotplug_schedule()`, semaphore operations, debugger operations, `acpi_check_resource_conflict()`, `acpi_resources_are_enforced()`, and sleep prepare/enter hooks.

Control flow reserves FADT resources at fs init, discovers the RSDP from lockdown-checked command line, arch, EFI, or legacy paths, pre-maps FADT GAS registers during `acpi_os_initialize()`, creates workqueues and initializes OSI in `acpi_os_initialize1()`, and removes mappings/IRQ/workqueues in termination. Permanent memory mappings are refcounted in an RCU-protected `acpi_ioremaps` list and freed through queued RCU work. ACPICA deferred work is queued to notification or GPE workqueues, with GPE work on CPU 0; hotplug uses a separate ordered queue to avoid flush deadlocks.

Persistent state includes SCI handler/context/IRQ, workqueues, permanent map list/refcounts, initialization flag, resource-enforcement mode, OS name/revision overrides, debugger owner/ops, sleep hook pointers, FADT logical addresses, and `poweroff_on_fatal`. Dependencies include ACPICA internals, EFI, lockdown, architecture table lookup, IRQs, PCI raw config access, workqueues, resource management, hotplug, PM sleep, and kernel debugger support.

Risks are mapping refcount/RCU bugs, static 512-byte `vsprintf()` printing, SCI-only interrupt support, semaphore delete BUG with waiters, fatal ACPI signal poweroff, resource-enforcement policy effects, and workqueue deadlock ordering. Test signals include root pointer paths, lockdown behavior, mapping reuse/unmap, I/O width handling, no-IOPORT builds, SCI install/remove, deferred execution queues, hotplug scheduling, debugger module ownership, semaphore timeouts, resource strict/lax/no modes, FADT GAS lifecycle, and sleep hook status translation.

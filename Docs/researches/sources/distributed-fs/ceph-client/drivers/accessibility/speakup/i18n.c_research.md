# sources/distributed-fs/ceph-client/drivers/accessibility/speakup/i18n.c Research

## Purpose
`i18n.c` implements Speakup's message catalog. It stores default English strings, lets users override messages, validates formatted-message overrides, groups message ranges, initializes defaults, and frees user strings at unload.

## Important APIs And Control Flow
`spk_msg_get()` returns the active string for an enum index. `spk_msg_set()` replaces one message with a `kmemdup_nul()` copy after bounds checks and format validation for formatted messages. `spk_find_msg_group()` locates named groups such as `ctl_keys`, `colors`, `formatted`, `function_names`, `key_names`, `announcements`, and `states`. `spk_reset_msg_group()`, `spk_initialize_msgs()`, and `spk_free_user_msgs()` manage active/default pointers. Setting allocates first, validates, then under `speakup_info.spinlock` frees any old user string and installs the new pointer.

## State And Persistence
State is two arrays indexed by `enum msg_index_t`: immutable default pointers and mutable active pointers. User overrides are dynamically allocated and persist until reset, replacement, or module unload. No disk persistence exists.

## Dependencies And Integration Points
The file depends on `i18n.h` enum ordering, kernel allocation and string helpers, `speakup_info.spinlock`, and callers in key help, kobjects, and speech output. Format validation is tied to default formatted strings and supported conversions `%c`, `%d`, `%s`, `%x`, and `%ld`.

## Risks
Enum order must stay synchronized with default strings and comments indicating cursor and edge enum alignment. `spk_msg_get()` performs no bounds check. Adding a default message with another conversion requires validator changes. Callers must handle `-ENOMEM` and `-EINVAL`.

## Test Signals
Test initialization, get/set/reset/free cycles, invalid indices, formatted-message specifier mismatch, escaped `%%`, width/precision handling, group lookup, concurrent reads while setting under lock, and leak checks on repeated overrides.

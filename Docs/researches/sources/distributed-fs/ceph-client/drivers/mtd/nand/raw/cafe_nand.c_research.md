# sources/distributed-fs/ceph-client/drivers/mtd/nand/raw/cafe_nand.c

Purpose: this PCI driver supports the Marvell 88ALP01 OLPC "CAFE" NAND controller. It is an older raw NAND integration using legacy NAND callbacks, optional DMA into a small coherent page buffer, Reed-Solomon hardware syndrome registers, custom bad-block table descriptors, and PCI suspend resume register restoration.

Important APIs, types, and functions: `struct cafe_priv` owns the `nand_chip`, PCI device, MMIO base, Reed-Solomon control object, cached `ctl1`/`ctl2` command state, transfer counters, page address, DMA flag, DMA address, and coherent DMA buffer. The legacy NAND hooks are `cafe_nand_cmdfunc()`, `cafe_device_ready()`, `cafe_read_byte()`, `cafe_read_buf()`, `cafe_write_buf()`, and `cafe_select_chip()`. ECC-specific functions include `cafe_nand_read_page()`, `cafe_nand_write_page_lowlevel()`, `cafe_ooblayout_*()`, the CAFE BBT descriptors, and the Galois-field helpers used by `init_rs_non_canonical()`. PCI lifecycle is handled by `cafe_nand_probe()`, `cafe_nand_remove()`, and `cafe_nand_resume()`.

Control flow: probe verifies the flash-memory PCI class, enables the PCI function, maps BAR0, creates the RS decoder, installs legacy NAND callbacks, chooses flash BBT behavior unless `skipbbt` is set, derives or accepts three timing registers, resets the NAND block, requests a shared IRQ, enables the NAND clock/global IRQ routing, disables DMA for identification, and scans up to two chip selects. Attach allocates a 2112-byte coherent DMA buffer, programs its address, restores the module `usedma` setting, configures page-size/ECC bits in `ctl2`, selects a 512-byte or 2 KiB BBT layout, and installs host ECC callbacks. Page reads issue `nand_read_page_op()`, read OOB through the legacy buffer hook, inspect hardware ECC result/syndrome registers, run the RS decoder, and patch data/OOB bytes according to the controller's 12-bit symbol mapping. Page writes stage data and OOB, set the ECC autogeneration bit in `ctl2`, then complete the program operation.

State and persistence: persistent state includes module parameters (`usedma`, `skipbbt`, debug flags, `checkecc`, optional timing words), cached timing registers, coherent DMA buffer address, selected chip bit in `ctl1`, and ECC/BBT layout chosen after chip scan. Hardware state is reset and timing/DMA/global-control registers are restored during resume. There is no runtime PM; remove unregisters MTD, runs `nand_cleanup()`, releases IRQ, RS tables, MMIO, DMA memory, and the PCI device.

Dependencies and integration points: the file depends on PCI IDs for `PCI_DEVICE_ID_MARVELL_88ALP01_NAND`, raw NAND legacy hooks, MTD partition parsers (`cmdlinepart`, `RedBoot`), Linux Reed-Solomon library support, coherent DMA, IRQ handling, and CAFE-specific global/NAND register definitions. It exposes `mtd->name = "cafe_nand"` and uses flash-resident BBT descriptors tailored to its OOB layout.

Risks: this driver predates the modern `exec_op` NAND interface and relies on a large `cmdfunc()` that emulates multi-step NAND commands through controller-specific control bits. Command completion is polled up to 500 ms and IRQ handling mostly acknowledges bits, so interrupt problems may only appear as long busy waits. The 2112-byte DMA buffer matches 2 KiB page plus 64-byte OOB assumptions; unexpected page sizes are rejected, but future geometry changes would need new sizing. ECC correction manually maps RS symbols across data and OOB and can corrupt data if syndrome interpretation is wrong. `cafe_nand_remove()` frees the coherent DMA buffer after `nand_cleanup()`, while the detach hook also frees it, which is a double-free risk if both paths run with current NAND cleanup semantics. Timing defaults may become `0xffffffff` if firmware left registers unset, which is safe but very slow and hardware-dependent.

Test signals: validate PCI class filtering and BAR mapping, timing parameter handling, two chip-select scan, DMA enabled and disabled modes, read ID/status without DMA during identification, page read/write with ECC autogeneration, corrected and failed ECC accounting with `checkecc=1`, OOB-only operations, flash BBT placement for 512-byte and 2 KiB pages, suspend/resume restoring timing and DMA registers, and module removal without DMA buffer lifetime warnings.

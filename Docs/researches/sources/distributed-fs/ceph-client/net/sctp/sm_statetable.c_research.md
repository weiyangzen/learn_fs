# sources/distributed-fs/ceph-client/net/sctp/sm_statetable.c

## Purpose
`sm_statetable.c` is the declarative dispatcher for the SCTP state machine. It maps each event category and subtype to the `sctp_sf_*` state function that should handle it for the current SCTP association state. The file does not implement protocol behavior itself; instead it provides read-only tables for chunk events, ULP primitive events, internal "other" events, and timeout events, plus lookup helpers that choose the proper table entry.

## Important APIs, Types, And Tables
The public API is `sctp_sm_lookup_event(struct net *net, enum sctp_event_type event_type, enum sctp_state state, union sctp_subtype event_subtype)`, which returns a `const struct sctp_sm_table_entry *` containing a function pointer and debug name. Invalid event families or out-of-range subtype indexes return the static `bug` entry pointing at `sctp_sf_bug()`.

The main tables are `chunk_event_table[SCTP_NUM_BASE_CHUNK_TYPES][SCTP_STATE_NUM_STATES]`, `addip_chunk_event_table`, `prsctp_chunk_event_table`, `reconf_chunk_event_table`, `auth_chunk_event_table`, `pad_chunk_event_table`, `chunk_event_table_unknown`, `primitive_event_table`, `other_event_table`, and `timeout_event_table`. The `TYPE_SCTP_FUNC()` macro stores both `.fn` and `.name`; the `TYPE_SCTP_*` macros expand to per-state rows for a specific chunk, primitive, other event, or timeout subtype.

## Control Flow
Lookup starts in `sctp_sm_lookup_event()`. Chunk events go to `sctp_chunk_event_lookup()`, timeout events index `timeout_event_table`, other events index `other_event_table`, and primitive events index `primitive_event_table`. The `DO_LOOKUP` macro bounds-checks non-chunk subtypes against their maximum values and logs a warning before returning `bug` if a subtype exceeds its legal range.

`sctp_chunk_event_lookup()` first rejects invalid states, normalizes `SCTP_CID_I_DATA` to the DATA row, and indexes base chunk IDs directly when `cid <= SCTP_CID_BASE_MAX`. Extended chunks are dispatched by switch: FWD TSN and I-FWD TSN use PR-SCTP handlers, ASCONF/ASCONF-ACK use ADD-IP handlers, RECONF uses the RE-CONFIG handler, AUTH uses the AUTH handler, and PAD always discards. Unknown chunk IDs fall back to `chunk_event_table_unknown`, whose behavior depends on state and ultimately lets `sctp_sf_unk_chunk()` apply the unknown-chunk action bits for established-style states.

The chunk table encodes protocol state legality. DATA is OOTB in CLOSED, discarded during handshake, processed in ESTABLISHED/SHUTDOWN-PENDING, handled by the shutdown fast path in SHUTDOWN-SENT, and discarded after SHUTDOWN-RECEIVED/ACK-SENT. INIT is normal in CLOSED, simultaneous in COOKIE-WAIT/COOKIE-ECHOED, duplicate in established and shutdown states, and resends SHUTDOWN ACK in SHUTDOWN-ACK-SENT. COOKIE ECHO is normal in CLOSED and duplicate-cookie logic everywhere else. SACK is accepted in COOKIE-ECHOED and established/shutdown-received style states but discarded in closed or shutdown-sent/ack-sent states.

Primitive rows describe user-facing operations. ASSOCIATE is only implemented in CLOSED. SHUTDOWN in ESTABLISHED starts graceful shutdown, in COOKIE-WAIT/ECHOED tears down early, in closed returns an error, and in shutdown states is ignored. ABORT maps to state-specific abort handlers that stop the appropriate timers. SEND is accepted during COOKIE-WAIT, COOKIE-ECHOED, and ESTABLISHED, but reports closed/shutdown errors elsewhere. REQUESTHEARTBEAT is allowed in most non-closed states. ASCONF and RECONF primitives are allowed once established through shutdown-received and rejected in closed/handshake/shutdown-ack-sent states.

Timeout rows route only the states in which each timer is meaningful. T1-init fires in COOKIE-WAIT; T1-cookie in COOKIE-ECHOED; T2-shutdown in SHUTDOWN-SENT and SHUTDOWN-ACK-SENT; T3-rtx in COOKIE-ECHOED, ESTABLISHED, SHUTDOWN-PENDING, and SHUTDOWN-RECEIVED; T4-rto only in ESTABLISHED; T5 guard in SHUTDOWN-PENDING and SHUTDOWN-SENT; heartbeat in established, shutdown-pending, and shutdown-received; delayed SACK in established, shutdown-pending, and shutdown-sent; autoclose in ESTABLISHED; RECONF and PROBE in ESTABLISHED. Other timer/state combinations use `sctp_sf_timer_ignore()` or `sctp_sf_bug()` for impossible timeout-none entries.

## State And Persistence
All table data is static const and compiled into the kernel image/module. There is no runtime mutation or durable persistence in this file. Runtime state is only consumed as indexes: the current `enum sctp_state`, event family, and subtype select a handler that will mutate association state through command side effects in `sm_statefuns.c`.

The table layout persists as an ABI-like internal contract: enum numeric ordering for states, chunk IDs, primitive subtype IDs, other subtype IDs, and timeout subtype IDs must match the row order and array dimensions. Extended chunk dispatch also assumes constants such as `SCTP_CID_ASCONF`, `SCTP_CID_RECONF`, `SCTP_CID_AUTH`, and `SCTP_CID_PAD` are not part of the base direct-index range.

## Dependencies And Integration Points
This file depends on `<net/sctp/sctp.h>` and `<net/sctp/sm.h>` for state/event/chunk enums and `struct sctp_sm_table_entry`. It references nearly every state function implemented in `sm_statefuns.c`, so the two files must evolve together. The state-machine driver calls `sctp_sm_lookup_event()` before invoking the returned handler; logging uses `pr_warn()` with SCTP module formatting when subtype values exceed bounds.

The table integrates base RFC 4960 behavior with extension chunks and timers: ADD-IP ASCONF, PR-SCTP FORWARD TSN/I-FORWARD TSN, RE-CONFIG, AUTH, PAD discard, ECN chunks, heartbeat/probe timers, autoclose, and internal events such as `NO_PENDING_TSN` and `ICMP_PROTO_UNREACH`.

## Risks
The largest risk is table drift. A wrong row or state column silently routes protocol events to the wrong handler, which can accept invalid traffic, discard valid traffic, fail to stop timers, leak associations, or abort live connections. Because many macros are positional rather than named initializers, the ordering of `enum sctp_state` and subtype enums is critical. Adding a new SCTP state, primitive, timeout, base chunk, or extension chunk requires updating dimensions, maximum checks, and every relevant row.

Bounds checking is asymmetric: non-chunk tables use `DO_LOOKUP`, while chunks rely on `sctp_chunk_event_lookup()` and direct `cid <= SCTP_CID_BASE_MAX` indexing. Any mismatch between chunk ID values and `SCTP_NUM_BASE_CHUNK_TYPES` would become an indexing bug. Unknown chunks must preserve the RFC action-bit behavior by reaching `sctp_sf_unk_chunk()` outside CLOSED; mapping unknown chunks to generic discard would break extension negotiation semantics. The `SCTP_CID_I_DATA` normalization intentionally routes interleaved DATA to DATA state policy before deeper stream logic validates format, so that path must remain aligned with stream interleaving support.

## Test Signals
Useful tests are dispatch-focused. For every state, feed representative chunk IDs and assert the selected function name: INIT, INIT ACK, COOKIE ECHO/ACK, DATA/I-DATA, SACK, ABORT, SHUTDOWN, SHUTDOWN ACK, SHUTDOWN COMPLETE, ERROR, HEARTBEAT/ACK, ECNE/CWR, ASCONF/ACK, FWD TSN/I-FWD TSN, RECONF, AUTH, PAD, and unknown chunks with all action-bit combinations. Primitive dispatch tests should cover ASSOCIATE, SHUTDOWN, ABORT, SEND, REQUESTHEARTBEAT, ASCONF, and RECONF across all states. Timer dispatch tests should cover T1/T2/T3/T4/T5/HEARTBEAT/SACK/AUTOCLOSE/RECONF/PROBE in both valid and invalid states. Negative tests should pass out-of-range primitive/other/timeout subtypes and invalid states to confirm `sctp_sf_bug()` or timer ignore behavior and warning paths.

# Research: sources/distributed-fs/ceph-client/rust/kernel/uaccess.rs

## sources/distributed-fs/ceph-client/rust/kernel/uaccess.rs

Purpose: provides safe-positioned wrappers for userspace memory access. Important APIs/types are `UserPtr`, `UserSlice`, `UserSliceReader`, `UserSliceWriter`, reader methods `skip/clone_reader/len/is_empty/read_raw/read_slice/read_slice_partial/read_slice_file/read<T>/read_all/strcpy_into_buf`, writer methods `len/is_empty/write_slice/write_dma/write_slice_partial/write_slice_file/write<T>`, and helper `raw_strncpy_from_user`.

Control flow: `UserSlice::new` records an unchecked user address and length; actual validation happens in copy functions. Creating readers/writers consumes the slice to discourage accidental double fetch. Reads and writes check remaining length, call `copy_from_user`, `_copy_from_user`, `copy_to_user`, or `_copy_to_user`, then advance pointer and reduce length only on success. File-offset helpers reject negative offsets and update offsets by transferred bytes. `strcpy_into_buf` bounds by slice length, uses `strncpy_from_user`, adds/validates NUL termination, and returns `&CStr`. DMA writes copy from coherent memory by raw pointer without forming a normal slice. State is the current user pointer and remaining length. Dependencies include allocator vectors, `Coherent`, file offsets, `KnownSize`, `FromBytes`, `AsBytes`, `CStr`, and uaccess bindings. Integration points are syscall/ioctl/file read-write paths and drivers exposing buffers to userspace. Risks include TOCTOU when cloning or recreating readers, partial modification on error, typed reads requiring valid-any-bit-pattern `FromBytes`, writes leaking padding unless `AsBytes` is correct, offset overflow assumptions, and kernel threads without a current userspace mm. Test signals: bad address `EFAULT`, short buffers, partial offset behavior, NUL string edge cases, DMA range errors, and race-oriented tests that validate copied data after every read.

## sources/distributed-fs/ceph-client/fs/smb/client/compress.c

Purpose: implements SMB 3.1.1 client-side message compression decisions and transmit wrapping for READ/WRITE traffic when compression was negotiated and enabled for the share. It contains a write-data compressibility heuristic, a request-level `should_compress()` gate, and `smb_compress()` which builds an SMB2 compression transform around an LZ77-compressed write payload or falls back to sending the original request.

Important APIs, types, and functions: exported functions are `should_compress(const struct cifs_tcon *, const struct smb_rqst *)` and `smb_compress(struct TCP_Server_Info *, struct smb_rqst *, compress_send_fn)`. Local heuristic helpers include `collect_sample()`, `is_compressible()`, `has_repeated_data()`, `is_mostly_ascii()`, `calc_byte_distribution()`, `has_low_entropy()`, and `cmp_bkt()`. `struct bucket` stores sampled byte frequency counts. `smb_compress()` depends on `lz77_compressed_alloc_size()` and `lz77_compress()` from `compress/lz77.c`.

Control flow: `should_compress()` rejects missing tcon/session/server, disabled negotiated compression, shares without `SMB2_SHAREFLAG_COMPRESS_DATA`, and commands other than SMB2 WRITE/READ. READ requests are allowed after the negotiation/share gates because the server response may be compressed. WRITE requests must be at least `SMB_COMPRESS_MIN_LEN` and pass `is_compressible()`. The heuristic samples 2 KiB chunks with 2 KiB gaps at page-size cadence up to 4 MiB, first accepting repeated half-sample data and mostly ASCII data, then sorting byte buckets by frequency and classifying byte distribution, using approximate Shannon entropy only for the ambiguous middle case.

State and persistence behavior: no persistent state is stored. `is_compressible()` copies from a temporary `iov_iter` clone and does not advance the caller's iterator. `smb_compress()` copies the original write data into a temporary source buffer, allocates a worst-case destination buffer, compresses with LZ77, and sends a stack-local `struct smb_rqst` containing compression header, original SMB2 write request iov, and compressed payload. On LZ77 failure with `-EMSGSIZE` or non-beneficial output length, it sends the original uncompressed request.

Dependencies and integration points: integrates with SMB2 write send paths in `smb2pdu.c` and low-level transport in `transport.c`, using `compress_send_fn` so the transport can pass `__smb_send_rqst()`. It depends on SMB2 compression header definitions in common `smb2pdu.h`, CIFS server/tcon state in `cifsglob.h`, I/O iterators, kernel allocation helpers, sorting, and the LZ77 implementation. Negotiation state is populated by SMB2 negotiate context parsing, and share compression state comes from tree connect flags.

Risks: the heuristic intentionally trades CPU for avoiding wasted compression, but bad thresholds can either waste CPU on incompressible writes or miss useful compression. `smb_compress()` currently validates that the first iov is exactly an SMB2 write request, so call sites must not pass transformed/chained layouts. Large writes allocate full source and worst-case destination buffers with `kvzalloc()`, which can be expensive under memory pressure. The compression header `Offset` assumes the uncompressed SMB2 write request iov precedes the compressed data exactly as built. Compression plus encryption is disabled by the caller today; changing that ordering would require careful transform stacking validation.

Test signals: mount with `compress` against SMB 3.1.1 servers that negotiate LZ77 and set share compression; write tests below and above `PAGE_SIZE`; incompressible random/encrypted-like data should fall back to plain send; repeated, sparse, and ASCII-heavy data should compress; short-copy and allocation-failure fault injection should return `smb_EIO` or `-ENOMEM`; verify the original iterator remains reusable; inspect transform header fields and offset on the wire; confirm READ requests pass the gate without local compression; and confirm encrypted requests are not routed through this path until supported.

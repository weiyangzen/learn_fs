# sources/distributed-fs/ceph-client/fs/eventpoll.c

Purpose: Implements Linux epoll: creation of epoll file descriptors, interest-set management, wakeup callbacks attached to target files, ready-list delivery to userspace, nested-epoll loop/path checks, file-release cleanup, optional busy-poll controls, and proc/sysctl observability.

Important APIs, types, and functions: `struct eventpoll` owns the mutex, wait queues, ready list, overflow list, RB tree of interests, watched user, owning file, reverse refs, refcount, wakeup source, and optional busy-poll parameters. `struct epitem` represents one watched file/fd pair with RB node, ready-list link, per-file hlist link, waitqueue registrations, event mask/data, and optional wakeup source. `ep_poll_callback()` is installed on target wait queues. `ep_insert()`, `ep_modify()`, and `ep_remove()` implement control operations. `ep_send_events()` and `ep_poll()` implement event transfer and waiting. `do_epoll_ctl()`, `do_epoll_wait()`, `do_epoll_pwait()`, and syscall wrappers expose the ABI. `eventpoll_release_file()` cleans up watches when target files close.

Control flow: `epoll_create*()` allocates `eventpoll`, initializes locks/lists/RB tree, creates an anonymous inode file, and publishes the fd. `epoll_ctl(ADD)` validates the epoll fd and target pollability, checks EPOLLEXCLUSIVE constraints, locks the target epoll graph when needed, prevents cycles and excessive wakeup paths, allocates an `epitem`, attaches it to the target file's `f_ep` hlist, inserts it into the epoll RB tree, registers poll waitqueue callbacks, and queues it ready if the target is already readable/writable. Wakeups from target files enter `ep_poll_callback()`, filter by interest mask, queue the item on `rdllist` or `ovflist`, manage wakeup sources, and wake epoll waiters. `epoll_wait()` first tries ready delivery, then optionally busy-polls, installs an exclusive wait entry under `ep->lock`, sleeps with timeout slack, and retries until events, timeout, or signal. `ep_send_events()` steals `rdllist`, sets `ovflist` active to catch concurrent callbacks, re-polls each item, copies events to userspace, applies ONESHOT/edge/level-trigger rules, and merges overflow events back.

State and persistence behavior: Interest state persists in the epoll anonymous file until explicit `DEL`, epoll fd release, or watched file release. The RB tree is protected by `ep->mtx`; ready and overflow lists are protected by `ep->lock`. Target files maintain reverse links through `file->f_ep` so close can remove all epoll watches. `ep->refcount` keeps eventpoll objects alive while epitems reference them. Per-user watch counts enforce `max_user_watches`, initialized from low memory and exposed via sysctl.

Dependencies and integration points: Integrates with VFS `->poll`, waitqueue callbacks, anon inodes, fd helpers, user-copy helpers, signals/timeouts, proc fdinfo, sysctl, RCU, SLAB_TYPESAFE_BY_RCU file lifetime rules, wakeup sources for `EPOLLWAKEUP`, capabilities, optional network busy poll and NAPI IRQ control, `KCMP` target lookup, and compat syscall variants.

Risks: Lock ordering is central: `epnested_mutex`, then `ep->mtx`, then `ep->lock`; callback paths can run in IRQ context and cannot sleep. Ready-list transfer relies on `ovflist` to avoid lost events while copying to userspace. Nested epoll needs both loop detection and reverse path limits to avoid deadlocks and wakeup storms. File teardown races require careful `file_ref_get()` and reverse-link removal. `POLLFREE` requires RCU-safe waitqueue handling. ONESHOT, EPOLLET, EPOLLEXCLUSIVE, and EPOLLWAKEUP each alter wakeup semantics and are easy to regress.

Test signals: Cover add/mod/del duplicate and missing fd cases, self-add rejection, nested epoll cycles and depth limit, reverse path limit, level-trigger requeue, edge-trigger one-shot delivery, ONESHOT disable and MOD rearm, EPOLLEXCLUSIVE validation and wake-one behavior, EPOLLWAKEUP capability filtering, concurrent close of watched files, POLLFREE waitqueue destruction, userspace copy faults during delivery, timeout and signal behavior for wait/pwait/pwait2, compat syscalls, fdinfo listing, sysctl watch limit enforcement, busy-poll ioctls and permission checks, and stress with many watched descriptors.

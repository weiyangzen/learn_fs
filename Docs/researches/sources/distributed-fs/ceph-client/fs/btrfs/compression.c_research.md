# sources/distributed-fs/ceph-client/fs/btrfs/compression.c

Purpose: implements the shared Btrfs compression engine around compressed bios, compressed folio allocation, per-filesystem compression workspaces, inline/extent decompression dispatch, and the sampling heuristic used to decide whether writeback should attempt compression. It is algorithm-neutral glue for zlib, lzo, zstd, and the "heuristic" pseudo-workspace, while algorithm-specific transforms live in the matching compression backends.

Important APIs/types/functions: `btrfs_compress_type2str()` and `btrfs_compress_is_valid_type()` map and validate mount/user strings. `struct compressed_bio` instances are allocated by `alloc_compressed_bio()`, `btrfs_alloc_compressed_write()`, and `btrfs_compress_bio()`, then completed by `end_bbio_compressed_read()` or `end_bbio_compressed_write()`. Read submission is `btrfs_submit_compressed_read()`, encoded-write submission is `btrfs_submit_compressed_write()`, full-bio decompression is `btrfs_decompress_bio()`, inline decompression is `btrfs_decompress()`, and decompressed buffer copying is `btrfs_decompress_buf2page()`. Workspace management is `btrfs_alloc_compress_wsm()`, `btrfs_free_compress_wsm()`, `btrfs_get_workspace()`, `btrfs_put_workspace()`, and zstd-specific manager hooks. The global compressed folio pool is served by `btrfs_alloc_compr_folio()`, `btrfs_free_compr_folio()`, `btrfs_compr_pool_count()`, and `btrfs_compr_pool_scan()`. Heuristic code uses `struct heuristic_ws`, `heuristic_collect_sample()`, `byte_set_size()`, `byte_core_set_size()`, `shannon_entropy()`, `sample_repeated_patterns()`, and `btrfs_compress_heuristic()`.

Control flow: compressed reads arrive as a normal `btrfs_bio` targeting file-cache folios. `btrfs_submit_compressed_read()` looks up the compressed extent map, allocates a separate compressed `compressed_bio`, allocates enough compression folios for the on-disk payload, optionally extends the original bio with speculative readahead pages from the same compressed extent, and submits the compressed bio at the original disk sector. Completion calls `end_bbio_compressed_read()`, which runs `btrfs_decompress_bio()`, copies decompressed bytes into the original bio through the algorithm backend and `btrfs_decompress_buf2page()`, zero-fills any remaining original bio range on success, ends the original bio, and returns compressed folios to the pool. Compressed writeback calls `btrfs_compress_bio()`, allocates a write bio, chooses a clamped compression level, gets the right workspace, invokes the selected algorithm compressor, and returns a `compressed_bio` whose size is the compressed payload. Completion finishes the ordered extent, optionally clears page-cache writeback over the original file range, frees compressed folios, and drops the bio.

State and persistence: persistent process-wide state includes `btrfs_compressed_bioset` and the global `compr_pool` shrinker-backed list of order-0 folios. Per-filesystem state is the `fs_info->compr_wsm[]` array of workspace managers, with one pseudo-manager for the heuristic and algorithm managers for zlib/lzo/zstd. Each `compressed_bio` records the original inode range, compression type, writeback behavior, optional original read bio, embedded `btrfs_bio`, and ordered extent pointer. Compression does not create durable metadata by itself; durable effects happen through ordered extent completion, extent items written elsewhere, file data checksums, and incompat bits set by users of compression such as defrag. The folio pool is deliberately transient and drainable by the shrinker and module exit.

Dependencies and integration: depends on Btrfs bio helpers, extent maps, ordered extents, extent-IO state bits, subpage helpers, filemap/folio APIs, memalloc NOFS handling, PSI memstall accounting, shrinkers, biosets, and zlib/lzo/zstd backend APIs declared in `compression.h`. It integrates with mount/remount compression choices through type/level validation, with inline extent reads through `btrfs_decompress()`, with normal read IO through `btrfs_submit_compressed_read()`, with writeback through `btrfs_compress_bio()`, and with defrag compression through the same type and level validation.

Risks: read readahead for compressed extents is conservative and disabled for current subpage and block-size-greater-than-page-size cases, so behavior differs by sectorsize and folio order. `btrfs_compress_is_valid_type()` accepts strings with a valid prefix, which is intentional for option parsing but risky if reused as exact validation. Workspace acquisition never returns allocation failure and can wait indefinitely, relying on preallocation and bounded compression time; failed initial preallocation is only warned and retried. `heuristic_collect_sample()` assumes pages exist in the mapping and uses `find_get_page()` without local NULL handling, so it depends on callers invoking it only for prepared page-cache ranges. The compressed folio pool caches only order-0 folios and has global thresholds, so memory pressure and large-folio/block-size paths must be tested separately. Completion paths are sensitive to inode lifetime: after ordered extent finish or writeback clearing, comments note the inode may be gone.

Test signals: build with zlib, lzo, and zstd enabled; mount with each compression type and several levels; exercise regular writeback compression, encoded compressed writes through `btrfs_submit_compressed_write()`, inline compressed reads, random reads inside compressed extents, and speculative readahead. Check low-memory paths by forcing workspace allocation failures and shrinker scans, verify no compressed folio leaks after bio errors, and test subpage and block-size-greater-than-page-size configurations where readahead/pooling is disabled. Heuristic signals include highly repetitive data, text-like data, encrypted/random data, sparse/hole-adjacent data, and boundary ranges smaller than the sample interval. Error-injection should cover failed extent-map lookup, failed compressed folio allocation, failed bio add, decompressor errors, and ordered-extent completion with writeback errors.

# sources/distributed-fs/ceph-client/fs/ufs/super.c

`super.c` owns UFS filesystem registration, mount/reconfigure/unmount, superblock parsing, export support, inode cache setup, statfs, error policy, and delayed superblock syncing. It converts mount options and on-disk UFS variants into `struct ufs_sb_info` and `struct ufs_sb_private_info`.

Key integration objects are the `ufs` `file_system_type`, `ufs_context_ops`, `ufs_super_ops`, and `ufs_export_ops`. `ufs_parse_param()` handles `ufstype=` and `onerror=`, while `ufs_fill_super()` allocates private state, selects flavour-specific sizes/flags, probes endian/magic, retries with on-disk fragment/superblock sizes or NeXTstep offsets, validates clean state, derives geometry and limits, loads the root inode, copies summary totals, and reads cylinder groups for writable mounts. `ufs_setup_cstotal()`, `ufs_put_cstotal()`, `ufs_read_cylinder_structures()`, and `ufs_put_super_internal()` move summary/cylinder metadata between disk buffers and in-core caches. `ufs_sync_fs()` and `ufs_mark_sb_dirty()` update timestamps/state and schedule delayed sync work; `ufs_reconfigure()` handles ro/rw transitions; `ufs_statfs()` reports free blocks/inodes.

Persistent state includes `fs_clean`, `fs_time`, Sun fs_state, cylinder summaries, and cylinder groups. Errors can mark the filesystem bad and force read-only. Dependencies include fs_context, block-device mounting, NFS export helpers, UFS inode/cylinder/buffer helpers, byte swapping, and on-disk layouts. Risks are flavour/endian detection, clean-state logic, retry cleanup, rw gating, delayed work lifetime, and cylinder I/O failures. Tests need representative UFS images, remounts, statfs checks, export handles, sync behavior, and fault injection.

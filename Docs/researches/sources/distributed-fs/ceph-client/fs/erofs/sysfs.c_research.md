# sources/distributed-fs/ceph-client/fs/erofs/sysfs.c

Purpose: Provides EROFS sysfs exposure under `/sys/fs/erofs`, including global feature-advertisement files and per-mounted-superblock tunables.

Important APIs, types, and functions: `struct erofs_attr` extends `struct attribute` with an attribute ID plus an offset into either `struct erofs_sb_info` or `struct erofs_mount_opts`. Macro families such as `EROFS_ATTR_RW_UI`, `EROFS_ATTR_FUNC`, and `EROFS_ATTR_FEATURE` declare attributes. `erofs_attr_show()` renders supported features, unsigned integer fields, boolean fields, and optional compression acceleration engines. `erofs_attr_store()` updates integer/boolean tunables, handles `drop_caches`, and optionally configures zip acceleration engines. `erofs_register_sysfs()` and `erofs_unregister_sysfs()` attach and detach a per-superblock kobject. `erofs_init_sysfs()` registers the root kset and feature kobject; `erofs_exit_sysfs()` releases them.

Control flow: Module init calls `erofs_init_sysfs()`, which names and registers the `erofs_root` kset under `fs_kobj`, then adds a `features` kobject with static read-only feature attributes. During mount, `erofs_register_sysfs()` initializes `sbi->s_kobj`, assigns the EROFS kset, adds the kobject under the superblock sysfs name, and waits on `s_kobj_unregister` if initialization fails. Attribute reads map the requested `erofs_attr` to either a constant response or an in-memory field. Attribute writes parse input with `kstrtoul()`, validate range, and store directly into runtime mount state. Unmount removes the kobject only if it reached sysfs, then waits for release completion.

State and persistence behavior: Sysfs stores no on-disk state. Runtime writes modify fields such as `sync_decompress` and `dir_ra_bytes` in the mounted `erofs_sb_info`; `drop_caches` causes immediate cache invalidation rather than storing a value. Feature files always print `supported` for features compiled into this source table. The release path uses a completion embedded in `erofs_sb_info` to prevent freeing superblock-private memory while sysfs still owns a kobject reference.

Dependencies and integration points: Depends on the EROFS superblock layout in `internal.h`, compression helpers in `compress.h`, kobject/kset sysfs APIs, the managed compressed-data mapping (`MNGD_MAPPING`), `z_erofs_shrink_scan()`, and optional acceleration hooks (`z_erofs_crypto_*`). It is called from `super.c` during module init/exit and mount/unmount.

Risks: Offset-based attribute access is compact but brittle if an attribute is declared with the wrong struct type or field type. Writable attributes are updated without additional locking, so consumers must tolerate racy reads of simple scalar tunables. `drop_caches` can trigger broad cache invalidation and shrinker activity, so it needs coverage under concurrent reads. Acceleration store disables all engines before enabling the requested list; a later parse failure can leave all engines disabled.

Test signals: Verify `/sys/fs/erofs/features/*` content, per-mount kobject names, mount/unmount races, rejected invalid `sync_decompress` and boolean values, `dir_ra_bytes` round trips, `drop_caches` values 1 through 3, invalid `drop_caches` ranges, and acceleration-engine parsing when `CONFIG_EROFS_FS_ZIP_ACCEL` is enabled.

# sources/distributed-fs/ceph-client/fs/erofs/zutil.c

Purpose: Provides shared utilities for compressed EROFS: global temporary decompression buffers, a reserved page pool, pagepool allocation/release helpers, and the global shrinker that reclaims compressed pcluster cache entries across mounted superblocks.

Important APIs, types, and functions: `struct z_erofs_gbuf` owns a spinlock, vmapped buffer, backing page array, and page count. `z_erofs_gbuf_init()`, `z_erofs_gbuf_growsize()`, `z_erofs_get_gbuf()`, `z_erofs_put_gbuf()`, and `z_erofs_gbuf_exit()` manage per-CPU-like global buffers. `__erofs_allocpage()` and `erofs_release_pages()` allocate from a request pagepool, optional reserved pool, or the page allocator. `erofs_shrinker_register()` and `erofs_shrinker_unregister()` add/remove mounted superblocks from the shrinker list. `erofs_init_shrinker()` installs the kernel shrinker, whose count and scan callbacks are `erofs_shrink_count()` and `erofs_shrink_scan()`.

Control flow: Module init allocates the global buffer descriptors, initializes spinlocks, and registers the shrinker. Buffer growth is serialized by a mutex, allocates pages for each buffer, vmaps them, then swaps each buffer under its spinlock; old vmaps are released after the pointer swap. A decompressor caller disables migration, selects a buffer by CPU modulo buffer count, locks it, and receives the pointer only if large enough. Page allocation first consumes a caller pagepool, then the reserved global pool if allowed, then `alloc_page()`. Releasing pages preferentially refills the reserved pool. Mounted superblocks are added to a global list; shrink scans iterate fairly, trylock each superblock's unmount mutex, and call `z_erofs_shrink_scan()` until enough pclusters are freed.

State and persistence behavior: All state is runtime-only. Module parameters `global_buffers` and `reserved_pages` size the global buffer/reserved-page behavior. `erofs_global_shrink_cnt` tracks globally reclaimable pcluster objects. `erofs_sb_list`, `shrinker_run_no`, and each superblock's `shrinker_run_no` coordinate fair scanning. Superblocks remain on the shrink list only while mounted.

Dependencies and integration points: Supports decompressor implementations that need global work buffers, `zdata.c` pagepool and pcluster reclaim, sysfs `drop_caches`, superblock mount/unmount in `super.c`, and the kernel shrinker API. Uses vmalloc/vmap, bulk page allocation, migration disabling, spinlocks, mutexes, and list iteration.

Risks: `z_erofs_get_gbuf()` assumes a nonzero global-buffer count and pairs migration disable with spinlock ownership; misuse can deadlock or corrupt per-CPU buffer selection. Buffer growth has partial-allocation cleanup complexity. Reserved pages are shared globally, so accounting bugs can leak or double-put pages. Shrinker unregister loops until the superblock XArray is empty; if pcluster references never drop, unmount can spin with reschedules. Shrinker scans must not race with unmount list removal.

Test signals: Validate module parameters at zero and nonzero values, buffer growth before/after decompression starts, concurrent `get_gbuf`/`put_gbuf`, allocation failure during growth, reserved-page refill/drain, pagepool LIFO behavior, global shrink count transitions, sysfs drop-caches invoking shrink, unmount with cached pclusters, and concurrent shrink scans across multiple mounted EROFS filesystems.

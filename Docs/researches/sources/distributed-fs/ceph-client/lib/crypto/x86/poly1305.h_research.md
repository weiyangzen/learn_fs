# sources/distributed-fs/ceph-client/lib/crypto/x86/poly1305.h

## Purpose
x86_64 Poly1305 architecture glue. It declares the assembly routines generated from `poly1305-x86_64-cryptogams.pl`, defines the x86 context overlay, selects scalar/AVX/AVX2/AVX512 at runtime, and protects SIMD execution with kernel FPU APIs.

## APIs, Control Flow, And Integration
`struct poly1305_arch_internal` overlays the generic state with base-2^26 limbs, `is_base2_26`, base-2^64 `hs`, `r`, `pad`, and `rn[9]` key powers. `convert_to_base2_64()` converts AVX state back to scalar form. `poly1305_blocks()` selects scalar for no AVX, short messages below 18 blocks without SIMD setup, or unusable FPU; otherwise it processes up to 4 KiB per `kernel_fpu_begin/end()` using AVX512, AVX2, or AVX. `poly1305_emit()` selects scalar or AVX finalization. `poly1305_mod_init_arch()` enables static keys from boot CPU features and xstate, suppressing AVX512 on Skylake-X.

## State, Dependencies, Risks, And Tests
Static keys persist after init; per-message state persists in the Poly1305 context. Dependencies include CPU feature helpers, static branches, `<asm/fpu/api.h>`, generic Poly1305 types, and exact assembly offsets. Risks include FPU misuse, context layout drift, and incorrect base conversion when callers switch execution contexts. Tests should cover short/long messages, 4 KiB chunking, AVX-to-scalar fallback, and dispatch matrices with AVX, AVX2, AVX512, and no AVX.

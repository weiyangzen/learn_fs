# sources/distributed-fs/ceph-client/arch/riscv/purgatory/Makefile

Purpose: builds the standalone RISC-V kexec purgatory image and embeds it into the kernel. Important variables/rules include `purgatory-y`, `PURGATORY_OBJS`, copied string/ctype/memcpy/memset/sha256 objects, `PURGATORY_CFLAGS_REMOVE`, `PURGATORY_CFLAGS`, `purgatory.ro`, `purgatory.chk`, and `kexec-purgatory.o`. Control flow compiles freestanding objects with kernel instrumentation removed, links a relocatable purgatory object, links a non-relocatable check binary to catch unresolved symbols, and makes `kexec-purgatory.o` depend on both. State is build artifact state only; no runtime persistence. Dependencies include lib string/ctype/sha256, RISC-V assembly string routines, KASAN/CFI/ftrace/stack protector flags, and kexec purgatory ABI. Risks are unresolved symbols hidden by `ld -r`, instrumentation leaking into freestanding code, unsupported profile-guided overlapping sections, and missing string routines under sanitizer configs. Test signals: `CONFIG_ARCH_SUPPORTS_KEXEC_PURGATORY`, kexec/kdump boot, sanitizer/ftrace/CFI build variants, and `purgatory.chk` link failures.

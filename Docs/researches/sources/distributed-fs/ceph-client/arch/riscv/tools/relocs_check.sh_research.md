# sources/distributed-fs/ceph-client/arch/riscv/tools/relocs_check.sh

Purpose: filters generic relocation-check output for RISC-V vmlinux builds and reports suspicious relocations. Important inputs are objdump path, nm path, and vmlinux path; important variables are `bad_relocs` and `num_bad`. Control flow validates argument count, invokes `${srctree}/scripts/relocs_check.sh`, removes accepted `R_RISCV_RELATIVE` and `R_RISCV_NONE` records, exits success if none remain, otherwise prints a warning and the remaining lines. State is shell-local only. Dependencies include `srctree`, generic relocs script, `grep`, `wc`, and relocation names emitted by binutils/LLVM tools. Integration is with architecture post-link validation for relocatable kernels. Risks include filtering out too much if relocation names change format, warning rather than failing, quoting sensitivity around tool paths, and dependence on `srctree` being set. Test signals: vmlinux containing only allowed relocations, injected unsupported relocation, LLVM/binutils output variants, and missing argument path.

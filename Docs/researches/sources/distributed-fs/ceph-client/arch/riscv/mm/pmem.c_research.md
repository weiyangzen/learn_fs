# sources/distributed-fs/ceph-client/arch/riscv/mm/pmem.c

Purpose: provides the RISC-V persistent-memory cache maintenance hooks required by libnvdimm/DAX code. Important APIs are `arch_wb_cache_pmem` and `arch_invalidate_pmem`, both GPL-exported. Control flow first prefers platform `noncoherent_cache_ops` callbacks when `CONFIG_RISCV_NONSTANDARD_CACHE_OPS` supplies them, otherwise emits architecture CMO alternatives through `ALT_CMO_OP` using `riscv_cbom_block_size`. State is external: the global noncoherent cache operation table and probed cache block size. There is no persistence, but correctness directly affects durability of persistent memory writes. Dependencies include `linux/libnvdimm.h`, `asm/cacheflush.h`, `asm/dma-noncoherent.h`, `virt_to_phys`, and RISC-V alternative patching. Risks are missing cache operation support on noncoherent platforms, incorrect physical address conversion for non-linear addresses, and block-size mismatches. Test signals: pmem flush/invalidate tests, DAX fsync/powerfail validation, nonstandard ops platforms, and CMO-disabled fallback behavior.

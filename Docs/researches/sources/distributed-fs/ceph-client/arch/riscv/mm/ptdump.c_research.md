# sources/distributed-fs/ceph-client/arch/riscv/mm/ptdump.c

Purpose: implements debugfs page-table dumping and W+X mapping checks for RISC-V. Important types/functions include `pg_state`, `addr_marker`, `ptd_mm_info`, `prot_bits`, `pg_level`, `note_page`, `ptdump_walk`, `ptdump_check_wx`, and `ptdump_init`. Control flow initializes address markers for fixmap, PCI I/O, vmemmap, vmalloc, linear mapping, KASAN, modules, and kernel mappings; `ptdump_walk_pgd` calls the note callbacks, which coalesce adjacent entries with matching level/protection and print ranges. `ptdump_check_wx` walks kernel mappings without a `seq_file`, counting writable executable pages. State is transient per walk, plus static marker tables and debugfs files; no persistent data is written. Dependencies include generic `linux/ptdump.h`, debugfs/seq_file, RISC-V page bits including Svpbmt/NAPOT, EFI runtime mappings, KASAN, and `init_mm`. Risks include marker ordering mistakes, incorrect protection masks for new PTE bits, false W+X reports over huge/NAPOT mappings, and debugfs-only observability. Test signals: read `kernel_page_tables`, EFI table dumping, `CONFIG_DEBUG_WX`, KASAN/Svpbmt/NAPOT configs, and boot logs from `ptdump_check_wx`.

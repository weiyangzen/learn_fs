# sources/distributed-fs/ceph-client/arch/riscv/net/bpf_jit_comp32.c

Purpose: implements the RV32G eBPF JIT backend by representing each 64-bit BPF register as high/low 32-bit RISC-V storage, with some callee-saved BPF registers spilled in a scratch area. Important functions include `emit_imm*`, `emit_alu_i64`, `emit_alu_r64`, `emit_branch_r64`, `emit_bcc`, `emit_call`, `emit_bpf_tail_call`, `emit_load_r64`, `emit_store_r64`, `bpf_jit_emit_insn`, and prologue/epilogue builders. Control flow translates each BPF opcode to RV32 instruction sequences, handles long branches with extra jumps, stores BPF R6-R9/AX on stack, emits helper calls through fixed `lui/jalr` sequences, and implements tail calls by decrementing the tail-call counter then jumping to `prog->bpf_func + 4`. State is held in `rv_jit_context` and stack layout: saved registers, BPF scratch registers, BPF stack, and call stack. Dependencies include BPF helper address resolution, verifier zext metadata, RISC-V instruction encoders, `struct bpf_array`, and kernel calling convention. Risks include carry/borrow mistakes in 64-bit arithmetic, unsupported 64-bit div/mod and 8-byte atomics, branch range convergence issues, stack spill offset errors, and tail-call prologue assumptions. Test signals: BPF selftests on RV32, arithmetic/branch/endian tests, helper-call and tail-call programs, stack-depth tests, atomic rejection paths, and JIT convergence failures.

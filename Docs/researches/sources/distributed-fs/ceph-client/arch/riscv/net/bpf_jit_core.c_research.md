# sources/distributed-fs/ceph-client/arch/riscv/net/bpf_jit_core.c

Purpose: provides common RISC-V BPF JIT orchestration independent of RV32/RV64 instruction lowering. Important APIs include `build_body`, `bpf_jit_needs_zext`, `bpf_int_jit_compile`, `bpf_jit_alloc_exec_limit`, `bpf_arch_text_copy`, `bpf_arch_text_invalidate`, and `bpf_jit_free`. Control flow allocates/reuses `rv_jit_data`, initializes context, estimates offsets, runs up to `NR_JIT_ITERATIONS` until code size converges, allocates packed RW/RX images plus exception table space, runs a final emission pass, finalizes executable memory, fills line info, and frees intermediate state. State is stored in `prog->aux->jit_data`, `ctx->offset`, packed binary headers, and BPF aux fields (`bpf_func`, `jited`, `jited_len`, `extable`). Dependencies include backend prologue/epilogue/insn emitters, BPF binary pack allocator/finalizer, RISC-V text patching, CFI offset handling, and arena address helpers. Risks include non-converging offsets, final-pass failures after subprogram JITing, stale `jit_data`, incorrect RO/RW address use for relative offsets, and text patching failures. Test signals: BPF JIT enable levels, subprogram JITs, line info, exception table sizing, JIT pack allocation failure paths, and `bpf_jit_free` after partial compilation.

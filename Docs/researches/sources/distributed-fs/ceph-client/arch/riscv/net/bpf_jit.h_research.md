# sources/distributed-fs/ceph-client/arch/riscv/net/bpf_jit.h

Purpose: is the shared instruction encoding and helper layer for RV32/RV64 BPF JIT backends. Important APIs/types include `rv_jit_context`, `rv_jit_data`, RISC-V register enums, `emit`, `emitc`, `rv_offset`, condition inversion, immediate-range helpers, raw R/I/S/B/U/J/AMO encoders, compressed instruction encoders, extension-aware helpers, and declarations for prologue/epilogue/insn emission. Control flow is compile-time inline code generation: backends call helpers that choose compressed RVC encodings and Zba/Zbb/Zacas instructions when legal, otherwise emit base ISA sequences. State is `rv_jit_context`: generated halfword buffer, read-only image pointer, offsets, flags, stack size, exception offsets, and arena addresses. Dependencies include BPF core headers, RISC-V ISA extension detection, CFI, compressed ISA support, and kernel JIT binary packing. Risks are incorrect immediate bit packing, compressed-instruction eligibility bugs, extension detection mismatch, and offset unit confusion between halfwords and bytes. Test signals: BPF selftests on RV32/RV64, JIT dump inspection, extension matrix builds, branch range tests, atomic/cmpxchg tests, and verifier zext cases.

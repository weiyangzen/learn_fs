# sources/distributed-fs/ceph-client/arch/riscv/net/bpf_jit_comp64.c

Purpose: implements the RV64 eBPF JIT backend, including normal program JITing, exception table fixups for probe memory, text poking, trampolines, kfunc call support, percpu moves, arena access, and fsession support. Important functions include `bpf_to_rv_reg`, `emit_imm`, `emit_branch`, `emit_bpf_tail_call`, `emit_ldx/st/stx`, `emit_atomic_ld_st`, `emit_atomic_rmw`, `ex_handler_bpf`, `add_exception_handler`, `bpf_arch_text_poke`, `__arch_prepare_bpf_trampoline`, `arch_prepare_bpf_trampoline`, `bpf_jit_emit_insn`, and support predicates. Control flow marks used callee-saved registers during emission, converges offsets over multiple passes, emits KCFI/fentry/TCC prologue slots, lowers BPF opcodes to RV64/RV32W instructions, records faulting memory accesses, and builds trampolines around fentry/fexit/modify-return/original-call paths. State lives in `rv_jit_context`, BPF aux exception tables, trampoline images, and text patching locks; persistent state is none. Dependencies include BPF verifier metadata, text patching, CFI/KCFI, per-cpu offsets, stop-machine-safe text updates, RISC-V Zba/Zbb/Zacas extensions, and kernel trampoline APIs. Risks include out-of-range calls, incorrect extable fixups, live text patch races, stack layout mistakes in trampolines, unsupported arena instructions without Zacas, and prologue offset ABI assumptions. Test signals: BPF selftests, trampoline/fentry/fexit/kfunc tests, probe memory fault tests, text poke tests, CFI-enabled builds, arena atomics, and extension matrix boot tests.

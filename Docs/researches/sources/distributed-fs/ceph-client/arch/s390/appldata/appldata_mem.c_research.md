# sources/distributed-fs/ceph-client/arch/s390/appldata/appldata_mem.c

Purpose: implements the APPLDATA memory statistics provider. Important type/function are the packed `appldata_mem_data` record, `appldata_get_mem_data`, module init/exit, and static `appldata_ops`. Control flow allocates one DMA-capable data record, registers with the base, and on each callback increments `sync_count_1`, samples VM events, `si_meminfo`, file page cache, swap info, TOD timestamp, then increments `sync_count_2`. State is the binary record consumed by z/VM; the layout is compatibility-sensitive and versioned through APPLDATA product/modification metadata. Dependencies include VM event counters, sysinfo, swap, page state, TOD clock, and base registration APIs. Risks include changing packed layout, counter truncation/semantic drift, static `sysinfo` reuse relying on serialized callbacks, underflow in cached calculation, and z/VM reading while Linux updates. Test signals: module load/unload, APPLDATA start/stop sysctl, memory pressure and swap activity, sync count consistency, and record-size validation.

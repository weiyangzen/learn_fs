# sources/distributed-fs/ceph-client/arch/s390/appldata/appldata_net_sum.c

Purpose: implements the APPLDATA aggregate network statistics provider. Important type/function are packed `appldata_net_sum_data`, `appldata_get_net_sum_data`, module init/exit, and static `appldata_ops`. Control flow allocates the record, registers it, then each callback increments sync count, walks `init_net` devices under RCU, accumulates `rtnl_link_stats64` packet/byte/error/drop/collision counters, records interface count and TOD timestamp, and completes sync count. State is the z/VM-visible binary record; no disk persistence. Dependencies include netdevice iteration, `dev_get_stats`, init network namespace, RCU, TOD clock, and APPLDATA base APIs. Risks include layout compatibility, only monitoring `init_net`, counter narrowing through temporary unsigned long variables on unusual builds, devices changing during RCU iteration, and z/VM collecting mid-update. Test signals: module load/unload, APPLDATA sysctl start/stop, interface hotplug, traffic generation, counter consistency, and namespace expectations.

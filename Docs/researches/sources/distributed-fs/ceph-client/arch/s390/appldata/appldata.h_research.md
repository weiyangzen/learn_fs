# sources/distributed-fs/ceph-client/arch/s390/appldata/appldata.h

Purpose: defines the internal APPLDATA provider interface and record metadata for Linux-z/VM Monitor Stream modules. Important constants include `APPLDATA_MAX_REC_SIZE`, record IDs for memory/OS/network/process, proc name length, and legacy sysctl IDs. Important type/API is `struct appldata_ops` plus declarations for `appldata_register_ops`, `appldata_unregister_ops`, and `appldata_diag`. Control flow is defined by consumers: providers fill `appldata_ops`, register it, and the base calls its callback and DIAG function. State fields include list membership, sysctl header/table, active flag, record number, callback data pointer, record size, module owner, and EBCDIC modification level. Dependencies include kernel list/sysctl/module types and `u16`. Risks are binary record size exceeding z/VM limits, provider lifetime races around `owner` and `data`, proc name truncation, and record ID compatibility. Test signals: provider register/unregister, max record size rejection, sysctl table creation, and DIAG start/stop paths.

# sources/distributed-fs/ceph-client/arch/s390/appldata/appldata_os.c

Purpose: implements the APPLDATA OS statistics provider for CPU time, load, runnable/thread counts, and per-online-CPU data. Important types/functions include packed `appldata_os_per_cpu`, flexible `appldata_os_data`, `appldata_get_os_data`, module init/exit, and static `appldata_ops`. Control flow allocates a maximum-sized record for possible CPUs, registers it, then each callback updates sync count, scheduler/load statistics, per-online-CPU jiffies converted from `kcpustat`, CPU IDs, record size, and timestamp. If active CPU count changes while monitoring, it starts a new record with the new size and stops the old size. State is the allocated record plus `ops.size`, both visible to z/VM through DIAG. Dependencies include scheduler statistics, loadavg, CPU iteration, TOD clock, APPLDATA base, and record-size limits. Risks are packed ABI changes, hotplug-size update ordering, DIAG failure during size transition, max record size exceeding 4024 bytes, and z/VM reads during update. Test signals: CPU hotplug, load generation, APPLDATA start/stop, sync count checks, max CPU config, and DIAG failure logging.

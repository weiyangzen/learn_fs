# sources/distributed-fs/ceph-client/arch/s390/appldata/appldata_base.c

Purpose: provides the APPLDATA base infrastructure for z/VM monitor records, exporting registration and DIAG 0xDC helpers to provider modules. Important functions include `appldata_diag`, virtual timer setup, sysctl handlers for `timer` and `interval`, `appldata_generic_handler`, `appldata_register_ops`, `appldata_unregister_ops`, and `appldata_work_fn`. Control flow uses a virtual timer to queue ordered work; the work iterates active providers and calls callbacks. Provider sysctl writes start by taking a module reference, collecting an initial record, issuing `APPLDATA_START_INTERVAL_REC`, and marking active; stop clears active and issues `APPLDATA_STOP_REC`. State includes `appldata_timer`, interval/active flags under spinlock, ordered workqueue, ops list under mutex, per-provider sysctl tables, and module reference counts. Dependencies include z/VM DIAG assembly API, vtimer, sysctl, workqueue, module refs, and provider `appldata_ops`. Risks include callback lifetime races, DIAG failure leaving module refs unbalanced, timer/work ordering during module unload, and binary record compatibility. Test signals: sysctl read/write, interval changes while active, provider load/unload while timer runs, DIAG failure injection, and lockdep around timer/work/list paths.

# sources/distributed-fs/ceph-client/arch/s390/Makefile

Purpose: supplies top-level s390 architecture build flags, machine tuning, decompressor flags, image targets, install behavior, and preparation rules. Important variables/rules include `LD_BFD`, `KBUILD_LDFLAGS`, `KBUILD_CFLAGS[_DECOMPRESSOR]`, `CC_FLAGS_MARCH`, expoline/ftrace/stack protector flags, `STACK_SIZE`, `KBUILD_IMAGE`, `bzImage`, `zfcpdump`, `archheaders`, `archprepare`, `vdso_prepare`, and `archhelp`. Control flow selects `-march/-mtune` from config, removes/sets instrumentation-sensitive flags, exports decompressor settings, builds `arch/s390/boot/bzImage`, and generates vdso offsets after prepare0 when needed. State is build graph and exported make variables only. Dependencies include compiler/linker option probes, s390 boot/tools/syscalls/vdso directories, binutils ELF target names, and generic Kbuild commands. Risks include incompatible compiler flags, expoline/ftrace interactions, vdso header ordering hacks, decompressor freestanding violations, and install target assumptions. Test signals: matrix builds for march/tune configs, Clang/GCC/binutils variants, ftrace/expoline/stackprotector builds, `make install`, and zfcpdump image generation.

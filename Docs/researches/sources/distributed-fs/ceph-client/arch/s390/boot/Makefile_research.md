# sources/distributed-fs/ceph-client/arch/s390/boot/Makefile

Purpose: builds the s390 boot/decompressor image and final `bzImage`. Important variables/rules include sanitizer disables, minimum `-march=z10`, decompressor flags, object lists, section comparison targets, linker rules for `vmlinux`/`vmlinux.syms`, symbol dumping, binary/metadata objcopy steps, compression suffix rules, `piggy.o`, and `section_cmp`. Control flow links an early-boot vmlinux from boot objects and compressed payload, verifies boot data sections match the main vmlinux, extracts `.vmlinux.info`, creates symbol blobs, compresses the main kernel, embeds it, and objcopies the final image. State is build artifact state and generated binaries only. Dependencies include boot source objects, compression tools, `objdump`, `nm`, linker scripts, relocs generated by postlink, and Kconfig compression choice. Risks include sanitizer/instrumentation leakage into early boot, section mismatch breaking preserved boot data, compression tool size metadata errors, symbol table format drift, and march flag filtering. Test signals: all compression modes, uncompressed kernel, KASLR/KMSAN/KASAN/stackprotector configs, section comparison failure injection, and boot under IPL/qemu.

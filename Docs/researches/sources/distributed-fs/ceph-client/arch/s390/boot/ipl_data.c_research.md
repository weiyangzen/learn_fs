# sources/distributed-fs/ceph-client/arch/s390/boot/ipl_data.c

Purpose: defines the initial s390 IPL lowcore data embedded at the front of the boot image. Important types/symbols are `struct ipl_lowcore`, `CCW0`, `PSW_MASK_DISABLED`, and static `ipl_lowcore` in `.ipldata`. Control flow is data-driven by firmware/channel IPL: initial PSW and CCWs load image ranges into memory, restart PSW points to `IPL_START`, and default new PSWs enter disabled wait with diagnostic addresses. State is the boot image header/lowcore contents, including CCW chains and PSW slots; no mutable runtime logic in this file. Dependencies include lowcore offsets, CCW command/flag definitions, `jump_to_kernel` symbol for debugger discovery, and the s390 IPL ABI. Risks include changing binary layout breaking firmware/file utility detection, wrong CCW ranges truncating initial load, invalid PSW masks, and `.ipldata` linker placement errors. Test signals: IPL boot, file utility recognition, objdump layout checks, restart PSW start, and disabled-wait addresses for unexpected interrupts.

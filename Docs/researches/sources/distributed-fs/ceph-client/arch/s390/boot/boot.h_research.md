# sources/distributed-fs/ceph-client/arch/s390/boot/boot.h

Purpose: is the central early-boot interface header for s390 decompressor/startup code. Important definitions include `IPL_START`, `struct vmlinux_info`, boot memory/physmem APIs, IPL/report/cert APIs, command-line parsing hooks, facility/alternative setup, VM setup, boot printing macros, `boot_panic`, linker symbols, and address translation macros. Control flow is declarative: it defines the functions and symbols used across assembly and C boot files, and maps logging to `boot_printk`. State declarations cover global machine info, loglevel controls, vmlinux metadata, boot data ranges, compressed image boundaries, stacks, and decompressor symbols. Dependencies include lowcore, physical memory info, stacktrace, printk, and linker scripts. Risks include ABI/layout drift in `vmlinux_info`, wrong address translation macros under KASLR/identity mapping, missing declarations for early boot objects, and panic paths relying on stacktrace/disabled wait. Test signals: compile coverage across boot files, KASLR/non-KASLR boot, stack protector/KASAN metadata, decompressor symbol use, and early panic diagnostics.

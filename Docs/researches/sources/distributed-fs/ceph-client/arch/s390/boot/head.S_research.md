# sources/distributed-fs/ceph-client/arch/s390/boot/head.S

Purpose: contains the low-level s390 image entry points for IPL, VM reader loading, normal startup, and inclusion of kdump startup. Important labels/symbols include `ipl_start`, loader subroutines, `startup`, entry-point ABI table at `S390EP`, `startup_normal`, and `startup_pgm_check_handler`. Control flow switches to ESAME/64-bit mode, optionally loads parameter and ramdisk files through CCW programs from the IPL device, resets VM reader state, jumps to `startup`, clears portions of lowcore, installs early PSWs/control registers, initializes TOD/timer state, stack, SCLP buffer, verifies facilities, and calls `startup_kernel`. State manipulated includes lowcore fields, control registers, IPL parameter area, initrd start/size, TOD fields, and stack. Dependencies include IPL ABI offsets, `boot.h`, SCLP, lowcore layout, CCW/IRB/ORB formats, and `head_kdump.S`. Risks are ABI-breaking table changes, incorrect absolute addressing, CCW loader edge cases, lowcore corruption, early exception handler failures, and fragile VM/native IPL detection. Test signals: IPL from disk/reader/tape-like paths, parameter file and ramdisk loading, SALIPL/PSW restart, early program-check handling, and kdump entry selection.

# sources/distributed-fs/ceph-client/arch/s390/boot/head_kdump.S

Purpose: provides the s390 kdump low-level entry and relocation/data-mover code for the crash kernel. Important symbols are `startup_kdump`, `startup_kdump_relocated`, `DATAMOVER_ADDR`, and `COPY_PAGE_ADDR`. Control flow switches to 64-bit mode, detects whether the code is already relocated, copies a small position-independent data mover to low memory and reserved memory, swaps old and new kernel ranges pagewise through a temporary page, then starts the relocated kernel through a restart PSW. Without `CONFIG_CRASH_DUMP`, it enters a disabled wait loop. State is physical memory contents during the kernel swap, base/size values read from the startup area, and restart PSWs. Dependencies include SIGP architecture switch, startup label layout, crash dump config, and absolute addressing. Risks include data mover overlap, corruption when kdump base/size are wrong, position-independent code assumptions, low-memory scratch conflicts, and silent disabled-wait failure. Test signals: crash dump boot, relocation/no-relocation paths, reserved memory sizing, disabled path when crash dump is off, and memory integrity after data mover execution.

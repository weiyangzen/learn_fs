# sources/distributed-fs/ceph-client/arch/s390/boot/decompressor.c

Purpose: wraps the selected kernel decompression library for s390 early boot and manages decompressor heap bounds. Important APIs are `mem_safe_offset`, `deploy_kernel`, and internal `decompress_error`; important variables are `free_mem_ptr` and `free_mem_end_ptr`. Control flow sets heap size by compression algorithm, includes exactly one decompressor implementation, reports failures through `boot_panic` after optional ring-buffer dump, and calls `__decompress` from `_compressed_start` to the output buffer using `vmlinux.image_size`. State is early heap pointer state and compressed image linker symbols; no persistent data. Dependencies include boot logging, linker symbols, selected compression library, page alignment, and `decompressor.h`. Risks include heap size too small for an algorithm, decompressor generic code using unsupported facilities, output size mismatch, and no recovery after decompression failure. Test signals: all compression formats, corrupted compressed image, bootdebug error dump, and memory-safe offset placement against initrd/boot allocations.

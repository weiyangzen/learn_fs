# sources/distributed-fs/ceph-client/arch/s390/boot/als.c

Purpose: verifies that the boot CPU supports all architectural facilities required by the kernel. Important functions are `u16_to_decimal`, `print_missing_facilities`, `facility_mismatch`, and `verify_facilities`. Control flow reads the facility list with `__stfle`, compares it against `FACILITIES_ALS`, prints missing facility numbers in bounded lines, reports detected machine type on mismatch, and enters disabled wait. State is the global `stfle_fac_list` populated during early boot; no persistence. Dependencies include SCLP/boot printing, `get_cpu_id`, lowcore disabled wait, and generated facility masks. Integration is called from `startup_normal` before `startup_kernel`. Risks include incorrect facility masks bricking boot on valid machines, output truncation hiding diagnostics, and relying on early console availability. Test signals: boot on minimum z10 and newer CPUs, forced missing facility masks, `facilities=` command-line clearing, and early boot log output.

# sources/distributed-fs/ceph-client/arch/s390/boot/alternative.c

Purpose: adapts the normal s390 alternative-instruction implementation for early boot and adds parsing of the `debug-alternative` boot parameter. Important functions are `alt_debug_all`, `alt_debug_modify`, `alt_debug_parse`, and `alt_debug_setup`, with the shared implementation included from `../kernel/alternative.c`. Control flow enables debug output globally, per alternative type, per facility/feature range, or with exclusion syntax using `!`. State is the global `alt_debug` masks and spec flag used by the alternative patching code; no persistence. Dependencies include boot printing, facility/machine-feature bit operations, command-line parser in `ipl_parm.c`, and shared alternative patcher internals. Risks include parser accepting partial malformed strings, early-boot divergence from runtime alternative code, and debug settings affecting boot log volume. Test signals: `debug-alternative`, typed/ranged filters, excluded filters, facility and machine-feature alternatives, and boot with alternative patch debug enabled.

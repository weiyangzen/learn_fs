# File Research: sources/teaching/xv6-public/x86.h

Inline x86 instruction helpers and trapframe layout.

Contents:
- Port I/O helpers: `inb`, `insl`, `outb`, `outw`, `outsl`.
- String-store helpers: `stosb`, `stosl`.
- Descriptor loading: `lgdt`, `lidt`, `ltr`.
- Interrupt and flags helpers: `readeflags`, `cli`, `sti`.
- Segment helper `loadgs`.
- Atomic `xchg`.
- Control register helpers `rcr2` and `lcr3`.
- `struct trapframe`, matching hardware and `trapasm.S` pushed state.

Role:
- Low-level architecture interface used across drivers, locks, traps, and VM.

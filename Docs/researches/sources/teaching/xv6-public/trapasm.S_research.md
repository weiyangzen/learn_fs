# File Research: sources/teaching/xv6-public/trapasm.S

Assembly trap entry/return path.

Key behavior:
- `alltraps` saves segment registers and general registers, switches data segments to kernel data, pushes the trapframe pointer, and calls `trap`.
- `trapret` restores registers/segments, discards trap number and error code, and returns with `iret`.

Important interactions:
- Vector stubs generated by `vectors.pl` jump to `alltraps`.
- `allocproc` arranges new processes to return through `trapret`.

# File Research: sources/cow-pools/bcachefs-tools/include/linux/rculist.h

This header maps Linux RCU hlist APIs to Userspace RCU equivalents. It includes URCU RCU-list headers and aliases `hlist_add_head_rcu`, `hlist_del_rcu`, `hlist_for_each_rcu`, and `hlist_for_each_entry_rcu`.

It is a thin adapter only.

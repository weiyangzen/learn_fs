# File Research: sources/cow-pools/bcachefs-tools/include/linux/ioprio.h

This header defines Linux I/O priority bit layout and constants. It provides `IOPRIO_CLASS_SHIFT`, `IOPRIO_PRIO_MASK`, class/data extraction macros, `IOPRIO_PRIO_VALUE()`, `ioprio_valid()`, I/O priority classes, selector enums, best-effort priority count, and normal fallback priority.

It is a constants-only compatibility header.

# File Research: sources/cow-pools/bcachefs-tools/include/linux/posix_acl_xattr.h

This header defines the extended-attribute wire format for POSIX ACLs. It provides `POSIX_ACL_XATTR_VERSION`, `ACL_UNDEFINED_ID`, `posix_acl_xattr_entry`, and `posix_acl_xattr_header` using little-endian integer fields.

It declares no-op/default xattr handlers `nop_posix_acl_access` and `nop_posix_acl_default`.

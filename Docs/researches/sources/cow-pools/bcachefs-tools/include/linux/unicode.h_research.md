# File Research: sources/cow-pools/bcachefs-tools/include/linux/unicode.h

Declares Unicode normalization and casefolding interfaces used by filesystem name handling. It defines Unicode version packing, `UTF8_LATEST`, normalization modes `UTF8_NFDI` and `UTF8_NFDICF`, `struct unicode_map`, and UTF-8 validate/compare/normalize/casefold/load APIs.

Implementations live under `linux/unicode/`.

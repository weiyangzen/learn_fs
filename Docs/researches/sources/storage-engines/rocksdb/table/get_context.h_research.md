# Research: sources/storage-engines/rocksdb/table/get_context.h

- **Purpose:** Declares `GetContext` and `GetContextStats`, the shared context object table readers use to communicate point lookup progress/results to upper DB layers.
- **Important APIs/types/functions:** `GetContextStats` cache and MultiGet counters; `GetContext::GetState` enum (`kNotFound`, `kFound`, `kDeleted`, `kCorrupt`, `kMerge`, `kUnexpectedBlobIndex`, `kMergeOperatorFailed`); constructors with optional timestamp support; `MarkKeyMayExist`; `SaveValue` overloads; `State`; timestamp and tombstone helpers; pinned-iterator accessor; replay-log setter; sequence/callback helpers; `ReportCounters`; blob verification key helper; `push_operand`; `replayGetContextLog`.
- **Control flow:** The declaration documents the point-lookup contract: callers initialize context with target user key and output holders, then invoke `SaveValue` for every matching internal key until it returns false, or `MarkKeyMayExist` when no-IO uncertainty prevents a definitive miss. Terminal states stop lookup except merge accumulation.
- **State and persistence behavior:** Holds pointers to comparator, merge operator, logger, stats, output values/columns, timestamp, merge context, range tombstone sequence, system clock, sequence output, replay log, pinned iterator manager, read callback, blob-index flag, tracing get id, and blob fetcher. It also stores sampled file-read state and a pinned copy of blob user key when timestamps are involved.
- **Dependencies:** Forward-declares blob, merge, comparator, logger, wide-column, pinned-iterator, statistics, clock, and parsed-key types; includes read callback/status/types.
- **Integration points:** Central to `TableReader::Get` implementations, table cache, block cache no-IO behavior, DB Get APIs, merge operand APIs, row cache replay, blob value resolution, and wide-column entity lookup.
- **Risks:** Because most members are raw pointers to optional caller-owned state, constructor argument ordering and lifetime must be correct. `TimestampSize()` assumes a non-null comparator. `SaveValue` semantics vary by `do_merge_`, `pinnable_val_` vs `columns_`, timestamp support, and blob fetcher availability.
- **Test signals:** Consumers should assert final state, value/columns contents, sequence/timestamp outputs, value-found uncertainty, merge operands/results, and stats reporting under found, not-found, deleted, merge, blob, wide-column, and callback-filtered cases.

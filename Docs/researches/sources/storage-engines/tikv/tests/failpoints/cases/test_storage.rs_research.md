# sources/storage-engines/tikv/tests/failpoints/cases/test_storage.rs

See the grouped report section in `Docs/researches/groups/subset-b-008947_research.md` for the full source-aligned research. Summary: this file is a large failpoint suite for TiKV storage scheduler, RaftKV early errors, deadline handling, async apply prewrite, pipelined/resumable pessimistic locks, shared/exclusive lock behavior, raw CAS latching, shutdown ordering, and leadership-change races. It exercises `Storage::sched_txn_command`, `TestStorageBuilderApiV1`, `MockLockManager`, MVCC readers, raw APIs, gRPC `TikvClient`, resource-control scheduling, and raftstore v1/v2 clusters. Key risks covered are stale command propagation, hidden writes after early errors, leaked locks/latches, max timestamp unsync, deadline enforcement, and shared-lock waiter correctness.

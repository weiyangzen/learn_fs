# sources/object-store/apache-ozone/hadoop-ozone/recon/src/main/resources/webapps/recon/ozone-recon-web/package.json

## Purpose

`package.json` defines the Recon web UI package metadata, dependency graph, development scripts, lint/test commands, browser targets, and mock API proxy. It describes a private Vite-based React 16 application named `ozone-recon` at version `0.2.0`, managed with `pnpm@10.28.2`.

## Important APIs, Types, Scripts, and Dependencies

Key scripts are `start` (`vite --port=3000`), `build` (`vite build`), `serve` (`vite preview`), `test` (`vitest`), `e2e` (`playwright test`), `mock:api` (`json-server --watch api/db.json --routes api/routes.json --middlewares api/pagination.js --port 9888`), `dev` (`npm-run-all --parallel mock:api start`), and ESLint commands.

Runtime dependencies include React 16, React Router 5, Ant Design 4, Axios, ECharts, AG Charts, React Markdown with GFM support, Moment, Less, Roboto font assets, filesize, classnames, pretty-ms, react-select, and TypeScript. Development dependencies include Vite 4, the SWC React plugin, Vitest, jsdom, Testing Library, MSW, Playwright, json-server 0.15.1, npm-run-all, ESLint/Prettier tooling, and React type packages.

## Control Flow

`pnpm dev` starts both the mock API on port 9888 and Vite on port 3000. The app calls `/api/v1/...` endpoints, while the mock API uses `api/routes.json` and `api/pagination.js` to serve fixture data. `pnpm e2e` invokes Playwright, whose config starts `pnpm start` unless it can reuse a local server. Build, unit test, and lint workflows are exposed through `pnpm build`, `pnpm test`, and `pnpm lint`.

## State and Persistence Behavior

Package state is dependency and tooling configuration. Installed versions are constrained here and resolved in the lockfile. Mock fixture state lives in `api/db.json` and is watched by `mock:api`. Test reports and screenshots may be generated by Playwright and individual specs.

## Dependencies and Integration Points

This manifest integrates with Vite and `playwright.config.ts` on port 3000, json-server mock files under `api`, React code under `src`, Assistant Markdown rendering via `react-markdown`/`remark-gfm`, and CI/developer commands that invoke build, test, E2E, and lint scripts.

## Risks

React 16 plus newer dev tooling can create peer-dependency pressure. Vite, TypeScript, and plugin upgrades need compatibility checks. The `proxy` field may not be sufficient for Vite unless proxying is also configured in Vite config. `lint` only targets `src/*`, which may miss nested files. `mock:api` depends on json-server v0.15 middleware ordering, and Playwright starts only `pnpm start`, not the mock API, so specs that rely on backend fixtures must stub calls or arrange a backend separately.

## Test Signals

Relevant checks are `pnpm build`, `pnpm test`, `pnpm lint`, `pnpm e2e`, and manual `pnpm dev` smoke testing. For mock API behavior, run `pnpm mock:api` and request rewritten endpoints directly.

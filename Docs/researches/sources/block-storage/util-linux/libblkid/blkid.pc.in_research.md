# File Research: sources/block-storage/util-linux/libblkid/blkid.pc.in

## Purpose
Template for the pkg-config metadata installed as `blkid.pc`.

## Main Components
- Defines `prefix`, `exec_prefix`, `libdir`, and `includedir` from configure substitutions.
- Publishes package name `blkid`, description `Block device id library`, and `@LIBBLKID_VERSION@`.
- Exposes compile flags as `-I${includedir}/blkid`.
- Exposes link flags as `-L${libdir} -lblkid`.

## Dependencies and Interactions
Generated by the build system from Autotools substitutions. Consumers use this file through `pkg-config --cflags --libs blkid`.

## Research Notes
The template intentionally points includes at the `blkid` subdirectory because the public generated header is installed as `include/blkid/blkid.h`.

# sources/control-plane/rook/pkg/operator/ceph/config/keyring/cephx.go

Purpose: CephX key rotation decision and status update policy. Important APIs include supported-version constants, `CephxKeyIdentifierAnnotation`, `ShouldRotateCephxKeys()`, `CephVersionToCephxStatusVersion()`, `parseCephVersionFromStatusVersion()`, `UninitializedCephxStatus()`, and `UpdatedCephxStatus()`. Control flow blocks rotation on unsupported running Ceph versions and uninitialized status, honors disabled/empty policy, rotates when configured key generation exceeds status, and has retained internal logic for a Ceph-version-update policy. Status rendering uses `Major.Minor.Extra-Build`, omitting commit IDs. State persists only when callers write returned status to CR status or deployment annotations. Dependencies include Ceph API Cephx types and Ceph version comparison helpers. Risks include strict status parsing, disabled public policy value for version update, preserving brownfield empty status when no rotation occurs, and version constants gating auth rotate support.

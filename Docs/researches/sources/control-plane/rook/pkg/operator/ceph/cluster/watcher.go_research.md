# sources/control-plane/rook/pkg/operator/ceph/cluster/watcher.go

Purpose: event helper logic for Node and hot-plug device ConfigMap watches. APIs include `clientCluster`, `newClientCluster()`, `checkStorageForNode()`, `onK8sNode()`, `onDeviceCMUpdate()`, and `getCephCluster()`. Node control flow fetches the CephCluster, skips already checked nodes using process-local `nodesCheckedForReconcile`, ignores unschedulable or intolerable nodes, ensures storage settings permit node OSDs, requires Ready cluster phase, validates placement, queries Ceph for OSDs on the host, and triggers reconcile only when no OSDs are found or Ceph query failure implies reconciliation. Hot-plug flow compares serialized device lists, requires Ready cluster phase, and skips PVC-backed device sets. State is process-local dedup plus Ceph/Kubernetes reads; no persistent cursor survives restart. Dependencies include controller-runtime client, k8sutil node checks, discover device comparison, Ceph OSD host queries, and CephCluster status/spec. Risks include nil/empty cluster defaults, global dedup never cleared in-process, and assuming query failures mean reconcile.

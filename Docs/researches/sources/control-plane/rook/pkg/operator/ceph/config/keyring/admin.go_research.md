# sources/control-plane/rook/pkg/operator/ceph/config/keyring/admin.go

Purpose: specialized keyring Secret support for `client.admin` and cluster metadata annotations. APIs include admin/crash/exporter resource constants, `AdminStore`, `SecretStore.Admin()`, `AdminStore.CreateOrUpdate()`, and `ApplyClusterMetadataToSecret()`. Control flow formats the admin keyring with broad mds/mon/osd/mgr caps from `ClusterInfo.CephCred.Secret`, writes it via `SecretStore.CreateOrUpdate`, then re-fetches the Secret, clears annotations, applies cluster metadata annotations, and updates the Secret. State persists in the `rook-ceph-admin-keyring` Secret, owner references, and annotations. Dependencies include Kubernetes Secrets, clusterd context, Ceph cluster info, and Ceph API annotation specs. Risks include resetting all annotations before applying metadata, admin resource-name collision warning from generic SecretStore, and broad admin caps requiring careful Secret handling.

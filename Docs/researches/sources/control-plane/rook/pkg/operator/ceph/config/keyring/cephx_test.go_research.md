# sources/control-plane/rook/pkg/operator/ceph/config/keyring/cephx_test.go

Purpose: comprehensive unit tests for CephX rotation decisions and status transitions. `TestShouldRotateCephxKeys` covers unset/disabled policies, KeyGeneration comparisons, uninitialized status suppression, internal WithCephVersionUpdate behavior, invalid policy errors, commit ID ignoring, and unsupported running Ceph versions forcing no rotation. `Test_parseCephVersionFromStatusVersion` validates strict `X.Y.Z-B` parsing and round trips. `TestUpdatedCephxStatus` covers brownfield empty status retention, greenfield uninitialized initialization, rotation incrementing, configured generation jumps, and status retention when no rotation occurred. State is pure value transformation. Risks covered include accidental status downgrades and unwanted brownfield initialization. It does not execute Ceph auth commands or Kubernetes Secret writes.

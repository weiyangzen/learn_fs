# sources/control-plane/rook/pkg/operator/ceph/cluster/utils_test.go

Purpose: tests metadata behavior for `populateConfigOverrideConfigMap()`. The test creates a fake client and owner info, then verifies initial ConfigMap creation without Helm metadata has no labels/annotations, nil existing maps remain empty without Helm metadata, Helm release annotation causes the expected two annotations and managed-by label to be added, removed labels/annotations are restored on subsequent calls, and unrelated metadata is preserved while Helm metadata is added. State validation is through the fake Kubernetes ConfigMap object. The test signal covers upgrade/backfill scenarios and coexistence with user metadata. It does not cover owner-reference failures, Kubernetes get/update API failures, placeholder data content, or the best-effort warning branch on non-NotFound get errors.

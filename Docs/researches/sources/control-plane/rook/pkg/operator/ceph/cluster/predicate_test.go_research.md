# sources/control-plane/rook/pkg/operator/ceph/cluster/predicate_test.go

Purpose: narrow unit tests for predicate helper behavior. `TestIsHotPlugCM` verifies only ConfigMaps labelled with Rook's app label equal to `rook-discover` are classified as hot-plug device ConfigMaps. `TestCompareNodes` validates `shouldReconcileChangedNode()` ignores empty/no-op changes, metadata resource version churn, heartbeat-only condition changes, and combined resource-version/heartbeat churn, but returns true when actual `NodeSpec` fields such as `PodCIDR` change. The test signals the expected noise-filtering contract for Kubernetes Node watch events. It does not cover the higher-level typed predicates for CephCluster skip labels, manager reload decisions, operator setting ConfigMap changes, duplicate clusters, or floating mon ConfigMap references, so regressions in those branches require separate integration or controller tests.

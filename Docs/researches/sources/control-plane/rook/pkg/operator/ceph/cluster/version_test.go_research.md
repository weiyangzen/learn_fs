# sources/control-plane/rook/pkg/operator/ceph/cluster/version_test.go

Purpose: unit tests for version comparison and support validation. `TestDiffImageSpecAndClusterRunningVersion` feeds JSON daemon version maps and checks error on missing `overall`, upgrade trigger on multiple versions, downgrade/higher-version detection, identical version suppression, build/commit differences, and same commit handling. `TestMinVersion` verifies versions below the configured minimum fail and Squid/Tentacle-or-newer minimum cases pass when unsupported versions are allowed. `TestSupportedVersion` verifies unsupported Reef and future Umbrella behavior, Squid/Tentacle support, and `AllowUnsupported` override. State is local fake cluster specs and unmarshaled version maps; no Kubernetes persistence is exercised. Risks covered are version comparison regressions, but not `detectAndValidateCephVersion()` status writes, Ceph health gating, external cluster validation, or mon connection config errors.

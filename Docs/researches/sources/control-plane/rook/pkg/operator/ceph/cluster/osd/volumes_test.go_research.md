# sources/control-plane/rook/pkg/operator/ceph/cluster/osd/volumes_test.go

Purpose: targeted tests for OSD encryption and data bridge volume construction. `TestGetEncryptionVolume` verifies the non-KMS path creates `osd-encryption-key` from the expected Secret, maps `dmcrypt-key` to `luks_key`, uses default mode 0400, and mounts `/etc/ceph` read-only. It then enables Vault-style KMS and verifies the volume becomes memory `emptyDir` and the mount becomes writable for key-encryption-key material. `TestGetDataBridgeVolumeSource` verifies provisioning returns memory `emptyDir`, while daemon runtime returns `HostPathDirectoryOrCreate` under the config dir, namespace, and claim. These tests signal the persistence contract: provisioning is ephemeral; running OSD bridge state is host-persistent to share locks. They do not cover metadata/WAL PVC list assembly or device mapper/udev volumes.

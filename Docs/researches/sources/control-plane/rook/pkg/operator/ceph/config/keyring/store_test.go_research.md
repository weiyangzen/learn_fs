# sources/control-plane/rook/pkg/operator/ceph/config/keyring/store_test.go

Purpose: tests generic SecretStore key generation, Secret lifecycle, and resource volume builders. `TestGenerateKey` uses a mock executor to verify generated key JSON is parsed, different keys are returned on later calls, and command failure produces an error. `TestKeyringStore` verifies create, independent second secret creation, update, readback from Secret, delete, Secret type, and StringData content. `TestResourceVolumeAndMount` verifies resource volume and mount names align with the Secret and that the mounted file path resolves to the generic keyring path. State is fake Kubernetes Secrets and mocked Ceph commands. Missing coverage includes GenerateKey fallback through `AuthUpdateCaps`, `RotateKey`, owner-reference failures, create/update API conflicts, Data vs StringData readback in real apiserver behavior, and Delete warning paths.

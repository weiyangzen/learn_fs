# sources/control-plane/rook/pkg/operator/ceph/cluster/predicate.go

Purpose: controller-runtime predicates controlling when CephCluster-related watches trigger reconcile or manager reload. Important APIs include `changedOrDeleted`, node, hot-plug ConfigMap, operator ConfigMap, floating-mon ConfigMap, and CephCluster watch predicates. Control flow suppresses noisy updates such as Secret updates without resource-version change, node heartbeat/resource-version-only changes, delete/generic node events, and non-hot-plug ConfigMaps. CephCluster spec diffs cause orchestration manager reload and usually return false to avoid duplicate reconcile; generation-only changes return true. Skip-reconcile label changes trigger reconcile, but objects with the label are otherwise ignored. State is not persisted except through Kubernetes events and logs. Dependencies include controller-runtime predicates/events, go-cmp comparers for resource.Quantity and metadata, Rook controller duplicate/label helpers, and cluster CR lists for floating mon config. Risks include under-triggering if diff comparers miss relevant node status, over-reloading on spec diffs, and silent false when list checks fail.

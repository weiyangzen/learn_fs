# sources/control-plane/rook/pkg/operator/ceph/config/defaults.go

Purpose: declares Rook's default Ceph CLI flags and centralized config-store defaults. `DefaultFlags()` returns fsid, keyring path, logging flags, and stored mon host env var flags. `LoggingFlags()` forces container-oriented stderr logging and disables default file logging. `DefaultCentralizedConfigs()` enables pool deletion, clears monitor cluster log file, and allows pool size one. `LegacyConfigs()` identifies old options to remove from the mon config database, currently global `log file`. State impact depends on caller: flags are immutable process args, while centralized configs persist in Ceph monitor config database. Dependencies include `NewFlag()` and Ceph version type, although current centralized defaults do not branch on version. Risks include defaults being hard to override when expressed as CLI flags and compatibility of pool-delete/size-one defaults with user expectations.

# sources/control-plane/rook/pkg/operator/ceph/config/keyring/volume.go

Purpose: builder helpers for mounting keyring Secrets into daemon pods. APIs include `VolumeBuilder`, `VolumeMountBuilder`, `Volume()`, `VolumeMount()`, resource/admin/crash/exporter volume constructors, matching mount constructors, and keyring file path helpers. Control flow is straightforward: resource names map to `<resource>-keyring` Secrets, mounted read-only under distinct directories for generic, admin, crash collector, and exporter keyrings. State is declarative Kubernetes Volume/VolumeMount spec; persistence comes from Kubernetes Secrets created by SecretStore/AdminStore. Dependencies include corev1 volume APIs and keyring resource-name constants. Risks include all generic resource mounts sharing `keyringDir`, comments for crash/exporter path helpers saying admin by mistake, and callers needing to keep Volume and VolumeMount resource names matched.

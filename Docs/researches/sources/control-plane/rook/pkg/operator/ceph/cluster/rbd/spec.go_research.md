# sources/control-plane/rook/pkg/operator/ceph/cluster/rbd/spec.go

Purpose: builds Kubernetes Deployment and container specs for RBD mirror daemons. APIs include `makeDeployment()`, `makeChownInitContainer()`, and `makeMirroringDaemonContainer()`. Control flow creates a pod template with chown init container, `rbd-mirror` main container, daemon volumes/mounts, host networking or Multus networking, placement, tolerations, labels/annotations, optional log collector sidecar, and replicas from `Spec.Count`. It sets deployment labels, revision history, selectors, Rook and Ceph version labels, and applies user metadata. State is declarative Kubernetes pod/deployment spec; persistence comes from mounted daemon volumes and host log/crash dirs in `DataPathMap`. Dependencies include controller daemon volume/env/flag helpers, keyring volume paths indirectly, k8sutil metadata/network helpers, and CephClusterSpec. Risks include no liveness probe, selector immutability when labels change, host network DNS behavior, and user metadata affecting rollout identity.

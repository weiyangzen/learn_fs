# sources/control-plane/rook/pkg/operator/ceph/cluster/rbd/mirror.go

Purpose: starts and updates the singleton RBD mirror deployment managed by the reconciler. `start()` validates memory against `cephRbdMirrorPodMinimumMemory`, builds daemon ID `a`, constructs a dataless `DataPathMap`, respects daemon skip-reconcile labels, generates/rotates the keyring, creates the Deployment spec, annotates the pod template with the cephx Secret resource version, sets owner reference and last-applied patch annotation, then creates or updates the Deployment. If update fails, it attempts delete-and-recreate to handle immutable selector changes. State persists in Kubernetes Deployments, annotations, owner refs, and keyring Secrets; Ceph auth may be changed by `generateKeyring()`. Dependencies include mon deployment update helpers, object matcher annotations, controller label helpers, DataPathMap, and Kubernetes apps APIs. Risks include only one daemon resource despite `Spec.Count` scaling replicas, broad skip-reconcile blocking all mirrors, and delete/recreate disruption.

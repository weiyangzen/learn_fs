# sources/control-plane/rook/pkg/operator/ceph/cluster/rbd/config_test.go

Purpose: verifies RBD mirror spec validation. `TestValidateSpec` asserts `Count: 0` is invalid, `Count: 1` is valid, and peer secret names do not impose a count limit: one peer and multiple peer secret names are both accepted. This documents current behavior that peer validation is mostly deferred to reconciliation and `ValidatePeerToken`, while local `validateSpec()` is intentionally minimal. The test signal is useful for avoiding accidental reintroduction of an old one-peer restriction, but it leaves untested the keyring generation path, Ceph auth caps, rotation errors, bootstrap peer secret retrieval, malformed peer token data, and mirror info hydration. Those behaviors are covered indirectly by controller tests and Ceph client mocks.

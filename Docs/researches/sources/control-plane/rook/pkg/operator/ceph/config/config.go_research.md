# sources/control-plane/rook/pkg/operator/ceph/config/config.go

Purpose: common Ceph config constants, CLI flag normalization, default monitor config application, and insecure global ID hardening. APIs include daemon type constants, path globals, `normalizeKey()`, `NewFlag()`, `SetOrRemoveDefaultConfigs()`, and `DisableInsecureGlobalID()`. Control flow normalizes config keys by replacing spaces and hyphens with underscores, formats CLI flags with dashes, writes default centralized configs, toggles `log to file` based on log collector enablement, deletes legacy config options, and sets `auth_allow_insecure_global_id_reclaim=false`. State persists in Ceph monitor centralized config database. Dependencies include `MonStore`, Ceph cluster info, cluster spec, and config default definitions. Risks include path globals being mutable for tests, default config writes requiring monitors to exist, partial failure when deleting legacy options, and CLI flags intentionally overriding monitor config values.

# sources/control-plane/rook/pkg/operator/ceph/cluster/osd/update.go

Purpose: OSD deployment update orchestration during CephCluster reconcile. Important APIs are `updateConfig`, `newUpdateConfig()`, `updateExistingOSDs()`, `getOSDUpdateInfo()`, FIFO `updateQueue`, O(1) `existenceList`, deployment list helpers, and `Cluster.rotateCephxKey()`. Control flow gates updates on optional PG cleanliness, Ceph `osd ok-to-stop`, `OSDMaxUpdatesInParallel`, skip-reconcile labels, node validity, and PVC/node deployment regeneration. State is mostly in memory during reconcile, but it reads Kubernetes Deployments and writes updated Deployment specs and CephCluster progress conditions; cephx rotation changes Ceph auth state and status annotations carried by OSD metadata. Dependencies include Ceph command clients, keyring rotation policy helpers, Kubernetes AppsV1 APIs, and OSD deployment builders. Risks include non-thread-safe queue mutation, skipped retries after deployment update failures, stale/missing deployment labels, and safety behavior around nodes removed from storage specs. Tests exercise queue behavior, ok-to-stop batching, unhealthy PG gates, skip labels, node/PVC paths, and cephx rotation.

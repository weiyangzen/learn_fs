# sources/control-plane/rook/pkg/operator/ceph/cluster/telemetry/telemetry.go

Purpose: defines Rook telemetry config-key names and a helper to write key/value telemetry into Ceph's monitor key/value store. Important API is `ReportKeyValue(context, clusterInfo, key, value)`. Constants cover Rook, Kubernetes, CSI, monitor, storage device set, network, external mode, and node/plugin counts. Control flow creates a config `MonStore`, calls `SetKeyValue`, logs warning on error, and logs debug on success. State persists in Ceph's `config-key` store, not Kubernetes. Dependencies include the config package monitor store, Ceph cluster info, clusterd context, and logging. Risks are low but include best-effort error handling that does not propagate failure, key-name compatibility with Ceph telemetry consumers, and global `CSIVersion` mutation elsewhere.

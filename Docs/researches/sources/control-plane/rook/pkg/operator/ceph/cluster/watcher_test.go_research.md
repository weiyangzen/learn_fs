# sources/control-plane/rook/pkg/operator/ceph/cluster/watcher_test.go

Purpose: tests watcher helper decisions with fake controller-runtime and Kubernetes clients. It defines helpers for fake clients and clusters. `TestCheckStorageForNode` verifies storage settings allow node reconciliation only when use-all-nodes, explicit nodes, or device sets exist. `TestOnK8sNode` uses a mock executor that fails OSD host lookup to confirm a ready cluster with storage settings triggers reconcile once and then is suppressed by `nodesCheckedForReconcile`. `TestOnDeviceCMUpdate` verifies wrong object types, missing device data, unchanged/unready cluster behavior, and ready-cluster device diffs triggering reconcile. Test state includes global node dedup and fake CR status. Risks covered include readiness gating and hot-plug diffing, but not unschedulable/toleration branches, PVC device-set skip, uninitialized Ceph config error, or successful OSD-on-host suppression.

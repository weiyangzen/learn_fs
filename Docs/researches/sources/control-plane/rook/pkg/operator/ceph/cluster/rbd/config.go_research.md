# sources/control-plane/rook/pkg/operator/ceph/cluster/rbd/config.go

Purpose: RBD mirror daemon configuration, keyring generation, deprecated bootstrap-peer import, and spec validation. APIs include `daemonConfig`, `generateKeyring()`, `fullDaemonName()`, `reconcileAddBootstrapPeer()`, `addPeer()`, and `validateSpec()`. Control flow creates or retrieves `client.rbd-mirror.<id>` keys with mon/osd mirror caps, optionally rotates via `SecretStore.RotateKey`, formats a keyring, and stores it in a Kubernetes Secret. Bootstrap peer reconciliation iterates deprecated secret names, validates token data, records pool/direction in `r.peers`, imports tokens into Ceph, then hydrates pool mirror info. State persists in Ceph auth, Kubernetes keyring Secrets, and in-memory `r.peers`. Dependencies include Ceph mirror client commands, keyring SecretStore, operator peer token validation, owner refs, and reconcile retry constants. Risks include deprecated peer behavior, secret validation failures, partial peer imports, and `validateSpec()` only checking `Count > 0`.

# sources/control-plane/rook/pkg/operator/ceph/config/config_test.go

Purpose: tests Ceph command-line flag formatting. `TestNewFlag` verifies empty values are retained, hyphenated keys remain hyphenated, underscore and space keys are converted to hyphenated flag names, and quoted values are passed through without escaping or stripping. This confirms the key normalization pipeline used by daemon default flags and command execution: internal keys normalize to underscores, CLI rendering converts underscores to dashes. The test does not cover `SetOrRemoveDefaultConfigs()`, monitor-store writes, legacy deletion, logging config toggles, or insecure global ID configuration. Its primary risk signal is compatibility with Ceph's accepted flag syntax and preserving literal values.

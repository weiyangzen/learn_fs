# sources/control-plane/rook/pkg/operator/ceph/config/probes_test.go

Purpose: tests liveness/startup probe disable and merge behavior across daemon key types. Helper tests confirm nil specs leave containers unchanged and `Disabled: true` removes probes. Integration-style checks build default and user probes to verify user timing/threshold fields override defaults while the handler remains the Rook-generated default. `TestGetProbeWithDefaults` covers empty desired probe using defaults, overriding default values while preserving the current exec command, and nil current probe returning desired values. State is pure Kubernetes container/probe structs. Signals cover the most important safety rule: user config can tune timings but not daemon-specific admin-socket commands. A minor gap is that the liveness integration helper accidentally calls startup configuration, but merge logic is shared.

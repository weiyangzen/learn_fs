# sources/control-plane/rook/pkg/operator/ceph/cluster/rbd/controller.go

Purpose: controller-runtime reconciler for `CephRBDMirror`. Important APIs include `Add()`, `newReconciler()`, `add()`, `watchOwnedCoreObject()`, `Reconcile()`, internal `reconcile()`, `reconcileCreateCephRBDMirror()`, and `updateStatus()`. Control flow fetches the CR, initializes status with uninitialized cephx metadata, validates spec, waits for a ready CephCluster, loads cluster info, detects running/desired Ceph versions, waits during upgrades, imports deprecated bootstrap peers, computes daemon cephx rotation need, starts/updates deployments, and writes Ready/Failed status with observed generation. State persists in CR status, Kubernetes owned resources, Secrets, and Ceph auth/mirror configuration. Dependencies include controller-runtime watches, Rook readiness/version helpers, reporting, event recorder, retry-on-conflict status updates, and keyring policy helpers. Risks include stale package-level version hook in tests, status update masking original reconcile errors, upgrade wait behavior, and partial external-cluster validation.

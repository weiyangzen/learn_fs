# sources/control-plane/rook/pkg/operator/ceph/cluster/version.go

Purpose: Ceph image version detection, validation, upgrade detection, and post-upgrade logging for CephCluster orchestration. APIs include `detectAndValidateCephVersion()`, `printOverallCephVersion()`, `diffImageSpecAndClusterRunningVersion()`, and `validateCephVersion()`. Control flow detects the version from the image, validates minimum/supported constraints unless external, updates cluster status, loads cluster info, writes connection config, compares running daemon versions to spec image, validates external/local version compatibility, and refuses upgrades when Ceph health is bad unless `SkipUpgradeChecks` is set. State persists through CephCluster version status and `cluster.isUpgrade`; it reads Ceph daemon versions and health from Ceph commands. Dependencies include Ceph version parsing/comparison, mon connection config, controller LoadClusterInfo, and daemon client health/version APIs. Risks include best-effort continuation when running versions cannot be read, downgrade detection returning true, and external-cluster image nuances.

# sources/control-plane/rook/pkg/operator/ceph/config/monstore.go

Purpose: wrapper around Ceph monitor centralized config database and config-key store. APIs include `MonStore`, `GetMonStore()`, `Option`, `SetIfChanged()`, `Set()`, `Delete()`, `Get()`, `GetDaemon()`, `DeleteDaemon()`, `DeleteAll()`, `SetKeyValue()`, `SetAllMultiple()`, `SetAll()`, internal `setAll()`, `UpdateConfigStoreFromMap()`, and `filterSettingsMap()`. Control flow normalizes config keys, executes Ceph commands with timeouts, parses daemon config JSON, batches settings through temporary INI files and `ceph config assimilate-conf`, retries failed batch keys by deleting first, and filters critical `mon_host`, `fsid`, and `keyring` options before applying CR maps. State persists in Ceph monitor config DB and config-key store; temporary files are created under `context.ConfigDir` and removed. Dependencies include Ceph command runner, INI parser, JSON parsing, filesystem temp files, and Rook fatal termination on temp write failure. Risks include type assertions on Ceph JSON, partial batch failures, critical key filtering only exact keys, and temp file cleanup errors.

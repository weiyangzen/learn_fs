# sources/control-plane/rook/pkg/operator/ceph/cluster/rbd/controller_test.go

Purpose: controller tests for `CephRBDMirror` readiness, peer handling, deployment creation, and cephx rotation. The file builds fake controller-runtime clients, fake Kubernetes clientsets, mock Ceph command executors, and stubs `currentAndDesiredCephVersion` and deployment update waits. Cases cover missing CephCluster, not-ready CephCluster, invalid peer secret data, successful peer secret import and Ready status, first reconcile status initialization, status retention on subsequent reconcile, brownfield unknown cephx status retention, KeyGeneration-driven rotation, Secret contents changing after rotation, and no extra rotation when status already satisfies config. Persistence signals include CR status, mon Secret data, rbd-mirror keyring Secret, Deployment updates, and Ceph auth command invocations. Risks include shared mutable package hooks and fake clients approximating status subresource behavior.

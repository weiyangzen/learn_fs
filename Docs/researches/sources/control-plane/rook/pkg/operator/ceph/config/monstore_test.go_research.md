# sources/control-plane/rook/pkg/operator/ceph/config/monstore_test.go

Purpose: unit tests for monitor config-store command construction, parsing, batch application, and critical-option filtering. Tests verify `Set()` normalizes spaces/hyphens to underscores and reports command failures, `Delete()` issues `config rm`, `GetDaemon()` parses Ceph JSON and returns only daemon-specific options, `DeleteDaemon()` removes options discovered for that daemon, `setAll()` invokes assimilate-conf using mocked execution, and `filterSettingsMap()` removes `mon_host` while preserving non-critical options. State is mocked command strings and fake clientsets. Signals cover key syntax compatibility and JSON parse errors. Missing coverage includes `SetIfChanged()`, `Get()`, `DeleteAll()` multi-error wrapping, `SetKeyValue()`, retry-after-delete behavior in `SetAll()`, temp file failure paths, and exact filtering of `fsid`/`keyring`.

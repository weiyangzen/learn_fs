# sources/control-plane/rook/pkg/operator/ceph/config/keyring/admin_test.go

Purpose: tests admin keyring Secret creation/update and volume helpers. `TestAdminKeyringStore` creates a fake SecretStore, writes an admin keyring from `ClusterInfo.CephCred.Secret`, verifies Secret type and keyring content, checks cluster metadata annotations are applied, then updates the admin secret with a different key. `TestAdminVolumeAndMount` verifies `Volume().Admin()` and `VolumeMount().Admin()` refer to `rook-ceph-admin-keyring` and place the keyring file at the expected mounted path. State is fake Kubernetes Secrets. Signals include annotation replacement and key update behavior. Missing coverage includes `ApplyClusterMetadataToSecret()` get/update failures, annotation clearing side effects beyond the tested metadata, owner reference errors, and crash/exporter keyring helpers.

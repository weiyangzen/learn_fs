# sources/control-plane/rook/pkg/operator/ceph/config/datapath.go

Purpose: shared mapping of Ceph daemon data, log, and crash directories between host and container. `DataPathMap` records host data dir, container data dir, and host log/crash root. Constructors distinguish stateful daemons (`NewStatefulDaemonDataPathMap` with host data dir and container `/var/lib/ceph/<type>/ceph-<id>`), stateless daemons (`NewStatelessDaemonDataPathMap` with only container data dir), and dataless daemons (`NewDatalessDaemonDataPathMap` with no container data dir but host path root for log/crash use). Methods return container crash/log dirs and host log/crash subdirs. State is declarative path construction; persistence behavior depends on whether `HostDataDir` is empty. Dependencies are path constants from config. Risks include path.Join cleanup changing trailing slash semantics, dataless host data dir exposing broader host path, and callers misinterpreting empty dirs.

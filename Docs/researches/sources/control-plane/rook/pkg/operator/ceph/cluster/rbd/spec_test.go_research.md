# sources/control-plane/rook/pkg/operator/ceph/cluster/rbd/spec_test.go

Purpose: validates the generated RBD mirror Deployment shape. `TestPodSpec` builds a fake CephCluster, `CephRBDMirror`, daemon config, cluster info, and reconciler, then calls `makeDeployment()`. Assertions cover deployment name, volume count, projected volume source count, volume mount count, default service account, Ceph daemon labels, resource requests/limits, priority class, image expectations through the shared pod-template tester, and required Rook/Ceph metadata. This is a structural test signal for integration with controller helpers and the Rook pod-template convention. It does not test network variants, Multus application, log collector sidecar, placement/tolerations beyond the generic suite, chown init details, or failure paths from invalid network configuration.

# sources/user-network-fs/libfuse/lib/mount_bsd.c

## Purpose
FreeBSD-specific libfuse mount implementation. It opens a FUSE device or consumes `FUSE_DEV_FD`, invokes `mount_fusefs`, and provides the same internal mount option API shape as the Linux implementation.

## Important APIs, Types, And Functions
- Local `struct mount_opts` tracks `allow_other`, `kernel_opts`, and `max_read`.
- `parse_mount_opts` maps FreeBSD and common FUSE options into a kernel option string.
- `fuse_mount_core` opens `/dev/fuse` or `FUSE_DEV_NAME`, honors `FUSE_NO_MOUNT`, and double-forks to execute `mount_fusefs`.
- `fuse_kern_mount` sets `MOUNT_FUSEFS_SAFE` and `MOUNT_FUSEFS_CALL_BY_LIB` before mounting.
- `fuse_kern_unmount` closes the FUSE fd and calls `unmount(..., MNT_FORCE)`.

## Control Flow
Parsing collects options accepted by FreeBSD mount utilities, including negated forms generated by `FUSE_DUAL_OPT_KEY`. Mounting obtains a device fd, then, unless disabled, forks a child that forks again and execs `mount_fusefs [-o opts] fd mountpoint`. The parent waits and returns the FUSE fd only after a successful mount helper exit.

## State And Persistence
State is limited to allocated option strings and environment variables. Persistence is delegated to the system `mount_fusefs` helper and kernel mount table. No explicit mtab manipulation happens here.

## Dependencies And Integration Points
Relies on FreeBSD kernel headers, `mount_fusefs`, FUSE device naming via `/dev/fuse` or environment overrides, and shared libfuse option parsing. It implements the `mount_common_i.h` contract for non-Linux builds.

## Risks
The environment-controlled fd/device path is powerful and must only be used in trusted process contexts. The double-fork status path only observes helper exit status, not detailed kernel mount failure causes. `system("mount_fusefs --version")` is simple but less controlled than exec with argv.

## Test Signals
Test `FUSE_DEV_FD`, invalid fd strings, `FUSE_DEV_NAME`, `FUSE_NO_MOUNT`, option pass-through, helper exec failure, and forced unmount after fd close.

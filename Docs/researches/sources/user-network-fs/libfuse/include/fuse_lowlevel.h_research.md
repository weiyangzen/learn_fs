# sources/user-network-fs/libfuse/include/fuse_lowlevel.h

`fuse_lowlevel.h` is the main public low-level API for inode-based FUSE filesystems. It defines request/session types, the callback table, reply functions, notification functions, session lifecycle functions, custom I/O hooks, command-line parsing, request context access, and newer sync-init/io-uring helpers.

Core types are `fuse_ino_t`, `fuse_req_t`, `struct fuse_session`, `struct fuse_entry_param`, `struct fuse_ctx`, `struct fuse_forget_data`, `struct fuse_custom_io`, `enum fuse_notify_entry_flags`, and `struct fuse_lowlevel_ops`. The operation table covers lifecycle, lookup/forget, namespace mutation, attrs/statx, file and directory I/O, xattrs, locks, ioctl, poll, write buffers, retrieve replies, readdirplus, copy-file-range, lseek, tmpfile, and syncfs. Reply/session APIs include `fuse_reply_*`, `fuse_add_direntry*`, `fuse_lowlevel_notify_*`, `fuse_session_new`, mount/unmount/destroy, single and multithreaded loops, custom I/O, receive/process buffer, sync init, teardown watchdog, and io-uring payload helpers.

Control flow is one callback per kernel request. The callback must issue exactly one valid reply except `forget`, `forget_multi`, and `retrieve_reply`. `fuse_file_info.fh` carries per-open state; lookup counts and entry timeouts drive kernel cache persistence; request context exposes caller credentials, security contexts, and groups. Notifications provide asynchronous cache and poll interactions.

Risks include missing/double replies, operation-specific permanent `ENOSYS` fallback behavior, unstable readdir offsets, lookup/generation lifetime bugs, notification deadlocks from related operation paths, writeback/direct-I/O semantic surprises, and ABI compatibility when extending `struct fuse_lowlevel_ops`. Test signals include dispatch/reply matrix coverage, ENOSYS fallbacks, lookup/forget accounting, readdir stability, notification/cache integration, xattr/ioctl retry, poll lifetimes, request context iteration, lifecycle loops, custom I/O, sync init, and io-uring payload handling.

# sources/user-network-fs/impacket/impacket/helper.py

Purpose: `helper.py` provides a small metaclass-based framework for defining protocol packet fields on top of `impacket.ImpactPacket.ProtocolPacket`. Packet classes can declare field descriptors in the class body and automatically receive getters, setters, properties, field tracking, and a useful representation.

Important APIs, types, and functions: `rebind()` wraps descriptor getter/setter methods so generated methods can receive custom names and docs. `Field` is the base descriptor factory; `Field.__call__()` injects `get_<field>`, `set_<field>`, and a property into the class namespace. `Bit` reads/writes one bit in a header byte. `Byte` reads/writes a byte. `Word` reads/writes a 16-bit value with configurable byte order. `Long` reads/writes a 32-bit value with configurable byte order. `ThreeBytesBigEndian` reads/writes a 24-bit big-endian field through a padded 32-bit operation. `ProtocolPacketMetaklass` scans class attributes for `Field` instances, applies them, records sorted `_fields`, and injects `_fields_repr()` and `__repr__()`. `ProtocolPacket` is the metaclass-enabled base that initializes the parent `ProtocolPacket` with subclass-provided `header_size` and `tail_size`, then optionally loads a packet buffer.

Control flow: At class creation time, `ProtocolPacketMetaklass.__new__()` copies the class dictionary, ensures `object` is among bases for old Python compatibility, finds every `Field`, asks each field to bind generated accessors/properties, sorts the field names, and creates repr helpers. At instance creation time, subclasses of `ProtocolPacket` allocate the underlying ImpactPacket header/tail, then parse an optional buffer. Runtime field access goes through the generated property, which delegates to `o.header.get_*` or `o.header.set_*` methods.

State and persistence behavior: The module has no durable persistence. It mutates class dictionaries during metaclass construction and mutates packet header bytes when generated setters are used. Instance state lives in the underlying ImpactPacket header, tail, and child packet chain.

Dependencies and integration points: It depends on `struct`, `functools`, `six.add_metaclass`, and `impacket.ImpactPacket` helper methods such as `get_byte`, `set_byte`, `get_word`, `set_word`, `get_long`, `set_long`, `get_bytes`, `array_tobytes`, `load_packet`, and `child()`. It is intended for older Impacket packet definitions that prefer declarative field descriptors over manual getter/setter boilerplate.

Risks: `rebind()` calls `functools.wraps(f)` without applying the returned decorator, so wrapper metadata preservation is ineffective apart from manual `__name__`/`__doc__` assignment later. `ProtocolPacketMetaklass` modifies `bases` by appending `object`, which is unusual in modern Python and can interact poorly with complex inheritance. `ThreeBytesBigEndian.setter()` uses masking and shifted writes that should be tested carefully for adjacent-byte preservation. Field descriptors are replaced by generated properties, so code expecting descriptor objects after class creation will not find them. The framework assumes subclasses define valid `header_size` and `tail_size`.

Test signals: Tests should define small packet subclasses with each field type, verify generated methods and properties, check byte-order behavior, confirm `_fields` sorting and `repr` output, and round-trip `ThreeBytesBigEndian` values without corrupting neighboring bits. Buffer-load tests should confirm `ProtocolPacket.__init__()` delegates to ImpactPacket parsing correctly.

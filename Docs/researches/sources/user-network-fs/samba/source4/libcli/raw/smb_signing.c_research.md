# sources/user-network-fs/samba/source4/libcli/raw/smb_signing.c

Purpose: implements SMB1 signing setup, outgoing MD5 signature generation, incoming signature verification, and signing-state transitions. Important APIs include `set_smb_signing_common()`, `mark_packet_signed()`, `signing_good()`, `sign_outgoing_message()`, `check_signed_incoming_message()`, `smbcli_set_signing_off()`, and `smbcli_simple_set_signing()`. Control flow writes sequence numbers into the signature field, marks the SMB header signed, hashes MAC key plus message bytes with GnuTLS MD5, and stores or compares the first 8 bytes. Incoming verification reconstructs the signature field from the expected sequence number and uses constant-time compare. State lives in `smb_signing_context`: signing policy, `doing_signing`, `seen_valid`, `next_seq_num`, and MAC key. Dependencies include raw request buffer layout, GnuTLS hash APIs, Samba crypto helpers, and `mem_equal_const_time()`. Risks include deprecated MD5 as required by SMB1, sequence mismatch, optional signing downgrade before a valid packet, silent return on GnuTLS hash errors in signing, and dumping key/signature material at debug levels. Test signals cover signed/unsigned negotiation, wrong sequence, empty key, malformed short packets, bad signature after `seen_valid`, and key construction from session key plus challenge response.

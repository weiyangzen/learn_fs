# sources/user-network-fs/samba/source4/libcli/raw/signing.h

Purpose: declares SMB1 signing state. The main type is `struct smb_signing_context`, with engine state `SMB_SIGNING_ENGINE_OFF`, `SMB_SIGNING_ENGINE_BSRSPYL`, and `SMB_SIGNING_ENGINE_ON`. It tracks MAC key material, next sequence number, local policy (`allow_smb_signing`, `mandatory_signing`), runtime behavior (`doing_signing`), and whether any valid peer signature has been seen. State is session/transport scoped and memory-only; `DATA_BLOB mac_key` owns secret key bytes until freed by signing shutdown. Dependencies include Samba `DATA_BLOB` and SMB signing implementation in `smb_signing.c`. Integration points include SMB1 negotiation/session setup and packet send/receive validation. Risks are sequence-number drift, confusing negotiated vs actively doing signing, and allowing unsigned traffic before a valid signature when signing is not mandatory. Test signals include mandatory signing enforcement, optional signing fallback, bad signature after a valid packet, and key cleanup when signing is disabled.

# sources/user-network-fs/samba/source4/libcli/raw/rawshadow.c

Purpose: queries shadow copy volume data via `FSCTL_GET_SHADOW_COPY_DATA` over raw SMB1 NT IOCTL. The exported API is `_PUBLIC_ NTSTATUS smb_raw_shadow_data(struct smbcli_tree *, TALLOC_CTX *, struct smb_shadow_copy *)`. Control flow builds a `RAW_IOCTL_NTIOCTL` request against the input FID, calls `smb_raw_ioctl()`, validates the returned blob header, then parses volume counts and UCS-2 snapshot names. State is held in the caller's `struct smb_shadow_copy` and talloc-allocated output name array. Dependencies include `libcliraw`, raw ioctl support, SMB constants, `smbcli_blob_pull_ucs2()`, and little-endian blob readers. Integration point is any client-side shadow-copy listing path that has an open file handle and wants snapshot names. Risks are malformed server responses: the code checks minimum 12-byte header and declared length but trusts `num_names` for allocation and iterates until string parsing fails. Test signals include short blob, overlarge declared data length, zero names, multiple UCS-2 names, nonterminated names, and FSCTL error propagation.

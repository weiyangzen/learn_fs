# sources/user-network-fs/samba/source4/libcli/raw/rawtrans.c

Purpose: provides raw SMB1 transaction wrappers for `SMBtrans`, `SMBtrans2`, and `SMBnttrans`. Important APIs are `smb_raw_trans_send/recv()`, `smb_raw_trans2_send/recv()`, and `smb_raw_nttrans_send/recv()`, plus synchronous wrappers. Control flow allocates a legacy `smbcli_request`, copies setup words, params, and data into the outgoing buffer, then delegates wire fragmentation/assembly to `smb1cli_trans_send()`. Completion callbacks call `smb1cli_trans_recv()`, map setup/param/data outputs into `req->trans2.out` or `req->nttrans.out`, update transport error state, and invoke user async callbacks. State is request-local but reaches into transport, session, and tcon `smbXcli` handles for signing, IDs, and timeout. Dependencies include tevent, `smbXcli_base`, raw request helpers, and talloc ownership transfer via `talloc_steal()`. Risks include mixed legacy/new-client ownership boundaries, correct setup word width conversion, and treating non-error NT statuses as completed responses. Test signals should exercise async and sync trans/trans2/nttrans, error statuses with and without returned data, pipe-name `SMBtrans`, timeout propagation, and ownership of returned blobs after request destruction.

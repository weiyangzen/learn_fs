# sources/user-network-fs/samba/source4/libcli/raw/request.h

Purpose: defines shared raw SMB request buffer contracts used by SMB1 and reused by SMB2 for range checking and string/blob parsing. Important types are `struct request_bufinfo` and `struct smb_request_buffer`; flags are `BUFINFO_FLAG_UNICODE` and `BUFINFO_FLAG_SMB2`. The buffer model stores the NBT-framed allocation, SMB header pointer, word vector pointer/count, data pointer/size, a moving append pointer, and a `request_bufinfo` view for pull/push helpers. State is entirely in-memory and request-owned; no persistence occurs. Dependencies are minimal except `signing.h` and the broader raw SMB helper macros that interpret the offsets. Integration points are raw request creation/parsing, signing code, and SMB2 request buffers which embed the same `request_bufinfo` shape. Risks are pointer invalidation when buffers are reallocated, incorrect alignment base, and consumers failing to respect `data_size` bounds. Test signals are indirect: fuzz malformed SMB buffers, exercise append growth, Unicode string pulls, and signing over resized buffers.

# sources/user-network-fs/samba/source4/libcli/raw/smb.h

Purpose: central raw SMB1 constant header for deny/open modes, openX and NTCreateX flags, filesystem attributes, browser version constants, and inclusion of trans2/interface/common definitions. There are no functions, but many public macros define wire-level values consumed by raw SMB open, file, search, fsinfo, and SMB2 compatibility wrappers. State and persistence are absent. Dependencies are `trans2.h`, `interfaces.h`, and `smb_common.h`. Integration points are broad: SMB1 open/create marshalling, SMB2 utility functions that reuse NTCreateX access/share/create-option constants, and tests that compare protocol behavior. Risks are semantic ambiguity in legacy bits, duplicated protocol values across dialects, and comments documenting known TODOs around NTCreateX directory behavior and ignored/invalid masks. Test signals are compile-time and behavioral: open/create tests should verify masks, share access, create dispositions, create options, filesystem attribute flags, and compatibility with servers that enforce "must ignore" vs invalid bits differently.

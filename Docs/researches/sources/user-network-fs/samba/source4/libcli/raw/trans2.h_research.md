# sources/user-network-fs/samba/source4/libcli/raw/trans2.h

Purpose: declares SMB1 TRANS2 info-level constants for filesystem, file/path query, file/path set, search, device characteristics, sector-size flags, and legacy Mac extensions. It is data-only but protocol-critical: constants such as `SMB_QFILEINFO_*`, `SMB_SFILEINFO_*`, and `SMB_FIND_*` map Samba raw enum levels to observed Windows wire levels, including aliases documented from W2K3 tests. State and persistence are absent. Dependencies are only header inclusion consumers. Integration points include raw fsinfo/fileinfo/search/setfileinfo encoders and parsers, SMB2 getinfo/setinfo level mapping for passthrough levels above 1000, and torture tests that probe alias behavior. Risks are accidental renumbering, adding levels without parser support, and confusing legacy `*_INFO` aliases with NT passthrough `*_INFORMATION` variants. Test signals include query/set alias matrices, search level parsing for each structure, sector-size flag decoding, UNIX extension levels, and unsupported "vista scan" placeholder levels returning controlled errors.

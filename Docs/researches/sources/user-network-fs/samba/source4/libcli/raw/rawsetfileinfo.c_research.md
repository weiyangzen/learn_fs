# sources/user-network-fs/samba/source4/libcli/raw/rawsetfileinfo.c

Purpose: implements raw SMB1 set-file-info and set-path-info client operations, including passthrough binary encoders shared with SMB2 setinfo. Important APIs are `smb_raw_setfileinfo_passthru()`, `smb_raw_setfileinfo_send()`, `smb_raw_setfileinfo()`, `smb_raw_setpathinfo_send()`, and `smb_raw_setpathinfo()`. The control flow maps `union smb_setfileinfo` levels to fixed-format blobs, then sends either legacy `SMBsetatr`/`SMBsetattrE`, security descriptor helper, or TRANS2 `SETFILEINFO`/`SETPATHINFO` requests. State is request-scoped: temporary talloc contexts own generated `DATA_BLOB`s until the request send path copies or references them. Dependencies include raw date helpers, EA list packing, NDR security descriptor marshalling, `smb_raw_trans2_send()`, and request setup helpers. Integration points include SMB2 `setinfo.c`, which reuses the passthrough encoder and switches rename layout to `RAW_SFILEINFO_RENAME_INFORMATION_SMB2`. Risks are protocol-layout fragility, unsupported levels returning `false`, a stray `printf("num_eas=%d\n")`, and lifetime mistakes if future code stops copying blobs before freeing the temp context. Test signals should cover every info level, rename/link layouts, EA packing, security descriptor set, setattr fallbacks, path vs handle variants, and server rejection paths.

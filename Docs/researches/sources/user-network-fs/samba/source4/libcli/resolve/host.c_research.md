# sources/user-network-fs/samba/source4/libcli/resolve/host.c

Purpose: adapts the extended DNS resolver into the generic "host" name-resolution method. APIs are `resolve_name_host_send()`, `resolve_name_host_recv()`, and `resolve_context_add_host_method()`. Control flow simply calls `resolve_name_dns_ex_send(..., do_fallback=true)` so `getaddrinfo()` is tried first and Samba raw DNS lookup can be used as fallback, then delegates recv to `resolve_name_dns_ex_recv()`. State is entirely in the underlying DNS composite context; this file carries no persistent state. Dependencies include tevent, socket, composite, NBT name types, and `resolve.h`. Integration point is `lpcfg_resolve_context()` when the configured method is `host`, usually the DNS/system resolver leg after lmhosts/WINS/bcast depending on order. Risks are mostly inherited from `dns_ex.c`, plus method registration gives no private data and does not itself filter NBT-only flags. Test signals include host-method registration, normal hostname lookup, forced NBT returning not found through DNS, fallback behavior, and recv ownership of address/name arrays.

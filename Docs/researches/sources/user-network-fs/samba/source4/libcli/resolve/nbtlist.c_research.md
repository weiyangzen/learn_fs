# sources/user-network-fs/samba/source4/libcli/resolve/nbtlist.c

Purpose: sends NetBIOS name queries to a list of target addresses for WINS or broadcast resolution. APIs are `resolve_name_nbtlist_send()` and `resolve_name_nbtlist_recv()`, with `nbtlist_handler()` as async completion. Control flow rejects forced DNS and long NetBIOS names, uppercases the name/scope, opens an NBT name socket, sends one `nbt_name_query_send()` per target, then completes on the first successful response by converting returned IPv4 addresses to `socket_address` entries with the requested service port. State includes the NBT socket, outstanding query array, per-query IO structs, target interface reference, and output arrays. Dependencies include `libnbt`, interface/socket utilities, composite contexts, and tevent through the NBT socket. Integration points are WINS and broadcast resolver modules. Risks include freeing `state->nbtsock` on first callback, which cancels remaining queries; no attempt is made to combine responses; length checks enforce 15-character NetBIOS names twice; and no-query address lists can leave the composite pending. Test signals include first-response wins behavior, all-query timeout, long names, forced DNS, uppercase conversion, WINS vs broadcast flags, and empty address list handling.

# sources/user-network-fs/samba/source4/libcli/resolve/resolve.h

Purpose: public interface for Samba's async name-resolution framework. It declares `struct socket_address`, `struct tevent_context`, resolver flags (`FORCE_NBT`, `FORCE_DNS`, `DNS_SRV`, `OVERWRITE_PORT`), callback typedefs `resolve_name_send_fn` and `resolve_name_recv_fn`, then includes generated prototypes. State is absent; this is an API contract header. Dependencies include `libnbt` for `struct nbt_name`, generated `proto.h`, interface forward declarations, and loadparm resolver prototypes. Integration points are resolver method implementations, SMB client socket connection, and callers that need either one address or all addresses. Risks are semantic mismatch among flags: not every backend honors every flag, and `OVERWRITE_PORT` is defined here but only useful where a backend explicitly implements it. Test signals are compile/API coverage, forced DNS/NBT behavior across all methods, SRV lookups returning ports, and ensuring generated prototypes stay synchronized with implementation files.

# sources/user-network-fs/samba/source4/libcli/resolve/wins.c

Purpose: registers a WINS NetBIOS name-resolution method backed by `resolve_name_nbtlist_send()`. APIs are `resolve_name_wins_send()`, `resolve_name_wins_recv()`, `resolve_context_add_wins_method()`, and `resolve_context_add_wins_method_lp()`. Control flow stores a copied WINS server address list plus interface reference, NBT port, and timeout; send returns NULL if there are no WINS servers and otherwise queries the list with `broadcast=false` and `wins_lookup=true`. State is `resolve_wins_data` allocated under the resolve context. Dependencies include loadparm WINS server list, interface loading, NBT list resolver, and socket utilities. Integration point is configured `wins` method when NetBIOS is not disabled. Risks include NULL address list silently skipping the method, lifetime of interface references, and all result behavior inherited from nbtlist's first successful reply. Test signals include no WINS servers, multiple servers with first failure/second success, timeout, forced DNS rejection, configured NBT port, and loadparm registration.

# sources/user-network-fs/samba/source4/libcli/resolve/dns_ex.c

Purpose: implements async DNS/host resolution by forking a child for blocking `getaddrinfo()`, raw DNS A/AAAA, or DNS SRV lookup. Important APIs are `resolve_name_dns_ex_send()` and `resolve_name_dns_ex_recv()`; helpers include `dns_lookup()`, `get_a_aaaa_records()`, `get_srv_records()`, `run_child_getaddrinfo()`, `run_child_dns_lookup()`, and `pipe_handler()`. Control flow creates a pipe, registers a tevent read FD, forks, has the child write comma-separated `addr@port/name` records, and has the parent parse those records into `socket_address` and canonical-name arrays. The talloc destructor kills lingering children if the request is abandoned. State includes flags (`FORCE_NBT`, `FORCE_DNS`, `DNS_SRV`), requested port/name, child pid/fd, tevent FD, and output arrays. Dependencies include resolver libc, `res_search`, Samba DNS unmarshalling, AD DNS SRV lookup, socket utilities, tevent, and `smb_strtoul()`. Risks include fork cost, child cleanup correctness, parsing a private text protocol, truncation/format issues, SRV aggregation order, and rejecting `0.0.0.0`. Test signals include getaddrinfo success, fallback to raw DNS on CNAME/non-RFC names, forced DNS/NBT flags, SRV with A/AAAA records, malformed child output, no bytes for NXDOMAIN, IPv6 builds, and cancellation/destructor behavior.

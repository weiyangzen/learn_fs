# sources/user-network-fs/samba/source4/libcli/resolve/resolve.c

Purpose: provides the generic ordered name-resolution framework and convenience APIs. Important functions include `resolve_context_init()`, `resolve_context_add_method()`, `resolve_name_all_send/recv()`, `resolve_name_ex_send()`, `resolve_name_send()`, `resolve_name_recv()`, `resolve_name_multiple_recv()`, `resolve_name_ex()`, and NBT name initializers. Control flow stores registered methods in a DLIST; `setup_next_method()` invokes each method's send callback until one returns a context, and `resolve_handler()` tries the next method when recv status is not OK. Literal IP addresses and `localhost` bypass methods and return immediately. State is in `resolve_state`: current method, flags, port, copied NBT name, child composite request, and result arrays. Dependencies include composite contexts, tevent, socket/tsocket conversion, NBT name duplication, and DLIST helpers. Integration points include SMB socket connection and SMB2 connect resolution. Risks include method send callbacks returning NULL causing silent skip, all methods sharing one status path, and immediate `localhost` conversion relying on socket helpers. Test signals include ordered fallback, method failure progression, literal IP bypass, multi-address recv, NULL event context, no registered methods, and ownership after `talloc_steal()`.

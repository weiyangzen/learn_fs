# sources/user-network-fs/samba/source4/libcli/resolve/lmhosts.c

Purpose: implements the LMHOSTS name-resolution method. Key callbacks are static `resolve_name_lmhosts_send()` and `resolve_name_lmhosts_recv()`, registered by `resolve_context_add_lmhosts_method()`. Control flow creates a composite context, calls `resolve_lmhosts_file_as_sockaddr()` for `dyn_LMHOSTSFILE`, applies the caller's port to each returned sockaddr, converts to `socket_address`, and populates parallel name strings. State is in `resolve_lmhosts_state` output arrays and the composite context. Dependencies include dynconfig, LMHOSTS parsing utilities, socket conversion, NetBIOS name types, and talloc. Integration point is the configured `lmhosts` method in resolve order, independent of NetBIOS-disabled checks. Risks include the loop incrementing by 2 while storing one entry per iteration, which is unusual and may skip records if `resolved_count` is a normal count; allocation checks also mistakenly test `state->addrs` after reallocating `state->names`. Test signals should cover one and multiple LMHOSTS entries, port override, missing file/name, memory failure paths, and verify all resolved addresses are returned without gaps.

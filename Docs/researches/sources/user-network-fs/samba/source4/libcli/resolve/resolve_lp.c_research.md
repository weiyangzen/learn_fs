# sources/user-network-fs/samba/source4/libcli/resolve/resolve_lp.c

Purpose: builds a `resolve_context` from Samba loadparm configuration. The only API is `lpcfg_resolve_context(struct loadparm_context *)`. Control flow reads `lpcfg_name_resolve_order()`, creates a context, and registers `wins`, `bcast`, `lmhosts`, or `host` methods; NetBIOS methods are skipped when `lpcfg_disable_netbios()` is true, and unknown method names are logged. State is the returned context and method-private data allocated beneath it. Dependencies include loadparm and resolver method registration APIs. Integration points include client connection setup paths that want policy-driven resolution order rather than hard-coded DNS. Risks include no hard failure on unknown methods, empty method lists yielding a context that later fails with bad network name, and loadparm-owned lifetime coupling because the context is allocated under `lp_ctx`. Test signals include each configured order permutation, NetBIOS-disabled behavior, unknown method logging, NULL method array, and successful fallback ordering in `resolve.c`.

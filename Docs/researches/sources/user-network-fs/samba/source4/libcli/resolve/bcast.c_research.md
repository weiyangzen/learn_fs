# sources/user-network-fs/samba/source4/libcli/resolve/bcast.c

Purpose: registers a broadcast NetBIOS name-resolution method. Key functions are `resolve_context_add_bcast_method()`, `resolve_context_add_bcast_method_lp()`, and static send/recv callbacks. Control flow builds an address list from IPv4 interface broadcast addresses, then calls `resolve_name_nbtlist_send()` with `broadcast=true` and `wins_lookup=false`; receive maps `NT_STATUS_IO_TIMEOUT` to `NT_STATUS_OBJECT_NAME_NOT_FOUND` to make broadcast miss semantics more useful. State is held in `resolve_bcast_data`: interface list, NBT port, and timeout. Dependencies include interface enumeration, loadparm, and the NBT list resolver. Integration point is `lpcfg_resolve_context()` when `name resolve order` includes `bcast` and NetBIOS is enabled. Risks include IPv6 interfaces being ignored, empty broadcast lists producing no useful query, and timeout-to-not-found hiding network issues. Test signals include multiple interfaces, IPv6-only hosts, disabled NetBIOS, no broadcast address, timeout mapping, and successful response selection.

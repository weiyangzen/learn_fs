# sources/user-network-fs/samba/source4/libcli/resolve/testsuite.c

Purpose: local torture tests comparing async host resolution against synchronous address interpretation. Important functions are `test_async_resolve()`, `test_sync_resolve()`, and `torture_local_resolve()`. Control flow repeatedly resolves the configured `host` for `timelimit` seconds, counts calls, and reports resolves per second. The async test uses `resolve_name_host_send/recv()`, while the sync test calls `interpret_addr2()` and `inet_ntoa()`. State is local counters, event context from torture, and configured host/timelimit. Dependencies include torture framework, tevent, resolver APIs, network utilities, and timeval helpers. Integration point is the local torture suite named `resolve`. Risks include performance-oriented tests asserting success but not validating returned address content, no explicit skip when `host` is unset, and DNS/environment dependence. Test signals are exactly this suite: async resolver can complete repeatedly under event loop, synchronous baseline remains callable, and rate output can expose blocking or child-cleanup regressions.

# sources/user-network-fs/samba/source4/libcli/smb2/lock.c

Purpose: implements SMB2 byte-range lock/unlock requests. APIs are `smb2_lock_send()`, `smb2_lock_recv()`, and `smb2_lock()`. Control flow allocates a body sized for `lock_count` lock elements, intentionally writes structure size `0x30` despite variable body length as required by protocol comments, writes lock count, sequence, handle, and each offset/length/flags/reserved tuple. Receive accepts non-error statuses, validates `0x04`, and reads reserved output. State is server byte-range lock state and per-request IO. Dependencies are SMB2 request helpers and handle push. Integration points are file locking tests and clients implementing advisory/mandatory range locks. Risks include integer overflow in `24 + lock_count*24`, unsupported/async pending lock behavior, and subtle protocol "lie about length" requirement. Test signals include lock, unlock, shared/exclusive flags, multiple ranges, conflict/pending statuses, cancellation, and huge lock_count validation.

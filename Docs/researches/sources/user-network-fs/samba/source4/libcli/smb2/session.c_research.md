# sources/user-network-fs/samba/source4/libcli/smb2/session.c

Purpose: manages SMB2 sessions and SPNEGO/GENSEC session setup, including multi-channel binding and encryption key debug output. APIs include `smb2_session_init()`, `smb2_session_channel()`, `smb2_session_setup_spnego_send/recv()`, and `smb2_session_setup_spnego()`. Control flow creates an `smbXcli_session`, starts GENSEC, exchanges tokens between `gensec_update_send()` and `smb2cli_session_setup_send()` until both sides are OK, handles reauth/channel-bind/anonymous cases, then installs session or channel keys. State includes GENSEC context, session ID in `smbXcli`, `needs_bind`, anonymous-session-key flag, forced session key, debug encryption options, and SPNEGO in-flight blobs/statuses. Dependencies include credentials, GENSEC, loadparm, tevent ntstatus helpers, and `smbXcli_base`. Integration points are SMB2 connect, encryption setup, signing, multi-channel, and Wireshark key dumps. Risks include complex dual-state token loop, anonymous server quirks around final signature verification, ownership of transport stolen into session, forced keys, and leaking key material via configured debug file. Test signals include NTLMSSP/SPNEGO, anonymous, reauth, channel binding, session setup continuation, bad final blobs, timeout, forced key, and SMB3 key derivation/debug output.

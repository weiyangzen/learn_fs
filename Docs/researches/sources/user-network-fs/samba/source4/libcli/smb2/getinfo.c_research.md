# sources/user-network-fs/samba/source4/libcli/smb2/getinfo.c

Purpose: implements generic SMB2 GETINFO plus raw-level file and filesystem wrappers. APIs are `smb2_getinfo_send/recv()`, `smb2_getinfo()`, `smb2_getinfo_map_level()`, `smb2_getinfo_file_send/recv()`, `smb2_getinfo_file()`, `smb2_getinfo_fs_send/recv()`, and `smb2_getinfo_fs()`. Control flow writes info type/class, output length, optional input buffer, additional information, flags, and handle; response pulls a dynamic blob. File/fs wrappers map Samba raw passthrough levels to SMB2 info type/class and parse blobs with raw SMB parsers. State is request-local; queried metadata remains server-side. Dependencies include SMB2 blob helpers, raw fileinfo/fsinfo parsers, and TRANS2 level conventions. Integration points include utilities, set/get attribute, stream enumeration, security descriptor reads, and compatibility with raw info unions. Risks include incorrect level mapping, output buffer sizing fixed at `0x10000`, quota/EAs requiring input flags, and returning raw blob ownership correctly. Test signals include security descriptors, all-information, alt-name, streams, filesystem size/attribute levels, invalid level mapping, large responses with credit charge, and malformed response offsets.

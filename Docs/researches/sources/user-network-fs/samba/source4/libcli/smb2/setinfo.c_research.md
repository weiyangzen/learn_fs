# sources/user-network-fs/samba/source4/libcli/smb2/setinfo.c

Purpose: implements SMB2 SETINFO and file-level raw union wrapper. APIs are `smb2_setinfo_send()`, `smb2_setinfo_recv()`, `smb2_setinfo()`, `smb2_setinfo_file_send()`, and `smb2_setinfo_file()`. Control flow writes mapped info level, pushes the data blob using length/offset order, flags, and handle; response validates a `0x02` fixed body. File wrapper maps raw levels to SMB2 info type/class, converts SMB1 rename level to SMB2 rename layout, encodes data with `smb_raw_setfileinfo_passthru()`, and sets security-info flags for security descriptor updates. State changes are server-side metadata/security/rename/delete/allocation changes. Dependencies include `getinfo.c` level mapping, raw setfileinfo passthrough encoder, SMB2 blob helpers, and raw constants. Integration points include SMB2 utilities and raw compatibility APIs. Risks include mutating `io->generic.level` for rename, unsupported passthrough levels returning NULL, security descriptor flag correctness, and blob lifetime after freeing. Test signals include basic info, disposition, allocation, EOF, rename, security descriptor, invalid level, server error, and response body validation.

# sources/user-network-fs/samba/source4/libcli/smb2/wscript_build

Purpose: Waf build definition for the `LIBCLI_SMB2` Samba subsystem. It lists source files included in the subsystem (`transport.c`, `request.c`, `session.c`, command wrappers, utilities, signing, lease break), enables autoproto generation to `smb2_proto.h`, declares private header `smb2.h`, and declares dependencies. State/persistence is build metadata consumed by Waf; it does not affect runtime directly. Dependencies include private `tevent-util`, `cli_smb_common`, `GNUTLS_HELPERS`, and public `smbclient-raw`, `gensec`, `samba-credentials`, and `tevent`. Integration point is the build graph and generated prototypes included by `smb2_calls.h`. Risks include missing a new source file from the list, stale autoproto output, wrong public/private dependency classification, and private header exposure assumptions. Test signals are configure/build success, generated `smb2_proto.h` contains expected prototypes, link tests for dependent subsystems, and packaging/install checks.

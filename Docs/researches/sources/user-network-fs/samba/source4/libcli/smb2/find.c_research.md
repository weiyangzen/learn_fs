# sources/user-network-fs/samba/source4/libcli/smb2/find.c

Purpose: implements SMB2 QUERY_DIRECTORY and optional parsing into raw search records. APIs are `smb2_find_send()`, `smb2_find_recv()`, `smb2_find()`, `smb2_find_level_recv()`, and `smb2_find_level()`. Control flow writes level, continuation flags, file index, directory handle, UTF-16 pattern, and max response size, computes credit charge, and sends. Receive validates `0x08` dynamic response and returns the raw blob. Level recv maps SMB2 find levels to raw search-data levels, iterates records using `smb_raw_search_common()`, and advances by `next_ofs`. State is per-request; directory enumeration cursor state is server-side and controlled by flags/file index. Dependencies include SMB2 blob helpers and raw search parsers. Integration points include utilities such as recursive delete and callers that need parsed directory listings. Risks include next-offset validation, unsupported info classes, memory growth per entry, and server-specific continuation behavior. Test signals include all supported find levels, empty directory, multi-entry blobs, malformed next offsets, large response credit charge, and continue/close flags.

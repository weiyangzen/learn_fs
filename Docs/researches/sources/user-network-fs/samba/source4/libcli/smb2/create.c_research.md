# sources/user-network-fs/samba/source4/libcli/smb2/create.c

Purpose: marshals and parses SMB2 CREATE requests, including create contexts. APIs are `smb2_create_send()`, `smb2_create_recv()`, and `smb2_create()`. Control flow writes core create fields, pushes the UTF-16 name, builds optional blobs for EAs, maximal access, allocation size, durable/persistent handles, timewarp, security descriptor, query-on-disk-id, leases v1/v2, app instance id, and custom blobs, then pushes the context list. Receive validates `0x58` response, extracts oplock, action, times, sizes, attributes, handle, parses returned create blobs, and fills specialized outputs for MXAC, QFID, RQLS, DHNQ, and DH2Q. State is request-local plus caller IO; server state created includes opened handles and durable/lease state. Dependencies include EA packing, NDR security descriptors, GUID conversion, SMB2 create blob helpers, lease helpers, and raw constants. Risks are complex blob layout/alignment, special empty-name/no-context dynamic-byte workaround, strict blob length checks, and handle leaks if callers do not close after partial success. Test signals include every create context, empty name, security descriptors, leases, durable reconnects, custom blobs, invalid blob lengths, and server create-action variants.

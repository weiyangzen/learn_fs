# sources/user-network-fs/samba/source4/libcli/smb2/ioctl.c

Purpose: implements SMB2 IOCTL request/response marshalling. APIs are `smb2_ioctl_send()`, `smb2_ioctl_recv()`, and `smb2_ioctl()`, plus `smb2_ioctl_is_failure()`. Control flow writes control code, handle, output and input blobs, maximum response sizes, flags, and credit charge based on max payload. Receive treats normal error statuses as failure except for documented FSCTLs that can return data with `STATUS_BUFFER_OVERFLOW` or copychunk responses, then validates `0x30` response and pulls input/output blobs. State is per-request and caller IO; actual state changes depend on FSCTL. Dependencies include SMB2 request/blob helpers and NDR IOCTL constants such as pipe, DFS, allocated ranges, and copychunk structures. Integration points include named pipe transceive, DFS referrals, server-side copy, and shadow/FSCTL style operations. Risks include nuanced status/data combinations, integer capping for credit calculation, and confusing `in.out` vs `in.in` blob naming. Test signals include success, buffer overflow with data, copychunk response with error status, generic failure, large payload credit charge, and malformed response offsets.

# sources/user-network-fs/samba/source4/libcli/smb2/signing.c

Purpose: implements legacy SMB2 signing helpers using HMAC-SHA256. APIs are `smb2_sign_message()` and `smb2_check_signature()`. Control flow skips non-SMB2/too-short buffers and session ID zero messages, requires a session key for signing, zeroes the 16-byte signature field, sets the signed flag, computes HMAC over the SMB2 header/PDU with at most the first 16 bytes of the session key, and copies/compares the first 16 digest bytes. State is only the in-place request buffer signature field and flags; key material is passed as `DATA_BLOB`. Dependencies include GnuTLS HMAC, SMB2 header offsets, constant-time compare, and GnuTLS-to-NTSTATUS mapping. Integration points are signing validation paths in older SMB2 client code; newer signing may be in lower `smbXcli` layers. Risks include SMB3 dialects using different algorithms elsewhere, mutating the received buffer during verification, allowing no-key verification to return OK, and debug dumps on bad signature. Test signals include signing with session ID, session ID zero skip, empty key, bad signature, short buffer, and exact HMAC vectors.

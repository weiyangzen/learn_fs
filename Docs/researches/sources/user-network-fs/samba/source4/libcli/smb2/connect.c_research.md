# sources/user-network-fs/samba/source4/libcli/smb2/connect.c

Purpose: provides composite SMB2 connection setup from host/share/credentials to a connected `smb2_tree`. APIs are `smb2_connect_send()`, `smb2_connect_recv()`, `smb2_connect_ext()`, and `smb2_connect()`. Control flow builds UNC and NetBIOS called/calling names, either wraps an existing SMBX connection or opens a socket via raw socket connect, negotiates SMB2 dialect, creates a session, runs SPNEGO session setup, optionally retries anonymous credentials, enables SMB3 encryption when requested, then tree-connects. State is in `smb2_connect_state`: credentials, loadparm, resolver, host/share, options, transport, session, and tree. Dependencies include tevent, raw socket connect, resolver, credentials, GENSEC settings, `smbXcli_base`, SMB2 transport/session/tree APIs, and SMB2 constants. Integration points are high-level client connection entry points and tests requiring an SMB2 tree. Risks include ownership moves between transport/session/tree, anonymous fallback changing credentials, encryption required vs desired semantics, existing-connection protocol validation, and timeout/error propagation across nested async layers. Test signals include fresh socket connect, existing connection, only-negprot mode, authentication failure with/without anonymous fallback, encryption desired/required, tree connect failure, and sync wrapper polling.

# sources/user-network-fs/samba/source4/libcli/smb2/keepalive.c

Purpose: implements SMB2 ECHO/keepalive. APIs are `smb2_keepalive_send()`, `smb2_keepalive_recv()`, and `smb2_keepalive()`. Control flow creates an `SMB2_OP_KEEPALIVE` request on a transport, optionally associates a session, writes the reserved body field, sends, and validates a `0x04` successful response. State is transport/session liveness only; no persistent protocol state is changed. Dependencies are SMB2 request and transport helpers. Integration points are idle handlers, liveness checks, and long-running clients that want to keep a connection active. Risks are low: the sync wrapper sends without a session, and failures indicate transport or server issues. Test signals include keepalive on connected transport, with session, after disconnect, timeout, and malformed response body.

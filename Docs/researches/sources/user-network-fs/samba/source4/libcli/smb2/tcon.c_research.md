# sources/user-network-fs/samba/source4/libcli/smb2/tcon.c

Purpose: initializes SMB2 tree contexts and channel tree copies. APIs are `smb2_tree_init()` and `smb2_tree_channel()`. Control flow allocates a tree, steals or references the supplied session depending on `primary`, and creates either a fresh `smbXcli_tcon` or a copy of a base tree's tcon for channels. State is local tree ownership of session and lower tcon context; no wire request is sent here. Dependencies include `smbXcli_base` and SMB2 session/tree structs. Integration points are `connect.c` after session setup, channel setup, and any caller building tree objects around existing sessions. Risks include checking `session` only after allocating tree, ownership confusion between primary and referenced sessions, and failing to copy tcon for channel paths. Test signals include primary tree frees session, non-primary tree references session, channel tcon copy, NULL session handling, and tcon allocation failure.

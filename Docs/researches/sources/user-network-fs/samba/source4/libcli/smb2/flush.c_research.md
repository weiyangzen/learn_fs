# sources/user-network-fs/samba/source4/libcli/smb2/flush.c

Purpose: implements SMB2 FLUSH. APIs are `smb2_flush_send()`, `smb2_flush_recv()`, and `smb2_flush()`. Control flow creates an `SMB2_OP_FLUSH` request with fixed body `0x18`, writes reserved fields and file handle, sends, then validates a `0x04` response and reads the reserved output. State is only per-request and the target server file handle's persisted data state. Dependencies are SMB2 request and handle helpers. Integration points are durability-sensitive write paths and tests verifying server flush semantics. Risks are straightforward: errors must be propagated and callers should not assume write persistence without successful flush; body validation is strict. Test signals include successful flush, invalid handle, flush after write, server error status, and malformed short response.

# sources/user-network-fs/samba/source4/libcli/smb2/write.c

Purpose: implements SMB2 WRITE. APIs are `smb2_write_send()`, `smb2_write_recv()`, and `smb2_write()`. Control flow creates an `SMB2_OP_WRITE` request with fixed body `0x30` and dynamic payload, pushes data as offset/length, writes file offset and handle plus two unknown 64-bit fields, sends, then validates `0x10` dynamic response and reads bytes written plus unknown response field. State changes are server file contents at explicit offset; no local file pointer is tracked. Dependencies are SMB2 request/blob helpers and handle serialization. Integration points are file upload/write loops and tests. Risks include no credit charge calculation here despite large writes, unknown fields not named semantically, partial writes requiring caller handling, and dynamic blob lifetime during send. Test signals include zero-byte write, short/partial write, large write, offset writes, invalid handle, server error, and malformed response.

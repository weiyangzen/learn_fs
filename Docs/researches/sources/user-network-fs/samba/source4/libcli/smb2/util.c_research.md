# sources/user-network-fs/samba/source4/libcli/smb2/util.c

Purpose: provides convenience SMB2 operations built from lower SMB2 and composite calls. APIs include `smb2_util_close()`, `smb2_util_unlink()`, `smb2_util_rmdir()`, `smb2_util_mkdir()`, `smb2_util_setatr()`, `smb2_util_getatr()`, `smb2_deltree()`, `smb2_util_handle_equal()`, `smb2_util_handle_empty()`, and `smb2_qpathinfo_alt_name()`. Control flow wraps common create/getinfo/setinfo/close sequences, recursively deletes directories by listing entries and removing streams, resets read-only attributes when needed, and returns basic metadata or alt names. State is mostly server-side filesystem state; local state uses temporary talloc contexts and handles. Dependencies include raw unions, SMB2 create/getinfo/setinfo/find/close, SMB composite unlink/rmdir/mkdir, security NDR types, and raw constants. Integration points are tests and higher-level client utilities. Risks include handle leaks on some `smb2_util_getatr()` error paths after create, recursive delete races, stream deletion assumptions, fixed share access choices, and attribute reset side effects. Test signals include file/dir create/delete, read-only files/dirs, streams on directories, nested deltree, get/set attributes, alt-name query, handle comparison, and failure cleanup paths.

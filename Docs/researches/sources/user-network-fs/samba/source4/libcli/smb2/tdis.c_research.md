# sources/user-network-fs/samba/source4/libcli/smb2/tdis.c

Purpose: implements SMB2 TREE_DISCONNECT. APIs are `smb2_tdis_send()`, `smb2_tdis_recv()`, and `smb2_tdis()`. Control flow creates an `SMB2_OP_TDIS` tree request with fixed body `0x04`, writes reserved field, sends, and validates a successful `0x04` response. State affected is server-side tree connection teardown; local tree object remains allocated. Dependencies are SMB2 request/transport helpers. Integration points are tree lifecycle cleanup and tests that disconnect shares without closing the whole session. Risks include callers using a tree after disconnect and no automatic invalidation of `smbXcli_tcon`. Test signals include successful disconnect, subsequent tree operation failure, disconnect with open handles, malformed response, and server error propagation.

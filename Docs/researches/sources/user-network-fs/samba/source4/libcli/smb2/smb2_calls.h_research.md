# sources/user-network-fs/samba/source4/libcli/smb2/smb2_calls.h

Purpose: declares SMB2 call-specific structures not generated elsewhere and includes generated SMB2 prototypes. Key structures are `smb2_negprot`, `smb2_getinfo`, and `smb2_setinfo`; it also notes that getinfo fs/file levels reuse raw passthrough SMB levels. State is absent except struct field contracts for caller IO. Dependencies include `libcli/raw/interfaces.h`, forward declarations for credentials, tevent, resolver, and GENSEC settings, then generated `smb2_proto.h`. Integration points are SMB2 negotiate/getinfo/setinfo implementations and all callers that include the main calls API. Risks are ABI/layout drift between these manually declared structures and implementation expectations, especially fixed body comments and raw level mapping. Test signals include compile coverage after autoproto generation, negotiate field parse/marshal tests, getinfo/setinfo wrappers, and raw level compatibility tests.

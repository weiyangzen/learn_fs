# sources/user-network-fs/samba/source4/libcli/smb2/close.c

Purpose: implements SMB2 close. APIs are `smb2_close_send()`, `smb2_close_recv()`, and `smb2_close()`. Control flow creates an `SMB2_OP_CLOSE` request with body `0x18`, writes close flags and file handle, sends it, then validates a `0x3C` response and extracts flags, timestamps, allocation size, EOF size, and attributes. State is per-request plus caller's `struct smb2_close`; no persistent state is mutated directly, although the server closes the handle. Dependencies include raw time pull helpers, SMB2 request helpers, and handle helpers. Integration points include utility close wrappers, deltree, create/open lifecycle cleanup, and tests that need post-close metadata. Risks include leaking server handles if callers ignore close failures, strict response shape, and no automatic handle invalidation in caller structures. Test signals include normal close with metadata, close of invalid handle, flags behavior, and transport error propagation.

# sources/user-network-fs/samba/source4/libcli/smb2/transport.c

Purpose: owns SMB2 transport creation, send queueing, compound submission, unsolicited break handling, connection teardown, credit asking, and idle callbacks. APIs include `smb2_transport_init()`, `smb2_transport_raw_init()`, `smb2_transport_dead()`, `smb2_transport_send()`, `smb2_transport_compound_start()`, `smb2_transport_compound_set_related()`, `smb2_transport_credits_ask_num()`, and `smb2_transport_idle_handler()`. Control flow wraps an established socket or existing SMBX connection, creates `smb2cli_req` objects from request buffers, starts a pending break subrequest when oplock/lease handlers exist, submits compounds, and maps lower-layer iov replies back into `smb2_request_buffer`. State includes `smbXcli_conn`, compound array/related flag, idle timer, oplock/lease callbacks, pending break request, and options. Dependencies include socket/raw layers, `smbXcli_base`, tevent, DLIST/talloc, and NDR headers. Risks include compound array slot handling, shared timeout/credit behavior, disconnect on break parse failure, contiguous iov assumptions, pending async status/cancel endtime handling, and lifetime of zeroed output buffers after send. Test signals include normal send/recv, pending responses, compounds related/unrelated, unsolicited oplock and lease breaks, idle timer reschedule, disconnect destructor, raw init with non-SMB2 protocol, and malformed iov/body.

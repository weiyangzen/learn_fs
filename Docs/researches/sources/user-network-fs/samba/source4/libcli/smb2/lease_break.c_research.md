# sources/user-network-fs/samba/source4/libcli/smb2/lease_break.c

Purpose: sends SMB2 lease break acknowledgements and parses responses. APIs are `smb2_lease_break_ack_send()`, `smb2_lease_break_ack_recv()`, and `smb2_lease_break_ack()`. Control flow creates an `SMB2_OP_BREAK` request with fixed body `0x24`, writes lease flags, lease key, state, and duration, sends, then validates a `0x24` response and reads returned lease fields. State is caller IO and server lease state. Dependencies include SMB2 request helpers and lease key structure definitions. Integration points include transport's unsolicited lease break handler, create leases, and clients that cache file data/metadata. Risks include exact fixed-body requirements, lease v1/v2 context differences handled elsewhere, and needing caller policy to decide downgrade state before ack. Test signals include acking read/write/handle lease changes, bad body size, invalid lease key response, server error propagation, and integration with unsolicited break callback.

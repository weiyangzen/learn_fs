# sources/user-network-fs/samba/source4/libcli/smb2/request.c

Purpose: core SMB2 request buffer construction, receive waiting, dynamic blob/string push-pull helpers, bounds checks, and handle serialization. Important APIs include `smb2_request_init()`, `smb2_request_init_tree()`, `smb2_request_receive()`, `smb2_request_destroy()`, `smb2_oob()`, `smb2_grow_buffer()`, all `smb2_push_*_blob()`/`smb2_pull_*_blob()` variants, UTF-16 string helpers, and `smb2_push_handle()`/`smb2_pull_handle()`. Control flow builds NBT-framed SMB2 headers, fixed bodies, and dynamic areas; senders append aligned dynamic blobs and receivers validate offset/length fields against body bounds. State includes request lifecycle enum, input/output buffers, status, credit charge, cancel flag, and async callback. Dependencies include raw request `request_bufinfo`, tevent event loop, SMB2 constants, talloc realloc, and charset conversion. Integration points are every SMB2 command wrapper and transport send/receive. Risks include pointer repair after realloc, dynamic padding fix semantics, strict max PDU size, offset wraparound, and callers forgetting `smb2_request_destroy()`. Test signals include every blob layout variant, null vs empty blobs, UTF-16 conversion errors, OOB fuzzing, buffer growth, event-loop receive, and handle round-trips.

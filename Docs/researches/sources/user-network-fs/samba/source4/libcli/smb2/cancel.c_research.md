# sources/user-network-fs/samba/source4/libcli/smb2/cancel.c

Purpose: cancels an outstanding SMB2 request. The only API is `NTSTATUS smb2_cancel(struct smb2_request *r)`. Control flow returns OK if there is no active tevent subrequest, otherwise calls `tevent_req_cancel()` and maps failure to `NT_STATUS_INTERNAL_ERROR`. State touched is the target request's `subreq`; protocol cancellation details are handled by the lower `smb2cli` request layer. Dependencies are tevent, SMB2 request structures, and raw headers. Integration point is long-running operations such as notify, lock, read, or any request where `smb2_request_done()` has marked `cancel.can_cancel`. Risks include cancellation being best-effort and no local state transition here, so callers still need to wait for final completion/error. Test signals include cancel before send/no subreq, cancel while pending, lower-layer cancel failure, and final status after cancellation.

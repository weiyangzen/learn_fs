# sources/user-network-fs/samba/source4/libcli/smb2/read.c

Purpose: implements SMB2 READ. APIs are `smb2_read_send()`, `smb2_read_recv()`, and `smb2_read()`. Control flow writes requested length, offset, file handle, minimum count, channel, remaining bytes, and channel descriptor fields, computes credit charge from requested length, and sends. Receive requires success, validates `0x10` dynamic response, pulls the data blob from offset/length fields, and reads remaining/reserved. State is per-request and server file position is explicit by offset, not stored locally. Dependencies are SMB2 request/blob helpers. Integration points are file data paths, tests, and higher-level read loops. Risks include large-read credit calculation, channel fields rarely used but marshalled, and caller-owned blob lifetime after request destruction. Test signals include zero-length/short reads, EOF, large reads over 64 KiB, invalid handle, malformed offset/length, and nonzero remaining.

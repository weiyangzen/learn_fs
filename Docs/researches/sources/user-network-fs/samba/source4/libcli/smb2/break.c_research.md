# sources/user-network-fs/samba/source4/libcli/smb2/break.c

Purpose: sends SMB2 oplock break acknowledgements and parses responses. APIs are `smb2_break_send()`, `smb2_break_recv()`, and `smb2_break()`. Control flow initializes an `SMB2_OP_BREAK` request with fixed body size `0x18`, writes requested oplock level, reserved fields, and file handle, then sends through `smb2_transport_send()`. Receive waits for completion, requires success, validates a `0x18` fixed body, and reads returned oplock level and handle. State is per-request and caller's `struct smb2_break`. Dependencies include SMB2 request helpers and handle push/pull functions. Integration points include transport break handling and clients acknowledging server oplock breaks. Risks are strict body-size validation rejecting nonconformant servers and no special handling of async break races beyond transport-level pending break support. Test signals include normal ack, bad body size, server error propagation, and handle round-trip.

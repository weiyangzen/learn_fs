# sources/user-network-fs/samba/source4/libcli/smb2/notify.c

Purpose: implements SMB2 CHANGE_NOTIFY. APIs are `smb2_notify_send()`, `smb2_notify_recv()`, and `smb2_notify()`. Control flow writes recursive flag, buffer size, directory handle, completion filter, and an unknown field; it asks for credits based on buffer size and temporarily sets request timeout to zero so notifications can pend indefinitely. Receive validates `0x08`, pulls the returned notification blob, counts variable-length entries, allocates `notify_changes`, and pulls UTF-16 names. State is per-request and server-side pending notify watch. Dependencies include raw string pull helpers and SMB2 blob helpers. Integration points are directory change monitoring and cancellation. Risks include timeout mutation on shared transport, parsing offset loops, memory leak of pulled blob on some early returns, and names not checked for pull failures. Test signals include pending notify, cancel, recursive/nonrecursive, multiple changes, malformed next offsets, large buffer credit charge, and timeout restoration under errors.

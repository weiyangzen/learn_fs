# sources/user-network-fs/samba/source4/libcli/smb2/logoff.c

Purpose: implements SMB2 LOGOFF. APIs are `smb2_logoff_send()`, `smb2_logoff_recv()`, and `smb2_logoff()`. Control flow creates an `SMB2_OP_LOGOFF` request on the session transport, associates the session for signing/session ID, writes reserved body field, sends, and validates a `0x04` success response. State affected is server-side session teardown; local session object is not destroyed by this wrapper. Dependencies include SMB2 request/transport helpers. Integration points are session lifecycle cleanup and tests that explicitly log off instead of disconnecting. Risks are callers retaining a local session/tree after successful server logoff, and failure handling when outstanding requests still exist. Test signals include successful logoff, subsequent request failure, logoff after tree disconnect, malformed body, and server error propagation.

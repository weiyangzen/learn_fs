# sources/user-network-fs/samba/source4/libcli/smb2/smb2.h

Purpose: private/public structural contract for the SMB2 client library. Important types are `smb2_request_buffer`, `smb2_transport`, `smb2_tree`, `smb2_session`, `smb2_request`, `smb2lsa_state`, and request state enum. It also defines `SMB2_MIN_SIZE`, `SMB2_MIN_SIZE_NO_BODY`, and `SMB2_CHECK_PACKET_RECV()`. State modeled here includes transport connection, compound request list, idle timer, oplock/lease handlers, pending break subrequest, options, session GENSEC and encryption/debug flags, tree tcon handle, and per-request buffers/status/async callback. Dependencies include raw request buffer info and raw client structures. Integration points are all SMB2 implementation files and generated prototypes. Risks include ownership complexity among transport/session/tree, TODO around removing `transport->ev`, strict body-size macro returns from caller context, and direct exposure of lower `smbXcli` handles. Test signals are broad compile and runtime tests for transport lifecycle, compound sends, unsolicited breaks, session setup, tree operations, and malformed packet validation.

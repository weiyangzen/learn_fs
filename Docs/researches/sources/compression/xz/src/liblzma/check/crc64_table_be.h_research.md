# sources/compression/xz/src/liblzma/check/crc64_table_be.h

Purpose: generated big-endian CRC64 table for the fast slice-by-four ECMA-182 implementation.

Important APIs/types/functions: defines `const uint64_t lzma_crc64_table[4][256]` using `UINT64_C()` constants. There are no functions; this header is included as a table definition.

Control flow: none at runtime. The four slices encode successive byte-folding positions for the reversed CRC64 polynomial, then are byte-swapped for big-endian processing. `crc64_fast.c` uses these slices after endian-specific word reads and shifts.

State and persistence: immutable program data. No initialization or external persistence.

Dependencies/integration: generated by `crc64_tablegen.c` with `WORDS_BIGENDIAN`; included by `crc64_fast.c` on big-endian builds. Requires `uint64_t` and `UINT64_C` declarations from included common headers.

Risks: generated constants must match both polynomial and byte order. Big-endian CRC regressions may be missed on little-endian CI, so table drift can remain latent. Including it in multiple translation units would duplicate the table definition.

Test signals: regenerate-and-diff checks, CRC64 known vectors on big-endian or emulated big-endian builds, and XZ Block CRC64 decode validation.

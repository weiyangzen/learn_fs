# sources/compression/xz/src/liblzma/check/crc_x86_clmul.h

Purpose: header-implemented x86/E2K CLMUL CRC32 and CRC64 accelerated backend, included once with `BUILDING_CRC_CLMUL` set to either `32` or `64`.

Important APIs/types/functions: defines target attribute `crc_attr_target`, mask table `vmasks`, vector helpers `my_load128()`, `keep_high_bytes()`, `shift_left()`, `shift_right()`, `fold()`, `fold_xor()`, selected `crc32_arch_optimized()` or `crc64_arch_optimized()`, and `is_arch_extension_supported()` when generic fallback exists.

Control flow: the optimized function complements CRC, handles small inputs with scalar reads and vector shifts, handles larger inputs by folding 16-byte lanes and a four-lane 64-byte loop with PCLMUL, folds remaining bytes into one 128-bit state, then uses Barrett reduction constants to extract the final CRC32 or CRC64. CPUID checks require CLMUL, SSSE3, and SSE4.1 before runtime dispatch selects this path.

State and persistence: immutable aligned `vmasks` table plus no per-call persistent state. Dispatch state is owned by the including CRC file.

Dependencies/integration: uses `<immintrin.h>`, optional `<intrin.h>` or `<cpuid.h>`, endian unaligned read helpers, and constants generated by `crc_clmul_consts_gen.c`. Included from CRC32/CRC64 fast files.

Risks: must never be included twice and must only run on CPUs with required instruction sets. The vector tail logic intentionally reads before/around the end within safe ranges; boundary errors are security-sensitive. Constants differ between CRC32 and CRC64 and cannot be mixed.

Test signals: forced CLMUL CRC32/CRC64 vectors for sizes 0 through at least 128 with every tail length, plus runtime dispatch tests on supported and unsupported CPUs.

# sources/compression/xz/src/liblzma/check/crc64_table_le.h

Purpose: generated little-endian CRC64 slice-by-four table for the fast CRC64 backend used by common XZ builds.

Important APIs/types/functions: defines `const uint64_t lzma_crc64_table[4][256]`. It is data-only and intentionally generated from `crc64_tablegen.c`.

Control flow: no active control flow. `crc64_fast.c` indexes the slices by bytes from the low 32 bits of the folded CRC/input word and combines them with shifted high CRC state.

State and persistence: read-only program data with process lifetime. It avoids runtime table initialization at the cost of about 8 KiB of data.

Dependencies/integration: generated by `crc64_tablegen.c` without `WORDS_BIGENDIAN`; included by `crc64_fast.c` when `WORDS_BIGENDIAN` is not defined. Used by public `lzma_crc64()` and therefore by Block integrity checks.

Risks: stale or manually altered constants break CRC64 compatibility across XZ files. The footprint may be inappropriate for small builds, which should choose `crc64_small.c` instead. The table must match the ECMA polynomial expected by the file format.

Test signals: CRC64 ECMA vectors, block encoder/decoder tests using default CRC64 check, and comparison between fast, small, assembly, and CLMUL implementations.

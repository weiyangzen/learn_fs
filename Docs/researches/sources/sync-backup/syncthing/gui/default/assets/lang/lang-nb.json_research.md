# sources/sync-backup/syncthing/gui/default/assets/lang/lang-nb.json

Purpose: provides Norwegian Bokmal translations for Syncthing's default AngularJS web GUI. It is a generated static locale file loaded as `assets/lang/lang-nb.json` for locale key `nb`, translating many primary GUI labels, device/folder workflows, connection text, versioning controls, security prompts, ignore-pattern operations, status messages, and theme names.

Important APIs/types/functions: the file is a JSON translation table for angular-translate. It has no executable APIs; the data contract is the object shape and the exact English source-string keys. The inspected table has 475 top-level keys and 478 flattened leaves, with a nested `theme.name` object for `black`, `dark`, `default`, and `light`. It has 19 interpolation-bearing entries and preserves all inspected variable names in values, including `{{name}}`, `{{label}}`, `{{count}}`, `{{file}}`, `{{device}}`, `{{address}}`, `{{path}}`, `{{receiveEncrypted}}`, `{{url}}`, `{{version}}`, `{{otherFolder}}`, `{{otherFolderLabel}}`, `{{syncthingInotify}}`, `{{folder}}`, and `{{folderlabel}}`.

Control flow: Syncthing's Angular app configures `$translateProvider` to load `assets/lang/lang-<locale>.json` and fall back to English. `LocaleService.autoConfigLocale()` chooses a locale from `?lang=`, saved `SYN_LANG`, or a browser preference list returned by `/rest/svc/lang`; `nb` is included in `valid-langs.js` and displayed as `Norwegian Bokmal` by `prettyprint.js`. Once `$translate.use('nb')` completes, Angular directives, filters, and instant lookups resolve text from this table while missing entries fall back to English.

State and persistence behavior: no state is stored in the JSON file. User preference persistence is external through localStorage key `SYN_LANG`, and active document state is represented by the HTML `lang=nb` attribute after load. The file is generated from Weblate and should be considered derived translation data, not a hand-maintained source of truth.

Dependencies and integration points: depends on angular-translate, the static files loader, AngularJS, `ngSanitize`, Syncthing's locale service, `valid-langs.js`, `prettyprint.js`, and `/rest/svc/lang`. It is tied to translation generation scripts: `script/translate.go` updates English source IDs and `script/weblatedl.go` downloads Weblate language files and regenerates valid language metadata.

Risks: the table is moderately incomplete with 83 missing English keys. Missing areas include folder/device group text, block indexing, several logging/login notices, listener status/failures, connection count, pause/unused status variants, some network and size-limit labels, and advanced ownership/xattr strings. Two values equal English keys (`LDAP`, `OK`), which may be intentional technical labels. Placeholder risk is low in the inspected version because there are zero placeholder mismatches, but missing keys will lead to visible English fallback in advanced screens.

Test signals: `jq` validates the file as an object. Structural checks found 475 top-level keys, 83 missing English keys, zero extra keys, no empty values, and zero placeholder mismatches. UI checks should load `?lang=nb`, verify advanced settings and log/login views for fallback, and exercise folder sharing prompts, pending-device prompts, warning dialogs, restore/delete confirmations, and receive-encrypted folder flows for interpolation and line wrapping.

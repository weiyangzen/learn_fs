# sources/cloud-native/soci-snapshotter/fs/source/source.go

Purpose: converts containerd snapshot labels into typed remote blob source metadata and annotates layer descriptors during unpack so the SOCI snapshotter can later resolve layer content, neighboring layer sizes, registry hosts, image references, and SOCI index hints.

Important APIs and flow: `GetSources` is the label-to-`[]Source` contract. `Source` carries registry hosts, parsed image reference, target descriptor, and a manifest containing the target plus neighboring layers. `FromDefaultLabels` requires containerd target reference and layer digest labels, parses optional target size, parses sibling layer digests and sizes when present, resolves registry host configuration through the supplied `RegistryHosts` callback, and returns one `Source`. `AppendDefaultLabelsHandlerWrapper` wraps an image handler, and for manifest children that are layers it adds SOCI size, SOCI index digest, and a bounded comma-separated layer-size annotation aligned to `TargetImageLayersLabel`.

State and persistence: no durable state is written. The important mutation is in-memory descriptor annotation during image unpack; those annotations become snapshot labels passed to the remote snapshotter.

Dependencies and integration: integrates with containerd image handlers, snapshotter target labels, registry host resolution, OCI descriptors/manifests, Docker registry host config, and OCI digest/reference parsing. `labels.Validate` is used to stop adding layer-size labels before label-size limits are exceeded.

Risks and test signals: missing target reference or digest labels fail source construction. Layer digest and size label length mismatches fail fast. Neighboring layer size collection can truncate for label limits, which is allowed but may reduce pre-resolution performance. The logic assumes layer-size annotations generated by the wrapper remain order-aligned with containerd layer-digest annotations.

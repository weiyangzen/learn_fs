# sources/cloud-native/moby/daemon/logger/internal/logdriver/entry.proto

Purpose: defines the compact protobuf schema for internal log entries.

Important APIs/types/functions: `LogAttr` has fields `key` and `value`; `LogEntry` has `source`, `time_nano`, `line`, `partial`, `partial_log_metadata`, and repeated `attrs`; `PartialLogEntryMetadata` has `last`, `id`, and `ordinal`.

Control flow/state/persistence: no runtime code, but the field numbers are persistent compatibility data. The local driver stores records containing this message between 4-byte size header/footer values. Plugin logging uses the same entry schema for stream transport.

Dependencies/integration: generated by gogofaster via `gen.go` into `entry.pb.go`; read by local logger marshaling and decoding.

Risks: changing field numbers or semantics can break existing local log files and plugin consumers. Adding fields is safer than renumbering or changing types.

Test signals: coverage comes from local logger round trips, protobuf decode tests through the local reader, and plugin adapter behavior.

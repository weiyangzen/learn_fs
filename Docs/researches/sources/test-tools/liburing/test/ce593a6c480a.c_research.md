# sources/test-tools/liburing/test/ce593a6c480a.c

Purpose: regression for task_work not running while userspace blocks on an eventfd read. Important APIs are `eventfd`, `io_uring_register_eventfd`, `io_uring_prep_poll_add`, pthread delayed writer, and optional SQPOLL fixed-file setup.

Control flow: register an eventfd for ring notifications, submit a poll on another eventfd, spawn a thread to write after one second, block reading the notification fd, then wait for and validate the poll CQE. State is eventfd counters and one pending poll. Risk is a hang or missing CQE if task_work is not processed while blocked.

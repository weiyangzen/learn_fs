# sources/test-tools/liburing/test/d77a67ed5f27.c

Purpose: SQPOLL wakeup regression ensuring a sleeping SQ thread handles `submit_and_wait`. Important APIs are `IORING_SETUP_SQPOLL`, `sq_thread_idle`, `io_uring_prep_nop`, `io_uring_sqe_set_data`, `io_uring_submit_and_wait`, and alarm timeout.

Control flow: create SQPOLL ring, sleep past idle, set a one-second alarm, submit/wait for a NOP, and verify CQE data is 42. State is SQ thread sleep/wakeup and CQE user data. Risks are timeout/hang, missing CQE, or data corruption.

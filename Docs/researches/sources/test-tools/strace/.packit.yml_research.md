# sources/test-tools/strace/.packit.yml

Purpose: Packit configuration for building strace RPMs from upstream commits and pull requests.

Important declarations: identifies `strace.spec`, upstream/downstream package names, SRPM build dependencies, and actions. `post-upstream-clone` runs `./bootstrap` and `./configure --disable-dependency-tracking --enable-Werror --enable-maintainer-mode`; `create-archive` runs `make dist-gzip` and lists the tarball. Jobs define COPR builds for pull requests and commits on `master` across Fedora rawhide targets except disabled aarch64.

Control flow: Packit runs action hooks at defined lifecycle points, then schedules COPR jobs.

State and persistence: creates Packit/COPR build artifacts and status checks outside the repo.

Dependencies and integration: depends on Autotools bootstrap, the spec file, Fedora build roots, and Packit service semantics.

Risks: `--enable-Werror` can make package gating sensitive to toolchain warnings. Disabled aarch64 target is a coverage gap. Archive creation assumes generated distribution state is complete. Test signals: Packit PR checks should produce successful COPR builds and a single `strace-*.tar.gz` archive.

# sources/test-tools/strace/.codecov.yml

Purpose: Codecov path normalization configuration for strace coverage uploads.

Important declarations: `fixes: - "::src/"` maps uploaded coverage paths into the `src/` directory prefix.

Control flow: no executable control flow; consumed by Codecov after GitHub Actions coverage upload.

State and persistence: affects external coverage reporting state in Codecov, not repository runtime state.

Dependencies and integration: paired with `.github/workflows/ci.yml` coverage job, which uses `codecov/codecov-action` with `working-directory: src`.

Risks: a terse global path fix can mis-map files if the upload layout changes or coverage is produced outside `src`. Test signals: inspect Codecov reports after CI and confirm source files are attributed to the intended `src/` paths.

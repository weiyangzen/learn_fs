# sources/test-tools/strace/src/linux/32/syscallent.h

Purpose: defines the main Linux generic 32-bit syscall dispatch table fragment used by strace for a 32-bit personality. The file maps syscall numbers to `struct_sysent` initializers: argument count, syscall classification flags, the decoder selected through `SEN(...)`, and the printable syscall name. It covers syscall slots 0 through 294 directly, leaves selected holes to be filled by time32 support or later common tables, reserves the 295-402 range for cross-architecture numbering alignment, and then includes the shared 32-bit and generic syscall table tails.

Important APIs/types/functions: each table row initializes `struct_sysent` from `src/sysent.h`, whose fields are `nargs`, `sys_flags`, `sen`, `sys_func`, and `sys_name`. `SEN(name)` is defined by `src/syscall.c` while including syscall tables, expanding to the syscall entry number enum and the decoder function pointer for `sys_name`. Shorthand flags such as `TD`, `TF`, `TN`, `TP`, `TS`, `TM`, `TC`, `TCL`, `PU`, `NF`, `SI`, `TSD`, and `CC` come from `src/sysent_shorthand_defs.h` and map to tracing classes or behavioral markers like descriptor, file, network, process, signal, memory, credentials, clock, pure getter, never-fails, memory-map-change, seccomp-default, and command-name-change. The file also exposes two architecture hooks: `sys_ARCH_mmap`, defaulting to `sys_mmap`, and `ARCH_WANT_SYNC_FILE_RANGE2`, which selects the printer/name pair for syscall 84.

Control flow: there is no runtime control flow inside this header; its control flow is preprocessor-driven at build time. `src/syscall.c` defines `SEN`, includes `sysent_shorthand_defs.h`, and includes this file inside the initializer for `sysent0[]` or another generated personality include. The compiler then materializes sparse designated initializers keyed by syscall number. Conditional paths choose `sync_file_range2` versus `sync_file_range`, include `../32/syscallent-time32.h` only when `HAVE_ARCH_TIME32_SYSCALLS` is enabled, and always append `syscallent-common-32.h` plus `syscallent-common.h`. Commented slots such as `io_getevents`, `pselect6`, `ppoll`, `futex`, clock syscalls, `recvmmsg`, `wait4`, `clock_adjtime`, and `io_pgetevents` document numbers intentionally filled by the time32 include when available.

State and persistence behavior: the file has no mutable runtime state and performs no persistence. Its persistent effect is the compiled `struct_sysent` array embedded in the strace binary. Flag choices affect persistent decoder metadata for the lifetime of the process, including syscall filtering groups, seccomp default tracing, `/proc/$pid/maps` cache invalidation for memory mapping changes, and `/proc/$pid/comm` cache invalidation for exec-like command changes.

Dependencies and integration points: this table depends on `struct_sysent`, the `SEN` macro, shorthand flag definitions, decoder functions named by `sys_*`, and generated syscall number integration around `src/syscall.c`, `sen.h`, and `scno` machinery. It integrates with personality-specific syscall arrays (`sysent0`, `sysent1`, `sysent2`) and with downstream syscall decode paths that select `sysent[scno]` for the current traced process. It also integrates with the generic Linux 32-bit time transition through `syscallent-time32.h` and `syscallent-common-32.h`, where legacy time32 and new time64 syscall entries are supplied. The `mmap2` entry uses `SEN(ARCH_mmap)`, allowing an architecture include to override the decoder while preserving the visible syscall name.

Risks: syscall table drift is the main risk. A wrong syscall number, argument count, decoder name, or display name causes strace to decode the wrong ABI surface. Incorrect flags degrade user-visible filtering (`-e trace=file`, `network`, `process`, etc.), seccomp filter selection, or cache invalidation after `mmap`, `munmap`, `execve`, and related calls. Conditional holes are risky because a missing `HAVE_ARCH_TIME32_SYSCALLS` configuration can leave legacy time syscalls undecoded, while an accidental duplicate initializer can silently change a slot. The generic reserved 295-402 range must stay aligned with common-table expectations, and `BASE_NR` handling in included common files must match the target architecture.

Test signals: build strace for a 32-bit Linux personality and confirm the generated syscall table compiles without duplicate or missing required initializers. Exercise representative syscall families and trace filters: file and descriptor calls (`openat`, `statx`, `ioctl`), network calls (`socket`, `sendmsg`, `accept4`), process/signal calls (`clone`, `execve`, `waitid`, `rt_sigaction`), memory calls (`mmap2`, `mprotect`, `munmap`), credentials (`setuid`, `getuid`), IPC (`msgget`, `semop`, `shmat`), and newer entries (`bpf`, `copy_file_range`, `rseq`). On configurations with time32 syscalls, verify names such as `pselect6`, `ppoll`, `futex`, and `clock_adjtime` decode through the time32 printers, and verify time64 entries from the common 32-bit include remain present at numbers 403 and above. Filtering tests should confirm each shorthand flag places the syscall in the expected trace class.

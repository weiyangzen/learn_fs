# sources/test-tools/lcov/tests/lcov/follow/follow.sh

## Purpose

`follow.sh` validates initial LCOV/geninfo capture when source paths include symbolic links. It builds two trivial C translation units under `rundir/src`, exposes the same tree through a `src2 -> src` symlink, and checks how `--follow` and `geninfo_follow_file_links=1` affect source-file identity in generated tracefiles.

## Important APIs, types, and functions

The script has no shell functions; it is a procedural test using variables and helpers from `../../common.tst`: `CC`, `COVER`, `LCOV_TOOL`, `GENINFO_TOOL`, `PARALLEL`, `PROFILE`, `KEEP_GOING`, `CLEAN_ONLY`, `LOCAL_COVERAGE`, `clean_cover`, and `cover`. It uses `gcc --coverage`-style compilation, `lcov --capture --initial`, `geninfo --initial`, `--no-external`, `--follow`, `--rc geninfo_follow_file_links=1`, `grep -c SF:`, `diff`, and `sed`.

## Control flow

After cleanup and compiler-version probing, the script skips GCC 5 and 6 because initial capture produces no data there. It creates `rundir/src`, symlinks `src2`, writes `a.c` and `b.c`, compiles `a.c` through the real path and `b.c` through the symlink, then captures initial data from `src` using `lcov` and `geninfo`. It asserts two `SF:` records and byte-identical `lcov`/`geninfo` outputs. It then captures through `src2`, verifies the tracefile is different because the symlink name is preserved, rewrites `src2` to `src` with `sed`, and expects equality. A final top-level `geninfo rundir --follow` capture must match the symlink-path capture.

## State and persistence behavior

The script creates and removes `rundir`, generated source/object/coverage files, and `.info` outputs. Its persistent test signal is only the pass/fail exit status and any optional local coverage generated by `cover`. Error handling is stateful through `KEEP_GOING`: failures either exit immediately or accumulate printed errors while continuing.

## Dependencies and integration points

It depends on a POSIX-like shell environment with Bash arrays, a C compiler with gcov coverage support, symlink support, LCOV tools, and `common.tst`. It integrates directly with LCOV path resolution and the `geninfo_follow_file_links` runtime configuration.

## Risks and test signals

The test is sensitive to GCC version behavior, filesystem symlink semantics, and exact tracefile ordering. Its strongest signals are `SF:` count equality, exact `diff` comparisons between capture modes, and the deliberate non-equality before symlink-path normalization.

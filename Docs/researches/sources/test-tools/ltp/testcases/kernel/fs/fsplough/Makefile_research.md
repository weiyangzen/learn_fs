# sources/test-tools/ltp/testcases/kernel/fs/fsplough/Makefile

## Purpose

This Makefile integrates the `fsplough` filesystem data-consistency test into the LTP build as a leaf testcase directory.

## Important APIs, Types, and Functions

It sets `top_srcdir ?= ../../../..` and includes `$(top_srcdir)/include/mk/testcases.mk` plus `$(top_srcdir)/include/mk/generic_leaf_target.mk`.

## Control Flow

There is no local target logic. The LTP make fragments discover and build the C source in the directory and install the resulting testcase binary.

## State and Persistence Behavior

The file owns no runtime state; object files and install outputs are generated by the included LTP rules.

## Dependencies and Integration Points

Depends on the LTP make framework and the local `fsplough.c` source. It is a normal testcases leaf, not a script-only directory.

## Risks and Edge Cases

Risk is limited to path correctness and compatibility with the generic leaf target. Any required compile flags must be supplied by the source or framework because this Makefile defines none.

## Test Signals

Build success for the `fsplough` binary and install discovery under the LTP testcase tree are the relevant signals.

# sources/test-tools/pynfs/showresults.py

Purpose: command-line utility for redisplaying pickled nfsv4 server tester results using the pynfs `testmod.printresults` renderer.

Important APIs and functions: `show(filename, opt)` opens a binary file, unpickles one object, and passes it with parsed options to `testmod.printresults`. `scan_options(p)` registers visibility toggles for passed, omitted, warning, and failed tests using `optparse`. `main()` validates at least one filename and calls `show` for each.

Control flow: when run from the package root, the script checks for `nfs4.1/testmod.py` under `sys.path[0]` and prepends that directory so `import testmod` resolves locally. CLI options are parsed once and applied to all files.

State and persistence: reads pickled result files only; it does not write. Runtime state is the unpickled test collection and option flags.

Dependencies and integration: depends on Python `pickle`, `optparse`, and a compatible pynfs `testmod` module. It integrates with test output files generated by nfsv4 server tester runs.

Risks: unpickling arbitrary files is code-execution unsafe and should only be used on trusted test artifacts. File descriptors are not explicitly closed. The local import path is tied to the `nfs4.1` layout. Test signals: feed a known pickled tester result and compare output under `--hidepass`, `--showomit`, and default filters.

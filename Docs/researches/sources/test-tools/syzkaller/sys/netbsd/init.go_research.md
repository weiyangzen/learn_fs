# sources/test-tools/syzkaller/sys/netbsd/init.go

Purpose: registers NetBSD target hooks for syzkaller's generated `prog.Target`. `InitTarget` installs a POSIX mmap generator and delegates call neutralization to the shared Unix neutralizer.

Important APIs/types/functions: `InitTarget(target *prog.Target)` constructs a tiny `arch` wrapper holding `*targets.UnixNeutralizer`. The only local type is `arch`, which exists to keep NetBSD-specific state open for future expansion.

Control flow: initialization is direct: create `arch`, assign `target.MakeDataMmap = targets.MakePosixMmap(target, false, false)`, and assign `target.Neutralize = arch.unix.Neutralize`.

State and persistence: no persistent state. Runtime state is limited to constants captured inside the shared Unix neutralizer.

Dependencies and integration points: integrates with `prog.Target` registration generated by sysgen and relies on `sys/targets/common.go` for POSIX mmap and Unix neutralization behavior.

Risks: NetBSD-specific hazards are not modeled here; any unsafe mknod/mmap behavior depends on the generic Unix neutralizer staying correct for NetBSD ABI details.

Test signals: `init_test.go` verifies NetBSD neutralization for `compat_50_mknod`, indirectly covering the installed neutralizer.

## Data Semantics

`raid6_gfmul[a][b]` stores `gfmul(a, b)` for every byte pair. The generator in `kernel-lib/mktables.c` computes each entry with repeated shift/XOR multiplication and reduction by polynomial constant `0x1d`:

- if the low bit of `b` is set, XOR the accumulator with `a`;
- update `a` as `(a << 1) ^ 0x1d` when the high bit overflows;
- shift `b` right until it reaches zero.

The visible rows match that layout: row `0x00` is all zeroes, row `0x01` is the identity mapping, and subsequent rows are precomputed GF products. The `aligned(256)` attribute is part of the table ABI/performance contract and matches both the generated definition and the header declaration.

## Control Flow

For any complete launch entry in this chunk, execution flow is:

1. VS Code starts the Go debug adapter with `mode: "test"` for `./cmd/bisync`.
2. The Go test binary receives the configured arguments.
3. The bisync test harness reads the selected `-case` scenario from `cmd/bisync/testdata/<case>`.
4. The harness maps `-remote` and `-remote2` to the two bisync paths under test.
5. The selected scenario drives setup, operations, assertions, and golden-output comparisons.

## Control Flow and State

`yylex()` initializes `yyin`/`yyout`, creates the initial flex buffer, runs DFA transitions through generated tables, dispatches matched actions, and returns parser tokens.

`YDVAR(nargs, var)` is the main directive action: it sets `num_args`, switches to `val` when arguments are expected, and returns a `VAR_*` token. Newlines increment `cfg_parser->line`; whitespace and comments are ignored. Double-quoted strings accumulate with `yymore()`, store `strdup(yytext)` into `yylval.str`, decrement `num_args`, and return `STRING_ARG`.

Include state is stored in `struct inc_state`, preserving filename, line, flex buffer, and top-level include mode. Glob includes optionally expand wildcard paths and push matches in reverse order for sorted processing.

## Risks and Edge Cases

- The scanner is non-reentrant; global flex state, `cfg_parser`, `yylval`, and include state make concurrent parses unsafe.
- Include depth limit is 100000, high enough for resource exhaustion before failure.
- Chroot stripping is prefix-based and does not verify a path boundary.
- Glob no-match silently includes nothing.
- Partial include-stack changes can occur if some glob matches open and later ones fail.
- `config_end_include()` decrements `inc_depth` before checking for an empty include stack.
- `strdup()` failure in string handling reports an error but still returns `STRING_ARG` with possibly null `yylval.str`.
- Newline inside a quoted string returns to `INITIAL`, which can make the rest of the directive parse as top-level input.

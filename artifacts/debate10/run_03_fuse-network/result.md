# learn_fs Source Repository Candidates

Generated by Agent 03 on 2026-06-15. Scope emphasis: userspace file
systems, FUSE, NFS/SMB/network filesystem protocols, Samba, NFS-Ganesha,
libfuse, sshfs, curlftpfs, go-fuse, and adjacent distributed filesystems.

## Boundary

This is a source-only research design. The repository should collect readable
upstream source, not release binaries, VM images, container images, package
caches, or benchmark datasets.

Target source volume: 20M-200M lines.

Recommended counting policy:

- Count checked-in source, tests, build scripts, protocol IDL, and examples.
- Exclude `.git`, binary fixtures, generated build outputs, vendored package
  caches, release tarballs, object files, container layers, and downloaded test
  datasets.
- For large projects with submodules, count the main repo first, then count
  submodules separately and record them explicitly.

Practical target shape:

- Minimal must-have set with Linux kernel, Samba, Ceph, GlusterFS, Lustre,
  NFS-Ganesha, nfs-utils, libfuse, sshfs, go-fuse, s3fs-fuse, cifs-utils,
  and a few compact protocol libraries: roughly 35M-55M source lines.
- Strong expansion with FreeBSD, illumos, rclone, GCSFuse, blobfuse2,
  SeaweedFS, JuiceFS, mergerfs, gocryptfs, impacket, libsmb2, and ksmbd-tools:
  roughly 55M-90M source lines.
- Upper expansion with all optional DFS/protocol variants and selected
  submodules/dependencies remains comfortably below 200M if binary/test-data
  exclusions are enforced.

## Omission Risks

- FUSE language bindings are broad. This proposal includes C and Go first.
  Python/Rust bindings such as pyfuse3, llfuse, fuse-rs, and bazil/fuse can be
  added if the research turns toward API design across languages.
- macFUSE and WinFsp are intentionally outside the first Linux/UNIX-centered
  set. Add them if cross-platform userspace filesystem ABI design becomes a
  goal.
- Object-store mounted filesystems change quickly. s3fs-fuse, rclone, gcsfuse,
  blobfuse2, and goofys cover the core designs, but S3/GCS/Azure SDK internals
  are not part of this source boundary unless explicitly pulled as dependency
  source.
- Samba is large and includes generated/IDL/test material. Do not compare its
  LOC one-to-one with compact SMB libraries unless the counting policy is
  identical.
- Ceph, Lustre, GlusterFS, and SeaweedFS contain tests, scripts, protocol
  bindings, and sometimes vendored or generated code. Record exclusions in
  `inventories/loc/`.
- nfs-utils, libtirpc, rpcbind, Kerberos/GSSAPI, and ID mapping cross package
  boundaries. The first pass includes nfs-utils and marks libtirpc/rpcbind for
  recheck; Kerberos implementations are dependency source, not file-system
  source, unless security protocol internals become in scope.
- Linux, FreeBSD, and illumos can dominate LOC. Keep them because they are VFS
  and protocol ground truth, but report totals both with and without OS roots.
- Several historical projects, especially curlftpfs and goofys, may be less
  active than current provider-backed mounts. They are still useful for source
  reading, but should not be treated as current best practice without commit
  and issue review.

## Verification Method

Use `Docs/source_fetch_manifest.tsv` as the canonical first-pass manifest.

Remote existence check:

```bash
while IFS=$'\t' read -r path category priority repo status loc reason; do
  case "$path" in path) continue ;; esac
  case "$repo" in
    https://sourceforge.net/*)
      curl -L -I "$repo" | sed -n '1p'
      ;;
    *)
      git ls-remote --heads --symref "$repo" HEAD >/dev/null &&
        printf 'OK\t%s\t%s\n' "$path" "$repo" ||
        printf 'FAIL\t%s\t%s\n' "$path" "$repo"
      ;;
  esac
done < Docs/source_fetch_manifest.tsv
```

Sparse/partial checkout pattern for very large repos:

```bash
mkdir -p sources/00-os-kernel sources/10-fuse-userspace sources/20-network-protocols sources/30-distributed-fs
git clone --filter=blob:none https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git sources/00-os-kernel/linux
git clone --filter=blob:none https://github.com/ceph/ceph.git sources/30-distributed-fs/ceph
```

Line-count verification, preferred:

```bash
brew install cloc
repo=sources/10-fuse-userspace/libfuse
git -C "$repo" rev-parse HEAD
cloc --vcs=git "$repo" --exclude-dir=.git --json --out "inventories/loc/$(basename "$repo").cloc.json"
```

Line-count verification, fallback without `cloc`:

```bash
repo=sources/10-fuse-userspace/libfuse
git -C "$repo" ls-files -z |
  xargs -0 wc -l |
  tail -n 1
```

Recommended inventory fields per checkout:

```text
path
repo_url
resolved_remote_url
default_branch
commit_sha
tag_or_branch
submodules_included
cloc_total_code
cloc_total_comment
cloc_total_blank
excluded_paths
license_summary
verification_date
```
